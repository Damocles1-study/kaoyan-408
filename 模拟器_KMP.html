KMP 步进器

next / nextval 逐步手算复盘 · 匹配过程单步回放（比较次数自动计数）· 手算自测 —— 对应王道第 4 章唯一考点：字符串模式匹配

① next / nextval 是怎么一格一格填出来的

真题/课后题预设：
点「下一步」看 get_next 每一步在做什么，或「一次到底」直接出结果。
两种手算法，考场上互相验算：
Ⅰ. PM 右移法（快）：先写部分匹配值表 PM[j]＝前 j 个字符的最长相等真前后缀长度；再把整张表右移一位、首位补 0，即得 next（位序从 1）。等价公式 next[j]=PM[j−1]+1。
Ⅱ. 递推法（稳，就是上面动画演示的）：令 k=next[j−1]，比较 pj−1 与 pk：相等则 next[j]=k+1；不等则 k←next[k] 继续退，退到 0 就填 1。
nextval：先有 next，再逐位修正——若 pj 与 pnext[j] 相同，则 nextval[j]=nextval[next[j]]（连锁塌陷）；否则 nextval[j]=next[j]。
自查三条硬约束：① next[1]=0、next[2]=1 恒成立；② next[j+1] ≤ next[j]+1（每次最多涨 1，跳涨必错）；③ 位序从 0 时整张表整体减 1（next[0]=−1），答案的相对关系不变。

② 匹配过程单步回放 —— 比较次数就是这么数出来的

真题预设：
点「下一步」逐次比较；每比较一次计数 +1，失配时看 j 退到哪里。
数比较次数的四条规矩（真题就靠这个给分）：① 只有真正执行了 S[i] 与 T[j] 的那一次算 1 次；② 失配的那一次也要算； ③ 失配后 i 不动、j←next[j]，接着在同一个 i 上比，算新的一次；④ j 退到 0（位序从 0 时为 −1）时走的是"i、j 同时加 1"分支，不产生比较，别多数。

③ 手算自测：先自己填，再判分

随机串默认用 2–3 种字符、长度 6–10——真题里的模式串就是这个规模（2015 abaabc、2019 abaabc、2024 aabaab）。填错的位置会标红并给出该位的推导过程。
