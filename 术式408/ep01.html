数循环、解递推：把「感觉是 n²」换成能写上卷面的推导
数据结构约 13 分钟
先答旧题
这是第一话，没有旧题。
从下一话开始，每话开头都先回答上一话的问题。答不出就翻回去看一眼，这比重读有用得多。

这一话是整本书的工具：看到代码，能写出它运行次数的式子，而不是靠「感觉」。

其之壹先把几个词讲明白

数据结构说的是三件事：逻辑结构（元素之间什么关系：线性、树、图、集合）、存储结构（在内存里怎么放：顺序、链式、索引、散列）、运算（能对它做什么）。

咒灵
逻辑结构和存储结构不能混

「有序表」是逻辑结构（只说顺序关系，和存储无关）；「循环队列」是存储结构（它规定了用数组加取模）。判断方法：把「用什么存」这个信息去掉，这个词还有意义吗？还有意义就是逻辑结构。

算法要满足五个特性：有穷性（有限步结束）、确定性（同样输入同样输出）、可行性、输入、输出。好算法追求四件事：正确、可读、健壮、高效。注意 算法可以有零个输入，但至少要有一个输出。

其之貳时间复杂度：只做一件事

时间复杂度描述运行次数随 n 增长的趋势。做法：找到执行次数最多的那条语句（基本操作），写出它的执行次数 T(n)，取最高阶项，扔掉系数。

术式
复杂度由小到大

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)

循环分三种写法：

① 循环变量线性变化：直接求和

两层循环 for(i=1;i<=n;i++) for(j=1;j<=i;j++) x++;，内层执行 i 次，所以 T(n) = 1+2+…+n = n(n+1)/2，是 O(n²)。

② 循环变量按倍数变化：设次数为 t

for(i=1;i<=n;i*=2) x++;。设循环跑了 t 次，第 t 次时 i = 2t，由 2t ≤ n 解出 t ≤ log₂n，所以是 O(log n)。

③ 条件里藏着平方：把条件翻译成 t

while(i*i<=n) i++; 跑 t 次之后 i = t，由 t² ≤ n 解出 t ≤ √n，所以是 O(√n)。

术式
循环题万能三步
  1. 设基本语句执行了 t 次。
  2. 写出第 t 次时循环变量的值（用 t 表示）。
  3. 代入循环条件，解出 t 和 n 的关系。
这段代码是多少？for(i=1;i<=n;i*=2) for(j=1;j<=i;j++) x++;

外层 i 取 1, 2, 4, …, 2k（2k ≤ n）。内层次数等于 i，所以总次数是等比数列求和：1+2+4+…+2^k = 2^(k+1) − 1 ≈ 2n。答案 O(n)，不是 O(n log n)。 这是一个经典坑：外层 log n 次、内层最多 n 次，直接相乘只是上界，不是紧界。内层次数随外层变化时，必须老老实实求和。

④ 递归：写递推式

递归函数看两个东西：一共调用多少层，每层干多少活。

术式
递归的三个标准式

T(n)=T(n−1)+O(1) ⟹ O(n)（阶乘）
T(n)=2T(n/2)+O(n) ⟹ O(n log n)（归并、快排最好）
T(n)=2T(n−1)+O(1) ⟹ O(2ⁿ)（汉诺塔、未优化斐波那契）

其之參空间复杂度：算额外开的那部分

只算算法额外用到的内存，输入数据本身不算。常见只有三档：

  • 几个临时变量：O(1)，叫原地算法。
  • 开一个和输入等长的辅助数组：O(n)。
  • 递归：递归深度就是空间。层数为 n 则 O(n)，层数为 log n 则 O(log n)。
咒灵
递归不是不占空间

递归调用的每一层都要压栈（第 20 话会看到栈帧真实的样子）。所以快排虽然没有开数组，空间却是 O(log n)，最坏 O(n)。

其之肆最好、最坏、平均

同一算法在不同输入上差别可以很大。没有特殊说明时，O() 指最坏情况。平均复杂度要算期望，比如顺序查找平均比较 (n+1)/2 次，但阶还是 O(n)。

不想推式子时

代入 n=4、n=8 手算次数，看 n 翻倍时次数翻几倍：翻 2 倍是 O(n)，翻 4 倍是 O(n²)，只多一点点是 O(log n)。

设 t，写循环变量，代入条件解 t。内层次数随外层变，相乘只是上界。时间写递推式，空间看递归深度。

领域展开

一句话：设 t，写循环变量，代入条件。
内外层相关时要求和，不能相乘。

2014實戰复杂度·嵌套与求和
下列程序段的时间复杂度是（　）。
count=0;
for(k=1;k<=n;k*=2)
    for(j=1;j<=n;j++)
        count++;

外层 k*=2 执行 log2n 次，内层执行 n 次，总 =n·(log2n+1)=O(nlog2n)。
外层 k 每次 ×2，跑 log₂n 次；内层上限写死是 n，和 k 无关，所以这里才可以直接相乘，得 O(n log n)。和刚才那道「内层等于 i」的题对比着记。
再深一层
外 log 层 × 内 n = n log n，选 C。
2019實戰复杂度·开方型
设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（　）。
x=0;
while(n>=(x+1)*(x+1))
    x=x+1;

设第 k 次循环终止，则 (x+1)2＞n 时停，x 从 0 增，k²＞n 即 k＞√n，故 O(n1/2)。
条件 n>=(x+1)*(x+1) 翻译过来就是 x+1 ≤ √n，属于第③种。
再深一层
x 加到 x²≈n 停，x≈√n，选 B。与上一题同宗（都是 √n）。
2012實戰复杂度·递归
求整数 n（n≥0）的阶乘的算法如下，其时间复杂度是（　）。
int fact(int n){
    if(n<=1) return 1;
    return n*fact(n-1);
}

递归每次 n−1，共递归 n 层，每层单语句，总次数 =1+1+…+1=n，故 O(n)。
每次递归只调用自己一次，n 层，每层 O(1)，所以 O(n)。
再深一层
线性递归、深度 n，选 B。对比上一题：那是 /2（log），这是 −1（n）。
2017實戰复杂度·累加型(√n)
下列函数的时间复杂度是（　）。
int func(int n){
    int i=0, sum=0;
    while(sum<n)
        sum += ++i;
    return i;
}

sum=1+2+…+i=(1+i)·i/2，循环到 sum≥n，即 i²/2≈n，i≈√(2n)，故循环次数 t 满足 (1+t)t/2＜n，T(n)=O(n1/2)。
sum += ++i：第 t 轮时 sum = 1+2+…+t ≈ t²/2，代入 sum<n 得 t ≈ √(2n)，即 O(n1/2)。同样是第③种模子。
再深一层
sum 是 1+2+…+i≈i²/2，追到 n 需 i≈√n，选 B。
做完再翻：这些题到底在问什么

这一类题只有一个做法：设 t，写循环变量，代入条件。选项里的 log 和根号，都是条件翻译出来的。
