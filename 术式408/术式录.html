第03话链表

术式
单链表四个基本动作

后插：s->next = p->next; p->next = s;
删除 p 的后继：q = p->next; p->next = q->next; free(q);
前插（不知道前驱）：先后插，再交换 p 和 s 的 data。
删除 p 本身（不知道前驱）：把后继的 data 拷过来，删掉后继。尾结点不能这样做。

术式
双链表的两个动作（在 p 后插入 s；删除 p 的后继 q）

插入改 4 个指针：
s->next = p->next;
if (p->next) p->next->prior = s;
s->prior = p;
p->next = s;
删除只需要改 2 个指针：
p->next = q->next;
if (q->next) q->next->prior = p;

术式
链表四个模子

倒数第 k / 中点 → 快慢指针
两表交点 → 长度差对齐
去重 / 找重复且值域有限 → 标记数组
要改顺序且空间 O(1) → 找中点 + 逆置 + 插入

第04话栈与队列

术式
卡特兰数与判合法

n 个不同元素的合法出栈序列数：C(2n,n) / (n+1)，n=3 时 5，n=4 时 14，n=5 时 42。
判合法：对每个已出栈元素，在它之后出栈且比它先入栈的元素，必须按入栈的逆序出现。

术式
循环队列（rear 指向队尾下一位）

队空：front == rear
队满：(rear+1) % M == front
长度：(rear − front + M) % M
入队：rear = (rear+1) % M；出队：front = (front+1) % M
区分满和空的另外两种方法：加 size 计数，或者加 tag 记录最后一次操作是入还是出。

术式
中缀转后缀

从左到右扫描：
操作数 → 直接输出。
左括号 → 入栈。
右括号 → 一直弹栈并输出，直到弹出左括号（括号都不输出）。
运算符 → 把栈里优先级高于或等于它的运算符都弹出输出（遇到左括号停），再把自己压栈。
扫描完 → 栈内全部弹出。

术式
后缀表达式求值

从左到右扫：操作数入栈；遇到运算符弹出两个，先弹出的是右操作数，次栈顶 op 栈顶，结果压回。

第06话二叉树与遍历

术式
树的两个恒等式

边数：总结点数 = 总度数 + 1，也就是 n = 边 + 1。
度为 m 的树：n = n₀+n₁+…+n_m，同时 n = 1·n₁+2·n₂+…+m·n_m + 1。两式相减就能解出叶子数 n₀ = 1 + n₂ + 2n₃ + … + (m−1)n_m。
k 叉树第 i 层最多 k^(i−1) 个结点；高为 h 最多 (k^h−1)/(k−1) 个。

术式
五条性质

① 叶子比度 2 的多一个：n₀ = n₂ + 1。
② 第 i 层最多 2^(i−1) 个结点，高 h 最多 2^h − 1 个。
③ 完全二叉树高度：h = ⌈log₂(n+1)⌉ = ⌊log₂n⌋ + 1。
④ 编号：i 的左孩子 2i，右孩子 2i+1，父亲 ⌊i/2⌋，所在层 ⌊log₂i⌋+1。
⑤ 完全二叉树的叶子：n₀ = ⌈n/2⌉，最后一个分支结点编号 ⌊n/2⌋；n 为偶数时有且只有 1 个度为 1 的结点，奇数时没有。

术式
能唯一确定二叉树的组合

中序 + 先序 / 后序 / 层序 都可以。先序 + 后序不行。
方法：先序（或后序）找根，中序切左右子树，递归。

术式
树类代码题三个模子

求全局量（高度、结点数、WPL）：return f(左)+f(右)+…。
要知道层数（宽度、路径）：参数 depth 往下传。
判定（是否 BST、是否平衡）：全局 flag 或返回值带回，中序递增判 BST。

第07话线索、森林、哈夫曼与并查集

术式
怎么做线索题
  1. 把这棵树的遍历序列写出来（题目问哪种就写哪种）。
  2. 只看空指针：左空指向序列中的前一个，右空指向序列中的后一个。
  3. 序列的第一个没有前驱、最后一个没有后继，线索为 NULL。
术式
森林 / 树 / 二叉树的遍历对应
树森林二叉树
先根先序先序
后根中序中序

只有这两组，没有后序的对应。

术式
数量对应

森林的叶子数 = 对应二叉树中「左指针为空」的结点数（没孩子 ⟺ 没长子）。
二叉树中右指针为空的结点数 = 非终端结点数 + 1（每个有孩子的家长，其最小孩子没有弟弟；再加上最后一棵树的根）。

术式
哈夫曼三条
  1. n 个叶子，总共 2n−1 个结点，没有度为 1 的结点（因为每次合并新增 1 个，合并 n−1 次）。
  2. 权越小离根越远；最小的两个一定是兄弟。
  3. 不唯一（左右可换、权相等时选法不同），但 WPL 唯一。

m 叉哈夫曼树：要补 0 权虚结点让 (n−1) % (m−1) == 0，否则根不满。

术式
并查集的复杂度

无优化：Find 最坏 O(n)。按大小合并：树高不超过 ⌊log₂n⌋+1，Find O(log n)。再加路径压缩：几乎 O(1)（α(n)）。

第08话二叉搜索树、AVL 与红黑树

术式
BST 三个操作

查找：比根小往左，比根大往右。平均 O(log n)，最坏（退化成链）O(n)。
插入：查找失败的那个位置就是插入位置，新结点必定是叶子。
删除：叶子直接删；只有一棵子树的让子树顶替；有两棵子树的，用中序后继（右子树最左）或中序前驱的值替换，再删那个结点。

术式
高度为 h 的 AVL 最少结点数

N(h) = N(h−1) + N(h−2) + 1，N(0)=0，N(1)=1。
序列：1, 2, 4, 7, 12, 20, 33, 54……
n 个结点的 AVL 高度是 O(log n)，查找也是 O(log n)。

术式
红黑树五条性质
  1. 每个结点非红即黑。
  2. 根是黑的。
  3. 叶（NIL 空结点）是黑的。
  4. 红结点的孩子必须是黑的（不能连续两个红）。
  5. 任一结点到其所有后代 NIL 的路径上，黑结点数相同（称为黑高 bh）。
术式
红黑树的结论

① 最长路径 ≤ 2 × 最短路径（最短全黑，最长红黑相间）。
② n 个内部结点的树高 h ≤ 2log₂(n+1)。
③ 黑高为 bh 的子树至少有 2^bh − 1 个内部结点。
④ 根黑高为 k 时，内部结点数最少 2^k − 1（全黑满二叉树），最多 2^(2k) − 1（红黑相间的满二叉树）。
⑤ 新插入的结点染红（染黑会破坏性质 5，染红只可能破坏性质 4，好修）。
⑥ 删除或插入的调整都是 O(log n)，旋转次数至多常数次。

第09话图的存储与遍历

术式
边数的临界值

n 个顶点连通，最少 n−1 条边。
有向图强连通，最少 n 条边（一个环）。
保证任何情况都连通，最少 C(n−1, 2) + 1 条边：先让 n−1 个点互相连满，再连上最后一个点。
n 个顶点、边数 > n−1，一定有环（无向图）。

术式
邻接矩阵的 m 次方

Aᵐ[i][j] = 从 i 到 j 长度为 m 的路径条数。

术式
四种存储对比
存储适用空间判断 i-j 有边求度
邻接矩阵稠密、有向无向O(n²)O(1)O(n)
邻接表稀疏、有向无向O(n+e)（有向）O(度)出度 O(度)、入度 O(e)
十字链表有向O(n+e)O(度)好求
多重表无向O(n+e)O(度)好求
术式
遍历的复杂度（只看存储方式）

邻接矩阵：O(n²)。邻接表：O(n+e)。BFS 和 DFS 都一样。
空间都是 O(n)（队列或递归栈）。

术式
遍历能回答的问题

连通分量数 = 主循环里调用 BFS/DFS 的次数。
BFS 求无权图单源最短路径（边数最少）。
判断有向图有环：DFS 时遇到「还在递归栈里」的顶点；或拓扑排序失败。
DFS 退出顺序的逆序 = 拓扑序。

第10话最小生成树与最短路径

术式
两个算法对比
算法思路时间适合
Prim从一个点长大，每次选跨越的最小边O(n²)（矩阵）稠密图
Kruskal所有边排序，能选就选，用并查集判环O(e log e)稀疏图
术式
MST 的性质

代价唯一，树可能不唯一。
所有边权不同 ⟹ MST 唯一（反过来不成立）。
Prim 从不同点开始，选边次序不同，但代价相同。
最小的边不一定在所有 MST 中（若有并列最小边且成环）；但严格唯一最小的那条边一定在每棵 MST 中。

术式
Dijkstra 手算表头

每一轮写一行：S 集合 | dist[每个顶点] | path[每个顶点]。

  1. 未确定的顶点中选 dist 最小的 u，放入 S。
  2. 用 u 更新：若 dist[u]+w(u,v) < dist[v]，更新 dist[v]，path[v]=u。

时间 O(n²)。不能处理负权。

第11话拓扑排序与关键路径

术式
拓扑排序三句话

算法：不断删入度为 0 的顶点，用栈或队列暂存。
判环：输出顶点数 < n ⟹ 有环。
时间：邻接表 O(n+e)，邻接矩阵 O(n²)。
唯一性：每一轮入度为 0 的顶点恰好一个 ⟺ 拓扑序列唯一。

术式
四个量的算法（照表填）

ve(事件最早)：从前往后，ve[k] = max(ve[j] + w(j,k))。
vl(事件最迟)：从后往前，vl[k] = min(vl[j] − w(k,j))。汇点 vl = ve。
e(活动最早)：e = ve[起点]。
l(活动最迟)：l = vl[终点] − 权。
关键活动：l − e = 0。

第12话顺序、折半、分块与散列

术式
顺序查找

成功 ASL = (n+1)/2。失败（无序、有哨兵）= n+1。
有序顺序表的失败 ASL 可以提前结束，= n/2 + n/(n+1)。

术式
判定树三条

高度 h = ⌈log₂(n+1)⌉ = 最多比较次数（成功或失败都不超过 h）。
逐结点判据：mid 向下取整时，每个结点 右子树结点数 − 左子树结点数 ∈ {0, 1}；向上取整时反过来。整棵树要始终如一。
中序遍历有序（它也是 BST）。失败结点有 n+1 个，都在外部。

术式
分块 ASL

长度 n 分 b 块、每块 s 个：
索引和块内都顺序查：ASL = (b+1)/2 + (s+1)/2，当 s = √n 时最小，为 √n + 1。
索引用折半：ASL = ⌈log₂(b+1)⌉ + (s+1)/2。

术式
常用构造与冲突处理

散列函数：除留余数法 H(k)=k%p（p 取不大于表长的最大质数，这样余数分布均匀）；直接定址、数字分析、平方取中。
开放定址法：Hᵢ = (H(k)+dᵢ) % m。线性探测 dᵢ=1,2,3…；平方探测 dᵢ=1²,−1²,2²,−2²…；双散列 dᵢ=i·H₂(k)。
拉链法：同一个地址的放一条链表。
装填因子 α = n / m。ASL 只依赖 α，不直接依赖 n。

术式
手算 ASL

成功：每个关键字比较次数之和 ÷ 关键字数。
失败：对散列函数的每个可能取值（注意是 mod p 的 p 个，不是表长 m），一直走到空位，比较次数算上这次碰到空位的比较 ÷ p。

第13话B 树与 B⁺ 树

术式
m 阶 B 树（4 条关键规则）

孩子数上限：每个结点至多 m 棵子树，至多 m−1 个关键字。
孩子数下限：根至少 2 棵（除非它就是叶子，关键字至少 1 个）；其他非叶结点至少 ⌈m/2⌉ 棵子树，⌈m/2⌉−1 个关键字。
平衡：所有叶子在同一层（叶结点下面的「失败结点」不含信息）。
n 个关键字的失败结点数 = n+1。

关键字数与高度（从第 1 层算到最后一层有关键字的层）

高度 h 的 B 树关键字数最多 mʰ − 1。
最少：第 1 层 1 个关键字；第 2 层 2 个结点；第 3 层 2⌈m/2⌉ 个结点……除根外每个结点 ⌈m/2⌉−1 个关键字。合起来 n_min = 2⌈m/2⌉^(h−1) − 1。

第14话插入与交换排序

术式
比较排序的下界

基于比较的排序，最坏至少要 ⌈log₂(n!)⌉ 次比较，也就是 Ω(n log n)。

术式
直接插入与折半插入

直接插入：最好 O(n)（已有序），最坏 O(n²)，稳定，O(1) 空间。适合基本有序或 n 小。
一趟特征：前 k 个有序，但不一定是最终位置。
折半插入：比较次数减少到 O(n log n)，但移动次数不变，总时间仍 O(n²)，稳定。

术式
希尔排序

时间约 O(n^1.3)，最坏 O(n²)。不稳定（相同元素可能分到不同组）。只能用顺序存储，因为要按增量随机访问。
判增量：看相距 d 的元素是否各自有序。

术式
冒泡

最好 O(n)，最坏 O(n²)，稳定，O(1) 空间。
一趟特征：末尾（或开头）增加一个最终位置的元素。

术式
快排

平均 O(n log n)，最坏 O(n²)（已有序或逆序），空间 O(log n)（递归栈），不稳定。
枢轴越接近中位数越好，递归树矮；已有序时每次只去掉一个，退化成冒泡。
平均性能是内部排序中最好的。要用顺序存储（随机存取）。
第 k 小：只递归一边，平均 O(n)。
第二趟结果：第一趟后至少 1 个元素到位；第二趟后至少 3 个（枢轴在中间时），若第一趟枢轴在端点，则至少 2 个。

第15话选择、归并、基数、外排与总表

术式
堆的几个结论

建堆：从 ⌊n/2⌋ 向前下沉，时间 O(n)（书上界 4n，比较次数实际约 1.88n）。
下沉：比较两个孩子 1 次，较大孩子和父亲 1 次，所以每层最多 2 次比较。
插入：放到末尾向上调，每层 1 次比较。
删除：末尾补到堆顶，向下调。
堆排序：最好最坏都是 O(n log n)，O(1) 空间，不稳定。
应用：取前 k 大（维护大小为 k 的小根堆）；优先队列。

术式
归并

时间永远 O(n log n)，空间 O(n)，稳定。趟数 ⌈log₂n⌉。m 路归并趟数 ⌈log_m n⌉。
两个长 m、n 的有序表合并：最少比较 min(m,n) 次，最多 m+n−1 次。

术式
基数排序

d 位、r 进制：时间 O(d(n+r))，空间 O(r)，稳定。
用的是链式队列，每趟 r 个队列。
移动次数与初始序列无关。

术式

第16话计算机系统与性能公式

术式
冯·诺依曼的要点
  1. 五大部件组成。
  2. 指令和数据同等地位，都放在存储器，按地址访问。
  3. 指令和数据都用二进制表示。
  4. 指令由操作码和地址码组成。
  5. 指令在存储器顺序存放，靠 PC 自动 +1 顺序执行（也可改变）。
  6. 以运算器为中心（现代多以存储器为中心）。
术式
六个寄存器（后面每一章都要用）

PC 程序计数器：下一条指令地址。程序员可见。
IR 指令寄存器：当前指令。不可见。
MAR 主存地址寄存器：位数对应地址线。不可见。
MDR 主存数据寄存器：位数对应存储字长。不可见。
GPR 通用寄存器；PSW 程序状态字（含标志位）。

术式
CPU 执行时间

CPU 时间 = 指令条数 × CPI × 时钟周期
= 指令条数 × CPI / 主频
MIPS = 主频 / (CPI × 10⁶)
平均 CPI = Σ (各类比例 × 各类 CPI)

术式
指标的单位

主频（Hz）= 1 / 时钟周期。1 GHz → 1 ns。
CPI：每条指令的平均时钟周期数。
MIPS：每秒百万条指令。MFLOPS：每秒百万次浮点运算（GFLOPS、TFLOPS、PFLOPS、EFLOPS、ZFLOPS 依次 ×1000）。

第17话定点数：补码与运算电路

术式
补码三招

负数求补码：绝对值的二进制「取反 +1」。或者从右往左，第一个 1 及其右边不变，左边全部取反。
求 −x：不管 x 正负，连符号位一起「取反 +1」。
真值：−b₇·2⁷ + b₆·2⁶ + … + b₀。最高位是负权，这是最本质的定义。

术式
边界值（必背）

n 位补码：最小 −2^(n−1)（1000…0），最大 2^(n−1)−1（0111…1），−1 是全 1。
n 位无符号：最大 2ⁿ−1（全 1）。
8 位 −128 的机器数 80H；16 位 −32768 的机器数 8000H；32 位 8000 0000H。

术式
转换三条规则

① 同宽度：位不变，解释变。无符号 = 补码 + 2ⁿ（补码为负时）。
② 长→短：截断高位。
③ 短→长：看原类型，无符号补 0（零扩展），有符号补符号位（符号扩展）。
混合运算：int 和 unsigned 运算时，int 转成 unsigned。

术式
四个标志位

ZF 结果全 0。SF 结果最高位（看作有符号时的符号）。
OF 有符号溢出：OF = C_n ⊕ C_(n−1)（最高位进位 ⊕ 次高位进位）。等价：两个同号数相加，结果符号相反。
CF 无符号的进位/借位：CF = C_out ⊕ Sub。加法时 CF=C_out，减法时取反。

术式
比较后的条件（指令系统的条件转移就是它）
比较无符号有符号
X = YZF=1ZF=1
X > YCF=0 且 ZF=0SF=OF 且 ZF=0
X < YCF=1SF≠OF
术式
三种移位

逻辑移位（无符号）：左右都补 0。
算术右移（有符号）：高位补符号位，相当于 ÷2 向下取整。
算术左移：低位补 0，相当于 ×2，符号位变化则溢出。

术式
乘除要记的结论

n 位 × n 位 = 2n 位。 C 的 int * int 只取低 32 位，所以可能溢出。
乘法溢出判断：有符号：高 n 位不是低 n 位符号的扩展；无符号：高 n 位不全为 0。
除法溢出：只有 最小负数 ÷ (−1)，以及除以 0（产生异常）。
C 语言整数除法向 0 取整；移位是向下取整。

扩展操作码算术

从地址最多的开始。k 位操作码有 2ᵏ 种，分给高层 a 条，剩 2ᵏ−a 个前缀。每个前缀再扩展 m 位，得到 (2ᵏ−a)×2ᵐ 条下一层指令。

第20话程序的机器级表示

术式
函数调用五句话

① 参数从右向左压栈；第一个参数离 ebp 最近，[ebp+8]。
② call 压返回地址；ret 弹返回地址。
③ 函数开头：push ebp; mov ebp, esp。
④ 返回值放 eax。
⑤ 递归调用 n 层，就有 n 个栈帧；栈溢出就是这里用完了。

汇编器：汇编 → 可重定位目标文件（.o），每个模块地址从 0 开始。
链接器：两个任务，① 符号解析（把引用和定义对应），② 重定位（合并各段，把相对地址改成运行时地址）。

第21话CPU 的数据通路与控制器

术式
寄存器位数和可见性

PC 位数 = 主存地址位数。指令按字对齐时，低位恒 0，可少 log₂(字节数) 位。
MAR = 地址位数；MDR = 存储字长；IR = 指令字长。
程序员可见：PC、GPR、PSW。不可见：MAR、MDR、IR、暂存器。

术式
四个周期的微操作（默写）

取指：PC→MAR；MEM→MDR；MDR→IR；PC+1→PC（读命令由 CU 发）。
间址：Ad(IR)→MAR；MEM→MDR；MDR→Ad(IR)。
执行：看指令。
中断：SP−1→SP, SP→MAR；PC→MDR 写入内存；向量地址 →PC。

术式
微指令的编码

直接编码：一位对应一个命令，最长最快。
字段直接编码：互斥的命令放一个字段。一个字段 m 个命令需要 ⌈log₂(m+1)⌉ 位，+1 是留给「什么都不做」。
下地址字段：位数 = ⌈log₂ 微指令总数⌉。

术式
水平型和垂直型微指令

水平型：一条微指令能并行发出多个微命令。长、快、并行能力强，用户编写难。
垂直型：类似机器指令，一条只做一个动作，要译码。短、慢、易编。

第22话指令流水线与多处理器

术式
流水线指标（k 段、n 条、周期 Δt）

总时间 T = (k + n − 1)Δt。
吞吐率 TP = n / T，理想最大 1/Δt。
加速比 S = n·k·Δt / T，n 很大时趋近 k。
效率 E = S / k。
时钟周期 = 最慢段的时间 + 段寄存器延迟。

术式
数据冒险三种解法

① 阻塞：插 nop 或由硬件停顿。简单，慢。
② 转发（旁路）：把 EX 或 MEM 段已经算出来的结果，直接送到 ALU 入口，不等写回。运算指令一般不用再阻塞。
③ 编译器重排：把无关的指令调到中间。
Load-use 特例：load R1 后紧跟使用 R1，转发也要阻塞 1 个周期，因为 MEM 结束才有数据，而下一条的 EX 已经要用了。

术式
控制冒险的处理

① 阻塞：等分支结果出来。在 EX 段出结果就损失 2 个周期；在 MEM 段损失 3 个。
② 提前判断：把比较放在 ID 段，只损失 1 个周期。
③ 分支预测：静态（比如总预测不转移）；动态（根据历史，循环命中率很高）。
④ 延迟槽：转移指令后一条总是执行（MIPS）。
预测错了要清空已经进入流水线的指令。

术式
超标量 / 动态

超标量：多条流水线，一个周期发射多条指令，CPI 可小于 1。功能段时间不缩短。靠硬件判断哪些指令能同时发。
超流水：把一段再切成更多小段，提高主频。
超长指令字 VLIW：由编译器把多条指令打包成一条。
动态流水线：硬件调度，可以乱序执行，顺序提交。指令被某操作数卡住时，后面无关的指令可以先走。

术式
Flynn 分类

SISD：单指令流单数据流，普通单核，可以用流水线。
SIMD：一条指令处理多个数据（向量运算、GPU）。
MISD：现实中几乎没有。
MIMD：多核、多处理器。

第23话中断、异常与内核态

术式
用户态与内核态

内核态（管态）：所有指令都能执行。用户态（目态）：只能执行非特权指令。
特权指令：开关中断、I/O、改 PSW、改基址/界限寄存器、设置时钟、加载页表基址。
用户→内核，只有一条路：中断或异常（包括 trap）。 内核→用户：修改 PSW（iret）。

术式
分界线

硬件：关中断、保存断点（PC、PSW）、形成入口地址（中断向量）。
OS：保存通用寄存器、保存/设屏蔽字、处理、恢复、iret。
响应时机：指令周期结束时，且开中断、有请求。

术式
系统调用三句话

发起在用户态，执行在内核态。
分类：设备管理、文件、进程控制、进程通信、内存管理。
库函数和系统调用：printf 是库函数，内部调用 write；sin() 不进内核。命令解释程序（Shell）也是用户程序。

第24话操作系统的骨架

术式
四个特征

并发：宏观同时，微观交替（单核）。共享：互斥共享、同时共享。虚拟：时分（虚拟 CPU）、空分（虚拟内存）。异步：走走停停，不可预知。
并发和共享互为前提，是最基本的两个特征。

术式
多道程序的优点

CPU 利用率高、吞吐量大、I/O 设备利用率高。代价：系统开销变大、单个作业周转可能变长。

术式
微内核的四个基本功能

进程（线程）管理、低级存储器管理、中断和陷入处理、进程通信。服务器以用户态运行，通过消息传递通信。

术式
引导要记

BIOS 放在 ROM，不易失；OS 放在硬盘；启动完成后 OS 在 RAM。
MBR 包含引导代码和分区表，位于磁盘第一个扇区。

术式
两类虚拟机

第一类（裸金属）：Hypervisor 直接跑在硬件上，运行在最高特权级，性能好。虚拟机里的 OS 以为自己在内核态，其实是用户态，特权指令被捕获后模拟（陷入并模拟）。
第二类（寄居）：Hypervisor 作为应用跑在宿主 OS 上（如 VMware Workstation、VirtualBox），性能差。
虚拟内核态：虚拟机内部的 OS 看到的内核态，硬件上其实是用户态。

第25话进程与线程

术式
五态及转换

就绪：什么都有，只差 CPU。阻塞：等某件事（I/O 完成、信号量），给它 CPU 也没用。
运行→阻塞是进程自己主动做的。阻塞→就绪是别人唤醒的。运行→就绪是被动的（时间片到、被抢占）。
阻塞不能直接变运行，就绪不能直接变阻塞。

术式
创建和终止

创建：申请 PID 和 PCB → 分配资源 → 初始化 PCB → 插入就绪队列。
引起创建：用户登录、作业调度、提供服务、程序请求（fork）。
fork 后：子进程得到父进程地址空间的一份副本（写时复制），有自己的 PID。父子谁先运行不确定。exec 用新程序替换地址空间。
终止：正常结束、异常结束、外界干预。

术式
进程 vs 线程

进程：资源分配的基本单位。线程：CPU 调度的基本单位。
线程共享：代码段、数据段、堆、打开的文件。
线程私有：PC、寄存器组、栈（含栈指针）、线程 ID、TCB。
同一进程内线程切换不引起进程切换，不切地址空间。

术式
三种多线程模型

多对一：多个用户线程映射到一个内核线程。切换快，但一个阻塞全部阻塞，不能并行。
一对一：每个用户线程一个内核线程。并发好，开销大（Linux 的做法）。
多对多：折中。

术式
四种通信方式

共享内存：两个进程映射同一块物理内存。之后直接读写，不再经过内核，所以最快；互斥同步要自己用 PV 做。
消息传递：send / receive，内核负责复制。可直接发给对方，也可间接经过信箱。不用共享，天然同步，但慢。
管道：内存中的一个固定大小的缓冲区，当文件操作。半双工，字节流，一端写一端读。满了写阻塞，空了读阻塞，所以它就是一个有容量限制的生产者消费者。读过的数据就没了，所以多个读者要小心。
信号：异步通知（比如 Ctrl+C）。发给进程后先挂起，进程从内核态返回用户态时检查并执行处理函数。只传一个信号编号，不传数据。

第26话CPU 调度与上下文切换

术式
衡量好坏的指标

周转时间 = 完成时间 − 到达时间。
带权周转时间 = 周转时间 ÷ 服务时间（≥1）。
等待时间 = 周转 − 服务（I/O 不计入等待时，还要减）。
响应时间 = 首次得到 CPU − 到达。
CPU 利用率 = 忙 ÷ 总。吞吐量 = 完成数 ÷ 时间。

术式
什么时候能调度

要调度：当前进程结束、阻塞；时间片用完；有更高优先级进程到达（抢占）。
不能调度：正在处理中断；执行原语；进程在内核程序的临界区中。
普通临界区可以调度：进程在用户程序的临界区（比如正在用打印机）时可以被抢占，只是别人进不了这个临界区。

术式
上下文切换

调度是选一个；切换是实施。
切换内容：保存 PC、PSW、通用寄存器到 PCB；更新 PCB 状态并放入队列；选中新进程，加载它的现场；切换地址空间（页表基址），TLB 随之作废。
切换本身不做有用功，还让 TLB 和 Cache 失效。同一进程内的线程切换不用换地址空间，开销小得多。

术式
HRRN 公式

响应比 = (等待时间 + 服务时间) ÷ 服务时间。
等待相同时，短的优先。服务相同时，等得久的优先。长作业等久了响应比一直涨，不会饥饿。非抢占。

术式
RR 的结论

时间片太大退化成 FCFS；太小切换开销占比太大。不会饥饿。
到达和时间片到同时发生：默认新进程先入队（题目另有说明除外）。

第27话互斥的实现：从锁到信号量

术式
基本概念

临界资源：一次只能一个进程用（打印机、共享变量）。临界区：访问临界资源的那段代码。
互斥：不能同时用。同步：有先后，A 做完 B 才能做。
一个进程的结构：进入区 → 临界区 → 退出区 → 剩余区。

术式
互斥的四条准则

① 空闲让进：临界区没人，要进的可以马上进。
② 忙则等待：有人在里面，其他人等。
③ 有限等待：不能无限等（不饥饿）。
④ 让权等待：进不去就让出 CPU，不要占着 CPU 空转。
前三条必须满足；第四条尽量满足，下面可以看到很多方法做不到。

术式
三种硬件方法

关中断：进入临界区前关中断，就不会被切走。只适合单处理机内核：多核时别的 CPU 不受影响，交给用户又太危险。
TestAndSet（TSL）：原子地「读旧值、置 1」。
Swap：原子地交换两个值。
共性：后两者实现简单、适合多处理器；都忙等，不满足让权等待；可能饥饿。

术式
信号量的语义

value > 0：还有这么多可用资源。value < 0：有 |value| 个进程在等。
初值：互斥 = 1；同步 = 0；资源 = 数量。
P、V 本身是原语，靠关中断或 TSL 实现，时间极短。

术式
条件变量 vs 信号量

条件变量没有值，只有队列。x.wait() 阻塞自己，放开管程；x.signal() 唤醒一个，没人等就什么都不做（不累积）。
信号量有值，V 会累积，能记住「曾经 V 过」。
管程既能实现互斥，也能实现同步。

第28话PV 大题：五个模子

术式
写者优先（读写公平）的改法

多加一个 w=1，读者和写者都先 P(w)。读者拿到 count 之后就 V(w)；写者写完才 V(w)。写者一来占住 w，后面的读者就进不去了。

术式
三种解法

① 限制人数：最多 4 人同时拿筷子，就至少有一人能拿到两根。
② 奇偶法：奇数号先左后右，偶数号先右后左，破坏环。
③ 一次拿两根：拿筷子的动作用一个 mutex 保护。

第29话死锁

术式
四个必要条件（缺一不可）

① 互斥：资源不能共用。
② 不可剥夺：不能从别人手里抢。
③ 请求并保持：拿着一个，还要别的。
④ 循环等待：等待关系成环。

术式
不死锁公式

m > n(k−1) ⟺ 一定不死锁。
需求各不相同（kᵢ）时：m > Σ(kᵢ − 1)，也就是 m ≥ Σkᵢ − n + 1。

术式
预防：破坏哪一条

互斥：把资源改造成可共享（如 SPOOLing）。多数资源做不到。
不可剥夺：申请失败就放弃已有的。适合 CPU、内存这种能保存现场的，不适合打印机。
请求并保持：一次申请全部（静态分配）。资源浪费，可能饥饿。
循环等待：资源编号，按编号递增申请。编号不便改动，加设备麻烦。

术式
四步

① 检查 Request ≤ Need，否则出错（超过声明）。
② 检查 Request ≤ Available，否则等待（不用查安全性）。
③ 试探分配：Available −= Request，Allocation += Request，Need −= Request。
④ 安全性算法：Work = Available，反复找 Need ≤ Work 的进程，让它跑完，Work += Allocation。全部能跑完才安全；不安全就回滚，让它等。

术式
死锁定理

图能完全简化（所有边都去掉）⟺ 没有死锁。化简后还有边的进程，就是死锁进程。

第30话主存：芯片与连接

术式
程序的局部性

时间局部性：刚访问过的，很快还会再访问（循环变量、循环里的指令）。
空间局部性：访问了某地址，很快会访问它附近（数组、顺序执行的指令）。

术式
DRAM 引脚怎么算

地址引脚 = ⌈地址位数 / 2⌉（复用，减半）。数据引脚 = 每单元位数。
行列怎么分：行列尽量接近，让引脚最少；不能完全相等时行数取少的，因为刷新按行，行少刷新快。

术式
低位交叉公式

连续读 n 个字：T + (n−1)·r。理想情况 r = T / m。
访问冲突：相邻不足 m 次的两次访问落到同一模块，后者要等前者的周期结束。

术式
扩展四步

① 片数 = 总容量 ÷ 单片容量。
② 位方向 每组几片；字方向 几组。
③ 地址：低位接芯片（log₂单片单元数），高 ⌈log₂组数⌉ 位译码。
④ 控制：CPU 的 MREQ# 接译码器使能，保证 CPU 访问 I/O 时不会误选内存。

第31话Cache

术式
性能公式

命中率 H = 命中次数 ÷ 总访问次数。
先查 Cache，不命中再访问主存：T = H·Tc + (1−H)(Tc+Tm)，等价于 T = Tc + (1−H)·Tm。
同时访问：T = H·Tc + (1−H)·Tm。
带缺失的 CPI：CPI = CPI₀ + 每条指令访存次数 × 缺失率 × 缺失损失。

术式
地址划分三步

① 块内偏移 = log₂(块大小)，块大小要换算成「编址单位」，按字编址和按字节编址结果不同。
② 组号 = log₂(行数 ÷ 路数)。直接映射路数为 1，全相联组数为 1。
③ 标记 = 地址总位数 − 前两者。
定位：块号 = 地址 ÷ 块大小，组号 = 块号 % 组数，标记 = 块号 ÷ 组数。

术式
Cache 总容量

每行 = 数据位 + 标记位 + 有效位(1) + 脏位(回写才有，1) + 替换位(LRU 才有，log₂路数)。
总容量 = 行数 × 每行位数。

术式
写策略

全写 + 非写分配；回写 + 写分配（现代常用）。
全写不需要脏位；回写每行加 1 位脏位。

术式
算命中率的步骤

① 算每块放几个元素：块大小 ÷ 元素大小。
② 看访问顺序：顺序访问时，每块只在第一次访问时缺失。
③ 读后写同一个元素：写的那一次必命中，因为刚读进来。
④ 跳着访问：算相邻访问隔了多少块，算这些块落到哪些行，有没有互相赶走。

第32话内存管理基础

术式
三种装入

绝对装入：编译时就算好物理地址。只适合单道程序。
静态重定位（可重定位装入）：装入时一次性改掉所有地址。装入后不能再移动，而且要一次分够全部内存。
动态重定位（动态运行时装入）：运行到那条指令时才转换，靠重定位寄存器。程序可以被移动，能分散放，是现代系统的方式。

术式
三种链接

静态链接：运行前就合成一个文件。
装入时动态链接：边装入边链接。
运行时动态链接：用到某模块才链接。省内存，也便于共享和更新。

术式
地址转换（基本分页）

P = A ÷ 页大小，W = A % 页大小。先判断 P 不超过页表长度。
查页表得页框号 F，物理地址 = F × 页大小 + W。
偏移不变，只换页号。
访问一个数据要访存两次：一次读页表项，一次读数据。

术式
多级页表的算法

每级页表最多占一页。一页能放 页大小 ÷ 页表项大小 项，每级位数 = log₂(这个数)。
4 KB 页、4 B 页表项：一页 1024 项，每级 10 位，32 位地址切成 10 + 10 + 12。
k 级页表，访存 k+1 次（没有 TLB 时）。
优点：不要求大块连续内存；不用的区域不建表。多级不减少访存次数，反而增加。

术式
分页 vs 分段
维度分页分段
目的系统管理需要用户（程序结构）需要
大小固定，系统定不固定，程序定
地址空间一维二维（段号 + 偏移）
碎片内部外部
共享和保护难方便，一段就是一个逻辑单位

第33话地址翻译全链路

术式
地址一共切两次

第一次（虚拟地址）：VPN | 页内偏移。偏移位数 = log₂(页大小)。
第二次（物理地址）：标记 | 组号 | 块内。
TLB 全相联时，整个 VPN 就是 TLB 标记；组相联时，VPN 再切成 TLB 标记 | TLB 组号。

术式
带 TLB 的访存时间

TLB 命中：Tt + Tm。
TLB 缺失，页在内存：Tt + Tm（页表）+ Tm（数据），有时题目还给更新 TLB 的时间。
缺页：Tt + Tm（页表）+ Tp + Tt + Tm（数据）。末尾再来一遍 TLB 和数据，是因为要重新执行这条指令，此时 TLB 已经有了。

第34话虚拟内存

术式
虚拟内存的三个特征

多次性：一个进程分多次调入。对换性：运行中可以换入换出。虚拟性：逻辑上扩大内存。
必须基于非连续分配（请求分页、请求分段、请求段页）。连续分配做不到只装一部分。
实际可用容量 = min(主存 + 外存, 地址空间大小)。

术式
缺页处理

① 硬件：地址转换时发现 P=0，产生缺页异常，CPU 转入内核。
② OS：有空闲页框就直接用；否则用置换算法选一页，若 M=1 先写回磁盘。
③ OS：启动磁盘 I/O 读入页面，进程阻塞，CPU 转去跑别的进程。
④ OS：I/O 完成，中断唤醒进程，修改页表（P=1，填页框号）。
⑤ 重新执行这条指令。

术式
改进型 CLOCK 的顺序

第一轮：找 (0,0)，不改任何位。
第二轮：找 (0,1)，把扫过的 A 清 0。
没找到就重复第一轮、第二轮。最多四轮。
淘汰优先级：(0,0) → (0,1) → (1,0) → (1,1)。

术式
置换算法对比

OPT：最优，不可实现。FIFO：差，有 Belady。LRU：好，开销大。CLOCK：接近 LRU，开销小。

术式
三种组合（只有这三种）

固定分配局部置换：页框数不变，缺页赶自己的。开始时难定数目。
可变分配全局置换：缺页就从空闲页框给一个，没有了就赶别的进程的。别人缺页会增加。
可变分配局部置换：缺页赶自己的；缺页太频繁时再多给几个。
没有「固定分配全局置换」：全局置换拿别人的页框就是在增加自己的页框数，和固定矛盾。

术式
回收的优先顺序

干净页比脏页便宜（不用写盘）。文件映射页可以写回文件；匿名页（堆、栈）要写到交换区。

术式
有效访问时间

T = (1−p)·Tm + p·缺页处理时间。

第35话文件与目录

术式
文件操作

create：分配空间 + 建目录项。delete：释放空间 + 删目录项。
open：按路径找目录，找到 FCB 读入内存，返回描述符（不读数据）。
read/write：按指针找数据块。
close：写回 FCB。
打开文件表：系统一张（FCB、引用计数），每个进程一张（读写指针、指向系统表）。

术式
混合索引公式

设块大小 B、指针大小 p，每块放 k = B / p 个指针。
最大文件块数 = 直接 + k·(一级) + k²·(二级) + k³·(三级)。
访盘次数（inode 已在内存）：直接 1，一级 2，二级 3，三级 4。

术式
打开路径的访盘

打开 /a/b/c：读根目录 inode（一般已在内存）→ 根目录块 → a 的 inode → a 的目录块 → b 的 inode → b 的目录块 → c 的 inode。每层目录大约 2 次。

术式
链接的三句话

硬链接：目录项指向同一个 inode，link count +1，删一个 count −1，减到 0 才真正删除。不能跨文件系统。
软链接：一个新文件，有自己的 inode，内容是路径。可以跨文件系统；原文件删了就断了。
软链接不增加原文件引用计数。

第36话文件系统

术式
位图的两个公式

位图大小 = 块数 / 8 字节。占多少块 = 位图字节 / 块大小，向上取整。
块号 → 位图位置：盘块号 = 块号 / (块大小×8)（+ 起始块）；字节号 = (块号 % (块大小×8)) / 8。

术式
VFS 四个对象

超级块（一个文件系统）；inode（一个文件）；dentry（路径项，缓存在内存）；file（一个打开实例）。
VFS 向上提供统一接口，向下要求具体文件系统实现一组函数。

术式
挂载三步

① 找到设备（检查超级块）；② 把文件系统加入挂载表；③ 把挂载点的 inode 标记为已挂载，访问这个目录时转到新文件系统的根。
原目录下的内容被遮住，卸载后恢复。

第37话磁盘与固态硬盘

术式
磁盘访问时间

Ta = 寻道时间 + 平均旋转延迟 + 传输时间 + 控制器延迟
平均旋转延迟 = 转一圈时间的一半 = 1/(2r)。
传输时间 = 字节数 / (每圈字节 × 转速) 或 字节数 / 传输率。
寻道时间占主要部分，所以调度算法优化的就是它。

术式
算法对比
算法特点缺点
FCFS公平慢
SSTF每次最近饥饿，磁臂黏着
SCAN到头再回两端不公平
C-SCAN单向一圈才一次
LOOK / C-LOOK不到头就回实际常用
术式
SSD 的特点（大纲新增）

由闪存块构成，每块多个页；按页读写，按块擦除。写之前必须先擦。
读快（随机访问），写比读慢；没有机械部件，所以无寻道延迟，调度算法基本用 FCFS。
闪存转换层（FTL）：逻辑块到物理页的映射。
磨损均衡：每块擦写次数有限。动态：写入时选低磨损的块；静态：周期性搬动长时间不变的数据。

第38话总线

术式
分类与组成

片内总线、系统总线（数据线、地址线、控制线）、I/O 总线、通信总线。
数据线：可传数据、命令、状态字（不只是数据）。地址线：位数决定寻址空间。控制线：时序和控制信号（握手应答走这里）。
单总线、双总线、三总线：越多越能隔离慢设备。

术式
总线带宽

带宽 = 总线宽度 × 工作频率 × 通道数
工作频率 = 时钟频率 × 每周期传输次数。这是理想上限，不考虑事务时序。

术式
定时方式

同步：统一时钟，简单，时钟由一个独立模块提供，适合速度差不大。
异步：握手（不互锁、半互锁、全互锁），可靠，时钟无关，速度差大可用。
半同步：同步基础上加一个 Wait 信号。
分离式：事务分两半，请求之后放开总线。

第39话I/O 方式

术式
端口编址

统一编址：端口和内存共用地址，用访存指令（MOV）。指令丰富，但占地址。
独立编址：专门的 I/O 指令（IN/OUT），独立的地址空间。清晰，但指令少。

术式
三种方式的 CPU 占用率（核心公式）

查询（定时）：占比 = 每秒查询次数 × 单次周期数 / 主频。
中断：每秒中断次数 = 传输率 / 每次传的字节数；占比 = 每秒次数 × 每次开销周期 / 主频。
DMA：每秒中断次数 = 传输率 / 块大小；占比 同上；再问是否抢总线。

术式
响应优先级和处理优先级

响应优先级：同时请求时先理谁，硬件固定。
处理优先级：谁可以打断谁，由屏蔽字决定，OS 可改。
屏蔽字 Mi=1 表示屏蔽第 i 级。各级的屏蔽字通常也屏蔽自己和优先级低的。

术式
DMA 三阶段

预处理（CPU）：设主存首地址、设备地址、字数、方向。
传送（DMAC）：申请总线、传输、修改地址和计数。
后处理（CPU）：中断处理，校验。

术式
DMA 与 CPU 抢总线

CPU 停止访存：DMA 期间 CPU 不访存。
周期挪用（窃取）：DMA 偷一个存取周期，优先级高于 CPU（设备数据不等人）。
交替访问：CPU 和 DMA 轮流用。
注意 CPU 不能「因 DMA 而做不了事」，只有访存受影响。

术式
设备分类（OS 口径）

块设备（磁盘，可寻址）、字符设备（键盘，不可寻址）。网络设备（套接字）。低、中、高速。
控制方式演化：查询 → 中断 → DMA → 通道。

第40话I/O 软件层次

术式
每层干什么

用户层：库函数、假脱机。
设备独立性：逻辑设备名映射、权限检查、缓冲、错误报告、分配回收。
驱动程序：计算柱面、磁头、扇区，启动设备。每种设备一个。
中断处理：保存状态，处理完唤醒进程。

术式
应用程序接口

字符设备接口：get/put，字节流。
块设备接口：read/write/seek，块，可寻址。
网络设备接口：socket。
阻塞 I/O：调用后进程等，直到完成。非阻塞 I/O：立即返回，轮询询问状态。

术式
块设备的时间

单缓冲，稳态每块：max(T, C) + M。
单缓冲，n 块总时间：n(T+M) + C。
双缓冲，稳态每块：max(T, C+M)。
双缓冲，n 块总时间：nT + M + C。

术式
分配用到的数据结构

SDT（系统设备表）→ DCT（设备控制表）→ COCT（控制器）→ CHCT（通道）。
逻辑设备表 LUT：逻辑名 → 物理设备。
方式：独占、分时共享、虚拟（SPOOLing）。安全分配 vs 不安全分配。

术式
SPOOLing 的结论

把独占设备改造成共享设备：虚拟设备。
组成：输入井、输出井（磁盘）；输入缓冲、输出缓冲（内存）；输入进程、输出进程（守护进程）。
不需要用户作业控制。它破坏死锁的「互斥」条件。

第41话分层与性能指标

术式
三个模型

OSI 七层：物理、链路、网络、传输、会话、表示、应用（物链网传会表应）。
TCP/IP 四层：网络接口、网际、传输、应用。
五层教学模型：物链网传应。
表示层：数据格式转换（加密、压缩）。会话层：会话管理、同步。
传输层：第一个端到端的层。

术式
协议、接口、服务

协议：水平的，对等层之间的规则（语法、语义、同步）。
服务：垂直的，下层向上层提供。
接口：相邻层之间，访问服务的地方（SAP）。
PDU=PCI+SDU。上层的 PDU 是下层的 SDU。

术式
时延四件套

发送时延 = 帧长 / 带宽（在发送方）。
传播时延 = 距离 / 信号速度。
处理时延、排队时延。
时延带宽积 = 传播时延 × 带宽（管道能装多少比特）。
RTT：一个来回。
利用率高了时延会暴涨。

术式
分组交换总时间

T = (k + m − 1) · r + (k 跳的传播)
k：链路段数（数链路不数设备）；m：分组个数；r：每个分组一跳的发送时延。
报文交换：k × (L / C)。

第42话物理层

术式
两个母公式

奈氏（无噪声）：C = 2W · log₂V（b/s）。W 是带宽（Hz），V 是状态数。
香农（有噪声）：C = W · log₂(1 + S/N)（b/s）。
分贝换算：dB = 10·log₁₀(S/N)。30 dB → S/N = 1000；log₂1001 ≈ 10。
波特率 ≤ 2W。比特率 = 波特率 × log₂V。

术式
五种编码

NRZ：不归零。无法同步。NRZI：跳变表示 0（USB）。曼彻斯特：中间跳变，自同步；以太网用。差分曼彻斯特：比特开始处跳变表示 0。
调制：调幅 AM、调频 FM、调相 PM、QAM（幅度 + 相位组合）。

术式
接口四特性

机械（形状）、电气（电压）、功能（每根线的含义）、过程（时序）。

术式
物理层设备

中继器：放大信号。集线器：多端口中继器，广播，所有端口一个冲突域。
不识别地址，不隔离冲突。

第43话链路层：可靠传输

术式
四种组帧方法

字符计数法：首字节写长度。一错全错。
字节填充：FLAG 定界，内容中有 FLAG 就加转义字符。
零比特填充（HDLC）：FLAG = 01111110；发送方遇到 5 个连续 1 就插入 0。
违规编码：用曼彻斯特中不用的码。

术式
CRC（检错，不纠错）

生成多项式最高次 r，就在数据后补 r 个 0，模 2 除，余数就是校验码。
接收方再除，余数 0 则无错。

术式
海明码（纠 1 位，检 2 位）

校验位数 r：2ʳ ≥ m + r + 1。
校验位放在 2 的幂次位（1,2,4,8…）。
第 i 个校验位负责所有编号二进制第 i 位为 1 的位。
纠错：把校验的异或结果拼起来，就是错的那一位的编号。
海明距离 d：检错 d−1，纠错 (d−1)/2。

术式
三协议窗口上限（序号 n 位）
协议发送窗口接收窗口
S-W11
GBN≤ 2ⁿ − 11
SR≤ 2^(n−1)≤ 2^(n−1)

SR 中 W发 + W收 ≤ 2ⁿ。

术式
利用率母公式

U = min(1, N · T_D / T)
N：窗口大小（S-W 为 1）；T_D：发一帧的时间；T：发送周期，从开始发到收到确认 = T_D + RTT + T_A。
不计确认帧：T_A = 0。
捎带确认等长帧：T_A = T_D。
实际速率 = U × 带宽。

第44话链路层：谁能发言

术式
四种复用

FDM 频分（调频广播）。TDM 时分（轮流）；统计 TDM（按需）。WDM 波分（光的 FDM）。
CDM 码分：每站有一个码片序列，彼此正交。发 1 时发码片，发 0 时发反码，叠加传输。
解码：接收向量 · 码片 / 码片长度 = +1 表示 1，−1 表示 0。

术式
三种坚持

1-坚持：闲就发，忙了一直听。非坚持：忙就等随机时间再来。p-坚持：闲时 p 概率发。

术式
CSMA/CD 公式

最短帧长 L_min = 2τ × C；τ = 距离 / 传播速度。
以太网：争用期 512 比特时间，最短帧 64 B。最长数据 1500 B。
帧间间隔 96 比特时间。
二进制指数退避：第 k 次冲突后，从 [0, 2^min(k,10) − 1] 个争用期中随机选一个等；16 次放弃。

术式
CSMA/CA

预约：RTS → CTS（可选）。
确认：收到数据要回 ACK（因为不能检测冲突）。
帧间隔：SIFS < PIFS < DIFS。ACK、CTS 用 SIFS（最高优先）。
退避：信道从忙变闲才退避。

术式
802.11 四个地址（常考）

地址 1 永远是接收方（RA），地址 2 永远是发送方（TA）。
发往 AP（To DS=1）：地址 1=AP(BSSID)，地址 2=源，地址 3=目的。
AP 发出（From DS=1）：地址 1=目的，地址 2=AP，地址 3=源。

术式
以太网 MAC 帧

MAC 地址 48 位，高 24 位厂商。
前导码 8 B 不算帧长。最短 64 B，最大 1518 B。
无连接、不可靠。10Base-T：双绞线；100Base-T：双绞线。

术式
自学习

来的时候学源地址：记录「源 MAC ↔ 入端口」。
转发查目的地址：查到就从那个端口转发；查不到就泛洪（入端口外全部）；目的就在入端口同一网段，丢弃。
广播帧：泛洪。

术式
两种转发

直通：只看目的 MAC（6 B）就转发，时延低，不校验。时延 = 6×8 / C。
存储转发：全部接收并校验，时延 = 帧长 / C。

第45话IPv4 与子网

术式
首部三个单位

首部长度 ×4 B。总长度 ×1 B。片偏移 ×8 B。
口诀：「一八四，总片首」：总长度 1，片偏移 8，首部长 4。

术式
分片

每片的数据长度必须是 8 的倍数（最后一片除外），因为片偏移单位是 8。
片偏移 = 本片数据相对原始数据开头的位置 ÷ 8。

术式
特殊地址

0.0.0.0：本机（只能做源）。127.x.x.x：环回。主机全 0：网络地址。主机全 1：广播（只能做目的）。255.255.255.255：受限广播。
私有地址：10/8、172.16/12、192.168/16，互联网路由器不转发。

术式
子网四问（/n）

掩码：n 个 1。
网络地址：IP AND 掩码。
广播地址：网络位不动，主机位全 1。
可用主机数：2^(32−n) − 2。
块大小：256 − 掩码那一字节。

术式
最长前缀匹配

目的 IP 和每条路由的前缀比较，都匹配时选 最长的那条，前缀越长越具体。
默认路由 0.0.0.0/0：没有其他匹配时走它。

第46话IP 的辅助协议与新特性

术式
路由 vs 转发

路由：全局，算出路径，生成路由表（路由算法）。
转发：本地，查表把分组送到输出端口。
一个是后台算，一个是一直在做。

术式
SDN（软件定义网络）

控制平面和数据平面分离：控制器集中算路由，通过南向接口下发流表，交换机只转发。北向接口向应用开放。

术式
ARP

作用：同一网段内，IP → MAC。
请求广播，响应单播。结果放 ARP 缓存，定时过期。
跨网段时：解析的是默认网关的 MAC。

术式
DHCP 四步（应用层，基于 UDP）

① Discover（广播，源 0.0.0.0）
② Offer（服务器提供）
③ Request（广播，告诉所有服务器我选谁）
④ ACK
给 IP、掩码、网关、DNS。地址是租用的，有期限。

术式
两个应用

ping：回送请求和回答。
traceroute：依次发 TTL=1,2,… 的分组，收「时间超过」确定路径。

术式
NAT 要点

既看 IP 也看端口，所以路由器工作到了传输层。外部不能主动访问内网（除非配置端口映射）。

术式
IPv6 主要特点

128 位地址。首部固定 40 B（+扩展首部）。去掉首部校验和；路由器不分片（只有源主机分，路由器发 ICMP「分组太大」）。
地址表示：8 组 16 位十六进制，连续 0 可用 ::（一次）。
单播、组播、任播（没有广播）。
过渡：双栈、隧道。

术式
组播

D 类地址：224.0.0.0 ~ 239.255.255.255，只能做目的。
IP→MAC：低 23 位映射到 01-00-5E-...（所以 32 个 IP 对一个 MAC）。
IGMP：主机和本地路由器之间，只在本地。
组播路由：建树。

术式
三个实体

移动节点、归属代理、外部代理（外地代理）。
永久地址（归属地址）+ 转交地址。
过程：节点向归属代理注册转交地址 → 通信方发到永久地址 → 归属代理截获并隧道转发 → 外部代理解封 → 给移动节点。回程可以直接发。

术式
路由器结构

路由选择部分：运行路由协议。分组转发部分：输入端口、交换结构、输出端口。
输入和输出端口都可能排队，输出排队严重时丢弃（拥塞）。
实现到第 3 层。交换结构有内存、总线、交叉开关三种（交叉开关可以并行）。

第47话路由算法与协议

术式
RIP

应用层，UDP 520。距离向量。
距离 = 跳数，最大 15，16 = 不可达。所以只适合小网络。
定期（30 s）只和邻居交换自己的整个路由表。180 秒收不到就认为邻居不在了。
坏消息传得慢（计数到无穷）；好消息传得快。

术式
OSPF

IP 数据报直接承载（协议号 89）。链路状态。Dijkstra。
洪泛给区域内所有路由器，只在变化时（或定期长周期）。
可分区域；主干区域 0；支持多路径负载均衡。
报文：Hello（发现邻居）、DD（数据库描述）、LSR（请求）、LSU（更新）、LSAck（确认）。

术式
BGP

AS 之间。TCP 179。路径向量。
只寻求较好的路径（可达，且没有环），不求最优。
步骤：BGP 发言人之间建立 TCP 连接，交换路径向量。

术式
记忆表
协议封装算法范围

OSPFIP链路状态（Dijkstra）AS 内

第48话UDP 与 TCP 连接

术式
端口

熟知端口（0–1023）：20/21 FTP、23 Telnet、25 SMTP、53 DNS、69 TFTP、80 HTTP、110 POP3、143 IMAP、161 SNMP、443 HTTPS。
登记（1024–49151）；动态（49152–65535）。
TCP 用四元组（两端 IP:端口）标识连接；UDP 只用目的 IP 和目的端口分用。

术式
UDP 特点

无连接、尽力交付、面向报文（不拆不合）、无拥塞控制、首部 8 B。适合实时音视频、DNS。

术式
字段语义

seq：本段数据的第一个字节的序号。
ack：期望收到的下一个字节的序号（累积确认），ACK=1 才有效。
SYN、FIN 各占一个序号。
纯 ACK 不占序号。
MSS：最大段长，只算数据部分，握手时协商。

术式
握手要点

为什么三次：确认双方的发送和接收都正常，防止旧的连接请求造成错误。如果只有两次，一个滞留的旧 SYN 到达后，服务器就会白白建立连接。
服务器的资源：第二次握手后分配（SYN 洪泛攻击就利用这一点）。
状态：LISTEN → SYN-RCVD → ESTABLISHED。

术式
为什么要 TIME-WAIT

① 保证最后一个 ACK 到达（丢了对方会重发 FIN，可以重发 ACK）。② 让本连接的旧报文都消失，不干扰新连接。
TIME-WAIT = 2MSL，主动关闭方才有。

术式
连接管理的时间（以 RTT 计）

建立：发起方收到第二次握手 = 1 RTT，此后就能发数据；对方收到第三次握手 = 1.5 RTT。
释放（对方立即回 FIN+ACK 的最快情况）：对方进入 CLOSED = 1.5 RTT；发起方进入 CLOSED = 1 RTT + 2MSL。

第49话TCP 可靠、流控与拥塞

术式
RTT 估计

RTTs = (1−α)·RTTs + α·新 RTT（α=1/8）
RTTd = (1−β)·RTTd + β·|RTTs − 新 RTT|（β=1/4）
RTO = RTTs + 4·RTTd。
重传过的段的 RTT 不用来估计，因为分不清确认是针对哪一次的（Karn 算法）。

术式
发送窗口

发送窗口 = min(rwnd, cwnd)
可发字节数 = 发送窗口 − 在途未确认的

术式
拥塞四步（核心）

慢开始：cwnd < ssthresh 时，每个 RTT 翻倍。但不超过 ssthresh。
拥塞避免：cwnd ≥ ssthresh 时，每个 RTT +1。
超时：ssthresh = cwnd/2，cwnd = 1，重新慢开始。
3 个重复 ACK（快重传 + 快恢复）：ssthresh = cwnd/2，cwnd = ssthresh，然后线性增长。

第50话应用层

术式
DNS 要点

应用层，主要 UDP 53（报文小，可用 TCP）。
递归查询：我问你，你帮我查到答案。迭代查询：你告诉我下一步问谁。
主机 → 本地域名服务器：通常递归。本地 → 其他：通常迭代。
缓存：可以大幅减少查询。
最多查询次数：根 → 顶级 → 权威；再多一级，多一次。

术式
FTP 关键

两条 TCP 连接：控制连接（21，全程保持）、数据连接（传一次建立一次，传完就关）。
主动模式：服务器用 20 端口连客户。被动模式：服务器随便开一个端口，客户去连。
带外控制，有状态。

术式
邮件协议

SMTP：TCP 25，推送，只支持 7 位 ASCII。所以有 MIME 把二进制编码成 ASCII（base64）。
POP3：TCP 110，下载后（通常）删除，无状态。
IMAP：TCP 143，在服务器上操作，有状态。
HTTP 也可以取邮件（网页邮箱）。

术式
HTTP 特点

TCP 80；无状态（用 Cookie 补）。
非持续连接（1.0）：每个对象一个 TCP。持续连接（1.1）：一个 TCP 多个对象；分非流水线、流水线。
方法：GET、POST、HEAD、PUT、DELETE。
状态码：200 OK，301 永久移动，304 未修改，404，500。
代理缓存：减少访问。

术式
RTT 账本（n 个对象 + 1 个 HTML）
方式RTT
非持续、串行2(n+1)
非持续、无限并行4
非持续、m 条并行2 + 2⌈n/m⌉
持续、非流水线n + 2
持续、流水线3
