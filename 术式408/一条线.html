卷一 数据结构

主线：程序里的数据怎么摆。先摆成一排（线性表），再摆成一棵（树），再摆成一张网（图）；摆好之后只做两件事——找（查找）和排（排序）。

1复杂度选择每年 1 题 · 第01话

复杂度只问一件事：数据量翻倍时，要多干多少活。所以只留增长最快的那一项，常数全扔掉。

必背

  • 增长快慢排序O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
  • for(i=1;i<n;i*=2)O(log n)
  • 两重循环，内层从 i 跑到 nO(n²)
  • 递归 T(n)=2T(n/2)+O(n)O(n log n)

题眼

  • 单层循环，循环变量乘倍或平方增长设执行 k 次，写出第 k 次后循环变量的值，令它等于终止条件，解 k（考过 4 次）

最简单的摆法是排成一排。

2线性表、链表与算法大题算法大题年年 13–15 分 · 第02话 第03话 · 算法题速成

顺序表是一排连号的座位：按号找人快，中间插人要整排挪。链表是一串手拉手的人：插人只要松两只手，但找第 i 个得从头数。

必背

  • 顺序表 按位置访问 / 插入删除O(1) ／ O(n)，平均移动约 n/2 个
  • 链表 按位置访问 / 已知前驱的插入删除O(n) ／ O(1)
  • 单链表删除 p 的后继q=p->next; p->next=q->next; free(q);
  • 双链表插入改几个指针 / 删除改几个插入 4 个，删除 2 个
  • 算法题的评分结构基本思想（约 3 分）＋ 代码（约 7–8 分）＋ 复杂度（约 2 分），暴力解也给大半分

题眼

  • 数组、值域有界、要求「时间尽可能高效」开一个标记数组或计数数组，一遍打标、一遍找（考过 3 次）
  • 几个有序数组每个数组一个指针，每轮只动最小的那个（2 次）
  • 链表求倒数第 k 个、找中点、找公共后缀两个指针，一个先走（2 次）
  • 二叉树求 WPL、判 BST、加括号递归三行：空树返回什么、左右各递归、合起来（3 次）
  • 图、邻接矩阵、数度两重循环：行是出边，列是入边（2021、2023、2024 三次）
  • 完全没思路先排序再扫一遍，O(n log n) 的解也能拿 10 分左右

算法大题照写（三段，每段单独起头）

  1. 「(1) 基本设计思想」：用两三句话写清用什么数据结构、扫几遍、每遍做什么。
  2. 「(2) 算法实现」：先写函数头和变量，再写循环，最后写返回值；关键语句旁写一句注释。
  3. 「(3) 复杂度」：写「时间复杂度 O(…)，空间复杂度 O(…)」，与第 (1) 段说的一致。
  4. 想不出最优解就写暴力解，三段照样写全。

线性表只能在两端或中间操作。如果只许从一头进出，就是栈和队列。

3栈、队列、数组与串选择每年 2 题 · 第04话 第05话

栈是一摞盘子，后放的先拿；队列是排队打饭，先来的先走。循环队列是把队伍首尾接成一个圈，所以要空一个位置来区分「空」和「满」。

必背

  • n 个元素的出栈序列总数卡特兰数 C(2n,n)/(n+1)
  • 循环队列 队满 / 队空（牺牲一格）(rear+1)%Mfront ／ rearfront
  • 循环队列 元素个数(rear−front+M)%M
  • 中缀转后缀操作数直接输出；运算符入栈前先弹出栈里优先级≥它的；左括号直接入栈，右括号弹到左括号为止
  • 对称矩阵 aij（i≥j，下标从 1 起）存到一维数组的位置前面有 i(i−1)/2+j−1 个元素
  • KMP 的 next模式串第 j 位失配时，j 跳到「前 j−1 位的最长相等前后缀长度 + 1」

题眼

  • 判断出栈序列是否可能草稿上画栈，一步一行（考过 5 次）
  • 特殊矩阵压缩存储求下标只数「它前面有几个元素」，再看下标从 0 还是 1 开始（4 次）

一排摆不下有层级关系的数据，于是摆成一棵树。

4树：遍历、哈夫曼、度数选择每年 2–3 题 · 手算大题 3 年 · 第06话 第07话

树是一个家族谱。先序、中序、后序只是「根」在什么时候被念到：先念根、中间念根、最后念根。哈夫曼树是让「常用的字」离根最近，所以编码最短。

必背

  • 结点数与度n = n0+n1+n2+…，且 n = 分支数+1 = n1+2n2+3n3+…+1
  • 二叉树n0 = n2+1
  • 完全二叉树 n 个结点的高度⌊log₂n⌋+1
  • 高为 h 的 m 叉树最多结点(mh−1)/(m−1)
  • 能唯一确定二叉树中序＋先序，或中序＋后序（先序＋后序不行）
  • 森林 → 二叉树左孩子右兄弟；森林的先根＝二叉树先序，森林的后根＝二叉树中序
  • 哈夫曼树 WPL等于所有非叶结点权值之和
  • 哈夫曼树 n 个叶子共几个结点2n−1，没有度为 1 的结点
  • 并查集找根、按秩合并；路径压缩后几乎是 O(1)

题眼

  • 给结点总数、叶子数、某度结点数，求另一个列两个方程：结点数=各度之和，结点数=分支数+1（考过 5 次）
  • 「最小 WPL」「最优编码」「最少比较次数的合并」构造哈夫曼树（8 次）
  • 判断一组编码是不是前缀码、译码画一棵 0 左 1 右的二叉树（4 次）
  • 给两种遍历序列先序第一个、后序最后一个是根，在中序里一刀切开（4 次）

手算大题照写（哈夫曼类）

  1. 写「构造哈夫曼树：每次取权值最小的两个合并」，然后逐步列出每次合并的两个数和结果。
  2. 画出最终的树，标出每个叶子的路径长度。
  3. 写「WPL = Σ 权值 × 路径长度 = …」。
  4. 问编码就在每条左边写 0、右边写 1，逐个读出。

树长歪了查找会变慢，于是要「让树保持矮」。

5查找树：BST、AVL、B 树选择每年 1–2 题 · 第08话 第13话

BST 是一棵「左小右大」的树，查找就是一路问「比我大还是比我小」。AVL 是给 BST 加一条规矩：左右子树高度差不超过 1，一旦歪了就转一下。B 树是把树压得又矮又胖，因为每下一层就是一次读磁盘。

必背

  • BST 中序遍历得到递增序列
  • AVL 调平四种LL 右旋一次；RR 左旋一次；LR 先左后右；RL 先右后左（看新结点在最低失衡点哪个孩子的哪棵子树）
  • 高为 h 的 AVL 最少结点nh = nh−1+nh−2+1，n1=1，n2=2
  • m 阶 B 树每个结点的关键字数根 1 到 m−1；其余 ⌈m/2⌉−1 到 m−1
  • B 树插入满了中间第 ⌈m/2⌉ 个关键字上提，结点一分为二；只从根长高
  • B 树删除不够了先向兄弟借，借不到就与兄弟合并
  • B⁺ 树与 B 树的区别B⁺ 树数据全在叶子，叶子串成链表，适合范围查找

题眼

  • AVL 插入后问根或某结点找最低的失衡结点 A，看新结点落在 A 的哪个孩子的哪棵子树（考过 4 次）
  • B 树最多最少几个关键字或结点一层一层数：最少时每个结点取 ⌈m/2⌉−1 个，关键字数+1=孩子数（4 次）

树是一对多。关系变成多对多，就是图。

6图：存储、最小生成树、最短路、拓扑、关键路径手算大题 5 年 · 2024、2025 都考 · 第09话 第10话 第11话

图是一张地图。最小生成树是「用最少的总路费把所有城市连通」；最短路径是「从我家出发去每个城市各要多远」。两件事不一样：最小生成树不保证任意两点间路最短。拓扑排序是排课表——先修课排在前面。

必背

  • 无向图 n 个顶点最少几条边连通 / 完全图几条边n−1 ／ n(n−1)/2
  • 邻接矩阵 / 邻接表 存储与遍历O(n²) ／ O(n+e)
  • 无向图邻接矩阵第 i 行非零个数顶点 i 的度；有向图行看出度、列看入度
  • Prim / KruskalPrim 从一个点向外长，每次加最近的点，O(n²)，适合稠密图；Kruskal 按边权从小到大加边、不成环就要，O(e log e)，适合稀疏图
  • Dijkstra每轮选一个未确定的最小 dist，用它更新邻居；不能有负权边
  • Floyd三重循环 O(n³)，以每个顶点为中转试一遍
  • 拓扑序列唯一每一步入度为 0 的顶点都恰好一个
  • 关键路径正推 ve 取最大，逆推 vl 取最小；活动余量 = l−e，余量为 0 的是关键活动
  • 缩短关键活动不一定缩短工期（可能有多条关键路径）；延长一定延期

题眼

  • 「最小代价连通」「铺路」「布线」最小生成树，列边表一条条试（考过 3 次）
  • 「从某点到其余各点的最短距离」Dijkstra，按轮列 dist 表（5 次）
  • 「哪个不是拓扑序列」看前几位是不是入度为 0
  • 「判断某序列是不是 DFS 序列」每走一步问：当前点还有没访问的邻居吗，有就必须走它

手算大题照写（Dijkstra 表）

  1. 画一张表：列是各个顶点，行是第 1、2、3… 轮。
  2. 第 1 轮写出源点到各点的直接距离，不相邻写 ∞。
  3. 每轮圈出本轮选中的最小值，写一行「选 X，用 X 更新：…」。
  4. 最后一行写出各点的最短距离和路径。

数据摆好之后，第一件事是找。

7查找：折半、散列手算大题 2 年 · 2024 又考 · 第12话

折半查找是翻字典：每次翻到中间，扔掉一半。散列是按名字直接算出柜子号，柜子被占了就按规则找下一个。

必背

  • 折半查找判定树高度 / 查找长度上界⌈log₂(n+1)⌉
  • 折半 mid⌊(low+high)/2⌋，判定树中每个结点左子树结点数 = 右子树或右子树−1
  • 分块查找块间有序、块内无序；长度 n 分 √n 块最优
  • 线性探测冲突就看下一个格子，(H+1)%m，(H+2)%m …
  • 装填因子 α表中元素数 ÷ 表长，α 越大冲突越多

题眼

  • 散列表求 ASL先把表完整填出来，再逐个关键字数比较次数（成功），逐个地址数到空位的次数（失败）（考过 4 次）

手算大题照写（散列）

  1. 写出散列函数和处理冲突的方法。
  2. 逐个插入，每个关键字写一行「H(k)=…，冲突则…，放入地址 …」。
  3. 画出最终的表。
  4. 写「ASL成功 = (各关键字比较次数之和) ÷ 关键字个数 = …」；失败的分母是散列函数可能取到的地址个数，不是表长。

第二件事是排。

8排序选择每年 2–3 题 · 手算大题 3 年 · 第14话 第15话

插入排序像抓扑克牌，一张张插进手里已排好的部分；快排是选一个人当分界，比他矮的站左边、高的站右边；归并是把两摞已排好的牌合成一摞；堆排是每次从堆顶拿走最大的。

特性总表

  • 直接插入平均 O(n²)，基本有序时 O(n)，稳定
  • 希尔不稳定，省的是移动次数
  • 冒泡O(n²)，稳定，每趟把一个最大的放到最后
  • 快排平均 O(n log n)，有序时退化成 O(n²)，不稳定；每趟枢轴归位
  • 简单选择O(n²)，比较次数与初始序列无关，不稳定
  • 堆排O(n log n)，建堆 O(n)，不稳定，适合从大量数据里取前 k 个
  • 归并O(n log n)，空间 O(n)，稳定
  • 基数O(d(n+r))，稳定，不比较
  • 稳定的口诀插（直接插入）、冒（冒泡）、归（归并）、基（基数）
  • 每趟至少一个元素到最终位置冒泡、快排、简单选择、堆排

题眼

  • 给出某趟结果问是哪种排序或枢轴与最终有序序列逐位对齐，看哪些已归位（考过 3 次）
  • 「与初始序列无关」简单选择的比较次数、堆排、归并
  • 「从大量数据中选前 k 个」小根堆（取最大 k 个）或大根堆（取最小 k 个）
  • k 路归并要补几个虚段(n−1) % (k−1) 不为 0 就补 (k−1)−余数 个

卷二 计算机组成原理

主线：数据在机器里是什么。先把数变成一串位（数据表示），位放在存储器里（离 CPU 越近越快越小），指令告诉 CPU 去拿哪些位、做什么，CPU 一拍一拍执行指令，总线和 I/O 把机器和外面接起来。

9数据的表示与运算选择每年 3–4 题 · 大题 4 年 · 第16话 第17话 第18话

同一串位，戴不同的眼镜读出不同的数：当无符号数读、当补码读、当浮点数读。机器只管加位，「溢出」是人戴着有符号眼镜看才发现的问题。

必背

  • n 位补码范围−2n−1 ～ 2n−1−1
  • 求负数的补码正数原码按位取反再加 1
  • 有符号溢出 OF两个同号数相加，结果符号变了；等价于最高位进位 ⊕ 次高位进位
  • 无符号溢出 CF加法看最高位有没有进位；减法看有没有借位
  • 等长的有符号与无符号互相赋值位模式不动，只换读法；负数当无符号读要加 2ⁿ
  • 短数扩成长数无符号补 0，有符号补符号位
  • IEEE 754 单精度1 位符号、8 位阶码（偏置 127）、23 位尾数，值 = (−1)S × 1.M × 2E−127
  • 阶码全 0 / 全 1全 0 是 0 或非规格化数；全 1 是无穷大或 NaN
  • 逻辑右移 / 算术右移补 0 ／ 补符号位；左移两者都补 0
  • CPU 时间指令条数 × CPI × 时钟周期 = 指令条数 × CPI ÷ 主频

题眼

  • 加减法问 OF、CF同一串位按两种眼镜各算一遍：OF 看有符号，CF 看无符号（考过 6 次）
  • 十六进制串问浮点值先拆出阶码，看是不是全 0 或全 1，再套公式（5 次）
  • n 位乘法取低 n 位，问是否溢出无符号：高 n 位全 0 才不溢出；有符号：高 n+1 位全相同才不溢出（4 次）

大题开头照写（数据表示）

题眼

  • Cache 任何问题第一步把主存地址切成「标记 | 组号 | 块内地址」（考过 12 次）
  • 数组遍历问缺失次数先算一块装几个元素；按行遍历每块缺失 1 次，按列遍历可能每次都缺失（6 次）

12CPU：数据通路与流水线大题 4 年 · 选择每年 2 题 · 第21话 第22话

  • 三种冒险结构（抢同一部件）、数据（后一条要读前一条还没写回的寄存器）、控制（转移）

13总线与 I/O 方式选择每年 3 题 · 大题 3 年 · 第38话 第39话

14OS 骨架：中断、内核态、系统调用选择每年 2–3 题 · 第23话 第24话

用户程序是乘客，OS 是司机。乘客想下车（读文件、申请内存）不能自己去踩刹车，只能按铃（系统调用、陷入指令），司机接手后才动刹车（内核态）。

必背

  • 外中断 / 异常外中断来自 CPU 外部（I/O、时钟），与当前指令无关；异常由当前指令引起
  • 异常返回到哪故障（如缺页）返回到引起它的那条指令重新执行；陷入（如系统调用）返回到下一条
  • 特权指令只能在内核态执行，如开关中断、设置时钟、I/O 指令、修改页表基址
  • 从用户态进内核态唯一途径是中断或异常（包括 trap 指令）
  • 陷入指令本身在用户态执行

题眼

  • 判断外中断、故障还是陷入看是谁触发的、处理完回到哪一条（考过 9 次）
  • 「中断处理中哪一步是硬件做的」硬件只做三件事：关中断、保存断点、找入口；保存其他寄存器以后都是 OS（6 次）
  • 「哪条指令只能在内核态执行」它会不会影响别的进程或整个系统（4 次）

15进程、线程与调度选择每年 3 题 · 第25话 第26话

16同步互斥与 PV 大题大题 10 年 · 2024、2025 都考 · 第27话 第28话

信号量是一个计数器加一个排队的地方。P 是「拿一张票，没票就去排队」，V 是「还一张票，有人排队就叫醒一个」。互斥是只有一张票的门；同步是「我做完了给你发一张票，你才能开始」。

必背

  • P(S)S−1；若 S < 0，进程阻塞排队
  • V(S)S+1；若 S ≤ 0，唤醒一个排队的进程
  • 互斥信号量初值 / 同步信号量初值1 ／ 0（或资源的初始个数）
  • 互斥四准则空闲让进、忙则等待、有限等待、让权等待；前三条必须满足
  • P 的顺序先 P 同步信号量（如 empty、full），再 P 互斥信号量（mutex），反过来会死锁
  • 生产者消费者empty 初值 = 缓冲区大小，full 初值 0，mutex 初值 1
  • 读者写者（读者优先）count 记录读者数，第一个读者 P(rw)，最后一个读者 V(rw)，count 本身用 mutex 保护
  • 前驱图每条边 a→b 设一个初值 0 的信号量：a 做完 V，b 开始前 P

题眼

  • 「互斥访问」「只能一个」一个初值为 1 的 mutex，临界区前后 P、V
  • 「A 做完 B 才能做」一个初值为 0 的信号量：A 后 V，B 前 P（前驱图考过 2 次）
  • 「最多 n 个同时」「既不死锁又尽量多并发」一个初值为 n 的计数信号量当门票，先 P 它再拿其他资源（2 次）
  • 有界缓冲区生产者消费者模子：empty、full、mutex 三个

PV 大题照写

  1. 写「设信号量：mutex=1，用于…的互斥；empty=n，表示…；full=0，表示…」。每个信号量写清含义和初值，这一段 2–3 分。
  2. 按进程分别写 process A(){ while(1){ … } }，先写不带 PV 的动作。
  3. 在每个「要用公共资源」的动作前加 P、后加 V；同步关系按「谁先做谁 V」加。
  4. 检查一遍：同步的 P 在互斥的 P 前面；每个 P 都有对应的 V。

每个进程都拿着一部分资源又在等别人的，就会死锁。

17死锁与银行家算法选择每年 1–2 题 · 第29话

四辆车同时开进一个十字路口，每辆都占着一个角、等着前面那个角，谁也走不了。死锁的四个条件缺一个就不会发生，预防就是去掉其中一个。

必背

  • 四个必要条件互斥、请求并保持、不可剥夺、循环等待
  • n 个进程各需 k 个资源，不死锁的最少资源数m = n(k−1)+1，即 m > n(k−1)，注意是严格大于
  • 银行家算法第一步Need = Max − Allocation
  • 安全性检查Work = Available，找一个 Need ≤ Work 的进程，Work += 它的 Allocation（不是 Max），直到全部完成
  • 不安全状态不一定已经死锁，只是可能死锁
  • 预防 / 避免 / 检测预防破坏条件；避免靠银行家；检测靠资源分配图化简

题眼

  • 「至少几个资源不会死锁」每人先给 k−1 个，再多给 1 个（考过 2 次，坑都在等号上）
  • 银行家表格题先算 Need 和 Available，再用 Work 推进，写出安全序列（5 次）

18内存管理与虚拟内存大题 9 年 · 选择每年 3 题 · 第32话 第33话 第34话

分页是把内存切成一样大的格子，进程也切成同样大的页，页可以随便放进任何格子，页表记录「第几页放在第几格」。虚拟内存是只把正在用的页放进内存，其余留在磁盘，用到了再搬（缺页）。TLB 是页表的「书桌」，和 Cache 是同一个思路。

  • 缺页处理缺页是异常（故障），处理完重新执行引起缺页的那条指令
  • FIFO / LRU / OPT换最早进来的 ／ 换最久没用的 ／ 换以后最晚用到的；只有 FIFO 有 Belady 异常
  • CLOCK访问位为 1 就清 0 跳过，遇到 0 就换掉
  • 改进 CLOCK按 (访问位, 修改位) 依次找 (0,0)，再找 (0,1) 并把经过的访问位清 0，循环
  • 抖动分给进程的页框太少，刚换出就要用，频繁缺页

卷四 计算机网络

主线：数据离开这台机器。物理层把位变成信号；链路层负责一段线上的两台机器能可靠说话；网络层负责跨很多段线找到对方（IP、路由）；传输层负责两个进程之间不丢不乱（TCP）；应用层是人真正用的那些服务。

20体系结构与物理层选择每年 2–3 题 · 第41话 第42话

发送时延是把一车货全部装上车的时间（与数据量和带宽有关）；传播时延是车在路上开的时间（与距离有关）。奈氏定理说的是「一条路最多能开多少种车」，香农定理说的是「路上有噪声时最多能拉多少货」。

必背

  • 发送时延 / 传播时延数据长度 ÷ 带宽 ／ 距离 ÷ 传播速度
  • 分组交换发完 m 个分组、经过 k 段链路(k+m−1) × 每个分组的发送时延（另加传播时延），k 数的是链路段数
  • 奈氏准则最大速率 = 2W × log₂V（W 带宽，V 状态数）
  • 香农定理最大速率 = W × log₂(1+S/N)；dB 换算 S/N = 10dB/10
  • 两个都给取较小的那个
  • OSI 七层 / TCP/IP 四层物理、链路、网络、传输、会话、表示、应用 ／ 网络接口、网际、传输、应用
  • 曼彻斯特编码每个码元中间必有一次跳变

题眼

  • 求信道最大速率给状态数用奈氏，给信噪比用香农，都给取小（考过 5 次）
  • 问某协议或设备属于哪一层看它解决什么问题，别看名字（5 次）

21链路层：可靠传输与介质访问选择每年 4–5 题 · 大题 3 年 · 第43话 第44话

停等协议是寄一封信、等回信才寄下一封，线路大部分时间空着。滑动窗口是一口气寄好几封再等回信。CSMA/CD 是开会时先听有没有人在说话，同时开口了就都停下、各等一会儿再说。

必背

  • 停等协议信道利用率发送时间 ÷ (发送时间 + RTT + 确认帧发送时间)，确认帧小时忽略
  • 滑动窗口利用率min(1, 窗口数 × 发送时间 ÷ 一个发送周期)
  • 序号 k 位时窗口上限停等 1；GBN 发送窗口 ≤ 2k−1；SR 发送窗口和接收窗口都 ≤ 2k−1
  • CSMA/CD 最短帧长2 × 传播时延 × 数据率；以太网最短帧 64B
  • 争用期2τ，以太网争用期是 512 位的发送时间
  • 冲突域 / 广播域集线器不隔冲突也不隔广播；交换机每个端口一个冲突域；路由器隔广播域
  • 交换机按 MAC 地址表转发，学习源地址，目的未知就广播

题眼

  • 信道利用率先画一个发送周期：从开始发第一帧到收到确认，再看这期间真正在发数据的时间（考过 7 次）
  • 窗口最大能取多少停等 1、GBN 2k−1、SR 2k−1（5 次）
  • 数冲突域和广播域从每台设备的端口往下看（5 次）

大题开头照写（链路层）

  1. 写出数据率、帧长、传播时延，算「发送一帧时间 = 帧长 ÷ 数据率 = …」。
  2. 写「一个发送周期 = 发送时间 + 2 × 传播时延（+ 确认帧时间）= …」。
  3. 写「利用率 = …」，再按题问的窗口数调整。

一段线解决了。跨过很多段线、找到地球另一边的主机，是网络层的事。

22网络层：IP、子网、NAT、路由大题 8 年 · 2024、2025 都考 · 第45话 第46话 第47话

IP 地址像「城市 + 门牌号」：子网掩码说清前面几位是城市（网络号）。路由器只看城市往哪走，到了城市再按门牌送。NAT 是公司前台：对外所有人用同一个总机号，前台记着哪通电话转给谁。

必背

  • 网络地址IP 地址与子网掩码按位与
  • 可分配主机地址数2主机位数 − 2（全 0 网络地址、全 1 广播地址）
  • /30 子网4 个地址，2 个可用，正好给点对点链路两端
  • 等分 N 个子网子网位 = log₂N，从主机位里借
  • 路由聚合把几个网络地址展开成二进制，数公共前缀位数
  • 最长前缀匹配多条路由都匹配时选前缀最长的
  • IP 首部固定 20B；TTL 每过一个路由器减 1；首部长度单位 4B，片偏移单位 8B
  • IP 分片除最后一片外，每片数据长度是 8 的倍数，MF=1
  • NAT出去改源地址和端口，进来改目的地址和端口；外部要主动访问内部，得配静态映射
  • ARP由 IP 查 MAC，请求广播、应答单播；只在一个局域网内用
  • RIP / OSPF / BGP距离向量、跳数最多 15、UDP ／ 链路状态、Dijkstra、直接用 IP ／ 自治系统之间、TCP
  • DHCP客户端用 0.0.0.0 发广播，服务器用 UDP 67、客户端 68

题眼

  • 求网络地址、网关、是否同网段只把掩码不是 0 也不是 255 的那个字节写成二进制（考过 5 次）
  • NAT 表出站改源、入站改目的（6 次）
  • 几条路由求聚合展开不同的那一字节，数公共前缀（4 次）
  • 问某段链路上帧的源、目的地址MAC 地址每一跳都换，IP 地址端到端不变（3 次）

大题开头照写（IP）

  1. 把相关的 IP 和掩码写出来，标明前缀长度。
  2. 写「网络地址 = IP ∧ 掩码 = …」，逐个给出。
  3. 子网划分写「需 N 个子网 ⟹ 借 … 位 ⟹ 每个子网 … 个地址，可分配 … 个」，再列出每个子网的地址范围。
  4. 路由表按「目的网络 | 掩码 | 下一跳 | 接口」四列写，默认路由写 0.0.0.0/0。

网络层只管把分组送到那台主机；送到哪个进程、丢了怎么办，是传输层的事。

23传输层：TCP选择每年 3–4 题 · 大题 2 年 · 第48话 第49话

TCP 是打电话：先拨号确认对方在（三次握手），说话时每句都要对方回「收到」，挂电话要双方各说一次再见（四次挥手）。拥塞控制是开车：刚上路慢慢加速（慢开始，翻倍），快到经验速度时改成一点点加（拥塞避免），一出事故就踩刹车。

必背

  • 三次握手SYN → SYN+ACK → ACK；SYN 和 FIN 各占一个序号，纯 ACK 不占
  • 确认号期望收到的下一个字节的序号
  • 发送窗口min(rwnd, cwnd)，再减去已发出未确认的
  • 慢开始每过一个 RTT，cwnd 翻倍，但不超过 ssthresh
  • 拥塞避免cwnd ≥ ssthresh 后，每个 RTT 加 1
  • 超时ssthresh = cwnd/2，cwnd = 1，重新慢开始
  • 收到 3 个重复 ACKssthresh = cwnd/2，cwnd = 新 ssthresh，直接进入拥塞避免（快恢复）
  • TIME_WAIT主动关闭方最后要等 2MSL
  • UDP 首部 / TCP 首部8B ／ 20B 起

题眼

  • 拥塞窗口变化逐个 RTT 列表写 cwnd 和 ssthresh（考过 8 次）
  • TCP 序号和确认号SYN、FIN 各占一个序号，数据按字节编号（7 次）
  • 还能发多少数据窗口从确认号开始，长度 min(rwnd, cwnd)，再扣掉已发的（5 次）

大题开头照写（拥塞窗口）

  1. 画一张表，列是「第几个 RTT | cwnd | ssthresh | 阶段」。
  2. 第一行写初始值；每行按规则推一步，阶段写「慢开始」或「拥塞避免」。
  3. 遇到超时或 3 个重复 ACK 单独写一行，写明 ssthresh 和 cwnd 的新值。
