408真题套卷术式录

算法题速成

每年第 41 题左右，13–15 分。代码能力一般也能稳拿 8–10 分，做法是不追最优解，只把一个能跑对的解写完整。这一页只有四样东西：给分方式、拆题四步、六个骨架、十八年对照表。全部代码都经过 gcc 编译和两万轮随机对拍。

一、这道题怎么给分

卷面三段大约占写什么
基本设计思想3–4 分三四句话，说清「用什么结构、扫几遍、每一步做什么」。不要求最优。
C 代码＋注释7–9 分函数写完整，关键行写注释。阅卷看的是逻辑对不对，小的语法瑕疵一般不扣。
时间、空间复杂度1–2 分照自己写的代码说，写对就给分。

具体分值每年略有不同，但规律稳定：正确的次优解，比写错的最优解分高。按往年评分惯例，正确但复杂度次优的解一般最高给到 10 分左右；写了最优解的思想但代码有大错，往往只有思想那几分。所以顺序是：先把保底解三段写全（约 12 分钟），有剩余时间再在思想里补一句最优解的想法。

考场规矩：想最优解不超过 3 分钟。3 分钟没思路，立刻写保底解。这 13 分里你要的是前 9 分。

二、拆题四步

  1. 圈数据结构，选骨架。题干里只会出现四种：数组、链表、二叉树、图。看到哪种，就拿下面对应的骨架，循环框架不用现想。
  2. 问自己「最笨的办法是什么」。数组题：对每个元素再扫一遍全数组；或者先排序。链表题：先遍历一遍数长度；或者把结点搬进数组。树题：递归，每个结点做同一件事。图题：邻接矩阵按行、按列加一遍。
  3. 往骨架里填一句话：「对每个元素（结点、顶点）做什么」。整道题真正要你想的只有这一句。
  4. 三段写卷面。思想照「用……存……；第一遍……；第二遍……；最后返回……」的句式写；复杂度照代码数循环层数。

三、六个骨架

每个骨架先给画面，再给一道真题的完整代码。背的时候先在草稿纸上画出画面，再默代码。

骨架 1　数组 ＋ 标记数组（一遍打标、一遍找）

画面：旁边放一排空抽屉，编号 0 到 n。扫原数组，看到数字 x 就在第 x 号抽屉里放一张纸条。扫完再从头看抽屉，第一个空的就是答案。
什么时候用：题干出现「是否出现过」「未出现的最小」「重复」「|data| ≤ n」——凡是取值范围有上限的，都可以拿数值当下标。
2018 年第 41 题 · 这就是参考答案的做法
int findMissMin(int A[], int n) {            // 2018：找没出现过的最小正整数
    int i, *B = (int *)malloc(sizeof(int) * (n + 1));
    for (i = 0; i <= n; i++) B[i] = 0;       // 标记数组清零
    for (i = 0; i < n; i++)                  // 一遍扫描：只关心 1..n 的数
        if (A[i] >= 1 && A[i] <= n) B[A[i]] = 1;
    for (i = 1; i <= n; i++)                 // 再扫标记：第一个没标的就是答案
        if (B[i] == 0) break;
    free(B);
    return i;                                // 1..n 全出现过时 i 正好是 n+1
}

复杂度：时间 O(n)，空间 O(n)。

骨架 2　数组 ＋ 多重循环打擂台（纯暴力）

画面：让每个人和所有人都比一次，手里一直攥着目前最好的那个结果。
什么时候用：题目要「最大、最小、所有可能的组合里……」，又想不到巧办法时。几个数组就几重循环。
2020 年第 41 题 · 保底解
int minDist(int A[], int n1, int B[], int n2, int C[], int n3) {   // 2020 保底解
    int i, j, k, d, min = 0x7fffffff;
    for (i = 0; i < n1; i++)                 // 三重循环：每个三元组都算一遍
        for (j = 0; j < n2; j++)
            for (k = 0; k < n3; k++) {
                d = abs(A[i] - B[j]) + abs(B[j] - C[k]) + abs(C[k] - A[i]);
                if (d < min) min = d;        // 打擂台，留最小的
            }
    return min;
}

复杂度：时间 O(n₁n₂n₃)，空间 O(1)。最优解的一句话（写在思想末尾可以多拿一两分）：三个指针各指一个数组，每次只把三个数里最小的那个的指针后移，因为距离其实等于 2×(最大−最小)，只有抬高最小值才可能变小。

2025 年第 41 题 · 保底解
void calMulMax(int A[], int res[], int n) {  // 2025 保底解
    int i, j;
    for (i = 0; i < n; i++) {                // 对每个 A[i]
        res[i] = A[i] * A[0];
        for (j = 1; j < n; j++)              // 和每个 A[j] 乘一遍，打擂台
            if (A[i] * A[j] > res[i]) res[i] = A[i] * A[j];
    }
}

复杂度：时间 O(n²)，空间 O(1)。最优解的一句话：先扫一遍记下全数组的最大值和最小值；A[i] 为正就乘最大值，为负就乘最小值，两个乘积取大的。

骨架 3　链表：p 停在前一个结点上

画面：手指 p 永远按在「待检查结点」的前一个上。要留，手指往后挪一格；要删，手指不动，把后面那个摘掉。
为什么：单链表删结点必须知道它的前驱。让 p 停在前一个，就不用另外维护前驱指针。
什么时候用：链表上的删除、去重、按条件过滤。
2015 年第 41 题 · 骨架 3 ＋ 骨架 1，就是最优解
void delAbsDup(PNODE h, int n) {             // 2015：带头结点，|data| ≤ n
    int m, *B = (int *)malloc(sizeof(int) * (n + 1));
    PNODE p = h, r;                          // p 永远停在「待查结点」的前一个
    for (m = 0; m <= n; m++) B[m] = 0;
    while (p->link != NULL) {
        m = p->link->data > 0 ? p->link->data : -p->link->data;
        if (B[m] == 0) { B[m] = 1; p = p->link; }          // 第一次见：留下，p 前进
        else { r = p->link; p->link = r->link; free(r); }   // 见过：删掉，p 不动
    }
    free(B);
}

复杂度：时间 O(m)（m 为结点数），空间 O(n)。

骨架 4　二叉树：递归三行

画面：站在任意一个结点上，只回答三个问题：我是空的吗（返回什么）；我自己要做什么；把左、右两边的结果怎么合起来。别去想整棵树。
要往下带信息（深度、范围）就加一个参数；要按顺序比较（判 BST）就用中序，外面放一个变量记上一个值。
2014 年第 41 题 · 往下带一个深度参数
int wplPre(BiTree t, int deep) {             // 2014：deep 是当前结点的深度（根为 0）
    if (t == NULL) return 0;                 // 空树贡献 0
    if (t->left == NULL && t->right == NULL) // 叶子：权值 × 深度
        return t->weight * deep;
    return wplPre(t->left, deep + 1) + wplPre(t->right, deep + 1);   // 左右相加
}
int WPL(BiTree root) { return wplPre(root, 0); }
2022 年第 41 题 · 顺序存储也是同一个递归，孩子下标是 2i+1、2i+2
int pre;                                     // 中序遍历中「上一个访问到的值」
int inOrder(SqBiTree *T, int i) {            // 2022：下标 i 的左孩子 2i+1、右孩子 2i+2
    if (i >= T->ElemNum || T->SqBiTNode[i] == -1) return 1;   // 空树算 BST
    if (!inOrder(T, 2 * i + 1)) return 0;    // 左子树不是，整棵就不是
    if (T->SqBiTNode[i] <= pre) return 0;    // 中序必须严格递增
    pre = T->SqBiTNode[i];
    return inOrder(T, 2 * i + 2);
}
int isBST(SqBiTree *T) { pre = 0; return inOrder(T, 0); }     // 结点值全为正，pre 从 0 起

两题复杂度都是：时间 O(n)，空间 O(h)（递归栈，h 为树高）。

骨架 5　图：邻接矩阵两重循环

画面：一张方格表。横着加一行＝这个顶点的出度，竖着加一列＝入度；无向图横竖一样，一行的和就是度。
什么时候用：2021、2023、2024 连续三年都是它。题干只要给了 MGraph 的定义，先把这两重循环写上。
2023 年第 41 题
int printVertices(MGraph G) {                // 2023：出度大于入度的顶点
    int i, j, out, in, cnt = 0;
    for (i = 0; i < G.numVertices; i++) {
        out = in = 0;
        for (j = 0; j < G.numVertices; j++) {
            out += G.Edge[i][j];             // 第 i 行的和 = 出度
            in  += G.Edge[j][i];             // 第 i 列的和 = 入度
        }
        if (out > in) { printf("%c ", G.VerticesList[i]); cnt++; }
    }
    return cnt;
}
2021 年第 41 题
int IsExistEL(MGraph G) {                    // 2021：奇度顶点个数为 0 或 2
    int i, j, deg, odd = 0;
    for (i = 0; i < G.numVertices; i++) {
        deg = 0;
        for (j = 0; j < G.numVertices; j++) deg += G.Edge[i][j];   // 无向图：一行的和 = 度
        if (deg % 2 == 1) odd++;
    }
    return odd == 0 || odd == 2;
}

两题复杂度都是：时间 O(n²)，空间 O(1)。2024 年（拓扑序是否唯一）是同一个模子多套一层：每一轮按列数出入度为 0 且没删过的顶点，恰好一个才继续，否则返回 0。

骨架 6　不会就先排序

画面：把一堆乱牌先理成从小到大，很多问题就变成「看中间那张」「前一半和后一半」。
什么时候用：主元素、中位数、划分成两半这类数组题的保底。插入排序六行，默下来随时可用。
工具：直接插入排序 ＋ 2013 年第 41 题保底解
void insertSort(int A[], int n) {            // 工具：直接插入排序，升序
    int i, j, t;
    for (i = 1; i < n; i++) {
        t = A[i];
        for (j = i - 1; j >= 0 && A[j] > t; j--) A[j + 1] = A[j];   // 比 t 大的往后挪
        A[j + 1] = t;
    }
}
int majority(int A[], int n) {               // 2013 保底解：排序后，主元素一定压在正中间
    int i, c = 0, x;
    insertSort(A, n);
    x = A[n / 2];
    for (i = 0; i < n; i++) if (A[i] == x) c++;   // 再数一遍确认
    return c > n / 2 ? x : -1;
}

复杂度：时间 O(n²)，空间 O(1)。2016 年（划分成两半使和之差最大）同理：排序后前 ⌊n/2⌋ 个归一组，其余归另一组。

五、卷面套话

思想：「算法的基本设计思想：用（标记数组 B / 指针 p / 递归函数 f）……。（1）先……；（2）再……；（3）最后返回……。」
复杂度：「算法的时间复杂度为 O(…)，空间复杂度为 O(…)。」一重循环 O(n)，两重 O(n²)；开了和 n 有关的辅助数组是 O(n)，递归写 O(h) 或 O(n)，否则 O(1)。
注释：每个循环上面写一句「这一遍在做什么」，判断分支后面写「什么情况」。有注释，代码有小错也容易拿到思路分。

六、怎么练（六天，每天 25 分钟）

  1. 每天一个骨架：先画画面，再合上页面默写代码，对照改错。
  2. 再从对照表里挑两年，只写保底解的三段卷面，每题限时 12 分钟。
  3. 套卷里遇到算法题，一律先写保底解；交卷后看精解里的最优解，只记那一句话。
