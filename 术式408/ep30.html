这一卷只回答一个问题：快的存储小而贵，慢的存储大而便宜，怎么让机器看起来又快又大。答案是分层加局部性。这一话先把最底下的硬件讲清楚：一块内存到底长什么样，怎么接到 CPU 上。

其之壹为什么要分层

CPU 执行一条指令是纳秒级，主存读一次要几十纳秒，磁盘读一次要几毫秒，差距是几十倍到百万倍。如果 CPU 每次都直接等主存，它一大半时间都在空转。全用最快的器件又贵到装不起。

出路是把少量快存储放在 CPU 旁边，把常用的东西放进去，不常用的放远处。这能成立，靠的是程序的一个规律。

术式
程序的局部性

时间局部性：刚访问过的，很快还会再访问（循环变量、循环里的指令）。
空间局部性：访问了某地址，很快会访问它附近（数组、顺序执行的指令）。

相邻两层之间，上层放的是下层的一部分副本。其中两对最要紧：

  • Cache—主存：解决速度。全由硬件管，程序员看不见。
  • 主存—辅存：解决容量。硬件和操作系统一起管，这就是虚拟内存。
因果

跨科第一枢纽

局部性原理 → Cache / TLB / 页面置换 LRU / 磁盘预读。这些机制之所以有效，理由都是同一个。

其之貳存储器怎么分类、用什么指标衡量

按存取方式分，这是最容易混的一组：

方式怎么找数据存取时间和位置的关系例子
随机存取 RAM直接按地址选中和地址无关SRAM、DRAM
只读存储 ROM同样按地址随机读和地址无关，只是通常不改写BIOS 芯片
顺序存取从头一路走到那儿和位置有关磁带
直接存取先定位到一小片，再在片内顺序找介于两者之间磁盘
相联存取按内容比对，不按地址所有项同时比TLB、Cache 的标记比较

ROM 这个名字容易误导。它也是随机存取，「只读」说的是能不能随便改，不是怎么找。U 盘和 SSD 用的 Flash 就属于这一家族，只是能电擦写。CD-ROM 虽然名字带 ROM，却是光盘，靠旋转定位，不是随机存取。

三个指标：

  • 存储容量 = 存储字数 × 字长。
  • 存取时间：从发出读命令到数据就绪。
  • 存取周期：连续两次独立读写之间的最小间隔。存取周期 大于 存取时间，多出来的部分是恢复时间（DRAM 读完要写回，尤其明显）。

还有一个概念要分开：地址线的条数取决于地址空间，不取决于实际插了多少内存。地址空间 64 MB、按字节编址，就要 26 位，哪怕只插了 32 MB。

其之參SRAM、DRAM、Flash

这三种的区别都能从「存一位用什么」推出来。

SRAM 用触发器存一位，要 6 个晶体管。只要通电，状态就一直保持，读出也不破坏，所以快；但占地大，容量做不大。于是拿来做 Cache。

DRAM 用一个电容存一位（电容有电表示 1），只要 1 个晶体管，密度高、便宜，做主存。代价有两个：

  1. 电容会漏电，所以要定期刷新，通常 2 ms 内要把所有行刷一遍。刷新按行进行。
  2. 读的时候电容放电，信息就没了（破坏性读出），必须马上写回去（再生）。这就是它存取周期长的原因。

Flash 用浮栅晶体管，断电不丢。读很快，但写之前必须先擦除，而且只能整块擦，所以写慢。

DRAM 的地址复用

DRAM 容量大，地址位数多。为了少占芯片引脚，把地址分两次送：先送行地址（行选通 RAS），再送列地址（列选通 CAS），用同一组引脚。

术式
DRAM 引脚怎么算

地址引脚 = ⌈地址位数 / 2⌉（复用，减半）。数据引脚 = 每单元位数。
行列怎么分：行列尽量接近，让引脚最少；不能完全相等时行数取少的，因为刷新按行，行少刷新快。

算一遍：一块 1M×8 位的 DRAM，地址 20 位，复用后 10 根；数据 8 根；共 18 根引脚（不算电源和控制）。而一块 2K×1 的芯片，地址 11 位：行 5 位、列 6 位，所以 32 行 64 列，地址引脚 6 根。

合上页面说一遍：DRAM 和 SRAM 差在哪？为什么 DRAM 要刷新？为什么地址引脚能减半？

SRAM 用触发器，不刷新、读不破坏、快、贵，做 Cache。DRAM 用电容，会漏电所以要刷新，读会放电所以要再生，便宜，做主存。地址分行列两次送，同一组引脚用两次，所以减半。

刷新的三种安排

方式怎么排特点
集中刷新攒到周期末尾一口气刷完有一段「死区」不能读写
分散刷新每次读写后顺带刷一行没有死区，但存取周期变长一倍
异步刷新把 2 ms 均分给各行，定时刷一行前两者折中，最常用
再深一层：内存条、SDRAM 和行缓冲

行缓冲：DRAM 读一行时，整行都被读到一个 SRAM 缓冲里。如果下一次还访问这一行，只送列地址即可，快很多。这也是空间局部性的一次应用。 SDRAM：同步 DRAM，读写由统一时钟控制，CPU 发出命令后可以先做别的事，到点再取。支持突发传输，给一次首地址，连续传多个字。DDR 在时钟上下沿都传数据，同样频率下速率翻倍。 内存条：多块 DRAM 芯片焊在一块板上，共同组成一个更宽的存储器，数据线通常 64 位。下面讲的位扩展就是它的原理。

其之肆多模块存储器

CPU 比 DRAM 快太多，又换不了器件，就用并行来补。

比方

四个仓库管理员

单体多字：一个管理员一次搬四件。搬得多，但四件必须都用得上。 低位交叉：四个管理员，货号连续的货分给不同的人。你要连续的货时，第一个人还没搬完，第二个人已经出发了，货一件接一件地到。

单体多字：一个模块，一次读出多个字。要求指令和数据都连续存放才划算。

高位交叉：高位选模块，连续地址落在同一个模块里。它只扩容量，不提速。

低位交叉：低位选模块，模块号 = 地址 % m。连续地址依次落在不同模块上，可以错开启动。

算一遍：四体低位交叉，每个模块存取周期 T = 200 ns，总线传一个字 r = 50 ns。第一个字 200 ns 到手，之后每隔 50 ns 到一个。连续读 8 个字用 200 + 7×50 = 550 ns。如果是单个模块，要 8×200 = 1600 ns。

术式
低位交叉公式

连续读 n 个字：T + (n−1)·r。理想情况 r = T / m。
访问冲突：相邻不足 m 次的两次访问落到同一模块，后者要等前者的周期结束。

判断冲突只看地址 % m。比如四体下，访问 1、5：都在模块 1，相隔不到 4 次，后者要等。

双口 RAM 是另一种并行：一块存储器有两组独立的地址、数据线，两个 CPU 可以同时访问不同单元；访问同一单元时才要排队。

合上页面说一遍：低位和高位交叉谁能提速？连续读 n 个字要多久？什么算冲突？

低位提速，高位只扩容。T+(n−1)r。相邻不足 m 次访问了同一模块就冲突。

其之伍主存和 CPU 怎么连

单片芯片的容量和位数都不够，要拼。三根线束：地址线选单元，数据线传数据，控制线（读写、片选）说干什么。

  • 位扩展：单元数够，位数不够。地址线、片选全部并联，每片接数据线的一段。这几片同时工作。
  • 字扩展：位数够，单元数不够。数据线并联，低位地址并联，高位地址经译码器选其中一片。任一时刻只有一片工作。
  • 字位同时扩展：先拼成一「组」（位扩展），再选组（字扩展）。

完整走一遍：用 2K×4 的芯片组成 8K×8。

术式
扩展四步

① 片数 = 总容量 ÷ 单片容量。
② 位方向 每组几片；字方向 几组。
③ 地址：低位接芯片（log₂单片单元数），高 ⌈log₂组数⌉ 位译码。
④ 控制：CPU 的 MREQ# 接译码器使能，保证 CPU 访问 I/O 时不会误选内存。

咒灵
ROM 和 RAM 混装

ROM 区和 RAM 区要分别算片数。主存常常低地址放 ROM（比如引导程序），其余放 RAM，两边用的芯片规格可以不同，算的时候按区域分开除。

合上页面说一遍：位扩展和字扩展，哪些线并联、哪些不并联？

位扩展：地址、片选都并联，数据分段接，所有片同时工作。字扩展：数据并联、低位地址并联，高位地址译码产生片选，每次只有一组工作。

领域展开

局部性：时间 + 空间；整个存储体系的基础。
DRAM：电容、破坏读、按行刷新、地址复用减半（行取少）。
低位交叉：T+(n−1)r；相邻不足 m 次同模块就冲突。
扩展：片数 = 总容量 ÷ 单片；高位地址译码选组。

2017實戰数组访问的两种局部性判别
某 C 语言程序段如下，下列关于数组 a 的访问局部性的描述中，正确的是（　）。
for(i = 0; i <= 9; i++){
    temp = 1;
    for(j = 0; j <= i; j++)
        temp *= a[j];
    sum += temp;
}

时间局部性是指最近的未来要用到的信息，很可能是现在正在使用的信息。本题的外层循环每次都会访问一次数组 a，体现了时间局部性。空间局部性是指最近的未来要用到的信息，很可能与现在正在使用的信息在存储空间上是邻近的。本题在访问数组 a 的过程中是顺序访问的，体现了空间局部性。
数组 a 被反复访问（时间）且下标顺序（空间），都有。
再深一层
选 A（两种局部性都有）。把循环展开看一眼，两种局部性一目了然：
i = 0：访问 a[0]
i = 1：访问 a[0], a[1]
i = 2：访问 a[0], a[1], a[2]
…
i = 9：访问 a[0] … a[9]

【空间局部性】每一轮内层循环都是 a[0]→a[1]→a[2]… 顺序走 ✔
【时间局部性】a[0] 被访问了 10 次，a[1] 被访问 9 次…… 反复重访 ✔
📌 与 3.5-06 对照，本题的关键差别在外层循环让内层重新来一遍：
3.5-06（单层遍历 v[N]）本题（三角形嵌套）
数组访问模式每个元素只碰一次前面的元素被反复碰
空间局部性有（顺序）有（顺序）
时间局部性无有 ✔
⟹ 判"有没有时间局部性"就问一句：同一个元素会不会被访问第二次？
📌 本题里 temp、sum、i、j 都是标量，通常分配在寄存器中，不参与 Cache 讨论——题目问的就是"数组 a 的访问局部性"，只看 a。
⚠️ C 项"无空间局部性"是最容易误选的：有人觉得"每轮都从 a[0] 重新开始，跳回去了，所以空间局部性差"。但空间局部性看的是一段时间内访问的地址是否集中——本题全程只在 a[0..9] 这十个相邻元素上打转，集中度极高，空间局部性反而很好。
2011實戰随机存取方式的判定 · CD-ROM 不是 ROM
下列各类存储器中，不采用随机存取方式的是（　）。

随机存取是指 CPU 可对存储器的任意一个存储单元中的内容随机存取，而且存取时间与存储单元的物理位置无关。选项 A、C、D 均采用随机存取方式，CD-ROM 即光盘，采用串行存取方式（直接存取）。注意：CD-ROM 是只读型光盘存储器，不属于只读存储器（ROM）。
CD-ROM 是光盘，串行存取。
再深一层
选 B。这题专治"看名字下结论"——CD-ROM 名字里有 ROM，却既不是 ROM，也不是随机存取。
CD-ROM = Compact Disc Read-Only Memory
  它是【光盘】：靠激光头沿螺旋光轨移动读取
  → 先移动光头到大致位置（随机），再顺着轨道等（顺序）
  → 属于【直接存取 DAM】，和机械磁盘同类
  → 存取时间【取决于数据在盘上的位置】 ⟹ 不是随机存取
📌 本题与 3.1-01（磁盘属于 DAM）是同一条判据的两次考查：凡是靠"机械运动定位"的介质（磁盘、光盘、磁带），存取时间必然与位置有关，一律不是随机存取。半导体存储器（EPROM/DRAM/SRAM/Flash）才是随机存取。
⚠️⚠️ 书上专门加了一句"CD-ROM 不属于只读存储器（ROM）"，这是个容易被跳过的细节：ROM 特指半导体只读存储器（MROM/PROM/EPROM/E²PROM/Flash）；CD-ROM 是光介质，只是恰好也只读。
📌 把"随机存取"的定义原句记牢（真题解析里逐字给了）："CPU 可对任意一个存储单元随机存取，且存取时间与存储单元的物理位置无关"。做这类题时，就拿"存取时间与位置有没有关系"这一把尺子去量，不看名字。
2010實戰RAM 与 ROM 的辨析
下列有关 RAM 和 ROM 的叙述中，正确的是（　）。
Ⅰ. RAM 是易失性存储器，ROM 是非易失性存储器
Ⅱ. RAM 和 ROM 都采用随机存取方式进行信息访问
Ⅲ. RAM 和 ROM 都可用作 Cache
Ⅳ. RAM 和 ROM 都需要进行刷新

RAM（分 DRAM 和 SRAM）断电后会失去信息，ROM 断电后不会丢失信息，故 Ⅰ 正确；它们都采用随机存取方式，故 Ⅱ 正确。Cache 一般采用高速 SRAM 制成，而 ROM 只读，不能用作 Cache，故 Ⅲ 错误；DRAM 需要定期刷新，而 ROM 不需要刷新，故 Ⅳ 错误。
ROM 不能作为 Cache（因为要写）。
再深一层
选 A。2010 年这道题几乎是本节全部概念的期末考，四个说法各查一条独立的轴：
说法查什么轴判定
Ⅰ 易失性断电后还在不在✅ RAM 丢，ROM 不丢
Ⅱ 随机存取怎么定位✅ 两者都是（本节金句）
Ⅲ 能否当 Cache能不能写、够不够快❌ ROM 只读，Cache 必须能写
Ⅳ 是否刷新靠什么维持信息❌ 只有 DRAM 刷新；SRAM 与 ROM 都不刷
⚠️ Ⅳ 有个隐藏的第二层错：即使只看 RAM，也只有 DRAM 需要刷新，SRAM 不需要——"RAM 都需要刷新"这半句本身就不成立。一句话里错两处。
📌 Ⅲ 为什么值得单独想一遍？因为"Cache 用什么做"是个正面考点：Cache 必须又快又能写 ⟹ 只能是 SRAM。ROM 写不了、Flash 写太慢、DRAM 不够快，三者都出局。
🔗 Ⅱ 正是 3.2-11 那句书上金句的真题现场：「支持随机存取的存储器并不一定是随机存储器」——ROM 是随机存取的，但不是 RAM。2011 年（3.2-30）紧接着又考了一次同一条，问"哪个不采用随机存取"，答案是 CD-ROM。
2012實戰闪存 Flash 的特性
下列关于闪存（Flash Memory）的叙述中，错误的是（　）。

闪存是 E2PROM 的进一步发展，可读可写，用 MOS 管的浮栅上有无电荷来存储信息。闪存依然是 ROM 的一种，写入时必须先擦除原有数据，所以写速度要比读速度慢，故 A 错误。闪存是一种非易失性存储器，采用随机访问方式；现在常见的 SSD 固态硬盘即由 Flash 存储器芯片组成。
闪存读写不一样快。
再深一层
选 A（它是错的）。Flash 的所有考点都能从一句话推出来：写之前必须先擦，而擦很慢。
选项判定依据
A 读写一样快❌ 错读接近 RAM，写要先擦除，慢一个量级以上
B MOS 管、半导体✅靠浮栅上有无电荷记信息，是半导体存储器
C 非易失✅浮栅被绝缘层包住，断电电荷跑不掉
D 随机访问、可替代外存✅SSD 就是 Flash 阵列做的
📌 D 项值得多看一眼：它同时说了两件事——「采用随机访问方式」（对，Flash 是半导体，不靠机械定位）与「可替代外部存储器」（对，SSD 已经普及）。注意这与"Flash 属于 ROM 的一种"（3.2-11）并不冲突：分类归 ROM，用途当外存。
⚠️ 本节考 Flash 已经第三次了（3.2-15 的 A 项、3.2-16、本题），三次问的都是同一件事：读快写慢、先擦后写、非易失。这说明它是个稳定送分点——把这三个短语背成一串就行。
🔗 串联 3.4 SSD：正因为"擦写次数有限"，SSD 才需要磨损均衡；正因为"读快"，SSD 才能把机械盘的寻道 + 旋转延迟一起干掉。
2015實戰需要刷新的存储器·SDRAM
下列存储器中，在工作期间需要周期性刷新的是（　）。

DRAM 使用电容存储信息，所以必须隔一段时间刷新一次，若存储单元长时间未被刷新，则存储的信息就会丢失。同步动态随机存储器 SDRAM 是现在最常用的一种 DRAM。
再深一层
选 B。整道题就考一个字母的展开：SDRAM 里的 D 是 Dynamic。
S RAM   = Static RAM        ← 触发器，不刷新
SD RAM  = Synchronous DRAM  ← 名字里带 D，本质仍是 DRAM，要刷新 ✔
ROM     ← 非易失，不刷新
Flash   ← 非易失，不刷新（但写前要擦）
📌 判"要不要刷新"只问一句：信息是不是存在电容里的？是 ⟹ 会漏电 ⟹ 必须刷新（只有 DRAM 家族）；不是（触发器 / 浮栅 / 掩模）⟹ 不刷新。
⚠️ 这题与 3.2-18 是同一考点的两种问法：3.2-18 把"SDRAM 不需要刷新"设为错误说法，本题把"SDRAM 需要刷新"设为正确答案。两题对照着做，这个点就再也不会翻船。
⚠️ 顺带把 DRAM 家族的字母表理一遍，选择题里会当选项出现：
SDRAM（同步）→ DDR SDRAM（双沿传输，一个时钟周期传两次）→ DDR2/3/4/5（预取位宽翻倍）；全都是 DRAM，全都要刷新。
2018實戰DRAM 阵列行列设计三约束
假定 DRAM 芯片中存储阵列的行数为 r、列数为 c，对于一个 2K×1 位的 DRAM 芯片，为保证其地址引脚数最少，并尽量减少刷新开销，则 r、c 的取值分别是（　）。

由题意，首先根据 DRAM 采用的行列地址线复用技术，应尽量选行列差值不要太大的，选项 B、C 的地址线只需 6 根（取行或列所需地址线的最大者），可排除选项 A 和 D。其次，为了减小刷新开销，而 DRAM 一般是按行刷新的，所以应选行数较少的，故选 C。
2K = 2¹¹。行列 r×c=2048，要让 max(行列位数) 最小（引脚少）且行少（刷新少）：行 2⁵=32，列 2⁶=64。
再深一层
选 C（r = 32, c = 64）。本题是「行列设计三条约束」的标准现场，三条依次用下去，答案唯一：
容量 2K×1 位 ⟹ 2¹¹ 个单元 ⟹ r × c = 2048，即 log₂r + log₂c = 11

约束① 地址引脚数 = max(log₂r, log₂c) 要最小
      ⟹ r 与 c 尽量接近
约束② DRAM 按【行】刷新，行数越少刷新开销越小
      ⟹ 在①的前提下取 r ≤ c
约束③ 综合 ⟹ 近似正方形，且行数略小于等于列数
选项rclog₂rlog₂c引脚数判定
A2048111011引脚太多 ❌
B6432656引脚够少，但 r > c ❌
C3264566引脚 6 且 r ≤ c ✔
D1204801111引脚太多 ❌
📌 B 与 C 是本题真正的对决，只差"谁当行"：两者引脚数都是 6，但 B 有 64 行、C 只有 32 行。刷新是按行做的，行少一半 ⟹ 刷新次数少一半 ⟹ 死时间少一半 ⟹ 选 C。
⚠️ 为什么引脚数取 max 而不是 (log₂r + log₂c)/2？因为行地址和列地址共用同一批引脚分两次送，引脚必须够装下较长的那一个。11 位地址拆成 5 + 6，引脚数就是 6，不是 5.5。
🔗 与 3.2-19 是同一个 r×c 关系的正反两问：那题问"引脚 +1 容量涨几倍"（答 4 倍），本题问"给定容量怎么分配 r 和 c"。两题都建立在"一根引脚同时服务行和列"这一点上。
2014實戰DRAM 引脚数计算·总容量是干扰项
某容量为 256MB 的存储器由若干 4M×8 位的 DRAM 芯片构成，该 DRAM 芯片的地址引脚和数据引脚总数是（　）。

4M×8 位的芯片数据线应为 8 根，地址线应为 log24M = 22 根，而 DRAM 采用地址复用技术，地址线是原来的 1/2，且地址信号分行、列两次传送，故地址线数为 22/2 = 11 根，所以地址引脚与数据引脚的总数为 11 + 8 = 19 根。此题需要注意 DRAM 采用的是传两次地址的策略，所以地址线为正常的一半，这是很多考生容易忽略的地方。
4M = 2²² 地址，复用减半 11 根；数据 8 根；共 19。
再深一层
选 A。本题的设计非常"考研"：给了一个用不上的 256MB，就为了看你会不会被它牵走。
【只看单片规格 4M×8 位】
  地址位数 = log₂(4M) = log₂2²² = 22
  DRAM 复用 ⟹ 地址引脚 = 22 ÷ 2 = 11
  数据引脚 = 8
  合计 = 11 + 8 = 19

【256MB 有什么用？】 只用来算"要几片"（本题没问），
                     与单片的引脚数【完全无关】。
⚠️⚠️ 两条互相独立的性质，别串线：
· 引脚数 ← 只由单片规格决定；
· 片数 ← 由总容量 ÷ 单片容量决定（那是 3.3 节的题）。
本题只问前者，256MB 是纯粹的噪声。
📌 三个错项的来路，正好是三种典型错误：
· B「22」＝只答了地址引脚，忘了加数据引脚，或忘了 ÷2 而把 22 当成引脚数；
· C「30」＝22 + 8，忘记 DRAM 要 ÷2——这是最主流的错法，书上专门点名了；
· D「36」＝按 256MB 去算地址位数（log₂256M = 28）再加 8。
🔗 2022 真题（3.2-37）C 项考的是同一个 ÷2（26 位地址 ⟹ 13 根引脚）。八年之间考了两次，且都在 C 项设为错误说法——这个坑的复现率极高。
2015實戰交叉编址·访存冲突判定
某计算机使用四体交叉编址存储器，假定在存储器总线上出现的主存地址（十进制）序列为 8005, 8006, 8007, 8008, 8001, 8002, 8003, 8004, 8000，则可能发生访存冲突的地址对是（　）。

各访存地址对应的存储模块序号（模块序号 = 访存地址 % 存储器交叉模块数）依次为：8005→1，8006→2，8007→3，8008→0，8001→1，8002→2，8003→3，8004→0，8000→0。判断可能发生访存冲突的规则：给定的访存地址在相邻的四次访问中出现在同一个存储模块内。据此，8004 和 8000 对应的模块号都为 0，且这两次访问相邻，满足发生冲突的条件。
模 4 看。8000、8004 同一个模块，而且相隔不到 4 次，所以会冲突。
再深一层
选 D。这题只有两步，但两步都要卡准：
第一步：算模块号 = 地址 mod 模块数（低位交叉的定义）
访问次序   1    2    3    4    5    6    7    8    9
地  址   8005 8006 8007 8008 8001 8002 8003 8004 8000
模块号      1    2    3    0    1    2    3    0    0

落在 Bank0 的是第 4 次(8008)、第 8 次(8004)、第 9 次(8000)
第二步：找"模块号相同 且 在相邻 m 次访问之内"的一对
模块号为 0 的有三个：8008(第4次)、8004(第8次)、8000(第9次)
  8008 与 8004：相隔 4 次 ⟹ 恰好一轮，M0 已做完，不冲突
  8004 与 8000：【相隔 1 次】⟹ M0 还在忙 ⟹ 冲突 ✔
📌 判据的两个条件缺一不可：① 同一模块；② 间隔 < m 次访问。只满足 ① 不算冲突——四体交叉本来就是让同一模块每 4 次才被点一次。
⚠️ 快速排除法（考场上 10 秒）：先把四个选项各自算一下差值。A(8004,8008) 差 4、B(8002,8007) 差 5、C(8001,8008) 差 7、D(8000,8004) 差 4。差值是 4 的倍数才可能同模块 ⟹ 只剩 A 和 D；再看它们在序列中的位置：A 两者相隔 4 次访问（不冲突），D 两者紧挨着（冲突）。
🔗 综 05 是本题的加长版，那里还有一个更阴的追加坑：前面发生的冲突会让后面的访问整体延后，从而使原本"看起来会冲突"的一对反而错开了。
2017實戰同时启动方式·未对齐的存取周期数
某计算机主存按字节编址，由 4 个 64M×8 位的 DRAM 芯片采用交叉编址方式构成，并与宽度为 32 位的存储器总线相连，主存每次最多读/写 32 位数据。若 double 型变量 x 的主存地址为 804 001AH，则读取 x 需要的存取周期数是（　）。

交叉编址的多模块存储器有轮流启动和同时启动两种方式，本题中所有存储模块一次并行读/写的总位数正好等于系统总线中的数据线数（4×8 = 32），所以可以判定采用的是同时启动方式。在同时启动方式下，一个存取周期可以对所有芯片的同一行都读取一个字节。double 型变量占 64 位（8B），其主存地址 804 001AH 的最低两位是 10，说明它从编号为 2 的芯片开始存储（编号从 0 开始），共占 3 行，因此需要同时启动 3 轮才能完成对 double 型变量的读取。从本题也可发现，采用同时启动方式时，一次读行也许会有没用的数据读入。
跨两次的情况：地址不对齐时，32 位宽，一个 8 字节 double 跨 3 个「4 字节单元」，要 3 次。
再深一层
选 C。本题是 3.2-28 的"未对齐加强版"，两步走：
【第一步：判断启动方式】4 片 × 8 位 = 32 位 = 总线宽度 ⟹ 所有模块同时启动（若是"单模块位数 = 总线宽度"才是轮流启动）。同时启动下，一个存取周期取出的是 4 个连续字节，且必须是 4 字节对齐的那一组。
【第二步：画出 double 占哪几组】
地址 804001AH，末位 A ⟹ 低两位 = 10 = 2 号芯片
double 占 8 字节：地址 …1A, 1B, 1C, 1D, 1E, 1F, 20, 21

  组(4B对齐)  片0   片1   片2   片3   说明
  [18~1B]     18    19   ▓1A▓ ▓1B▓  周期1（前2字节白读）
  [1C~1F]    ▓1C▓  ▓1D▓  ▓1E▓ ▓1F▓  周期2（全用上）
  [20~23]    ▓20▓  ▓21▓   22    23   周期3（后2字节白读）
⟹ 共 3 个存取周期
📌 心算捷径：看首地址落在组内第几位，加上数据长度，看跨几组。0x1A ÷ 4 = 6 余 2 ⟹ 从第 6 组的第 2 个字节开始；8 个字节从这里数过去，跨到第 8 组的第 2 个字节 ⟹ 涉及第 6、7、8 三组 ⟹ 3 个周期。
⚠️⚠️ 本题最容易的错法是"8B ÷ 4B = 2"直接选 B——那是对齐时的答案。只要首地址不是 4 的倍数，就必然多加一个周期。看到十六进制地址，先做一次 mod 4 / mod 8，这个动作要变成条件反射。
📌 书上末尾那句"一次读行也许会有没用的数据读入"点破了同时启动的代价：第 1 个周期里 18、19 两个字节、第 3 个周期里 22、23 两个字节都是白读的。这与 Cache 装入一整块时"多带回来的字节可能用不上"是同一回事——都赌空间局部性，赌输了就是浪费带宽。
⚠️ "64M×8 位"和"按字节编址"是背景条件，别去算总容量——本题不需要。
2010實戰连续编址·片选取地址高位
假定用若干 2K×4 位的芯片组成一个 8K×8 位的存储器，则地址 0B1FH 所在芯片的最小地址是（　）。

用 2K×4 位的芯片组成 8K×8 位的存储器共需 8 片，分为 4 组，每组由 2 片 2K×4 位的芯片并联组成 2K×8 位。各组芯片的地址分配为：第一组 0000H~07FFH，第二组 0800H~0FFFH，第三组 1000H~17FFH，第四组 1800H~1FFFH。地址 0B1FH 所在的芯片属于第二组，所以其所在芯片的最小地址为 0800H。
每组 2K，第一组 0000H–07FFH，第二组 0800H–0FFFH。0B1FH 在第二组。
再深一层
选 D。本题与 3.2-25 是命题人埋的一对"同题异构"，必须并排做：
8K×8 ÷ 2K×4：
  位扩展 8/4 = 2 片一组；字扩展 8K/2K = 4 组；共 8 片

【连续编址】片选取【高】2 位 ⟹ 每组占一整段连续地址
  第 1 组 0000H ~ 07FFH   （2K = 800H 个单元）
  第 2 组 0800H ~ 0FFFH   ← 0B1FH 落在这里
  第 3 组 1000H ~ 17FFH
  第 4 组 1800H ~ 1FFFH

⟹ 0B1FH 所在组的最小地址 = 0800H ✔
📌 快速定位法（不用列表）：地址 ÷ 每组容量，取整后再乘回去。
0B1FH = 2847，每组 2K = 2048
  2847 ÷ 2048 = 1 余 799 ⟹ 第 1 组（从 0 数）
  最小地址 = 1 × 2048 = 2048 = 0800H ✔
⚠️⚠️ 与 3.2-25 的对照（本节最值得记的一张表）：
3.2-25 交叉编址本题 连续编址

⟹ 两题的题面几乎一模一样，只差"交叉/连续"四个字，答案完全不同。读题时先把这四个字圈出来，再动手。
⚠️ 注意"芯片的最小地址"问的是整组的起点：同一组里两片是并联的（位扩展），它们覆盖完全相同的地址范围，只是各出 4 位。
2009實戰ROM 区与 RAM 区分别算片数
某计算机主存容量为 64KB，其中 ROM 区为 4KB，其余为 RAM 区，按字节编址。现要用 2K×8 位的 ROM 芯片和 4K×4 位的 RAM 芯片来设计该存储器，需要上述规格的 ROM 芯片数和 RAM 芯片数分别是（　）。

首先确定 ROM 的个数：ROM 区为 4KB，选用 2K×8 位的 ROM 芯片，需要 (4K×8) ÷ (2K×8) = 2 片，采用字扩展方式；RAM 区为 60KB，选用 4K×4 位的 RAM 芯片，需要 (60K×8) ÷ (4K×4) = 30 片，采用字和位同时扩展的方式。
ROM 4KB / 2KB = 2 片；RAM 60KB=60K×8，每片 4K×4，要 15×2 = 30 片。
再深一层
选 D。2009 年这道题定下了此后十几年的模板：ROM 区和 RAM 区各算各的，不能混在一起。
【ROM 区】4KB，用 2K×8 位芯片
  单片字长 8 = 系统字长 8 ⟹ 不用位扩展
  片数 = 4K / 2K = 2 片（纯字扩展）

【RAM 区】64KB − 4KB = 60KB，用 4K×4 位芯片
  单片字长 4 < 系统字长 8 ⟹ 位扩展 8/4 = 2 片一组
  组数 = 60K / 4K = 15 组（字扩展）
  片数 = 2 × 15 = 30 片（字位同时扩展）
⚠️⚠️ 本题两个最容易丢分的地方：
· 忘了扣 ROM：RAM 区是 60KB 不是 64KB ⟹ 会算成 32 片；
· 忘了位扩展：只按单元数算 60K/4K = 15 ⟹ 正好落进选项 B。选项 A/B/C 分别对应"漏算 ROM 的位扩展""漏算 RAM 的位扩展""两个都漏"，四个选项就是四种做法的组合。
📌 快速验算：总位数守恒。2×(2K×8) + 30×(4K×4) = 32K + 480K = 512K 位 = 64KB ✔ 恰好铺满主存。算完片数一定要做这一步回代，五秒钟就能查出漏项。
🔗 2016 真题（3.3-13）是本题的变体：那题用地址区间给出 ROM 范围，且只问 RAM 芯片数。两题并排看，"扣 ROM"这个动作就变成条件反射了。
2011實戰MAR 位数由地址空间决定
某计算机存储器按字节编址，主存地址空间大小为 64MB，现用 4M×8 位的 RAM 芯片组成 32MB 的主存储器，则存储器地址寄存器 MAR 的位数至少是（　）。

主存按字节编址，地址空间大小为 64MB，MAR 的寻址范围为 64M = 226，因此 MAR 至少是 26 位。实际的主存容量 32MB 不能代表 MAR 的位数，考虑到存储器扩展的需要，MAR 应保证能访问到整个主存地址空间；反过来，MAR 的位数决定了主存地址空间的大小。
地址空间 64MB，所以要 26 位，和实际装了多少内存无关。
再深一层
选 D。⭐ 这是全章最高频的单点陷阱，书上把道理写成了一句必背的话：
「实际的主存容量不能代表 MAR 的位数；MAR 应保证能访问到整个主存地址空间；反过来，MAR 的位数决定了主存地址空间的大小。」
题给两个数，只有一个有用：
  地址空间 64MB = 2²⁶ B → MAR 至少 26 位 ✔ 【用这个】
  实装容量 32MB = 2²⁵ B → 选项 C 的来路   ✘ 【干扰项】
📌 为什么必须按地址空间算？因为今天插了 32MB，明天可能插满 64MB——MAR 是 CPU 里的固定硬件，不会因为你少插了一根内存条而变窄。地址线有多少根，MAR 就有多少位，与主板上实际焊了多少芯片无关。
⚠️ 四个选项覆盖了四种错法，正好用来自查：
选项怎么算出来的错在哪
A 22 位log₂(4M) = 22算的是单片的地址位数
B 23 位—凑数
C 25 位log₂(32M) = 25用了实装容量（最主流的错法）
D 26 位log₂(64M) = 26用地址空间 ✔
🔗 与 3.1-07、3.3-05 是同一条线：地址总线根数 = MAR 位数 = log₂(地址空间)，三者互相锁定。凡题目同时给"地址空间"和"实际容量"，问 MAR/地址线就用前者，问片数就用后者——这两个数各有各的用处，别串。
2016實戰地址区间定 ROM 区·只问 RAM 片数
某存储器容量为 64KB，按字节编址，地址 4000H ~ 5FFFH 为 ROM 区，其余为 RAM 区。若采用 8K×4 位的 SRAM 芯片进行设计，则需要该芯片的数量是（　）。

5FFFH − 4000H + 1 = 2000H，即 ROM 区容量为 213B = 8KB。RAM 区容量为 64KB − 8KB = 56KB。需要 8K×4 位的 SRAM 芯片数量为 56KB ÷ (8K×4 位) = 14。
ROM 区 8KB，其余 56KB 用 8K×4（2 片一组 8K×8）：7×2 = 14 片。
再深一层
选 C。2016 年这道题是 2009 年（3.3-10）的加强版，多了一步"从地址区间算 ROM 大小"：
① ROM 区大小 = 5FFFH − 4000H + 1 = 2000H
   2000H = 2 × 16³ = 2 × 4096 = 8192 = 2¹³ = 8KB

② RAM 区 = 64KB − 8KB = 56KB = 56K × 8 位

③ 单片 8K×4 位：
   位扩展 8/4 = 2 片一组
   组数   56K/8K = 7 组
   片数   = 2 × 7 = 14 ✔
⚠️⚠️ 三个错项恰好是三种漏项，对照着自查最有效：
选项算法漏了什么
A 756K/8K = 7漏了位扩展（单片只有 4 位）
B 864K/8K = 8漏了扣 ROM，又漏位扩展
C 14(56K×8)/(8K×4)两者都算到了 ✔
D 16(64K×8)/(8K×4)漏了扣 ROM
📌 ⚠️ 题眼：问的是 SRAM 芯片数，SRAM = RAM 区，ROM 区不算。题干里"SRAM"这三个字母就是在告诉你"只算 RAM 那部分"。
📌 十六进制心算：2000H = 2·16³。速记表（本节反复用）：1000H = 4K、2000H = 8K、4000H = 16K、8000H = 32K、10000H = 64K。规律：十六进制多一位就 ×16 = 2⁴，首位 1/2/4/8 再分别 ×2⁰/2¹/2²/2³。
🔗 与 3.3-10（2009）连着做：两题都是"主存 = ROM 区 + RAM 区，分别算片数"，只是 2009 直接给 ROM 大小、2016 给地址区间。⟹ 见到"其余为 RAM 区"五个字，第一反应是做减法。
做完再翻：这些题到底在问什么

分类题专挑名字有误导的：CD-ROM 名字带 ROM，却不是随机存取；ROM 也是随机存取。
引脚题是减半加数据线，行数取少只在行列不等时起作用。
交叉编址题有两种问法：给地址序列问谁冲突，只看 % m；给数据在内存的位置问要读几次，看它跨几个总线宽度。
片数题按区域分开除，还会问译码后某地址所在芯片的起始地址：把地址按组大小向下取整。
地址线位数只看地址空间，不看实际装了多少。
