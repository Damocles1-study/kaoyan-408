束缚

算法大题三条铁律

  1. 暴力解也有分。 题目要求「时间上尽可能高效」时，最优解满分，暴力解通常能拿 8–10 分左右。想不出来就写暴力，一定不要交白卷。
  2. 思路必须单独写。 只写代码，思路这 3–4 分就没了。
  3. 语法错误扣分很少。 阅卷看逻辑，少个分号没事，所以别在语法上纠结。
怎么判断自己的方向对不对

看题目怎么说：说「时间上尽可能高效」→ 大概率要 用空间换时间（开一个标记数组）。说「空间复杂度 O(1)」或「时空都高效」→ 双指针、逆置、排序后扫描这类原地技巧。

其之貳顺序表：先记住它的特点

顺序表就是数组，逻辑上相邻的元素物理上也相邻。第 i 个元素的地址是 LOC(aᵢ) = LOC(a₁) + (i−1)·sizeof(T)，所以能随机存取，这是它最大的本事；代价是插入删除要挪元素。

术式
顺序表三个平均移动次数

插入：平均移动 n/2 个（有 n+1 个位置可插）
删除：平均移动 (n−1)/2 个（有 n 个可删）
查找：平均比较 (n+1)/2 次（成功时）

顺序表的结构与插入删除（基本功，要能默写）
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

// 在位序 i（从 1 开始）插入 e
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1) return false;   // 判位置
    if (L.length >= MaxSize) return false;         // 判满
    for (int j = L.length; j >= i; j--)            // 从后往前挪，否则会覆盖
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;
    L.length++;
    return true;
}

// 删除位序 i，用 e 带回
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++)             // 从前往后挪
        L.data[j - 1] = L.data[j];
    L.length--;
    return true;
}
咒灵
挪动方向

插入从后往前挪，删除从前往后挪。 反过来会把数据覆盖掉。C 语言里 &L 引用是 C++ 语法，考试允许用。

其之參四个原地技巧

数组类大题的绝大部分答案，都是这四招的组合。

招式一：逆置

数组整体逆置，只需要首尾交换，走到中点停。

模板：逆置 [left, right] 这一段
void Reverse(int a[], int left, int right) {
    while (left < right) {
        int t = a[left]; a[left] = a[right]; a[right] = t;
        left++; right--;
    }
}

循环左移 p 位（2010 真题）只用三次逆置。把序列看成两段 XY，要变成 YX：

▣ 三次逆置实现循环移位
原序列，n=7，要循环左移 p=3 位：前 3 个是 X，后 4 个是 Y，目标是 YX。
第一次：逆置 X。得到 X⁻¹Y。
第二次：逆置 Y。得到 X⁻¹Y⁻¹。
第三次：整体逆置。(X⁻¹Y⁻¹)⁻¹ = YX，完成。时间 O(n)，空间 O(1)。

招式二：双指针（快慢指针）

一个读指针 i 扫全部元素，一个写指针 k 指向下一个要写入的位置。删除所有值为 x 的元素：

模板：原地过滤（快慢指针）
void DelX(SqList &L, int x) {
    int k = 0;                        // 写指针：k 之前都是要保留的
    for (int i = 0; i < L.length; i++)
        if (L.data[i] != x)
            L.data[k++] = L.data[i];
    L.length = k;
}

招式三：有序合并（归并思想）

两个有序表，每次取两者中较小的那个。如果只需要第 k 小，不必真的合并，走到第 k 步就停。归并的思想在 第 15 话 的归并排序、外部排序还会用到。

模板：合并两个有序表
bool Merge(SqList A, SqList B, SqList &C) {
    if (A.length + B.length > MaxSize) return false;
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length)
        C.data[k++] = (A.data[i] <= B.data[j]) ? A.data[i++] : B.data[j++];
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];
    C.length = k;
    return true;
}

招式四：用下标当哈希（空间换时间）

元素值落在有限范围（比如 1 到 n）时，开一个标记数组 count[]，把值当下标。遇到「找缺失的数」「找重复的数」「绝对值去重」，第一反应就是它。

模板：标记数组（2018 真题：找未出现的最小正整数）
int FindMissMin(int A[], int n) {
    // 答案一定落在 1..n+1，因为 n 个数最多把 1..n 占满
    int *B = (int *)malloc(sizeof(int) * n);
    memset(B, 0, sizeof(int) * n);
    for (int i = 0; i < n; i++)
        if (A[i] > 0 && A[i] <= n)    // 超出范围的不影响答案
            B[A[i] - 1] = 1;
    int i;
    for (i = 0; i < n; i++)
        if (B[i] == 0) break;
    free(B);
    return i + 1;
}

还有一个高频题：主元素

模板：投票法找主元素
int Majority(int A[], int n) {
    int c = A[0], cnt = 1;
    for (int i = 1; i < n; i++) {
        if (A[i] == c) cnt++;
        else if (cnt > 0) cnt--;
        else { c = A[i]; cnt = 1; }
    }
    cnt = 0;                         // 第二趟：确认
    for (int i = 0; i < n; i++)
        if (A[i] == c) cnt++;
    return cnt > n / 2 ? c : -1;
}
领域展开

大题结构：思路 → 代码 → 复杂度，三块都要写。
四招：逆置 · 快慢指针 · 有序合并 · 下标当哈希。
判方向：要时间快就开标记数组，要 O(1) 空间就双指针或逆置。

2010實戰算法·数组·逆置法
设将 n(n>1) 个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p(0<p<n) 个位置，即将 R 中的数据由 (X₀,X₁,…,X_{n-1}) 变换为 (X_p,X_{p+1},…,X_{n-1},X₀,X₁,…,X_{p-1})。
经典三次逆置法：先逆前 p 个、再逆后 n−p 个、最后整体逆置。时间 O(n)、空间 O(1)——两方面都最优。（另有“借辅助数组”O(n)/O(p) 但空间更差）
void Rev(int R[],int l,int r){
    while(l<r){int t=R[l];R[l]=R[r];R[r]=t;l++;r--;}
}
void LeftRotate(int R[],int n,int p){     // 循环左移 p 位
    Rev(R,0,p-1);                         // ① 逆置前 p 个
    Rev(R,p,n-1);                         // ② 逆置后 n-p 个
    Rev(R,0,n-1);                         // ③ 整体逆置
}
这就是上面的三次逆置。原题要求「时空都尽量高效」，这个解时间 O(n)、空间 O(1)，可以直接满分。

2011實戰算法·折半·中位数
一个长度为 L(L≥1) 的升序序列 S，处在第 ⌈L/2⌉ 个位置的数称为 S 的中位数。现有两个等长升序序列 A 和 B，设计一个在时间和空间两方面都尽可能高效的算法，找出两个序列 A 和 B 的中位数（即 A、B 全部元素合并后的中位数）。
算法思想：分别求 A、B 的中位数 a、b。若 a==b 即答案；若 a＜b 则中位数落在“A 的后半 + B 的前半”，两边各舍去一半（保持两段等长）；反之亦然。每轮规模减半，时间 O(log₂n)、空间 O(1)。
int M_Search(int A[], int B[], int n){
    int s1=0,d1=n-1,s2=0,d2=n-1,m1,m2;
    while(s1!=d1 || s2!=d2){
        m1=(s1+d1)/2; m2=(s2+d2)/2;
        if(A[m1]==B[m2]) return A[m1];    // 相等即中位数
        if(A[m1]<B[m2]){                  // 舍 A 左半、B 右半(个数对称)
            if((s1+d1)%2==0){s1=m1;   d2=m2;}   // 奇数个：保留中点
            else            {s1=m1+1; d2=m2;}   // 偶数个
        }else{                            // 舍 A 右半、B 左半
            if((s1+d1)%2==0){d1=m1; s2=m2;}
            else            {d1=m1; s2=m2+1;}
        }
    }
    return A[s1]<B[s2]? A[s1] : B[s2];
}
暴力解：像上面那样归并走到第 ⌈L⌉ 步，时间 O(L)、空间 O(1)，能拿大部分分。最优解是两个中位数比较、各砍一半，时间 O(log L)。考场上想不到后者，就稳稳写归并，这正是「暴力也有分」的实际用法。
再深一层
核心是“每次同时砍掉 A、B 各一半且保持对称”，把 O(n) 归并降到 O(log n)。边界的奇偶处理最易错，已对拍验证。
2018實戰算法·标记数组·缺失正整数
给定一个含 n(n≥1) 个整数的数组，设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数。例如 {−5,3,2,3} 中未出现的最小正整数是 1；{1,2,3} 中是 4。
算法思想：n 个数中缺失的最小正整数必在 [1,n+1] 内，故只需关心 1~n 是否出现。用大小 n 的标记数组一趟标记、一趟从小到大找第一个未标记者。时间 O(n)、空间 O(n)——以空间换时间。
int MinMissing(int A[], int n){
    int *B=(int*)malloc((n+1)*sizeof(int));
    for(int i=0;i<=n;i++) B[i]=0;         // B[1..n] 标记 1~n 是否出现
    for(int i=0;i<n;i++)
        if(A[i]>0 && A[i]<=n) B[A[i]]=1;
    int i;
    for(i=1;i<=n;i++) if(B[i]==0) break;  // 第一个没出现的正整数
    free(B);
    return i;                             // 1~n 全出现则答案为 n+1
}
关键是想到「答案必在 1 到 n+1」：n 个数最多占满 1..n。想到这一点，标记数组的大小就确定了。时间和空间都是 O(n)。
再深一层
关键上界：答案不超过 n+1，所以＞n 或 ≤0 的数直接忽略。空间 O(n) 是“时间最优”的代价（题目只要求时间高效）。
2013實戰算法·摩尔投票·主元素
已知一个整数序列 A=(a₀,a₁,…,a_{n-1})，其中 0≤aᵢ<n。若存在 a_{p1}=a_{p2}=…=a_{pm}=x 且 m>n/2，则称 x 为 A 的主元素。请设计一个尽可能高效的算法，找出 A 的主元素；若存在则输出该元素，否则输出 −1。
王道解法：一趟“计数抵消”选出候选（相同则加、不同则减，减到 0 换候选），再扫描一遍统计候选出现次数，＞n/2 才是主元素。时间 O(n)、空间 O(1)。
int Majority(int A[], int n){
    int cand=A[0], cnt=1;                 // 摩尔投票选候选
    for(int i=1;i<n;i++){
        if(A[i]==cand) cnt++;
        else if(--cnt==0){cand=A[i]; cnt=1;}
    }
    cnt=0;                                // 二次扫描确认票数
    for(int i=0;i<n;i++) if(A[i]==cand) cnt++;
    return cnt>n/2 ? cand : -1;
}
最优解叫 Boyer-Moore 投票法：候选人遇到相同的 +1，不同的 −1，归零换人。不会时用计数数组：时间 O(n)、空间 O(n)，也是很高的分数。背下这个解法的同时，记住最后要 再扫一遍确认候选人确实过半，这一步常被漏。
再深一层
摩尔投票：主元素数量过半，一一抵消后必然幸存。务必要有第二趟确认——否则无主元素时会误报。与书同思路。
