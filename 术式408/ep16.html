其之壹五大部件

冯·诺依曼结构的核心是存储程序：指令和数据都以二进制放在主存里，机器自动逐条取出执行。

术式
冯·诺依曼的要点
  1. 五大部件组成。
  2. 指令和数据同等地位，都放在存储器，按地址访问。
  3. 指令和数据都用二进制表示。
  4. 指令由操作码和地址码组成。
  5. 指令在存储器顺序存放，靠 PC 自动 +1 顺序执行（也可改变）。
  6. 以运算器为中心（现代多以存储器为中心）。
CPU 怎么区分指令和数据

存储器里都是 0 和 1。取指周期取到的是指令，执行周期取到的是数据。

术式
六个寄存器（后面每一章都要用）

PC 程序计数器：下一条指令地址。程序员可见。
IR 指令寄存器：当前指令。不可见。
MAR 主存地址寄存器：位数对应地址线。不可见。
MDR 主存数据寄存器：位数对应存储字长。不可见。
GPR 通用寄存器；PSW 程序状态字（含标志位）。

一条指令怎么跑：把这些寄存器串起来看。比如当前要执行 LOAD R1, [5]（把地址 5 的内容放进 R1）。

  1. 取指：PC 的值送 MAR，存储器读出指令送 MDR，再送 IR；PC 加 1，指向下一条。
  2. 译码：控制器分析 IR 里的操作码，知道这是取数。
  3. 执行：把地址 5 送 MAR，读出内容送 MDR，再送 R1。

每条指令都是这个循环，CPU 从开机到关机就在重复这件事。

几个「长度」别混：机器字长 = CPU 一次能处理的二进制位数（通用寄存器、ALU 的宽度），「32 位机器」说的就是它。存储字长 = 一个存储单元的位数，MDR 与它相同。指令字长 = 一条指令的位数，IR 与它相同。三者可以不相等。MAR 位数决定能访问多少单元：MAR 32 位、按字节编址，就是 4 GB。

合上页面说一遍：五大部件是什么？MAR、MDR、IR、PC 各存什么？机器字长是什么？

运算器、控制器、存储器、输入、输出。MAR 存要访问的地址，MDR 存读写的数据，IR 存当前指令，PC 存下一条指令的地址。机器字长是 CPU 一次处理的位数。

其之貳程序怎样变成指令

咒灵
硬件只能直接执行机器语言

汇编语言也要汇编器翻译。硬件描述语言（Verilog）是用来设计硬件的，不是被执行的。 编译：一次译完，生成目标文件。解释：边翻译边执行，不生成目标文件，所以每次运行都要翻译。

系统的层次从下到上：微程序机器 → 传统机器（机器语言）→ 操作系统 → 汇编 → 高级语言。下层为上层提供服务。软硬件逻辑等价：同一功能既可由硬件也可由软件实现，前者快，后者灵活。

其之參性能公式

一个程序跑多久，拆开看只有三个因子：多少条指令、每条平均几个周期、一个周期多长。

术式
CPU 执行时间

CPU 时间 = 指令条数 × CPI × 时钟周期
= 指令条数 × CPI / 主频
MIPS = 主频 / (CPI × 10⁶)
平均 CPI = Σ (各类比例 × 各类 CPI)

术式
指标的单位

主频（Hz）= 1 / 时钟周期。1 GHz → 1 ns。
CPI：每条指令的平均时钟周期数。
MIPS：每秒百万条指令。MFLOPS：每秒百万次浮点运算（GFLOPS、TFLOPS、PFLOPS、EFLOPS、ZFLOPS 依次 ×1000）。
吞吐量：单位时间完成的量。响应时间：从提交到首次响应。

咒灵
三个常见误解

MIPS 高不等于快：指令集不同时比较 MIPS 没有意义，RISC 一条做的事比 CISC 少。主频高不等于快：还要看 CPI。CPU 时间不等于总时间：I/O 时间要分开算，只改善 CPU，I/O 那部分原封不动。

走一遍：主频 2 GHz。程序 10⁹ 条指令，其中 40% 算术（CPI=1）、40% 访存（CPI=3）、20% 转移（CPI=2）。

  • 平均 CPI = 0.4×1 + 0.4×3 + 0.2×2 = 2。
  • CPU 时间 = 10⁹ × 2 ÷ (2×10⁹) = 1 秒。
  • MIPS = 2000 ÷ 2 = 1000。

只改善一部分：程序总共 100 秒，其中 CPU 80 秒，I/O 20 秒。CPU 速度翻倍后，CPU 40 秒、I/O 仍 20 秒，共 60 秒，整体只快了 1.67 倍，不是 2 倍。

合上页面说一遍：写出 CPU 时间公式和 MIPS 公式。CPU 快一倍，整体为什么快不到一倍？

时间 = 条数 × CPI ÷ 主频；MIPS = 主频 ÷ CPI ÷ 10⁶。因为 I/O 时间不变。

领域展开

存储程序：指令和数据同地位；取指周期取到的是指令。
性能公式：时间 = 条数 × CPI / 主频；MIPS = 主频 / CPI。
只改善一部分：未改善的部分不变，分开算。

2015實戰语言级别·硬件直接执行
计算机硬件能够直接执行的是（　）。
Ⅰ. 机器语言程序　　Ⅱ. 汇编语言程序　　Ⅲ. 硬件描述语言程序

硬件能直接执行的只能是机器语言（二进制编码），汇编语言是增强机器语言的可读性和记忆性的语言，经过汇编后才能被执行。
再深一层
选 A。三个选项里最容易被放过的是 Ⅲ「硬件描述语言」，很多人没见过就默认它"和硬件有关所以能执行"——正好相反。
· Ⅰ 机器语言：二进制编码，唯一能被硬件直接执行的。✔
· Ⅱ 汇编语言：文本助记符，要经汇编程序翻译。✘
· Ⅲ 硬件描述语言（HDL，如 Verilog / VHDL）：它是用来"描述电路长什么样"的语言，不是给 CPU 执行的程序。它的归宿是被综合工具变成门级网表，再变成实际电路——它生产硬件，而不是运行在硬件上。✘
📌 本题的一句话答案：能被硬件直接执行的语言，古往今来只有机器语言一种。这条在 1.2-10、1.4 本章小结第 3 问里被反复问，属于必拿分。
2016實戰翻译程序·编译程序
将高级语言源程序转换为机器级目标代码文件的程序是（　）。

翻译程序是指把高级语言源程序转换为机器语言程序的软件。翻译程序有两种：一种是编译程序，它将源程序一次全部翻译成目标程序，并且会生成目标代码文件。另一种是解释程序，它将源程序的一条语句翻译成对应的机器目标代码，并立即执行，翻译一句执行一句，并且不会生成目标代码文件。汇编程序也是一种翻译程序，它把汇编语言源程序翻译为机器语言程序。
编译程序。汇编程序是把汇编语言转成机器语言。
再深一层
选 C。题干里三个限定词全是采分点，少看一个就选错：
「高级语言源程序」→ 排除 A 汇编程序（输入是汇编语言）
「目标代码文件」→ 排除 D 解释程序（不生成任何文件）
「源程序转换」  → 排除 B 链接程序
                （输入是 .o 目标文件，不是源程序）
⟹ 只剩编译程序。
⚠️ B 链接程序最容易被忽略地排除：链接干的是"把多个 .o 和库函数拼成可执行文件、解析外部符号引用"，它根本不接触源程序。对照 1.2-14（2022 真题）的四阶段：预处理 → 编译 → 汇编 → 链接，链接在最后一环。
📌 "生成目标代码文件"是编译 vs 解释的分水岭，这句话在 1.2-07 里也是判据。
2019實戰冯·诺依曼机·五大特点
下列关于冯·诺依曼基本思想的叙述中，错误的是（　）。

冯·诺依曼机的功能部件包括输入设备、输出设备、存储器、运算器和控制器，程序的功能都通过中央处理器（运算器和控制器）执行指令，选项 A 正确。指令和数据以同等地位存放于存储器内，形式上无差别，只在程序执行时具有不同的含义，选项 B 正确。指令按地址访问，数据由指令的地址码指出，除立即寻址外，数据均存放在存储器内，选项 C 错误。在程序执行前，指令和数据需预先存放在存储器中，中央处理器可以从存储器存取代码，选项 D 正确。
指令按地址访问，数据也按地址访问（也可能是立即数）。题目的错话就是「数据都在指令中直接给出」。
再深一层
选 C。C 错在一个"都"字——它把"立即寻址"这个特例硬说成了通例，而且方向说反了。
冯·诺依曼机的原话是「指令由操作码和地址码组成，地址码指出操作数的地址」——注意是地址，不是操作数本身。
正常情况：指令里放的是「数据在哪」
   → 拿地址去存储器取数（第4章各种寻址方式）
立即寻址：指令里放的是「数据本身」
   → 唯一的例外，且只能放很小的常数
⟹ 说"数据都在指令中直接给出"，等于说全世界只有立即寻址，显然错。
📌 这题给第 4 章「寻址方式」埋了伏笔：立即/直接/间接/寄存器/变址/相对……除立即寻址外，指令地址码给的都是找数据的线索而非数据。
⚠️ B 说"形式上无差别"是对的，别手滑——指令和数据在内存里都是 0/1，靠"什么时候取的"来区分（取指周期取出的当指令，执行周期取出的当数据），这正是冯·诺依曼第 3 条特点。
2013實戰MIPS 计算 · 单位换算错
某计算机的主频为 1.2GHz，其指令分为 4 类，它们在基准程序中所占比例及 CPI 如下表所示。该机的 MIPS 数是（　）。
指令类型所占比例CPI指令类型所占比例CPI
A50%2C10%4
B20%3D20%5

基准程序的 CPI = 2×0.5 + 3×0.2 + 4×0.1 + 5×0.2 = 3。计算机的主频为 1.2GHz，即 1200MHz，因此该机器的 MIPS = 1200÷3 = 400。
CPI = 0.5×2 + 0.2×3 + 0.1×4 + 0.2×5 = 3。MIPS = 1200/3 = 400。
再深一层
选 C。Python 复算（两步，第二步是全题唯一的坑）：
① 平均 CPI = 2×0.50 + 3×0.20 + 4×0.10 + 5×0.20
           = 1.0  + 0.6  + 0.4  + 1.0  = 3
   （自查：比例和 = 50+20+10+20 = 100% ✔）

② MIPS = 主频 ÷ (CPI × 10⁶)
       = 1.2×10⁹ ÷ (3 × 10⁶) = 400 ✔
⚠️ MIPS 公式里那个 10⁶ 是"百万"，不是随便凑的——把它当单位换算来做最不容易错：
MIPS 的字面意思 = 每秒执行多少「百万条」指令
每秒执行的指令条数 = 主频 ÷ CPI = 1.2×10⁹ ÷ 3 = 4×10⁸ 条/秒
换成"百万条"为单位：4×10⁸ ÷ 10⁶ = 400 ✔（这就是 MIPS 数）
⟹ 与其背公式，不如记"先算每秒多少条，再除以一百万"。这样 GIPS（2023 真题 1.3-20）只是把除数换成 10⁹，不用另背一个公式。
⚠️ 1.2GHz = 1200MHz = 1.2×10⁹Hz——书上写成 1200MHz 再除以 3 得 400，其实是直接用了"MHz ÷ CPI = MIPS"这个简写。这个简写只在主频单位取 MHz 时成立，背它容易翻车，还是按上面的两步走。
🔗 同类计算见 1.3-09（给条数求 MIPS）、1.3-20（2023，求 GIPS）。
2012實戰Amdahl 定律·只加速一部分
假定基准程序 A 在某计算机上的运行时间为 100s，其中 90s 为 CPU 时间，其余为 I/O 时间。若 CPU 速度提高 50%，I/O 速度不变，则运行基准程序 A 所耗费的时间是（　）。

程序 A 的运行时间为 100s，减去 CPU 时间 90s，剩余 10s 为 I/O 时间。CPU 提速 50% 后运行基准程序 A 所耗费的时间是 T = 90÷1.5 + 10 = 70s。【误区】CPU 速度提高 50%，而误认为 CPU 时间减少一半，从而误选选项 A。
CPU 时间变成 90/1.5 = 60 s，I/O 不变 10 s，共 70 s。这个「只改善一部分」的思路就是阿姆达尔定律。
再深一层
选 D。Python 复算：
I/O 时间 = 100 − 90 = 10 s        （不受影响，原样保留）
新 CPU 时间 = 90 ÷ 1.5 = 60 s     （速度×1.5 ⟹ 时间÷1.5）
总时间 = 60 + 10 = 70 s ✔
⚠️ 书上专门加了「误区」框，说明这题的错误率很高，两个坑要分清：
· 坑一（→ 选 A 55s）：把"速度提高 50%"当成"时间减少 50%"，算成 90÷2 + 10 = 55。速度和时间是倒数关系，不是加减关系。速度 ×1.5 ⟹ 时间 ×(1/1.5)，不是 ×0.5。
· 坑二（→ 选 B 60s）：忘了把 10s 的 I/O 时间加回来。题目明说 I/O 速度不变，那 10s 是"提速提不动的部分"，必须原样留着。
📌 这就是 Amdahl 定律的原型题：
新时间 = 不可加速部分 + 可加速部分 ÷ 加速倍数
系统加速比 = 旧时间/新时间 = 100/70 ≈ 1.43
             （远小于 CPU 提速的 1.5 倍）
⟹ 只要有一段没被加速，整体加速比就永远被它卡住上限：
   即使 CPU 快到无穷，本题也降不到 10s 以下，
   加速比封顶 100/10 = 10 倍。
"木桶效应"是组原全书的性能主线：Cache 命中率、流水线瓶颈段、I/O 与 CPU 速度差，讲的都是同一件事。
⚠️ 做题口诀：先把"不动的那部分"抠出来放一边，只对"动的部分"做除法，最后加回去。
2014實戰CPU 执行时间·比例缩放
程序 P 在机器 M 上的执行时间是 20s，编译优化后，P 执行的指令数减少到原来的 70%，而 CPI 增加到原来的 1.2 倍，则 P 在 M 上的执行时间是（　）。

假设原来的指令条数为 x，则原 CPI 为 20f/x（f 为 CPU 的时钟频率），经过编译优化后，指令条数减少到原来的 70%，即指令条数为 0.7x，而 CPI 增加到原来的 1.2 倍，即 24f/x，则现在程序 P 在机器 M 上的执行时间就为：(指令条数×CPI)/f = (0.7x×24f/x)/f = 24×0.7 = 16.8s。
20 × 0.7 × 1.2 = 16.8 s。三个因子相乘，变化直接乘上去。
再深一层
选 D。书上设了 x 和 f 绕了一圈，其实一步就够——因为同一台机器 M，主频没变：
执行时间 = (指令条数 × CPI) ÷ 主频
          ↓×0.7        ↓×1.2      ↓不变（还是机器 M）
新时间 = 旧时间 × 0.7 × 1.2 = 20 × 0.84 = 16.8 s ✔
📌 套路名：「同机比例缩放」。只要主频不变，执行时间就正比于「指令条数 × CPI」，各因子的倍数直接连乘即可，完全不必设未知数、不必知道 f 和 x 具体是多少。
⚠️ 三个错项各对应一个手误：
8.4s  = 20 × 0.7 × 0.6   把「增加到 1.2 倍」读错
11.7s ≈ 20 × 0.7 ÷ 1.2   把 CPI 增加当成除法（方向反了）
14s   = 20 × 0.7         漏乘 CPI 那一项 ← 最常见
16.8s = 20 × 0.7 × 1.2   ✔
"漏一个因子"是这类题的头号死法，写完先数一遍：题目改了几个量，式子里就该有几个因子。
⚠️ 本题也在说一件事：编译优化未必稳赚。指令条数降到 0.7，但 CPI 升到 1.2 倍，净收益只有 0.84。若 CPI 升到 1.5 倍，0.7×1.5 = 1.05 就反而变慢了——这正是 1.3-03、1.3-04 强调的"三要素互相制约"。
2017實戰CPU 执行时间·跨机器比值
假定计算机 M1 和 M2 具有相同的指令集体系结构（ISA），主频分别为 1.5GHz 和 1.2GHz。在 M1 和 M2 上运行某基准程序 P，平均 CPI 分别为 2 和 1，则程序 P 在 M1 和 M2 上运行时间的比值是（　）。

运行时间 = 指令数×CPI/主频。M1 的时间 = 指令数×2/1.5，M2 的时间 = 指令数×1/1.2，两者之比为 (2/1.5)∶(1/1.2) = 1.6。
时间比 = (2/1.5) ÷ (1/1.2) = 1.6。
再深一层
选 C。Python 复算：
t = 指令条数 I × CPI ÷ 主频
t₁ = I × 2 ÷ 1.5G = I × 1.3333/G
t₂ = I × 1 ÷ 1.2G = I × 0.8333/G
t₁ / t₂ = (2/1.5) ÷ (1/1.2) = 1.33333 / 0.83333 = 1.6 ✔（I 被约掉）
📌 题干里"具有相同的 ISA"这句话是解题的钥匙，不是背景介绍：ISA 相同 ⟹ 同一个程序 P 编译出的指令条数 I 相同 ⟹ 求比值时 I 可以约掉。没有这句话，本题无解（正是 1.3-03 的情形——那题因为没锁死指令条数，只能选"无法确定"）。
⚠️ 把这两题并排放，就看清了出题人的心思：
1.3-03：CPI 相同，ISA 未说明 ⟹ 指令条数未知 ⟹ 无法确定
1.3-17：ISA 相同（条数锁死）+ CPI、主频都给 ⟹ 可以精确求比值
看到"相同 ISA / 相同指令集"，第一反应就是"指令条数可约"。
⚠️ 问的是"M1 比 M2"还是"M2 比 M1"要看清——本题问 t₁/t₂ = 1.6（M1 更慢）；若问反了就是 0.625（选项 B 正是这个反向答案）。选项 B 和 C 互为倒数，就是给看反顺序的人准备的。
⚠️ 另外注意 M1 主频更高（1.5G > 1.2G）反而更慢，因为它的 CPI 是 2 倍——又一次印证"主频高 ≠ 性能好"（1.4 本章小结第 1 问）。
2011實戰性能指标·浮点速度指标
下列选项中，描述浮点数操作速度指标的是（　）。

MIPS 是每秒执行多少百万条指令，适用于衡量标量机的性能。CPI 是平均每条指令的时钟周期数。IPC 是 CPI 的倒数，即每个时钟周期执行的指令数。MFLOPS 是每秒执行多少百万条浮点数运算，用来描述浮点数运算速度，适用于衡量向量机的性能。
再深一层
选 D。四个缩写按"数什么"排一遍，答案自己跳出来：
缩写数的是适用
MIPS百万条指令/秒标量机、通用整数性能
CPI周期/指令单条指令的开销
IPC指令/周期（= 1/CPI）微架构效率
MFLOPS百万次浮点运算/秒向量机、科学计算
只有 MFLOPS 里的 FL = Floating-point，其余三个数的都是"指令/周期"，与浮点无关。
📌 只看缩写字母就能秒杀：认准 FL 两个字母。FLOPS 家族全员（M/G/T/P/E/Z FLOPS）都是浮点指标，见 1.3-18（2021 真题）。
⚠️ "标量机 vs 向量机"这对搭配值得单独记：MIPS 衡量标量机、MFLOPS 衡量向量机，这是王道原文的措辞，可能被直接考。
🔗 与 1.3-02（科学计算选 MFLOPS）是同一考点的两种问法。
2010實戰提高系统性能的措施
下列选项中，能缩短程序执行时间的措施是（　）。
Ⅰ. 提高 CPU 时钟频率　　Ⅱ. 优化数据通路结构　　Ⅲ. 对程序进行编译优化

CPU 时钟频率（主频）越高，完成指令的一个执行步骤所用的时间就越短，执行指令的速度就越快，说法 Ⅰ 正确。数据通路的功能是实现 CPU 内部的运算器和寄存器及寄存器之间的数据交换，优化数据通路结构，可以有效提高计算机系统的吞吐量，从而加快程序的执行，说法 Ⅱ 正确。计算机程序需要先转化成机器指令序列才能最终得到执行，通过对程序进行编译优化可以得到更优的指令序列，从而使程序的执行时间也越短，说法 Ⅲ 正确。
公式的三个因子都能被这三个措施影响。
再深一层
选 D（全部）。还是挂三要素，三条各打一个因子：
Ⅰ 提高时钟频率    → 时钟周期↓   （硬件工艺层面）
Ⅱ 优化数据通路    → CPI↓       （微体系结构层面，第 5 章主战场）
Ⅲ 编译优化        → 指令条数↓   （软件层面）
                    三个因子被三条措施各占一个，无一落空 ⟹ 全选
📌 这道 2010 真题实际上在考"三要素的完备性"：出题人故意让 Ⅰ/Ⅱ/Ⅲ 分别对应主频、CPI、指令条数，考你是否知道这三条是互相独立、各自都能生效的路径。
⚠️ Ⅱ 最容易被误判——"数据通路"是第 5 章的内容，第 1 章看到会发怵。其实只需知道：数据通路是 CPU 内部搬数据、做运算的那条路，把它优化了（比如加旁路、缩短关键路径）就能让指令少花周期 ⟹ CPI↓。
🔗 与 1.3-11 是同一考点的两个年份版本，连答案都一样是"全部"。记一句话即可：只要动到三要素中的任意一个，就能缩短执行时间。
做完再翻：这些题到底在问什么

计算题先写公式，再把题目的变化当成乘数代进去：指令数变 0.7 倍、CPI 变 1.2 倍，时间就乘这两个数。 「只改善一部分」的题，一定把 I/O 那部分原样加回来。 概念题：硬件只执行机器语言；冯·诺依曼的错误选项通常把一句说绝。
