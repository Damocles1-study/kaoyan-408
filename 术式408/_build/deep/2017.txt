#43 ★★★
考 unsigned 比较、int 溢出、float 的 24 位有效位与上溢。
本 n＝0 时 n－1 按 unsigned 是 2^32－1 ⟹ i≤n－1 永真 ⟹ 死循环；改成 int 就是 －1，不会。f(23)＝24 个 1，float 正好装得下 ⟹ 相等（00FF FFFFH、4B7F FFFFH）。f(24) 有 25 位，float 舍入后多 1。f(31) 是 32 个 1，按 int 读是 －1；int 能装下的最大 n 是 30。7F80 0000H 是 ＋∞；不溢出最大 n＝126，精确最大 n＝23。
