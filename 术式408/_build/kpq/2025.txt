// 2025 本题知识点（2025 年解析 PDF 不可靠，关键一步取自精研卡，已复算）
1. 外层条件 `i*i<=n`、内层 `j<=i` ⟹ 先求外层跑到多少，再把内层次数按外层累加
   卡 T循环求和, T循环次数
   坑 看到两层循环就判 $O(n^2)$；或把外层当成 $\log n$
2. 「栈的容量是 3」做括号匹配 ⟹ 栈里同时最多几个 ＝ 括号最大嵌套层数，只数括号
   卡 括号匹配
   坑 把字母、运算符也算进栈里；或只数同一种括号的层数
3. 顺序存储、−1 表示空，「不能表示一棵二叉树」⟹ 逐个检查非空结点：它的父结点 $\lfloor(i-1)/2\rfloor$ 是不是空
   卡 T顺序存储二叉树, 完全二叉树
   坑 用 1 起的下标公式算父结点（数组从 0 起）
4. 二叉树与森林「正确的是」⟹ 逐项找反例：完全二叉树的最后一个分支、表达式树根上是哪一步运算
   卡 孩子兄弟, 表达式树, T反例排除
   坑 「分支结点比叶子少」只对度只有 0 和 2 的树成立，单支树就反了
5. 频次 2,3,4,6,8,10,11 构造哈夫曼编码，数码长 ≥3 ⟹ 每次合并最小的两个，记下每个字符被合并了几层
   卡 T哈夫曼, 哈夫曼树, 前缀码
   坑 合并后新结点和原有结点权值相等时乱排，导致深度数错——相等时怎么放都不影响各叶子码长之和，但要一致画到底
6. 图的叙述「正确的是」⟹ 每条都造最小反例：一个有向环、一个有两种拓扑序的 DAG、一张带权图
   卡 图的基本性质, T反例排除
   坑 以为 BFS 也能在带权图上求最短路
7. 400 个元素、均匀分块、块间块内都顺序 ⟹ ASL 在块长 $\sqrt n$ 时最小
   卡 分块查找
   坑 块间用折半的结论（块越小越好）套到顺序上
8. 7 个关键字最多能构造几棵 4 阶 B 树 ⟹ 先定每结点关键字数 1～3，按树高分情况，再按根上关键字个数分配孩子
   卡 B树, TB树结点数
   坑 漏掉高 3 的那一种（每个结点 1 个关键字），或把关键字数相同但分法不同的孩子当成一种
9. 处理冲突「正确的是」⟹ 两种探测序列各能探到哪些单元；冲突是不是只发生在同义词之间
   卡 二次探测, 线性探测, 堆积
   坑 以为二次探测也能扫遍全表；以为冲突只在同义词之间
10. 「最坏情况下元素移动次数最少」⟹ 拿逆序输入，数每种排序的交换或移动次数
   卡 T排序特性对比
   坑 把「比较次数」和「移动次数」弄混——简单选择比较多但移动最少
11. 给出排序第 1 趟结果判算法 ⟹ 看「位置换了」的元素间隔：间隔相等就是希尔的增量
   卡 T希尔反推增量, 希尔排序
   坑 看到局部有序就判归并；归并第一趟是相邻两个有序
12. `short → unsigned int` ⟹ 先符号扩展成 32 位补码，再把这串位按无符号读
   卡 截断与扩展, 符号扩展, T等长换解释
   坑 以为转成无符号就取绝对值或补 0 扩展
13. 机器数 4730 0000H 求 float 值 ⟹ 拆成 符号 1 位 ＋ 阶码 8 位 ＋ 尾数，阶码减 127，尾数前补 1
   卡 IEEE754, T浮点先看阶码
   坑 忘了隐藏位 1（选 0.375），或阶码按 128 偏置
14. 8 位补码 $x-y$ 求结果和 OF ⟹ 先把两个数换成真值算出准确结果，看是否落在 $[-128,127]$；8 位结果取低 8 位
   卡 T溢出判别, 标志位, T标志位双线
   坑 只算出 8 位结果就判没溢出
15. 小端 + 边界对齐 + 结构体数组 ⟹ 先求一个元素占多少字节（含填充），再定 employee[1] 起址，最后在小端里找那个字节
   卡 T对齐小端, 边界对齐, 小端
   坑 忘了 name[10] 后要补 2 字节让 salary 4 字节对齐
16. 「由 ISA 规定的」⟹ 分清 ISA（程序员看得到的约定：指令格式、寄存器、寻址）和微架构（怎么实现）
   卡 ISA
   坑 把乘法器、控制器、数据通路这些实现选择当成 ISA
17. RISC「错误的是」⟹ 回忆 RISC 的几个标签：定长、Load/Store、寄存器多、硬布线、适合流水
   卡 CISC与RISC
   坑 把「难以流水」安到 RISC 头上——那是 CISC 的问题
18. CPI 与时钟周期「错误的是」⟹ 想 Cache 缺失时 CPU 在干什么：等待 ⟹ 每条指令的平均周期数会怎样
   卡 CPI, 单周期
   坑 以为 CPI 只由指令类型决定
19. 数据通路与控制器「错误的是」⟹ PC 属于哪一类寄存器；单周期与多周期控制器谁更复杂
   卡 数据通路, 单周期, T程序员可见
   坑 以为单周期控制器更复杂——多周期要按节拍分步发信号
20. 「1333MHz（实际单位是 MT/s）」+ 每周期 4 次 ⟹ MT/s 已经是每秒传送次数，不能再乘 4
   卡 突发传送带宽, T带宽口径
   坑 再乘 4 得 42.66GB/s
21. 适合 DMA 的设备 ⟹ 按「速度快、成块传输」挑；字符设备用中断
   卡 TDMA方式, DMA三阶段
   坑 以为打印机也是成块输出就该 DMA——针式打印机很慢、逐字符
22. 「触发外部中断请求」⟹ 分清来自 CPU 外部的事件和执行指令时的内部异常
   卡 外部中断源, T中断三分
   坑 把断点指令（自陷）当外中断；把「页故障处理结束」当中断事件
23. 上下文切换「不需要更新的」寄存器 ⟹ 问每个寄存器存的东西是进程私有还是全系统共用
   卡 进程切换, 中断向量表
   坑 以为所有寄存器都要换——中断向量表是全系统共用的
24. 虚拟化「错误的是」⟹ VMM 要管住客户 OS，它的特权级应该比客户 OS 高还是一样
   卡 虚拟化
   坑 以为不能模拟不同指令集
25. 就绪队列是按优先权有序的单链表 ⟹ 插入要找位置，选进程取表头，各是什么量级
   卡 T调度算法要素
   坑 以为插入总在表头 $O(1)$
26. LRU、3 页框、给定访问序列、0/1/2 已在内存 ⟹ 画「访问串 × 页框」表，每次淘汰最久没用的
   卡 T置换表
   坑 把开头 0、1、2 也当缺页；或淘汰时按进入时间（那是 FIFO）
27. 确定最少页框数要考虑的 ⟹ 想一条指令执行时最多要同时访问几页
   卡 最少页框
   坑 选「物理内存大小」——那决定能分多少，不决定最少要多少
28. VFS「正确的是」⟹ 它在具体文件系统之上加了一层什么
   卡 VFS
   坑 把「虚拟」理解成建在虚拟内存里
29. 新建文件 F「不会做的」⟹ 目录项里只有什么，属性放在哪
   卡 inode, T按名存取访盘
   坑 以为访问权限写在目录项里（那是 FCB 一体的老做法）
30. 内存映射文件「正确的是」⟹ 映射到的是虚拟地址还是物理地址；多个进程映射同一文件会怎样
   卡 内存映射文件, 页面共享
   坑 以为它直接映射到物理内存
31. 记录外存空闲空间 ⟹ 哪个结构里每个盘块都有一项、能标出「空闲」
   卡 FAT, 空闲块管理
   坑 选 FCB——它只记一个文件自己占了哪些块
32. 温彻斯特硬盘和固态硬盘「都要提供」⟹ 文件系统管理外存的最小单位是什么
   卡 磁盘格式化, 闪存
   坑 选「划分扇区」——固态硬盘没有磁道扇区；均衡磨损只有固态需要
33. 电路 / 报文 / 分组交换三种时间比较 ⟹ 电路：建立＋发送；报文：每段都要完整发一遍；分组：第一段发完 ＋ 最后一个分组再走剩下几段
   卡 T分组交换时延, T交换方式对比
   坑 忘了报文交换在每段都按那一段的带宽重新发送一遍
34. 给 4 个码字问检错纠错能力 ⟹ 两两求不同位数，取最小码距，再套 $e=d-1$、$t=\lfloor(d-1)/2\rfloor$
   卡 码距, 海明码
   坑 用最大码距或平均码距
35. 连续 11 次冲突后最大等待 ⟹ 指数退避 $k=\min(\text{冲突次数},10)$，最大 $2^k-1$ 个争用期，10Base-T 争用期 51.2μs
   卡 指数退避, T指数退避
   坑 k 取 11；或争用期按 0.512ms 算错一个数量级
36. DHCP REQUEST 报文的源、目的 IP ⟹ 此时主机拿到地址了吗？要让谁都听到吗？
   卡 DHCP报文, 特殊IP地址
   坑 以为收到 OFFER 后就能用 OFFER 里的地址发 REQUEST
37. NAT 改了 UDP 的哪些字段 ⟹ 出站改源 IP 和源端口；检验和包含伪首部里的 IP
   卡 NAT, TNAT改址, UDP检验和
   坑 忘了检验和也要重算
38. 甲在 t0 时刻的拥塞窗口与还能发几段 ⟹ 先按收到的 ACK 更新 cwnd，发送窗口 ＝ min(cwnd, rwnd) 再减在途
   卡 T发送窗口, 拥塞控制, T拥塞窗口
   坑 不减在途的那 1000B，多算一段
39. Time 服务 UDP 与 TCP 各要多久拿到时间 ⟹ UDP 一问一答；TCP 先握手，请求可以跟在第三次握手里
   卡 UDP, TRTT账本
   坑 TCP 多算一次挥手的时间——拿到时间就结束计时
40. POP3「正确的是」⟹ 分清读邮件（POP3/IMAP）、发邮件（SMTP）各走哪一段
   卡 邮件协议
   坑 以为 POP3 也负责用户代理发信
41. 求每个 A[i] 与任一 A[j] 乘积的最大值，要求时空高效 ⟹ 先想：乘积最大要么乘全局最大、要么乘全局最小
   卡 一趟最值, T标记数组
   坑 写成两重循环 $O(n^2)$（能拿部分分）；乘积溢出 int 不处理
42. AOE 网问工期、关键活动、可同时进行的活动、余量 ⟹ 正推 ve、逆推 vl，每条边算 $e,l$，余量 $l-e$
   卡 TAOE余量, 关键路径, T关键路径判断
   坑 「与 e 同时进行」要看可行时间段 [最早开始, 最迟结束] 是否与 e 的时段重叠，不是只看最早开始
43. 8 路组相联 32KB、块 64B，问地址划分与命中 ⟹ 切地址：块内位、组号位、标记位；看组号是否落在页内偏移里
   卡 TCache地址划分, VIPT, 组相联
   坑 组数算成 32KB÷64B（忘了除以路数）
44. 64 位乘除运算的机器级代码 ⟹ 符号扩展到 64 位后高 32 位全 1 还是全 0；固定次数的循环说明控制逻辑里有计数器
   卡 符号扩展, 乘法实现
   坑 把 8765 4321H 当正数做零扩展
45. 植树：甲挖坑、乙放苗填土、丙浇水，铁锹、水桶各 1 ⟹ 列「谁用什么工具」（互斥）和「谁等谁做完」（同步），坑数有上限
   卡 信号量同步, 同步互斥选择, TPV限流器
   坑 给只有丙用的水桶也加互斥；漏掉「最多挖几个坑」的计数信号量
46. 进程虚拟地址空间各区域 ⟹ 按变量类型对号：全局在数据段、局部在栈、malloc 在堆、代码在只读段、PCB 在内核区
   卡 虚拟地址空间, 系统调用
   坑 以为 strlen 这类库函数也会陷入内核
47. 卫星链路：时延、吞吐量、停等利用率与窗口 ⟹ 先算单向传播（上下两段）、发送时延，再画一个周期 ＝ 发送 ＋ 往返传播
   卡 T停等利用率, 停等协议, 时延带宽积, 两种时延
   坑 卫星的传播是「地面 → 卫星 → 地面」两段，RTT 是 4 段
