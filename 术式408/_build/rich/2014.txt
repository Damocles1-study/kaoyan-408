#1
@tpl T循环次数
::rev
- **该花** 30 秒。两层循环互不相干，各数各的再相乘。
- **卡点** 看到两层 for 就写 $O(n^2)$，没注意外层是 `k*=2`。
- **错了说明** 没有先看循环变量是「加 1」还是「乘 2」的习惯。
- **带走** 嵌套循环先看内层上限含不含外层变量：不含就各数各的再相乘，含就列表求和。
::read
「`for(k=1;k<=n;k*=2)`」 >> {{圈|k*=2}}：k 取 1, 2, 4, … 翻倍增长，执行约 $\log_2 n$ 次，不是 $n$ 次
「`for(j=1;j<=n;j++)`」 >> 内层上限是 $n$，{{波|与 k 无关}} ⟹ 每进一次外层，内层都跑满 $n$ 次，可以直接相乘
::fast
{{秒|外层翻倍 ⟹ log，内层跑满 ⟹ n，无关就相乘}}：$O(n\log_2 n)$，选 C。
::steps
外层：设执行 $t$ 次，第 $t$ 次时 $k=2^{t-1}$，需要 $2^{t-1}\le n$ ⟹ $t\le\log_2 n+1$ ⟹ 外层执行 $\lfloor\log_2 n\rfloor+1$ 次。
内层：`j` 从 1 到 $n$，固定执行 $n$ 次，与 `k` 的取值无关。
`count++` 的总次数 $=n(\lfloor\log_2 n\rfloor+1)$，量级为 $O(n\log_2 n)$，选 **C**。
~验算：$n=8$ 时 k 取 1、2、4、8 共 4 次，count＝32＝$8\times(3+1)$。
::note
- {{扣|把内层上限看成 k}}：若内层写成 `j<=k`，总次数是 $1+2+4+\dots+n\approx2n$，答案变成 $O(n)$（B 就是给这种看错准备的）。
- 对照 2017 第 1 题、2019 第 1 题：那两题是单层循环解方程，本题是两层无关相乘。
::vary
内层改为 `for(j=1;j<=k;j++)` >> 次数 $1+2+4+\dots+2^{\lfloor\log_2 n\rfloor}\lt2n$ ⟹ $O(n)$
外层改为 `for(k=1;k<=n;k++)`、内层改为 `for(j=1;j<=n;j*=2)` >> 仍是 $n$ 次 × $\log_2 n$ 次 ⟹ $O(n\log_2 n)$，谁在外谁在内不影响

@tpl T中缀转后缀
::rev
- **该花** 1 分半。一个符号写一行栈，写到 f 停。
- **卡点** 以为 `/` 还在栈底（错选 C、D），或把括号里 `-`、`*` 的上下次序写反（错选 A）。
- **错了说明** 「新运算符进栈前，先弹出优先级不低于它的」这条规则没执行到位。
- **带走** 中缀转后缀：新运算符先把栈顶优先级 ≥ 自己的弹光（遇「(」停）再进栈；栈里从底到顶优先级严格递增。
::read
「将中缀表达式 a/b+(c*d−e*f)/g 转换为等价的后缀表达式」 >> 栈里只放{{圈|运算符和左括号}}，操作数直接输出
「当扫描到 {{圈|f}} 时」 >> f 是操作数，不进栈；问的就是「第二个 `*` 刚压进去之后」的栈
「栈中的元素{{波|依次}}是」 >> 选项从左到右是栈底到栈顶
::fast
{{秒|栈内（同一层括号里）优先级必须自底向上严格递增}}：`/` 和 `+` 不可能同时在栈里（`+` 进栈前会把 `/` 弹掉）⟹ 排除 C、D；括号里 `*` 在 `-` 下面也不可能（`-` 进栈前会把 `*` 弹掉）⟹ 排除 A，选 B。
::steps
规则见 [[T中缀转后缀]]。逐个符号走：
| 扫到 | 动作 | 栈（底 → 顶） |
| a | 输出 | 空 |
| / | 栈空，进栈 | / |
| b | 输出 | / |
| + | `/` 优先级高于 `+`，弹出；`+` 进栈 | + |
| ( | 直接进栈 | + ( |
| c | 输出 | + ( |
| * | 栈顶是「(」，停；`*` 进栈 | + ( * |
| d | 输出 | + ( * |
| − | `*` 优先级高于 `−`，弹出；遇「(」停；`−` 进栈 | + ( − |
| e | 输出 | + ( − |
| * | 栈顶 `−` 优先级低于 `*`，不弹；`*` 进栈 | + ( − * |
| f | 输出 | ==+ ( − *== |
扫到 f 时栈中自底向上是 `+ ( − *`，选 **B**。
~往后走完：`)` 弹出 `*`、`−` 并消掉「(」；`/` 进栈；g 输出；最后弹 `/`、`+`。后缀式为 `ab/cd*ef*−g/+`。
::note
- {{扣|把「(」当成优先级最高}}：「(」进栈时谁也不弹；在栈里时谁也弹不动它，只有「)」能让它出栈。
- 同级运算符（`+` 遇 `−`、`*` 遇 `/`）也要弹：左结合，先来的先算。
::vary
同一表达式，扫描到 g 时栈中元素 >> `)` 把 `*`、`−`、`(` 清掉后栈是 `+`；`/` 优先级高于 `+`，进栈 ⟹ `+ /`
转换 a+b−c*d 时，栈中最多同时有几个运算符 >> `+` 进；`−` 来时弹 `+` 再进；`*` 进 ⟹ 最多 2 个（`− *`）

::rev
- **该花** 40 秒。空看「初始状态」，满看「再放一个就和空分不清」。
- **卡点** 被「两端均可入队出队」和「M−1」带偏，选了模 M−1 的 B、D。
- **错了说明** [[循环队列]]「取模永远用数组长度」没有记死。

::read
「end1 指向队首元素，end2 指向{{圈|队尾元素的后一个位置}}」 >> 就是教材里的 front、rear 那种定义（rear 指向下一个空位）
「两端均可进行入队和出队操作」 >> {{波|干扰信息}}：判空判满只看两个指针的相对位置，与从哪端进出无关
「最多能容纳 {{圈|M−1}} 个元素，初始时为空」 >> 留一个空位来区分空和满；M−1 是容量，不是模数
::fast
{{秒|模数只能是 M}} ⟹ B、D 出局。{{秒|空队时 end2 就指在 end1 上}}（队尾后一个位置＝队首位置）⟹ 队空是 `end1==end2`，C 出局，选 A。
::steps
队空：队中没有元素，「队尾元素的后一个位置」就是队首位置本身 ⟹ `end1 == end2`。
队满：已有 $M-1$ 个元素，从 end1 起占了 $M-1$ 格，end2 落在 end1 的前一格（循环意义下）⟹ end2 再走一步就回到 end1，即 `end1 == (end2+1) mod M`。
数组下标范围是 $0\sim M-1$，共 $M$ 个位置，循环一圈要 `mod M`；`mod (M−1)` 会让下标 $M-1$ 永远用不上。
对照选项：A 两条都对；B、D 模数错；C 的「队空」写成了另一种定义（end2 指向队尾元素本身时）的条件。选 **A**。
::note
- {{扣|把容量 M−1 当模数}}：这是 B、D 的全部设计。
- 若不留空位而另设一个计数器或标志位，就能存满 M 个，判空判满改看计数器——题干写了「最多 M−1 个」才能认定是留空位这种做法。
::vary
同样定义下，队列中元素个数的表达式 >> `(end2 − end1 + M) mod M`
若 end2 改为指向队尾元素本身、仍最多放 M−1 个，判空和判满 >> 空：`end1 == (end2+1) mod M`；满：`end1 == (end2+2) mod M`

@tpl T前缀码树
::rev
- **该花** 30 秒。找「短码是长码的开头」。
- **卡点** 逐个两两比太慢，或把题目问的「不是」看成「是」。
- **错了说明** 没有先按码长排序、只拿短码去套长码的做法。
- **带走** 判[[前缀码]]：只拿短码去比长码的开头；等长的码之间不用比。
::read
「{{圈|不是}}前缀编码的是」 >> 找反例：某个码是另一个码的开头
「D. 0, 100, 110, 1110, 1100」 >> 110 与 1100、1110 开头都是 11，重点看这三个
::fast
{{秒|只拿短的比长的}}：D 里 3 位的 110 正是 4 位 1100 的前三位 ⟹ 不是前缀码，选 D。
::steps
前缀码的要求：任何一个字符的编码都不是另一个字符编码的前缀。
A：01、0000、0001、001、1。1 开头的只有「1」自己；01 与 00 开头的三个不同；001 与 0000、0001 在第三位不同 ⟹ 是前缀码。
B：011、000、001、010、1。四个 3 位码两两不同，1 开头的只有「1」⟹ 是。
C：五个都是 3 位且互不相同，等长码不可能互为前缀 ⟹ 是。
D：110 是 1100 的前缀（1100 去掉末位就是 110）⟹ 不是前缀码，选 **D**。
::note
- 画成 0 左 1 右的二叉树更直观：前缀码的每个字符都落在叶子上。D 里 110 落在的结点下面还挂着 1100，它不是叶子。
- 对照 2020 第 42 题：那题要自己写「逐个编码插入二叉树」的判定过程，本题只用看一眼。
::vary
把 D 的 110 改成 101，是不是前缀码 >> 0、100、101、1110、1100 互不为前缀 ⟹ 是
A 的五个编码对应的二叉树有没有度为 1 的结点 >> 没有（0 下有 00、01，00 下有 000、001，000 下有 0000、0001），是哈夫曼树那样的严格二叉树

「指令 Cache 与数据 Cache {{圈|分离}}」 >> 取指令走一个 Cache，读写数据走另一个，两者可以同时访问
「{{圈|主要目的}}」 >> 找设计它的原因，不是找顺带的好处
::fast
{{秒|分离 ⟹ 同一拍既能取指又能访存 ⟹ 少一种流水线冲突}}，选 D。
::steps
五段流水线里，第 $i$ 条指令在 MEM 段访问存储器取数据时，第 $i+3$ 条指令正好在 IF 段访问存储器取指令。
若只有一个 Cache，这两次访问在同一个时钟周期争用同一个部件，后一条必须停一拍，这就是[[结构冒险]]（资源冲突）。
把指令 Cache 和数据 Cache 分开后，两次访问各走各的，冲突消失 ⟹ 主要目的是减少指令流水线的资源冲突，选 **D**。
A：缺失损失取决于从主存调块要多久，与分不分离无关。
B、C：分离后命中率和平均访存时间可能略有变化，但不是这样设计的原因。
::note
- 只有最靠近 CPU 的一级 Cache（L1）分成指令和数据两个；L2、L3 通常不分。
- 三种冒险各记一个典型：结构冒险＝争部件；[[数据冒险]]＝后一条要用前一条还没写回的数；[[控制冒险]]＝转移指令改了 PC。本卷第 44 题考后两种。
::vary
寄存器堆在 ID 段被读、在 WB 段被写，同一拍读写同一个寄存器怎么避免冲突 >> 前半个周期写、后半个周期读
把 Cache 分离后，load 指令后面紧跟一条使用其结果的指令，还会不会停顿 >> 会，那是数据冒险（load-use），与结构冒险无关

::read

::fast

::steps

每秒传送次数：时钟频率 66 MHz，每个周期上升沿、下降沿各传一次 ⟹ $66\text{M}\times2=132\text{M}$ 次。

- {{扣|因为「复用」就打折}}：复用只是地址和数据共用一组线，问最大数据传输率时不考虑传地址占掉的周期。

::vary

@tpl T死锁资源数
::rev
- **该花** 30 秒。$(3-1)+(4-1)+(5-1)+1$。
- **卡点** 算到 9 就选 A，忘了 9 台时正好全卡住。
- **错了说明** 「每人差一个」是最坏情况，这时还得再多 1 个，等号不能取。
- **带走** 保证不死锁的最少资源数＝每个进程（需求 − 1）加起来，再加 1。
::read
「n 台{{圈|互斥使用}}的同类设备，三个并发进程分别需要 3, 4, 5 台」 >> 最坏情况：每个进程都只差 1 台就够
「{{圈|可确保}}系统不发生死锁的设备数 n {{圈|最小}}为」 >> 在最坏分配之上再多 1 台
::fast
{{秒|2＋3＋4＝9 台时可能人人差一台；再加 1 台}} ⟹ 10，选 B。
::steps
最坏情况：三个进程分别已拿到 2、3、4 台（各差 1 台），共占用 $2+3+4=9$ 台。
若 $n=9$：此时设备分完，三个进程都在等最后 1 台，谁也不释放 ⟹ 死锁。
若 $n=10$：无论怎么分，至少有一个进程能凑够自己的需求（否则每个进程最多拿「需求 − 1」台，总共至多 9 台，还剩 1 台可以再分给某个进程让它凑齐）；它运行完释放设备，其余进程也能陆续完成 ⟹ 不会死锁。
所以最小的 $n=10$，选 **B**。
::note
- {{扣|取等号}}：公式是 $n\gt\sum(k_i-1)$，即 $n\ge\sum(k_i-1)+1$；A 的 9 就是忘了加 1。
- D 的 12 是把需求直接相加，那是「谁都不用等」的数量，不是「最小」。

@tpl T递归带深度
::rev
- **该花** 14 分钟。思想 2 分钟、类型定义 1 分钟、代码 8 分钟、检查 3 分钟。
- **卡点** 不知道深度从哪来；或只在叶子处乘深度却忘了往下传 `deep+1`；或漏写第 2 问的结点类型定义。
- **错了说明** 「递归函数多带一个层数参数」这个写法没练过。
- **带走** 二叉树上与层数有关的量：写 `f(结点, 深度)`，空返回 0，叶子返回贡献，否则返回左右两个 `f(孩子, 深度+1)` 之和。
::read
「WPL 是二叉树中{{圈|所有叶结点}}的带权路径长度之和」 >> 只有叶子算数：每个叶子贡献 weight × 它到根的路径长度（根的深度记 0）
「结点结构为 (left, weight, right)」 >> 第 2 问要把它写成 C 的结构体，别漏
「请设计求 T 的 WPL 的算法」 >> 遍历整棵树，到叶子就累加；遍历时要知道当前结点在第几层
::think
- 需要「每个叶子的深度」⟹ 遍历时把深度一路带下去：先序递归多带一个参数最省事，三行就够。
- 这题保底解就是最优解：每个结点访问一次，时间 $O(n)$。
- 不会递归的备选：层序遍历，一层一层出队，记当前层号。
::steps
设根的深度为 0，孩子的深度＝父亲的深度＋1。叶子 v 的带权路径长度＝`v->weight × v 的深度`。
定义 `wplPre(T, deep)` 表示「以 T 为根、T 位于深度 deep 时，这棵子树里所有叶子的带权路径长度之和」。
T 为空：没有叶子，返回 0。
T 是叶子（左右孩子都空）：返回 `T->weight * deep`。
否则：返回 `wplPre(T->left, deep+1) + wplPre(T->right, deep+1)`。
整棵树的 WPL＝`wplPre(root, 0)`。
~手算验证：根有左叶子 A（权 3）和右孩子 N，N 有两个叶子 B（权 4）、C（权 5）。A 深度 1，B、C 深度 2 ⟹ WPL $=3\times1+4\times2+5\times2=21$；程序：`wplPre(root,0)` $=$ `wplPre(A,1)` $+$ `wplPre(N,1)` $=3+(8+10)=21$。
::paper
**1）基本设计思想** ⛳4
采用先序遍历的递归算法，递归时用参数 deep 记录当前结点的深度（根的深度为 0）。若当前结点为空，返回 0；若为叶结点，返回该结点的 weight 与 deep 的乘积；否则返回其左、右子树的 WPL 之和，递归进入孩子时深度加 1。
**2）二叉树结点的数据类型定义** ⛳2
```
typedef struct BiTNode{
    int weight;                     // 叶结点的权值
    struct BiTNode *left, *right;   // 左、右孩子指针
}BiTNode, *BiTree;
```
**3）算法描述** ⛳7
```
int wplPre(BiTree T, int deep){     // deep 为 T 所指结点的深度
    if(T == NULL) return 0;         // 空树没有叶结点
    if(T->left == NULL && T->right == NULL)
        return T->weight * deep;    // 叶结点：权值 × 深度
    return wplPre(T->left, deep+1)  // 非叶结点：左右子树之和，深度加 1
         + wplPre(T->right, deep+1);
}
int WPL(BiTree root){
    return wplPre(root, 0);         // 根的深度为 0
}
```
时间复杂度 $O(n)$，空间复杂度 $O(h)$（递归栈，$h$ 为树高）。
**备选（层序遍历，不用递归）**：用队列按层遍历，每轮先记下队列中的结点数（就是这一层的结点数），把这一层的结点依次出队：是叶子就把 `weight × 层号` 加进 wpl，并把非空的孩子入队；一层处理完层号加 1。
```
#define MaxSize 1000
int WPL2(BiTree root){
    BiTree Q[MaxSize], p;
    int front = 0, rear = 0, deep = 0, wpl = 0, i, n;
    if(root == NULL) return 0;
    Q[rear++] = root;
    while(front < rear){
        n = rear - front;                       // 本层结点数
        for(i = 0; i < n; i++){
            p = Q[front++];
            if(p->left == NULL && p->right == NULL)
                wpl += p->weight * deep;        // 叶结点
            if(p->left)  Q[rear++] = p->left;
            if(p->right) Q[rear++] = p->right;
        }
        deep++;                                 // 进入下一层
    }
    return wpl;
}
```
