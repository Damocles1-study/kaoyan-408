#1
@ans D
@tpl T有序表合并
::rev
- **该花** 40 秒。合并要把每个结点摘一遍 ⟹ $O(m+n)$，再在选项里找同阶的写法。
- **卡点** 选项里没有 $O(m+n)$ 就慌了，选了 A；或以为「升序变降序」要多一趟逆置而选 B。
- **错了说明** 不知道 $O(m+n)$ 与 $O(\max(m,n))$ 是同一个量级。
- **带走** 两个有序表合并是 $O(m+n)$，等价写法是 $O(\max(m,n))$；要逆序就把尾插换成头插，代价不变。
::read
「两个长度分别为 m 和 n 的{{圈|升序}}链表……合并为一个{{圈|降序}}链表」 >> 每次取两表表头中较小的，用{{波|头插法}}接到结果表上：先插进去的小元素被压到后面，自然成降序
「最坏情况下的时间复杂度」 >> 数基本操作（比较、摘结点）的次数，再到选项里找同阶的
::fast
{{秒|每个结点都要被摘下来一次，共 m+n 次}} ⟹ $O(m+n)$。$\max(m,n)\le m+n\le2\max(m,n)$ ⟹ 就是 $O(\max(m,n))$，选 D。
::steps
做法：指针 p、q 分别指向两个表的第一个结点。比较 p、q 所指元素，把较小的那个结点摘下，头插到结果表；该表指针后移。
一个表摘完后，另一个表剩下的结点也要逐个摘下头插（因为要降序，不能整段直接接上）。
摘结点的次数：不管怎么比，两个表的结点都要各摘一次，恒为 $m+n$ 次。
比较的次数：最坏情况是两表元素交错（如 1,3,5 与 2,4,6），每比较一次只定下一个结点，直到只剩最后一个结点不用比 ⟹ $m+n-1$ 次。
所以最坏时间复杂度为 $O(m+n)$。
换写法：设 $M=\max(m,n)$，则 $M\le m+n\le2M$ ⟹ $m+n$ 与 $M$ 只差常数倍，$O(m+n)=O(\max(m,n))$，选 **D**。
~A 只提 $n$：若 $m$ 远大于 $n$ 就不对。B 是「每个元素都扫一遍另一个表」的量级，归并不回头。C 太小：连把所有结点接起来都不够。
::note
- {{扣|把「最坏比较次数 m+n−1」和「复杂度」混着选}}：问复杂度选 $O(\max(m,n))$；问比较次数最多才是 $m+n-1$、最少是 $\min(m,n)$。
- 升序合成升序（尾插）时，一个表走完后剩余部分可以整段接上；本题要降序，剩余部分仍要逐个头插——所以连最好情况也是 $O(m+n)$。
::vary
两个升序顺序表（长 m 和 n）合并成一个升序表，最少、最多各比较几次 >> 最少 $\min(m,n)$（短表全小于长表首元素）；最多 $m+n-1$
把两个升序链表合并成升序链表，且一个表所有元素都小于另一个表，最好情况的时间复杂度 >> 比较 $\min(m,n)$ 次后剩余整段接上 ⟹ $O(\min(m,n))$（尾插才有这个便宜，头插没有）

#2
@ans C
@tpl T出栈序列
::rev
- **该花** 1 分半。按 P₁ 是谁分三种情况，每种看 P₃ 能取谁。
- **卡点** 只想到 P₃ 取 4 以后的数（n−3 个），漏了 1 和 2，错选 A；或觉得情况太多选 D。
- **错了说明** 没有按「第一个出栈的是谁」分类；忘了 3 出栈后栈里还压着比它小的元素。
- **带走** 出栈序列某一位「可能取哪些值」：按前面几位分情况，每种情况看「此刻栈顶是谁、还有谁没进栈」，栈顶可以直接出，没进栈的可以进了就出。
::read
「入栈序列为 1,2,3,…,n」「{{圈|P₂=3}}」 >> 第二个出栈的是 3 ⟹ 3 出栈时 1、2 都已进过栈，其中恰有一个（或 4）已经先出去了
「P₃ {{波|可能取值的个数}}」 >> 把 P₁ 的各种可能列出来，对每种看 P₃ 能是谁，最后取并集
::fast
{{秒|P₃ 肯定不是 3，其余的数逐个想都能造出来}}：1（P₁=2）、2（P₁=1）、4 及以后（进到它就出）⟹ $n-1$ 个，选 C。
::steps
3 出栈之前只出过一个元素 P₁。P₁ 只可能是 1、2 或 4（见下）。
| P₁ | 操作 | 3 出栈后栈里（底→顶） | P₃ 可以是 |
| 1 | 进1 出1 进2 进3 出3 | 2 | 2（直接出）；或继续进 4…k 再出 k：4 ～ n |
| 2 | 进1 进2 出2 进3 出3 | 1 | 1；或 4 ～ n |
| 4 | 进1 进2 进3 进4 出4 出3 | 1 2 | 2；或 5 ～ n |
~P₁ 不可能是 5 及以后：那样 4 压在 3 上面，第二个出栈的轮不到 3。
并集：$\{1,2,4,5,\dots,n\}$，即除 3 以外的所有数，共 $n-1$ 个，选 **C**。
~验算 $n=4$：合法出栈序列里 P₂=3 的有 1,3,2,4；1,3,4,2；2,3,1,4；2,3,4,1；4,3,2,1 ⟹ P₃ ∈ {2,4,1}，3 个＝$n-1$。
::note
- {{扣|忘了栈里还压着 1 或 2}}：A 的 $n-3$ 就是只数了 4 ～ n。
- 对照 2020 第 2 题、2022 第 2 题：那两题给完整序列判合法，本题是「固定一位、问另一位」，方法都是画栈。
::vary
其他不变，改问「若 P₁=3，则 P₂ 可能取值的个数」 >> 3 先出时栈里是 1 2，P₂ 可以是 2，或 4 ～ n；1 被 2 压着出不来 ⟹ $n-2$ 个
若 P₁=n，则 Pᵢ 是多少 >> n 最先出 ⟹ 全部进栈后才开始出，只能依次弹 ⟹ $P_i=n-i+1$

#3
@ans D
@tpl TAVL旋转
::rev
- **该花** 2 分钟。一个个插，每次失衡都是同一种左旋；画到 7 得满二叉树。
- **卡点** 插 5、插 6 时失衡点找错（应找离新结点最近的那个失衡祖先），树画歪了。
- **错了说明** RR 型左旋不熟：失衡点 A 下去做左孩子，A 的右孩子 B 上来，B 原来的左子树改挂到 A 的右边。
- **带走** 递增序列依次插入 AVL，每次失衡都是 RR 型左旋；插入 $2^k-1$ 个后恰好是满二叉树。
::read
「将关键字 1, 2, 3, 4, 5, 6, 7 {{圈|依次插入}}初始为空的平衡二叉树」 >> 递增插入 ⟹ 新结点总挂在最右下 ⟹ 每次失衡都是 RR 型，做一次左旋
「平衡因子为 0 的{{圈|分支结点}}」 >> 叶子的平衡因子也是 0，但不算；只数有孩子的结点
::sk 300 150 画 | 先画最终的树（7 个结点正好排满三层），再在三个分支结点旁标平衡因子 0
s.tree((4,(2,(1,),(3,)),(6,(5,),(7,))),150,20,dx=72,dy=44,r=12)
s.text(168,18,'0',12,'r');s.text(96,62,'0',12,'r');s.text(240,62,'0',12,'r')
s.text(6,144,'分支结点 4、2、6 的平衡因子都是 0',11,'b')
::fast
{{秒|7＝2³−1 个递增关键字插入 AVL ⟹ 满二叉树}}，3 个分支结点左右等高，全是 0，选 D。
::steps
规则见 [[AVL]]、[[TAVL旋转]]。下面用「根(左,右)」写树形，「—」表示空。
插 1、2：2(…) 还没到，树是 1(—,2)，平衡。
插 3：1 的右子树高 2、左子树高 0，1 失衡，RR 型 ⟹ 以 1 为轴左旋：2(1,3)。
插 4：2(1,3(—,4))，各结点平衡因子绝对值不超过 1，不转。
插 5：5 挂在 4 的右边；3 的左高 0、右高 2，3 失衡（离 5 最近的失衡祖先），RR 型 ⟹ 左旋：2(1,4(3,5))。
插 6：6 挂在 5 的右边；根 2 的左高 1、右高 3，2 失衡，RR 型 ⟹ 左旋：4 上来做根，2 做 4 的左孩子，4 原来的左孩子 3 改挂到 2 的右边：4(2(1,3),5(—,6))。
插 7：7 挂在 6 的右边；5 的左高 0、右高 2，5 失衡，RR 型 ⟹ 左旋：4(2(1,3),6(5,7))。
最终是三层的[[满二叉树]]。分支结点 4、2、6 的左右子树等高，平衡因子都是 0 ⟹ 3 个，选 **D**。
::note
- {{扣|找失衡点从根往下找}}：要从新插入的结点往上找，第一个失衡的祖先才是旋转点（插 5 时转的是 3，不是 2）。
- {{扣|左旋后丢子树}}：插 6 时 4 的左孩子 3 必须改挂到 2 的右边，否则 3 丢了。
- 对照 2019 第 4 题、2021 第 6 题：那两题要分辨 LL、LR、RL、RR 四种；本题四次全是 RR。
::vary
若只插入 1 ～ 6，平衡因子为 0 的分支结点有几个 >> 树是 4(2(1,3),5(—,6))：2 是 0，4 是 0（左右都高 2），5 是 −1 ⟹ 2 个
若依次插入 7, 6, 5, 4, 3, 2, 1，结果有什么不同 >> 每次失衡是 LL 型右旋，最终仍是满二叉树 4(2(1,3),6(5,7))，答案还是 3

#4
@ans B
@tpl T哈夫曼, T虚段
::rev
- **该花** 2 分钟。先验要不要补 0，再三次合并，把三个合并值相加。
- **卡点** 没补虚叶子，直接 2+3+4 合并，算出 54 或 56。
- **错了说明** 不知道 k 叉哈夫曼树要先凑够「$(n-1)\bmod(k-1)=0$」。
- **带走** k 叉哈夫曼树：先算 $(n-1)\bmod(k-1)$，不为 0 就补权为 0 的叶子补到整除；WPL＝所有合并出来的结点权值之和。
::read
「{{圈|三叉树}} T 中 6 个叶结点」 >> 不是二叉！每次合并 3 个变 1 个，少 2 个；6 个叶子合并到剩 1 个要减 5，5 不是 2 的倍数 ⟹ 要补 1 个权为 0 的虚叶子
「带权（外部）路径长度{{圈|最小}}」 >> 构造三叉[[哈夫曼树]]
::sk 360 185 画 | 先补一个 0，再每次挑最小的三个合并；树画出来后把三个方框里的数相加
s.box(148,8,26,22,'r');s.text(161,24,'27',12,'r','middle')
for (x,t) in [(80,'6'),(161,'7')]: s.node(x,72,t,r=11);s.edge(161,30,x,72,r0=0,r1=11)
s.box(229,61,26,22,'r');s.text(242,77,'14',12,'r','middle');s.edge(161,30,242,61,r0=0,r1=0)
for (x,t) in [(190,'4'),(242,'5')]: s.node(x,125,t,r=11);s.edge(242,83,x,125,r0=0,r1=11)
s.box(283,114,24,22,'r');s.text(295,130,'5',12,'r','middle');s.edge(242,83,295,114,r0=0,r1=0)
for (x,t) in [(255,'0'),(295,'2'),(335,'3')]: s.node(x,170,t,r=11,c='b' if t=='0' else 'k');s.edge(295,136,x,170,r0=0,r1=11)
s.text(8,150,'WPL = 5+14+27',12,'r');s.text(8,170,'    = 46',12,'r')
::fast
{{秒|WPL＝合并出来的结点权值之和}}：补 0 后 $0+2+3=5$，$4+5+5=14$，$6+7+14=27$，$5+14+27=46$，选 B。
::steps
先验叶子数：三叉哈夫曼树每个分支结点都有 3 个孩子（见 [[严格k叉树]]），每次合并叶子数减 2。$(6-1)\bmod(3-1)=1\ne0$ ⟹ 补 $3-1-1=1$ 个权为 0 的虚叶子，权值集合变成 0, 2, 3, 4, 5, 6, 7。
第 1 次：取最小的三个 0、2、3，合并成 5。剩 4, 5, 5, 6, 7。
第 2 次：取 4、5、5，合并成 14。剩 6, 7, 14。
第 3 次：取 6、7、14，合并成 27，成为根。
WPL＝所有非叶结点的权值之和 $=5+14+27=46$，选 **B**。
~按定义验算（路径长度＝叶子到根的边数）：$6\times1+7\times1+4\times2+5\times2+2\times3+3\times3=46$。
~不补虚叶子会怎样：$2+3+4=9$，$5+6+7=18$，最后只剩 9、18 两个，根只有 2 个孩子——等于把最上面一层的位置浪费了，WPL $=9+18+27=54$，这就是 C。
::note
- {{扣|忘记补虚叶子}}：二叉哈夫曼树永远不用补（$k-1=1$），三叉及以上必须先验。
- 与外部排序的[[最佳归并树]]是同一件事：对照 2019 第 11 题，那题问的就是补几个虚段。
::vary
把题目改成四叉树，6 个叶子权值不变，要补几个虚叶子、最小 WPL 是多少 >> $(6-1)\bmod3=2$，补 $3-2=1$ 个 0：$0+2+3+4=9$，$5+6+7+9=27$ ⟹ WPL $=9+27=36$
三叉树改成 7 个叶子 2, 3, 4, 5, 6, 7, 8，要补吗、WPL 是多少 >> $(7-1)\bmod2=0$ 不补：$2+3+4=9$，$5+6+7=18$，$8+9+18=35$ ⟹ $9+18+35=62$

#5
@ans A
::rev
- **该花** 40 秒。X 有左兄弟 ⟹ X 是右孩子；后序里右孩子后面紧跟父亲。
- **卡点** 把「右线索」想成前驱，选了 D（Y 子树里最后被访问的是 Y 自己，也不是最右下结点）；或看 Y 在旁边就选 C。
- **错了说明** 没把「左右根」三个字和「兄弟、父亲」对应起来。
- **带走** 后序遍历中：右孩子的后继是父亲；左孩子的后继是「右兄弟子树里后序第一个结点」（没有右兄弟就是父亲）。
::read
「{{圈|后序}}线索二叉树中的叶结点 X」 >> 叶子的左右指针都空，都是线索；右线索指[[后序遍历]]序列里的后继
「X 存在{{圈|左兄弟}}结点 Y」 >> 有左兄弟 ⟹ X 是它父亲的{{波|右孩子}}
::sk 250 120 画 | 先画父亲 P、左孩子 Y（下面可以还有子树）、右孩子 X，再按「左右根」写出访问顺序
s.node(125,20,'P');s.node(70,70,'Y');s.node(180,70,'X');s.edge(125,20,70,70);s.edge(125,20,180,70)
s.poly([(70,82),(48,112),(92,112),(70,82)],'g',1.0,dash='3 3')
s.bend(186,58,137,16,k=-14,c='r',dash='4 3');s.text(192,40,'右线索',11,'r')
s.text(6,16,'后序：',11,'b');s.text(6,34,'…Y, X, P',12,'b')
::fast
{{秒|后序＝左右根：右孩子访问完就轮到根}}，X 是右孩子 ⟹ 后继是父结点，选 A。
::steps
设 X 的父结点为 P。X 有左兄弟 Y ⟹ Y 是 P 的左孩子，X 是 P 的右孩子。
后序遍历以 P 为根的子树：先遍历以 Y 为根的左子树（最后访问的是 Y），再遍历以 X 为根的右子树，最后访问 P。
X 是叶子，「以 X 为根的右子树」只有 X 一个结点 ⟹ 这一段的访问顺序是 …, Y, X, P。
X 的后继是 P，X 的右指针为空，所以右线索指向 P，即 X 的父结点，选 **A**。
~顺带：X 的前驱是 Y，所以 X 的左线索指向 Y（C 说的是左线索）。B 是后序遍历 Y 子树时最先访问的结点（不一定是最左下，但方向是这个），与 X 无关。
::note
- {{扣|把中序的结论搬过来}}：中序线索里「右线索指向某个祖先」要往上找；后序里右孩子的后继固定是父亲，最简单。
- 对照 2014 第 4 题：那题是中序线索，做法是写中序序列找左右邻；本题没有具体的树，只能按「左右根」推理。
::vary
同样条件，X 的左线索指向谁 >> 后序里 X 的前驱是左兄弟子树最后被访问的结点，就是 Y 本身
若 X 是后序线索二叉树中的叶结点，且是其父结点 P 的左孩子，P 还有右孩子 Z，X 的右线索指向谁 >> 后序遍历 Z 子树时第一个被访问的结点（从 Z 出发：有左孩子就往左，没有左孩子就往右，直到叶子）

#6
@ans C
@tpl T罗马数字组合
::rev
- **该花** 50 秒。记住「插入的结点一定是叶子」，四条两两互斥，各挑一条。
- **卡点** 觉得删非叶结点后「也许碰巧能插回原位」，在 Ⅲ、Ⅳ 之间犹豫。
- **错了说明** [[BST删除]]里「新插入的结点必为叶子」这句话没用上。
- **带走** 二叉排序树插入的新结点一定是叶子：删叶子再插回，树不变；删分支结点再插回，树一定变。
::read
「删除某结点 v ……{{圈|再将 v 插入}}」 >> 插入只会在某个空指针处挂一个新{{波|叶子}}，不会插到树的中间
「Ⅰ 与 Ⅱ、Ⅲ 与 Ⅳ」 >> 两对各自互斥，每对恰好对一条 ⟹ 实际上是两道判断题
::fast
{{秒|v 插回去以后一定是叶子}}：原来是叶子 ⟹ 回到原位，相同（Ⅱ）；原来不是叶子 ⟹ 现在是叶子，不同（Ⅲ）。选 C。
::steps
v 是叶子：删除时直接摘掉，其余结点不动。再插入 v，查找路径与原来找 v 的路径完全一样（路径上的结点都没变），走到 v 原来所在的那个空指针处挂上 ⟹ $T_3$ 与 $T_1$ 相同。Ⅱ 对，Ⅰ 错。
v 不是叶子：在 $T_1$ 中 v 至少有一个孩子。删除后由它的子树或者中序前驱 / 后继顶替它的位置。再插入时，v 作为新结点只能成为叶子。
$T_1$ 中 v 有孩子，$T_3$ 中 v 没有孩子 ⟹ 两棵树一定不同。Ⅲ 对，Ⅳ 错。
~例：$T_1$ 为根 2、左 1、右 3。删 2，用后继 3 顶替：根 3、左 1。再插 2：比 3 小往左，比 1 大往右 ⟹ 2 成为 1 的右孩子。$T_3$ 是根 3、左 1、1 的右孩子 2，与 $T_1$ 不同。
选 **C**。
::note
- {{扣|用「可能相同」的直觉判 Ⅳ}}：只要抓住「有孩子」与「没孩子」这个差别，就不必枚举删除的三种情形。

::vary

{{秒|D 从 a 出发，a 的邻接点是 b、e、h，可序列是 a,b,c,d,…}}：e、h 还没出就去了 c、d ⟹ 这是深度优先的走法，选 D。

判法见 [[T判BFS序列]]。逐项验：
A：h,c,a,b,d,e,g,f。h 的邻接点 a、c ⟹ 第 2、3 位是 c、a，对。c 带出 b、d，a 带出 e（b 已有）⟹ 接着 b,d,e，对。e 带出 f、g ⟹ g,f，对。是 BFS 序列。
B：e,a,f,g,b,h,c,d。e 的邻接点 a、f、g ⟹ 第 2 ～ 4 位是 a,f,g，对。a 带出 b、h ⟹ b,h，对。b 带出 c、d ⟹ c,d，对。是 BFS 序列。
C：d,b,c,a,h,e,f,g。d 的邻接点 b、c，对。b 带出 a，c 带出 h ⟹ a,h，对。a 带出 e；e 带出 f、g，对。是 BFS 序列。
D：a,b,c,d,h,e,f,g。a 的邻接点是 b、e、h，应当紧跟在 a 后面；序列里 b 之后是 c、d（b 的邻接点）⟹ a 的邻接点还没出完就往深处走了，不是 BFS 序列。
选 **D**。
~D 其实是一个深度优先序列：a→b→c→d，d 走不动退回 c，c→h，再退回 a，a→e→f，退回 e，e→g。
::note
- {{扣|同一层内的顺序看错}}：A 里 c 先于 a 出队，所以 c 的新邻接点（b、d）要排在 a 的新邻接点（e）前面；B 里 b,h 的顺序同理决定后面的顺序。
- 对照 2015 第 5 题、2016 第 6 题判 DFS 序列：DFS 是「有没访问的邻接点就必须往下走」，BFS 是「邻接点出完才能往下走」。
::vary
对同一个图，从 e 出发的广度优先序列，第 5 ～ 6 位只可能是哪两个顶点 >> e 后面三位是 a、f、g（任意顺序）；它们带出的新顶点只有 a 的 b、h ⟹ 第 5、6 位是 b、h
序列 a,e,h,b,g,f,c,d 是不是 BFS 序列 >> a 后面 e,h,b 对；出队顺序 e、h、b：e 带出 f、g（g,f 可以），h 带出 c，b 带出 d ⟹ 应为 …g,f,c,d，是 BFS 序列

::rev
- **该花** 15 分钟。保底解 8 分钟写完（思想 2、代码 4、复杂度 1、检查 1）；背过抵消法再花 5 分钟写最优解。
- **卡点** 想不出最优解就整题空着；或写了抵消法却漏掉第二趟「再数一遍确认」，没有主元素时输出了错的候选。

- **带走** 「找出现次数超过一半的元素」：保底开计数数组（或排序后取中间那个）再核对次数；最优是「不同的两两抵消、剩下的当候选、再数一遍确认」。
::read
「其中 {{圈|0≤aᵢ＜n}}」 >> 值域有界且不超过 n ⟹ 可以开一个长度为 n 的计数数组，用元素值当下标——保底解就在这句话里
「{{圈|m＞n/2}}，则称 x 为 A 的主元素」 >> 严格超过一半；主元素最多只有一个
「若存在则输出该元素，否则输出 {{圈|−1}}」 >> 可能不存在 ⟹ 无论哪种做法，最后都必须拿出现次数和 n/2 比一次
::think
- 先写保底：计数数组，两个循环，时间 $O(n)$、空间 $O(n)$。只因空间不是最优而扣几分，大部分分到手。
- 再想最优：主元素比其余所有元素加起来还多，「一个主元素拼掉一个别的元素」之后它还有剩 ⟹ 抵消法，只用两个变量。
- 时间不够就只交保底解，别把两种写一半。
::steps
**保底解（计数数组）**。开数组 `cnt[0..n-1]`，全部清 0。
扫描 A：每遇到一个 `A[i]`，就 `cnt[A[i]]++`。因为 $0\le a_i\lt n$，下标不会越界。
扫描 cnt：若某个 `cnt[x] > n/2`，x 就是主元素，返回 x；扫完都没有，返回 −1。
**最优解（抵消法）**。用 `c` 记候选、`cnt` 记它目前「净胜」几票。先令 `c=A[0]`、`cnt=1`，然后看 `A[1..n-1]`：
- `A[i]==c`：`cnt++`；
- 不等且 `cnt>0`：`cnt--`（拿一个候选和它抵消）；
- 不等且 `cnt==0`：候选已被抵消光，换 `c=A[i]`、`cnt=1`。
为什么对：每次 `cnt--` 等于从数组里划掉两个不同的元素。若主元素 x 存在，它超过一半，划掉的每一对里最多含一个 x，x 划不完 ⟹ 最后的候选一定是 x。
但反过来不成立：没有主元素时也会剩一个候选 ⟹ 再扫一遍数出 `c` 的出现次数，`> n/2` 才返回 `c`，否则返回 −1。
手推 A＝(0,5,5,3,5,7,5,5)，$n=8$：
| 读到 | 0 | 5 | 5 | 3 | 5 | 7 | 5 | 5 |
| 候选 c | 0 | 0 | 5 | 5 | 5 | 5 | 5 | 5 |
| cnt | 1 | 0 | 1 | 0 | 1 | 0 | 1 | 2 |
候选是 5；再数，5 出现 5 次，$5\gt8/2=4$ ⟹ 输出 5。
~再推 A＝(0,5,5,3,5,1,5,7)：cnt 依次为 1,0,1,0,1,0,1,0，候选停在 5；再数只有 4 次，$4\gt4$ 不成立 ⟹ 输出 −1。第二趟不能省，就是为这种情况。
::paper
**解法一（保底，时间 $O(n)$、空间 $O(n)$）**
**1）基本设计思想** ⛳3
因为 $0\le a_i\lt n$，可用元素值作下标。设辅助数组 cnt[0..n−1]，初值全为 0；扫描 A，对每个元素执行 cnt[A[i]]++，统计每个值出现的次数；再扫描 cnt，若有 cnt[x] > n/2，则 x 为主元素，否则没有主元素，输出 −1。
**2）算法描述** ⛳5
```
int Majority1(int A[], int n){
    int *cnt = (int *)malloc(sizeof(int) * n);  // cnt[x]：值 x 出现的次数
    int i, ans = -1;
    for(i = 0; i < n; i++) cnt[i] = 0;
    for(i = 0; i < n; i++) cnt[A[i]]++;         // 统计
    for(i = 0; i < n; i++)
        if(cnt[i] > n / 2){ ans = i; break; }   // 次数超过一半
    free(cnt);
    return ans;                                 // 不存在时为 -1
}
```
**3）复杂度** ⛳2　时间复杂度 $O(n)$，空间复杂度 $O(n)$。
**解法二（最优，时间 $O(n)$、空间 $O(1)$）**
**1）基本设计思想** ⛳4
分两步。第一步选候选：用 c 保存候选元素、cnt 计数，先令 c = A[0]、cnt = 1；依次扫描其余元素，与 c 相同则 cnt 加 1；不同时若 cnt > 0 则 cnt 减 1，若 cnt = 0 则把当前元素作为新的候选并令 cnt = 1。第二步确认：再扫描一遍数组，统计 c 的出现次数，若大于 n/2 则 c 是主元素，否则不存在主元素。
**2）算法描述** ⛳7
```
int Majority(int A[], int n){
    int i, c = A[0], cnt = 1;          // c：候选主元素；cnt：计数
    for(i = 1; i < n; i++){            // 第一趟：选出候选
        if(A[i] == c) cnt++;           // 与候选相同，计数加 1
        else if(cnt > 0) cnt--;        // 不同，抵消一个
        else { c = A[i]; cnt = 1; }    // 抵消光了，更换候选
    }
    cnt = 0;
    for(i = 0; i < n; i++)             // 第二趟：统计候选实际出现次数
        if(A[i] == c) cnt++;
    if(cnt > n / 2) return c;          // 超过一半才是主元素
    return -1;
}
```
**3）复杂度** ⛳2　时间复杂度 $O(n)$，空间复杂度 $O(1)$。
::note
- {{扣|抵消法漏第二趟}}：直接返回候选，在没有主元素的输入上出错，设计思想和代码两处都要扣。
- {{扣|判断写成 cnt >= n/2}}：$n=8$ 时出现 4 次不算主元素，必须是严格大于。
- 评分按算法效率分档：正确但不是最优的解（计数数组、先排序）大约能拿到 10 分上下，两重循环的 $O(n^2)$ 解更低一档——所以保底解一定要写完整。
- 骨架：保底解是「算法题速成」的骨架 1（数组＋标记数组），不会开数组就用骨架 6（先排序，主元素一定压在正中间）。两段代码已用 gcc 编译，与两重循环的暴力解在 20 万组随机数组上对拍一致。对照 2018 第 41 题（同样是值域有界开标记数组）。
::vary
