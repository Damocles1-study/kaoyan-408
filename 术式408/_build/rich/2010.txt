#1
@ans D
@tpl T出栈序列
::rev
- **该花** 1 分钟。每个选项数「连着出了几个」：出栈序列里一段连续下降的字母，就是一口气连续出栈。
- **卡点** 把四个选项都当成普通的「是否合法出栈序列」去判，发现全都合法，不知道该选谁。
- **错了说明** 没把「不允许连续 3 次出栈」翻译成序列上看得见的特征。
- **带走** 入栈次序固定时，一个出栈序列对应的操作过程是唯一的；序列里连续下降的一段（后一个比前一个先入栈）之间没有入栈，这一段有几个元素就是连续出栈几次。
::read
「不允许{{圈|连续 3 次}}进行出栈操作」 >> 两次出栈之间只要夹一次入栈就不算连续 ⟹ 在出栈序列里找「连续下降的一段」，长度到 3 就不行
::fast
{{秒|D 的 f、e、d、c、b 一路下降，连出 5 次}}，选 D。
::steps
入栈次序是 a、b、c、d、e、f。出栈序列里相邻两个元素 x、y：若 y 比 x 先入栈（字母更靠前），y 出栈前不需要再入栈 ⟹ 这两次出栈是连续的；若 y 比 x 后入栈，中间必须先把 y 压进去 ⟹ 不连续（画栈的方法见 [[T出栈序列]]）。
所以只要把每个选项按「下降段」切开，看最长的一段有几个元素。
| 选项 | 按下降段切开 | 最长连续出栈 |
| A | d c ｜ e b ｜ f a | 2 次 |
| B | c b ｜ d a ｜ e ｜ f | 2 次 |
| C | b ｜ c a ｜ e ｜ f d | 2 次 |
| D | a ｜ f e d c b | 5 次 |
~核对 A 的操作过程：入 a、b、c、d，出 d、出 c；入 e，出 e、出 b；入 f，出 f、出 a。每次最多连出 2 个。
D 中 a 出栈后要把 b～f 全部压入，再连续弹出 5 次，违反限制 ⟹ 选 **D**。
::note
- {{扣|只判「是不是合法出栈序列」}}：四个选项都是合法的出栈序列，区别只在连续出栈的次数。
- 对照 2011 第 2 题、2013 第 2 题：同样先把此刻压在栈里的元素列出来。
::vary
同样的限制下，以 c 开头的出栈序列第二个元素可以是 a 吗 >> 不可以，这与限制无关：c 出栈时栈里是 a、b，b 压在 a 上面，a 不可能比 b 先出
把限制改成「不允许连续 2 次出栈」，a、b、c 依次入栈能得到哪些出栈序列 >> 序列里不能有下降的相邻对 ⟹ 只能是 abc（每入一个就出一个）

@ans C
@tpl T受限双端队列
::rev
- **该花** 1 分钟。从后往前剥：e 最后入队，必在序列的一端；去掉 e 后 d 必在一端……剥不动的选项就是答案。
- **卡点** 四个选项逐个正着构造入队过程，花 3 分钟以上；或把「一端出队」当成两端都能出。
- **错了说明** 没抓住「两端入、一端出 ⟹ 出队序列就是队里的排列」这句话。
- **带走** 输出受限的双端队列（全部入队后再出队）：出队序列＝队内从出口端读起的排列；后入队的元素总在当时的两端 ⟹ 从最后入队的元素起逐个从两端剥，剥不下来就不可能。
::read
「允许在其{{圈|两端}}进行入队操作，但仅允许在{{圈|一端}}进行出队操作」 >> 输出受限的双端队列：每个新元素只能贴在队的最左或最右；出队只能从固定的一头依次取
「依次入此队列{{圈|后再}}进行出队操作」 >> 5 个元素全部进完才开始出 ⟹ 出队序列就是队里从出口端读过去的排列
::fast
{{秒|C：去掉两端的 e、d 后剩 b,c,a，下一个该剥的 c 夹在中间}}，选 C。
::steps
全部入队后，队里的排列从出口端读起就是出队序列（见 [[T受限双端队列]]）。
入队时每个元素只能加在当前排列的左端或右端 ⟹ 最后入队的 e 一定在排列的一端；去掉 e 后，d 一定在剩余排列的一端；依此类推。
检查 C（d,b,c,a,e）：e 在右端，去掉 ⟹ d,b,c,a；d 在左端，去掉 ⟹ b,c,a；下一个应是 c，但 c 在中间，两端是 b 和 a ⟹ 不可能。
~A（b,a,c,d,e）：依次去掉 e、d、c、b，剩 a，可以。B（d,b,a,c,e）：去掉 e、d、c（此时 b,a,c 的右端）、b，剩 a，可以。D（e,c,b,a,d）：去掉 e（左端）、d（右端）、c（左端）、b（左端），剩 a，可以。
选 **C**。
::note
- {{扣|把它当成输入受限}}：输入受限是一端进、两端出，判法不同（队内次序固定，看能否每次从两头之一取到）。
- 等价的说法：a、b 最先入队，在队里一定相邻；C 里 a、b 之间隔着 c。对照 2021 第 2 题（同一张卡）。
::vary
同一个队列，出队序列 c,a,b,d,e 可能吗 >> 去掉 e（右端）、d（右端）得 c,a,b；c 在左端去掉得 a,b ⟹ 可能
若改成「一端入队、两端出队」（输入受限），a,b,c,d,e 全部入队后能得到 d,b,c,a,e 吗 >> 队内次序固定为 a b c d e，第一个要取 d，但两端是 a 和 e ⟹ 不可能

@D b 的左线索指向 d；d 的左线索为空、右线索指向 b；c 的左、右线索分别指向 b、a

::rev
- **该花** 1 分钟。写出后序序列 d、b、c、a，数出 4 条线索该指向谁，再对图。
- **卡点** 没写序列就直接看图，把后序和中序的前驱后继弄混；或给有孩子的指针也连了线索。
- **错了说明** 线索是「遍历序列里的前驱后继」，不是树上的父子关系。
- **带走** 线索树的题第一步永远是写遍历序列；然后只看空指针：左空指向序列里的前一个，右空指向后一个。

| 结点 | 左指针 | 右指针 |

| d | 空 ⟹ 无前驱，线索为空 | 空 ⟹ 指向后继 b |

@ans C
@tpl TAVL旋转
::rev
- **该花** 1.5 分钟。48 挂在 37 的右边；从 48 往上找第一个失衡的结点是根 24；48 在 24 的右孩子的左子树里 ⟹ RL。
- **卡点** 只做了一次左旋（当成 RR），让 53 当了根，选 D；或者没调整直接读 37 的孩子，选 A。
- **错了说明** 判型没有看「新结点在失衡点的哪个孩子的哪棵子树」这两步路。
- **带走** AVL 插入：找最低的失衡点 A，从 A 往新结点走两步定型；LR、RL 型都是「孙子结点上来当根」，A 和 A 的那个孩子分列左右，孙子原来的左右子树分给它俩。
::read
「插入关键字 {{圈|48}} 后得到一棵新平衡二叉树」 >> 先按二叉排序树的规则找位置：48 比 24 大往右，比 53 小往左，比 37 大 ⟹ 成为 37 的右孩子；再检查平衡

{{秒|RL 型：孙子 37 上来当根，左挂 24、右挂 53}}，选 C。
::steps
原树：根 24，左孩子 13，右孩子 53；53 的左孩子 37、右孩子 90。
插入 48：48＞24 往右，48＜53 往左，48＞37 ⟹ 48 成为 37 的右孩子。
从 48 往上算[[AVL|平衡因子]]（左子树高 − 右子树高）：37 是 $0-1=-1$；53 是 $2-1=+1$；24 是 $1-3=-2$ ⟹ 最低的失衡点是 24。
判型（见 [[TAVL旋转]]）：新结点在 24 的右孩子（53）的左子树（37 那一支）里 ⟹ RL 型，先对 53 右旋，再对 24 左旋。
~第一步右旋：37 上升，53 成为 37 的右孩子，37 原来的右孩子 48 改挂到 53 的左边。此时 24 的右孩子是 37。
~第二步左旋：37 上升为根，24 成为 37 的左孩子（37 没有左子树，24 的右指针置空）。
结果：根 37；左子树 24（带左孩子 13）；右子树 53（左孩子 48、右孩子 90）。
37 的左、右孩子分别是 24、53，选 **C**。
~验算：中序 13, 24, 37, 48, 53, 90 递增；每个结点的平衡因子都在 −1～1 之间。
::note
- {{扣|当成 RR 只左旋一次}}：那样 53 当根，左边是 24 带着 13 和 37（下挂 48），高 3；右边只有 90，高 1 ⟹ 53 的平衡因子是 +2，仍然失衡。RR 要求新结点在右孩子的右子树。
- 提速：LR、RL 不用分两步转，直接「中间值当根」：A、B、C 三个结点里大小居中的那个（这里是 37）上去。
- 对照 2013 第 3 题、2019 第 4 题、2021 第 6 题：都用同一张判型卡。
::vary
若原树中插入的是 95 而不是 48，结果如何 >> 95 成为 90 的右孩子；24 的平衡因子为 −2，新结点在右孩子的右子树 ⟹ RR 型，左旋一次：53 当根，左 24（带 13、37），右 90（带 95）
若插入 48 后再插入 50，要不要调整 >> 50 成为 48 的右孩子；53 的平衡因子 $2-1=+1$，37 是 $2-3=-1$，都没有失衡 ⟹ 不用调整
本题调整后树高是多少，查找 48 要比较几次 >> 高 3；37 → 53 → 48，比较 3 次

#5
@ans B
@tpl T度数方程
::rev
- **该花** 40 秒。分支总数 $80+30+2+10=122$，结点总数 123，减去 41 个非叶结点。
- **卡点** 算出 122 就当答案选 D（它是分支数）；或选 A（41 是非叶结点数）。
- **错了说明** 没把「结点数＝分支数＋1」和「结点数＝各度结点数之和」两条式子都写出来。
- **带走** 任何树：结点数＝所有结点的度数之和＋1。给了各度结点数求叶子，就用这条式子减去非叶结点数。
::read
「{{圈|度为 4 的树}}……20 个度为 4、10 个度为 3、1 个度为 2、10 个度为 1」 >> 不是二叉树，$n_0=n_2+1$ 不能用；改用「每个结点的度＝它发出的分支数，除根以外每个结点恰有一条分支进来」
::fast
{{秒|叶子数＝1＋Σ(度−1)×个数＝1＋3×20＋2×10＋1×1＋0×10＝82}}，选 B。
::steps
设度为 $i$ 的结点有 $n_i$ 个，总结点数 $n$（列式方法见 [[T度数方程]]）。
按结点数：$n=n_0+n_1+n_2+n_3+n_4=n_0+10+1+10+20=n_0+41$。
按分支数：除根外每个结点都有一条分支连向父结点 ⟹ $n=$ 分支数 $+1$；分支数＝各结点度数之和 $=1\times10+2\times1+3\times10+4\times20=122$ ⟹ $n=123$。
两式联立：$n_0=123-41=82$，选 **B**。
::note
- {{扣|套二叉树的 $n_0=n_2+1$}}：那是由同一条式子在只有度 0、1、2 时推出来的，度更高的树要回到原式。
- 提速公式：$n_0=1+\sum_{i\ge2}(i-1)n_i$，度为 1 的结点不影响叶子数。
::vary
一棵度为 3 的树有 5 个度为 3 的结点、2 个度为 2 的结点，度为 1 的结点数未知，叶子有几个 >> $n_0=1+2\times5+1\times2=13$，与度为 1 的结点数无关
一棵三叉树只有度为 0 和度为 3 的结点，共 100 个叶子，度为 3 的结点有几个 >> $100=1+2n_3$ 无整数解 ⟹ 这样的树不存在；叶子数必须是奇数（见 [[严格k叉树]]）

#6
@ans A
@tpl T哈夫曼
::rev
- **该花** 30 秒。哈夫曼树只保证带权路径长度最小，形状可以很斜 ⟹ A 错。
- **卡点** 觉得「没有度为 1 的结点」就是完全二叉树；或对 D 拿不准而去验证，耽误时间。
- **错了说明** 把「正则二叉树（只有度 0 和度 2）」和「完全二叉树」混了。
- **带走** 哈夫曼树的四条性质：没有度为 1 的结点；权值最小的两个是兄弟；n 个叶子共 $2n-1$ 个结点；上层结点的权值不小于下层结点的权值。它不一定是完全二叉树。
::read
「叙述中{{圈|错误}}的是」 >> 找反例最快：权值 1、2、4、8 的哈夫曼树是一条斜链
::sk 300 132 画 | 先把 1、2 合成 3，再与 4 合成 7，再与 8 合成 15，每次新结点画在上方；看形状：第 3 层没满，第 4 层却有结点 ⟹ 不是完全二叉树

::fast
{{秒|权值相差悬殊时哈夫曼树是斜的}}，A 错。
::steps
A 错误：[[哈夫曼树]]只要求带权路径长度最小。取权值 1、2、4、8：1 和 2 合成 3，3 和 4 合成 7，7 和 8 合成 15，得到一条斜链，第 3 层只有 2 个结点而第 4 层还有结点，不是[[完全二叉树]]。

| 式子 | 转换过程 | 结果 |
| Ⅰ | int → float → int | 真 |
| Ⅱ | float → int → float | 假 |
| Ⅲ | float → double → float | 真 |
| Ⅳ | double 加减 | 假 |

**保底解**。借一个长为 p 的数组 S：把 R[0..p−1] 存入 S；把 R[p..n−1] 依次前移到 R[0..n−p−1]；再把 S[0..p−1] 放到 R[n−p..n−1]。共移动 $p+(n-p)+p=n+p$ 次，时间 $O(n)$，空间 $O(p)$。

**解法一（保底，时间 $O(n)$，空间 $O(p)$）**
**1）基本设计思想** ⛳2
借助辅助数组 S：先将 R 中前 p 个整数依次存入 S，再将 R 中后 n−p 个整数依次前移 p 个位置，最后将 S 中暂存的 p 个数依次放回 R 的后 p 个位置。
**2）算法描述** ⛳4
```
void ShiftByTemp(int R[], int n, int p){
    int *S = (int *)malloc(p * sizeof(int));   // 辅助数组，暂存前 p 个
    int i;
    for(i = 0; i < p; i++) S[i] = R[i];
    for(i = p; i < n; i++) R[i - p] = R[i];    // 后 n-p 个整体前移 p 位
    for(i = 0; i < p; i++) R[n - p + i] = S[i];// 前 p 个放到末尾
    free(S);
}
```

**解法二（最优，时间 $O(n)$，空间 $O(1)$）**
**1）基本设计思想** ⛳4
将问题看成把数组 AB 转换为 BA（A 代表前 p 个元素，B 代表后 n−p 个元素）。先将 A 逆置得到 $A^{-1}B$，再将 B 逆置得到 $A^{-1}B^{-1}$，最后将整个 $A^{-1}B^{-1}$ 逆置得到 $(A^{-1}B^{-1})^{-1}=BA$。例如 abcdefgh 循环左移 3 位：逆置前 3 个得 cbadefgh，逆置后 5 个得 cbahgfed，整体逆置得 defghabc。
**2）算法描述** ⛳7
```
void Reverse(int R[], int from, int to){      // 逆置 R[from..to]
    int i, temp;
    for(i = 0; i < (to - from + 1) / 2; i++){ // 只交换一半，否则又换回去
        temp = R[from + i];
        R[from + i] = R[to - i];
        R[to - i] = temp;
    }
}
void Converse(int R[], int n, int p){         // 循环左移 p 位
    Reverse(R, 0, p - 1);                     // 逆置前 p 个
    Reverse(R, p, n - 1);                     // 逆置后 n-p 个
    Reverse(R, 0, n - 1);                     // 整体逆置
}
```
**3）复杂度** ⛳2　三个 Reverse 的时间复杂度分别为 $O(p/2)$、$O((n-p)/2)$、$O(n/2)$，故算法的时间复杂度为 $O(n)$；只使用了常数个辅助变量，空间复杂度为 $O(1)$。
