#1
@tpl T循环求和
::read
「`for(int i=1;i<n;i*=2)`」 >> 外层 {{圈|i 每次翻倍}}：i 取 $1,2,4,\dots,2^t$，共约 $\log_2 n$ 轮
「`for(int j=0;j<i;j++)`」 >> 内层上界是 {{波|i}} 不是 n ⟹ 内层次数跟着外层变，==必须求和，不能相乘==
「问时间复杂度」 >> 基本语句是 `sum++`，数它总共执行几次
::sk 430 150 | 草稿：外层每取一个 i，内层就跑 i 次。两列表写出来，求和一眼就是等比数列
s.cells(10,10,[['i','内层次数'],['1','1'],['2','2'],['4','4'],['…','…'],['2^{t}','2^{t}']],cw=[80,80],ch=21)
s.text(190,36,'总次数 = 1+2+4+…+2^{t}',13)
s.text(190,60,'      = 2^{t+1} − 1',13)
s.text(190,86,'2^{t} < n ≤ 2^{t+1} ⟹ 总 < 2n',13,'r')
s.text(190,112,'⟹ O(n)，不是 O(n log n)',13,'r')
s.under(190,118,170)
::think
1. 先看内层次数和外层变量有没有关系：有（上界是 i），所以要逐轮写出来再加。
2. 外层 i 翻倍 ⟹ 内层次数是等比数列 1, 2, 4, …，等比数列的和约等于末项的 2 倍。
3. 末项 $2^t$ 比 n 小，所以总和不超过 2n。
::fast
{{秒|等比求和由最后一项主导}}：最后一轮内层跑不到 n 次，前面所有轮加起来也不到 n 次 ⟹ 总共不到 2n ⟹ O(n)。看到「外层翻倍、内层到 i」直接选 B。
::steps
外层：i 从 1 开始每次乘 2，条件 $i<n$ ⟹ i 依次取 $1,2,4,\dots,2^t$，其中 $2^t<n\le 2^{t+1}$。
内层：对每个 i，j 从 0 到 $i-1$，`sum++` 执行 i 次。
总次数 $=1+2+4+\dots+2^t=2^{t+1}-1$（等比数列求和）。
由 $2^t<n$ 得 $2^{t+1}<2n$ ⟹ 总次数 $<2n-1$；由 $n\le 2^{t+1}$ 得总次数 $\ge n-1$。
总次数在 $[n-1,\,2n)$ 之间 ⟹ 时间复杂度 $O(n)$，选 **B**。
~复算：n＝1024 时 i 取 1…512，总和 1023；n＝1025 时多一轮 i＝1024，总和 2047。都落在 $[n-1,2n)$ 内。
::note
- {{扣|外层 $\log n$ 轮 × 内层最多 n 次 ⟹ $O(n\log n)$}}：这是「上界乘上界」，只是一个松的上界，不是准确的阶。选 C 就错在这里。
- 能不能直接乘，只看内层次数是不是常数或只和 n 有关。本题内层次数是 i，就不能乘。
- $1+2+\dots+2^t=2^{t+1}-1$ 比末项的 2 倍少 1，这个式子在复杂度题里反复出现。
::vary
内层改成 `for(j=0;j<n;j++)` >> 内层次数与 i 无关，可以乘：$\log_2 n$ 轮 × n 次 ⟹ $O(n\log_2 n)$
外层改成 `i++`，内层仍是 `j<i` >> 内层次数 $0,1,2,\dots,n-1$，等差求和 $\frac{n(n-1)}2$ ⟹ $O(n^2)$
外层 `i*=2`，内层改成 `for(j=1;j<i;j*=2)` >> i＝$2^k$ 时内层跑 k 次，总 $0+1+\dots+t\approx\frac{(\log_2 n)^2}{2}$ ⟹ $O(\log^2 n)$
外层 `i*=3`，内层 `j<i` >> $1+3+\dots+3^t$ 仍被末项主导，末项＜n ⟹ 总＜1.5n ⟹ 还是 $O(n)$

@tpl T出栈序列, T反例排除
::read
「in 和 out 均为 S 中所有元素的任意排列」 >> in、out 是两串长度相同、元素相同的序列
「若 in 是入栈序列，则不能判断 out 是否为出栈序列」 >> {{圈|能判断}}：照 in 模拟一遍，栈顶对得上就出，最后栈空即合法 ⟹ A 错
「若 out 是出栈序列，则不能判断 in」 >> 判的还是同一对序列，同样能模拟 ⟹ B 错
「in 与 out 一定不同」 >> 「一定」⟹ 找反例：每个元素进栈后马上出栈，out＝in ⟹ C 错
「in 与 out 可能互为倒序」 >> 「可能」⟹ 找一个例子：全部进栈后再全部出栈 ⟹ D 对
::sk 430 140 | 草稿：两种极端操作。左：进一个出一个 ⟹ 原样；右：全进再全出 ⟹ 倒序
s.text(10,18,'进 1 出 1：',12,'b')
s.text(10,42,'in : a b c',13);s.text(10,64,'out: a b c',13);s.text(10,90,'⟹ 相同，C 的「一定不同」倒',12,'r')
s.box(250,30,36,84)
for k,t in enumerate(['c','b','a']): s.text(268,52+k*26,t,13,'k','middle')
s.text(230,18,'全进再全出：',12,'b')
s.arrow(300,40,300,106,'r');s.text(306,78,'弹出 c b a',12,'r')
s.text(214,134,'in a b c → out c b a，互为倒序 ⟹ D',12,'r')
::think
1. A、B 说「不能判断」——只要给出一个判断方法就能否定。
2. C 用「一定」、D 用「可能」：C 找一个反例，D 找一个正例。两种极端操作（进一个出一个、全进再全出）刚好各对付一个。
::fast
{{秒|「可能」类选项只要一个例子}}：全部入栈再全部出栈，出栈序列就是入栈序列倒过来 ⟹ D 成立。其余三个都是绝对化说法，不用细看。
::steps
A：给定入栈序列 in 和待判序列 out，用一个栈模拟：按 in 依次入栈，每入一个就看栈顶是否等于 out 当前要出的元素，相等就出栈并后移，反复检查；全部入完后栈空 ⟺ out 合法。所以「能判断」，A 错。
B：给定 out 和待判的入栈序列 in，判的是同一对序列，同样用上面的模拟，B 错。
C：每个元素入栈后立刻出栈，出栈顺序与入栈顺序完全相同，out＝in ⟹「一定不同」不成立，C 错。
D：所有元素先全部入栈，再依次出栈，后进先出 ⟹ out 恰是 in 的倒序 ⟹「可能互为倒序」成立，选 **D**。
~复算：in＝abcd 时，倒序 dcba、原序 abcd 都能模拟通过；24 个排列中合法出栈序列恰 14 个（[[卡特兰数]] $C_4$）。
::note
- 判出栈序列合法性的模拟是固定动作，不必背规律；n≤5 的序列手模拟不超过 30 秒。
- 常用的必要条件：若 $x$ 先出，in 里排在 $x$ 前面、还没出的元素之后只能按倒序出（不会出现「大—小—中」的模式）。
::vary
入栈 a,b,c,d，出栈 d,c,a,b 合法吗 >> 不合法：d 先出说明 a,b,c 都在栈里且 c 在顶；c 出后栈顶是 b，a 不可能先于 b 出
入栈 1,2,…,n，出栈序列共有多少种 >> [[卡特兰数]] $\frac{1}{n+1}C_{2n}^n$，n＝4 时 14 种
若 out 的第一个元素是 in 的最后一个元素，out 有几种 >> 只有 1 种：最后一个出来时其余全在栈里，只能按倒序出
把栈换成队列，in 与 out 的关系 >> 队列先进先出，out 一定等于 in；「可能互为倒序」只在 n＝1 时成立

@tpl T反例排除
::read
「p 与 q 在中序遍历序列中相邻，且 p 在 q 之前」 >> q 是 p 的{{圈|中序后继}}；中序＝左—根—右
「Ⅰ q 是 p 的双亲」 >> 画：p 是 q 的左孩子、p 没有右子树 ⟹ 中序 …p, q… 相邻 ✓
「Ⅱ q 是 p 的右孩子」 >> 画：q 是 p 的右孩子、q 没有左子树 ⟹ 中序 p, q 相邻 ✓
「Ⅲ q 是 p 的右兄弟」 >> 兄弟有共同的父亲 F：中序一定是 …p…{{波|F}}…q… ⟹ F 夹在中间，{{圈|不可能相邻}}
「Ⅳ q 是 p 的双亲的双亲」 >> 画：p 是 x 的右孩子，x 是 q 的左孩子 ⟹ 中序 x, p, q 相邻 ✓
::sk 460 150 | 草稿：四种关系各画一棵最小的树写中序。只有 Ⅲ 里 F 一定插在 p、q 之间（红圈）
s.tree(('q',('p',)),70,24,dx=34,dy=40,r=11);s.text(20,124,'Ⅰ 中序 p q ✓',12,'b')
s.tree(('p',None,('q',)),150,24,dx=34,dy=40,r=11);s.text(132,124,'Ⅱ 中序 p q ✓',12,'b')
s.tree(('F',('p',),('q',)),275,24,dx=34,dy=40,r=11);s.text(230,124,'Ⅲ 中序 p F q ✗',12,'r')
s.tree(('q',('x',None,('p',)),None),410,24,dx=36,dy=36,r=11);s.text(350,140,'Ⅳ 中序 x p q ✓',12,'b')
s.circle(275,24,16,'r')
::think
1. 「不可能的是」⟹ 能画出例子的都排除，画不出的就是答案。
2. 每种关系只画最小的树（2～3 个结点），写出中序看 p、q 是否紧挨着。
3. 画不出的那个，用中序「左—根—右」的定义说出原因。
::fast
{{秒|兄弟之间一定隔着父亲}}：p、q 是兄弟 ⟹ p 在 F 的左子树、q 在 F 的右子树，中序走完左子树、访问 F、再走右子树 ⟹ F 必在两者之间。Ⅲ 不可能，其余三种都画得出 ⟹ 仅 Ⅲ，选 B。
::steps
Ⅰ：让 p 做 q 的左孩子且 p 没有右子树。中序遍历 q 的左子树最后访问的是 p，接着访问 q ⟹ 相邻。可能。
Ⅱ：让 q 做 p 的右孩子且 q 没有左子树。访问 p 后进入右子树，右子树第一个访问的是它最左下的结点，q 没有左子树就是 q 本身 ⟹ 相邻。可能。
Ⅳ：q 的左孩子是 x，x 的右孩子是 p，p 没有右子树。中序：x、p、q ⟹ p、q 相邻，且 q 是 p 的双亲的双亲。可能。
Ⅲ：q 是 p 的右兄弟，设共同的父结点为 F，则 p 在 F 的左子树、q 是 F 的右孩子。中序遍历以 F 为根的子树：左子树（含 p）→ F → 右子树（含 q）⟹ p 与 q 之间至少隔着 F，不可能相邻。
只有 Ⅲ 不可能，选 **B**。
~复算：枚举 7 个结点以内的全部二叉树，统计中序相邻的每一对 (p, q)：关系 Ⅰ、Ⅱ、Ⅳ 都出现过，Ⅲ 一次也没有。
::note
- 一般规律：q 是 p 的中序后继 ⟹ p 有右子树时，q 是右子树最左下的结点；p 没有右子树时，q 是这样一个祖先——p 在 q 的左子树里。兄弟两种情况都不是。
- 这就是线索二叉树找中序后继的依据：右指针是线索就直接指向后继，否则去右子树找最左下。
::vary
改成「先序相邻，p 在 q 前」，Ⅲ 还不可能吗 >> 可能了：p 是叶子、q 是它的右兄弟，先序 F, p, q 相邻
先序相邻（p 在前）时，q 可能是 p 的双亲吗 >> 不可能：先序先访问根，双亲一定在孩子前面
改成「后序相邻，p 在 q 前」，四种关系哪些不可能 >> Ⅱ、Ⅳ 不可能：后序里孩子在双亲之前，q 是 p 的右孩子则 q 在 p 前；q 是祖父则 p 的双亲夹在 p、q 之间。Ⅰ（p 是 q 的右孩子）、Ⅲ（p、q 都是叶子兄弟）都可能
中序相邻、p 在前，且 p 有右子树，q 在哪 >> q 是 p 的右子树中最左下的结点

#4
@tpl T满树定高
::read
「三叉树 T 中有 244 个结点」 >> 问的是「至少」多高 ⟹ 每层尽量塞满 ⟹ 和{{圈|满三叉树}}比
「叶结点的高度为 1」 >> 锁定{{波|层数口径}}：只有一个结点的树高度为 1，不是数边
「高度至少是」 >> 找最小的 h，使高度为 h 的满三叉树结点数 ≥ 244
::sk 400 160 | 草稿：一层一层写最多结点数和累计数，244 落在 121 和 364 之间
s.cells(10,10,[['层','本层最多','累计'],['1','1','1'],['2','3','4'],['3','9','13'],['4','27','40'],['5','81','!121'],['6','243','!364']],cw=[40,70,60],ch=20)
s.text(200,120,'121 < 244 ≤ 364',14,'r')
s.text(200,144,'⟹ 5 层装不下，至少 6 层',13,'r')
s.arrow(196,114,176,124,'r')
::think
1. 高度固定时，结点最多的是满三叉树；要让高度最小，就让每层尽量满。
2. 写出满三叉树各层累计结点数，244 第一次装得下的那一层就是答案。
::fast
{{秒|$3^5=243$}}：高 5 的满三叉树 $\frac{3^5-1}{2}=121$ 个结点，高 6 是 $\frac{3^6-1}{2}=364$ 个。244 > 121 ⟹ 至少 6。
::steps
第 i 层最多 $3^{i-1}$ 个结点 ⟹ 高度为 h 的三叉树最多 $1+3+\dots+3^{h-1}=\frac{3^h-1}{2}$ 个结点。
h＝5：最多 $\frac{243-1}{2}=121$ 个，小于 244，装不下。
h＝6：最多 $\frac{729-1}{2}=364$ 个，不小于 244，装得下（前 5 层放满 121 个，第 6 层放 123 个）。
所以 T 的高度至少是 6，选 **C**。
~公式版：$h_{\min}=\lceil\log_3(2n+1)\rceil=\lceil\log_3 489\rceil=6$（$3^5=243<489\le 729=3^6$）。
::note
- 一般式：n 个结点的 m 叉树最小高度 $=\lceil\log_m(n(m-1)+1)\rceil$。考场上写累计表比套公式更不容易错。
- {{扣|按边数口径算成 5}}：题干特意写「叶结点的高度为 1」，就是防这个。若题干说根的深度为 0，答案要减 1。
- 「至少」看满树；「至多」看单链（每层一个结点）。
::vary
244 个结点的二叉树最少几层 >> 前 7 层最多 127、前 8 层最多 255 ⟹ 8 层
度为 3 的树有 244 个结点，最多几层 >> 必须有一个结点有 3 个孩子：一条单链，在某个结点上多挂 2 个叶子 ⟹ $244-2=242$ 层
三叉树有 244 个结点且高度恰为 6，第 6 层至少几个结点 >> 前 5 层最多 121 个 ⟹ 第 6 层至少 $244-121=123$ 个
完全三叉树（按层从左到右填）有 244 个结点，叶子几个 >> 非叶结点数 $\lceil(244-1)/3\rceil=81$ ⟹ 叶子 $244-81=163$ 个

#5
@tpl T反例排除, T哈夫曼
::read
「对任意给定的含 n（n>2）个字符的有限集 S」 >> 「任意」⟹ 选项要对所有 S 都成立，{{圈|一个反例就能否定}}
「哈夫曼编码集 ⟹ T₁；定长编码集 ⟹ T₂」 >> T₁ 是[[哈夫曼树]]（变长、按频次）；T₂ 是所有字符码长都相同的编码树
「A 结点数相同」 >> 哈夫曼树 $2n-1$ 个结点；定长树在 n 不是 2 的幂时有度为 1 的结点，结点数不同
「B T₁ 高度大于 T₂」 >> 频次接近时哈夫曼树也长得很齐，高度可以相同 ⟹ 不一定
「C 频次不同的字符在 T₁ 中处于不同层」 >> 频次 3,4,5,6 的哈夫曼树四个字符全在同一层 ⟹ 错
「D 频次不同的字符在 T₂ 中处于相同层」 >> 定长 ⟹ 码长都一样 ⟹ {{波|全在同一层}}，与频次无关 ✓
::sk 460 170 | 草稿：两组最小反例。左：3 个字符，哈夫曼 5 个结点、定长 6 个结点；右：频次全不同却全在同一层
s.text(10,16,'频次 1,2,3：',12,'b')
s.tree(('6',('3',('1',),('2',)),('3',)),70,34,dx=34,dy=34,r=10,size=11)
s.text(30,150,'T₁ 哈夫曼：5 个结点',12)
s.tree(('',('',('a',),('b',)),('',('c',))),195,34,dx=36,dy=34,r=10,size=11)
s.text(150,150,'T₂ 定长 2 位：6 个结点',12)
s.text(300,16,'频次 3,4,5,6：',12,'b')
s.tree(('18',('7',('3',),('4',)),('11',('5',),('6',))),375,34,dx=40,dy=40,r=11,size=11)
s.text(296,150,'全在第 3 层，高度也和定长一样',11,'r')
s.text(296,166,'⟹ B、C 都倒',11,'r')
::think
1. A、B、C 都是「对任意 S 都成立」的断言，各找一个小反例。
2. D 说的是定长编码：码长相同就是同一层的叶子——这就是定长编码的定义。
::fast
{{秒|定长编码＝码长都相同＝编码树里全在同一层}}，D 就是定义本身。A、B、C 都是「一定」式断言，选 D。
::steps
D：定长编码集中每个字符的编码长度相同，编码长度就是该字符在编码树中的深度 ⟹ 所有字符都在 T₂ 的同一层（且都是叶子），与频次无关 ⟹ D 正确。
A：取频次 1, 2, 3。哈夫曼：先合并 1＋2＝3，再合并 3＋3＝6 ⟹ T₁ 有 3 个叶子＋2 个内部结点＝5 个结点（哈夫曼树没有度为 1 的结点，共 $2n-1$ 个）。定长需要 $\lceil\log_2 3\rceil=2$ 位，T₂ 是根＋两个内部结点＋3 个叶子＝6 个结点（右边那个内部结点只有一个孩子）。5≠6 ⟹ A 错。
B：取频次 3, 4, 5, 6。哈夫曼：3＋4＝7，5＋6＝11，7＋11＝18 ⟹ 四个字符都在第 3 层（根为第 1 层），T₁ 高 3；定长 2 位的 T₂ 也高 3 ⟹ T₁ 并不比 T₂ 高，B 错。
C：同一个例子里四个字符频次各不相同，却都在 T₁ 的同一层 ⟹ C 错。
选 **D**。
::note
- 哈夫曼树的高度可以从 $\lceil\log_2 n\rceil+1$（各频次接近）到 n（频次像 1,1,2,4,8 这样成倍增长）——所以 B 的「一定更高」不成立。
- {{扣|把 T₂ 想成满二叉树，以为结点数也是 $2n-1$}}：只有 n 是 2 的幂时定长树才没有度为 1 的结点。
- 构造反例时避开相等的权值（如 2,3,4,5 合并出的 5 与原来的 5 相等），否则合并顺序有两种，结果不唯一，反例就不干净。
::vary
n＝4 且四个频次相同，T₁ 与 T₂ 是什么关系 >> 完全一样：都是高 3 的满二叉树、7 个结点
频次 1,1,2,4,8 的哈夫曼树有几层 >> 每次新合并的和都是最小的，长成一条斜链：$1+1=2$，$2+2=4$，$4+4=8$，$8+8=16$ ⟹ 5 层
哈夫曼树有 n 个叶子，度为 1 的结点几个 >> 0 个；度为 2 的 $n-1$ 个，共 $2n-1$ 个

「采用直接插入排序而不采用快速排序，可能的原因」 >> 列两列表，逐行看{{圈|插入排序赢在哪}}
「Ⅰ 大部分元素已有序」 >> 插入 O(n)；快排取首元素为枢轴时退化成 O(n²) ⟹ 是理由
「Ⅱ 待排序元素数量很少」 >> n 小时常数因子主导，快排的递归开销反而大 ⟹ 是理由
「Ⅲ 要求空间复杂度为 O(1)」 >> {{波|快排要递归栈}}，平均 $O(\log_2 n)$ ⟹ 是理由
「Ⅳ 要求排序算法是稳定的」 >> 插入稳定，快排不稳定 ⟹ 是理由
::think
1. 把两种排序的「初态敏感性、规模、空间、稳定性」四项写成表。
2. 每一项看插入排序是否占优：占优就是「选插入的理由」。
::fast
{{秒|快排唯一的优势是随机大数据的平均速度}}：题干四条一条都没提到它 ⟹ 四条都是选插入的理由，选 D。
::steps
列表对比：
| 指标 | 直接插入排序 | 快速排序 | 谁占优 |
| 基本有序 | 比较约 $n-1$ 次，O(n) | 枢轴取首元素时每次只分出一个，O(n²) | 插入 |
| n 很小 | 代码简单、常数小 | 递归调用、划分的固定开销大 | 插入 |
| 空间 | O(1) | 递归栈平均 $O(\log_2 n)$，最坏 O(n) | 插入 |
| 稳定性 | 稳定 | 不稳定 | 插入 |
Ⅰ、Ⅱ、Ⅲ、Ⅳ 每一条都是插入排序占优的方面，都是可能的原因，选 **D**。
::note
- {{扣|把快排当成原地排序就认为空间 O(1)}}：快排不需要辅助数组，但递归需要栈。空间不是 O(1) 的内部排序只有快排 $O(\log n)$、归并 O(n)、基数 O(r)。
- 工程上快排递归到子区间很短（十几个元素）时会改用直接插入排序，就是 Ⅱ 的道理。
::vary
要求平均时间最短、数据随机且量大，选哪个 >> 快速排序
要求稳定且时间 $O(n\log n)$ >> 归并排序（空间 O(n)）
要求空间 O(1) 且时间 $O(n\log n)$ >> 堆排序（不稳定）
初始序列基本有序，冒泡也能 O(n) 吗 >> 能：带交换标志的冒泡，一趟没有交换就停，只比 $n-1$ 次

::sk 450 140 | 草稿：规格化 → 填三段 → 四位一组读十六进制

::think

2. 规格化成 $\pm1.f\times2^{e}$，阶码 $=e+127$，尾数只写 f。
3. 32 位四位一组读十六进制。
::fast
{{秒|看阶码这 8 位}}：$e=-2$ ⟹ 阶码 125＝0111 1101，前 12 位就是 1 0111 1101 110 ⟹ BEE。B、C 的阶码是 126（指数 −1，值 −0.875、−0.9375），D 是 129（值 −7）。
::steps
$0.4375=\frac{7}{16}=\frac{4+2+1}{16}=0.0111_2$。

阶码 $E=e+127=125=0111\,1101_2$。
拼接：S | E | f ＝ 1 | 0111 1101 | 1100 0000 …0。
四位一组：1011 1110 1110 0000 0000 0000 0000 0000 ＝ BEE0 0000H，选 **A**。
~核对其余选项：BF60 0000H ＝ 1 0111 1110 1100… ⟹ $-1.11_2\times2^{-1}=-0.875$；BF70 0000H ⟹ $-1.111_2\times2^{-1}=-0.9375$；C0E0 0000H ＝ 1 1000 0001 1100… ⟹ $-1.11_2\times2^{2}=-7$。

::vary

D：芯片是 8192 行 × 8192 列，每次激活一行，整行读入行缓冲 ⟹ 行缓冲 $8192\times8$ 位。正确。
不正确的是 **C**。
::note
- SRAM 不复用地址，引脚数＝地址位数；DRAM 复用，引脚数＝地址位数的一半（行列相等时）。这一条年年考。
- 突发（burst）传送：行已打开在行缓冲里，后续只送列地址甚至只给时钟就能连续读出，靠的就是行缓冲。
::vary
若改成 SRAM 芯片 $2^{26}\times8$ 位，地址引脚几根 >> 26 根（不复用）
一片 $4\text{M}\times8$ 位 DRAM，行列相等，地址引脚几根 >> $4\text{M}=2^{22}$，行列各 11 位 ⟹ 11 根
DRAM 刷新按什么单位进行 >> 按行：一次刷新一整行，刷新地址只要行地址
用 $1\text{M}\times4$ 位芯片组成 $4\text{M}\times8$ 位存储器要几片 >> 字扩展 4 倍、位扩展 2 倍 ⟹ 8 片（见 [[T芯片数]]）

1. 扩展操作码的规则：长操作码以短操作码中「没用的编码」开头，保证不冲突。

::fast

::steps
二地址指令：操作码 $16-2\times6=4$ 位，共 $2^4=16$ 种编码，用掉 12 种，剩 4 种作为扩展前缀。
一地址指令：在剩下的 4 种前缀后面再用一个地址字段的 6 位扩展 ⟹ 操作码 10 位，共 $4\times2^6=256$ 种，用掉 254 种，剩 2 种前缀。
零地址指令：在剩下的 2 种前缀后面再用最后 6 位扩展 ⟹ 操作码 16 位，共 $2\times2^6=128$ 种。
零地址指令最多 128 条，选 **D**。
~另解（按零地址「空间」算）：全部 16 位都当零地址可有 $2^{16}$ 条；一条二地址指令占 $2^{12}$ 个零地址编码，一条一地址占 $2^6$ 个 ⟹ $2^{16}-12\times2^{12}-254\times2^6=65536-49152-16256=128$。
::note
- {{扣|选 2}}：2 是一地址那级剩下的「前缀数」，还要再乘 $2^6$。
- 「最多」⟹ 前面每一级都只用题目给的条数、其余全部留作前缀；若题目要求零地址也要一定数量，就反过来约束一地址的上限。
::vary
二地址 12 条，零地址要 256 条，一地址最多几条 >> 一地址剩余前缀需 ≥ $256/64=4$ 个 ⟹ 一地址最多 $256-4=252$ 条

进入内核后，系统调用入口程序（OS）保存通用寄存器的内容，再根据系统调用号调用相应的服务例程执行 ⟹ Ⅱ、Ⅲ 由操作系统完成。
选 **B**。
::note
- 与中断处理的分工完全一致（[[T中断分工]]）：硬件做「关中断、保存断点和 PSW、找入口」，其余都是软件。
- {{扣|把「保存通用寄存器」当成硬件}}：硬件只保存最少的现场（PC、PSW），通用寄存器由服务程序按需保存。
::vary
系统调用的参数通常怎么传递 >> 放在通用寄存器或内存（栈）里，入口程序取出
系统调用返回用户态时由谁恢复 PSW >> 执行中断返回（iret）指令，硬件恢复 PC 和 PSW
「系统调用是在用户态执行的」对吗 >> 不对：发起（trap 指令）在用户态，服务例程在内核态执行
库函数和系统调用的关系 >> 库函数（如 printf）在用户态运行，内部可能调用系统调用（如 write）

1. BST 的定义是「左子树所有结点 ＜ 根 ＜ 右子树所有结点」，比的是整棵子树，直接检查很麻烦；等价条件「中序严格递增」只需记住上一个访问的值。
2. 在数组上做中序递归：参数是下标 k；空的判法是 `k>=ElemNum || 值==-1`。
3. 用一个变量（指针传递）记录中序前驱的值：当前值 ≤ 它就返回 false，否则更新它。
4. 任何一处返回 false 都要层层传上去，不能只在当前层 return。
::steps
确定存储下标关系：根在 `SqBiTNode[0]`，结点 k 的左孩子 $2k+1$、右孩子 $2k+2$（下标从 0 开始；从 1 开始才是 $2k$、$2k+1$）。
递归出口：$k\ge$ ElemNum 或 `SqBiTNode[k]==-1` ⟹ 空树，返回 true（空树是 BST）。
中序递归：先递归左子树，左子树不是 BST 直接返回 false。
访问当前结点：若当前值 ≤ `*prev`（中序前驱的值）⟹ 逆序，返回 false；否则 `*prev=当前值`。
再递归右子树，返回它的结果。
主函数：`prev` 初值取 0（所有结点值都是正整数，0 比任何结点都小），调用 `inorder(&T,0,&prev)`。
复杂度：每个结点最多访问一次，时间 O(n)；递归栈深度等于树高 h，空间 O(h)（最坏 O(n)）。
~复算：C 代码 gcc 编译，生成 20000 棵随机顺序存储树（含 −1 空位、含相等值、一半构造成真 BST），与 Python 按「上下界递归」写的参照实现逐一对拍，零失配。
::paper
**1）基本设计思想**
二叉搜索树的中序遍历序列严格递增；反之中序序列严格递增的二叉树一定是二叉搜索树。因此在顺序存储上对 T 做中序遍历：结点 k 的左、右孩子下标为 $2k+1$、$2k+2$，下标越界或值为 −1 表示空。用变量 prev 记录中序遍历中上一个访问结点的值（初值为 0，小于所有结点值），访问当前结点时若其值 ≤ prev 则不是二叉搜索树，返回 false；否则令 prev 等于当前值继续遍历。遍历完毕未发现逆序则返回 true。⛳4
**2）算法实现**
```
typedef struct{
    int SqBiTNode[MAX_SIZE];
    int ElemNum;
}SqBiTree;

/* 对以下标 k 为根的子树做中序遍历；*prev 是中序前驱的值 */
bool inorder(SqBiTree *T, int k, int *prev){
    if (k >= T->ElemNum || T->SqBiTNode[k] == -1)
        return true;                          /* 空树是二叉搜索树 */
    if (!inorder(T, 2*k+1, prev))             /* 先遍历左子树 */
        return false;
    if (T->SqBiTNode[k] <= *prev)             /* 不大于前驱：逆序 */
        return false;
    *prev = T->SqBiTNode[k];                  /* 更新前驱 */
    return inorder(T, 2*k+2, prev);           /* 再遍历右子树 */
}

bool isBST(SqBiTree T){
    int prev = 0;                             /* 结点值均为正整数 */
    return inorder(&T, 0, &prev);
}
```
⛳9
**时空复杂度**：每个结点至多访问一次，时间复杂度 $O(n)$；递归栈深度为树高，空间复杂度 $O(h)$，最坏 $O(n)$（n 为 ElemNum）。
::note
- {{扣|只判「左孩子＜根＜右孩子」}}：右边草图那棵树每对父子都满足，却不是 BST。这样写一般只给一半左右的分。
- {{扣|空结点只判 −1 不判越界}}：`2k+1` 可能超出 ElemNum，访问数组越界；两个条件缺一不可，且越界判断要写在前面。
- {{扣|递归返回值不往上传}}：写成 `inorder(左); if(…) return false; inorder(右);` 时，左右子树里发现的 false 被丢掉。
- 题目「值均为正整数」就是给 prev 初值用的；若值可以为负，初值改用 `INT_MIN`，并单独处理第一个结点。
- 解法 2（官方另解）：从后往前扫描，用两个辅助数组记录每棵子树的最大、最小值，逐结点比较。也是 O(n)，但要 O(n) 辅助空间，不如中序法简洁。
::vary
二叉链表存储的二叉树判 BST >> 同一个中序模板：`if(!T) return true; 左; if(T->data<=prev) return false; prev=T->data; return 右;`
顺序存储下标从 1 开始，代码改哪里 >> 孩子改为 $2k$、$2k+1$，起点 `inorder(&T,1,&prev)`，越界判断改成 `k>ElemNum`
允许有相等关键字（左子树 ≤ 根），判断条件怎么改 >> 中序非递减即可：把 `<=` 改成 `<`；但「左 ≤ 根 ＜ 右」严格来说中序检查不能区分相等值在左还是在右，需要用上下界法
求这棵 BST 中第 k 小的值 >> 同一个中序遍历，计数到第 k 个访问的结点就返回

2. 第 2 问：抓住「单总线、一次一个数」：ALU 要两个输入同时有效，一个必须先存起来（Y）；输出产生时总线还被占着，结果也要先存起来（Z）。

::steps
1）SF：符号标志表示结果的正负，就是结果的最高位 ⟹ $SF=F_{15}$。
  加法 A＋B：两个正数（$A_{15}=B_{15}=0$）相加得负数（$F_{15}=1$），或两个负数相加得正数，就溢出；异号相加不可能溢出 ⟹ $OF=\overline{A_{15}}\,\overline{B_{15}}\,F_{15}+A_{15}B_{15}\overline{F_{15}}$。
  减法 A−B：A 为正、B 为负（正减负）结果为负，或 A 为负、B 为正（负减正）结果为正，就溢出；同号相减不可能溢出 ⟹ $OF=\overline{A_{15}}\,B_{15}F_{15}+A_{15}\overline{B_{15}}\,\overline{F_{15}}$（即把加法式中的 $B_{15}$ 取反）。
