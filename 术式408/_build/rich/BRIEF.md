## 任务

为术式408真题套卷重制 **<年份> 年整卷**的逐步精解。工作目录 `11408相关/408/复盘中心/术式408/`。
先读：`README.md` 末节「套卷精解」、`_build/rich_build.py` 开头的语法、样板 `_build/rich/2020.txt`、全局卡 `_build/rich/kp.txt`、草图库 `_build/sk.py`、本年旧精研卡 `_build/deep/<年份>.txt`、`assets/exam/y<年份>.js`（题面、选项、答案、原解析 sol/more、题库出处 src）。
每题：
1. 题面已是文字，一般不写 `@stem`。只有题面靠图且图是扫描件、看不清时（`../练习系统/图/` 下的 png/jpg），才用 `@stem` 重写并用 `::sk` 重画或改成表格；svg 图可保留。
2. 解析素材：卷子里的 sol/more、旧精研卡、题库 `../练习系统/data_*.js` 对应题，在此基础上**加工**，不照抄、不省步。

**块与标记**（语法以 `_build/rich_build.py` 开头为准）：
- `::read` 每题必写：逐句「原句 >> 看到它想到什么 / 该画什么 / 这句话的固定含义 / 能排除什么」，用 `{{圈|}}`、`{{波|}}` 圈画。
- `::sk` 草图：凡是人在草稿纸上会画的都画（树、图、链表指针变化、栈/队列状态、散列表、排序每趟、Cache/页表地址划分、流水线时空图、甘特图、PV 前驱图、TCP 窗口/拥塞窗口曲线、帧时序图等），画法看 `_build/sk.py` 与样板；坐标要算对，渲染后肉眼核对位置。
- `::think` 思路；`::fast` 秒杀/快法（选择题必写：排除法、极端值、口诀、一眼判据，用 `{{秒|}}`）。
- `::steps` 每一步，**不许跳步**，读者要能看懂每个环节；考场上可省的步骤行首加 `~`（灰底），行内可省用 `{{省|}}`。
- `::paper` 考场卷面：综合题必写，照三层铁律：分问作答、`⛳N` 采分点（按每问 1–3 分标）、算法题给「基本设计思想 → 完整 C 代码（```代码块，关键处注释）→ 时空复杂度」，代码必须 gcc 编译并随机对拍；选择题不写卷面
- `::note` 扣分点（`{{扣|}}`）、适用边界、提速心算、跨章联系。
- `::vary` 举一反三：每题 ≥3 条（重点题 ≥4 条），每条带答案（「变式 >> 答案」），要有真正改条件后的变化，不是换数字。
- `@tpl`：凡是能沉淀成跨年固定套路的都标上。先用 `kp.txt` 里已有的；没有就在本年文件顶部 `@tpl Txxx | 看到什么→先做什么` 新建（汇总时会提到全局）。定义、定理、公式、方法用 `[[id]]` 做弹窗，缺的在本年顶部 `@kp` 定义（写「是什么＋怎么用＋最小例子」）。
**正确性第一**：每题答案都要程序独立复算，写进 `_build/rich/chk/<年份>.py` 并跑通（模拟、穷举、对拍；算法题 C 代码 gcc 编译＋随机测试）。复算与原解析冲突时，第一反应是自己转录错了，回去放大看原图/原文。
**验收**：`python3 _build/rich_build.py <年份>` 必须 ✓ 通过；然后把中心目录（不含 `_build`）rsync 到你自己的 scratchpad，写个 `serve.py` 监听 `127.0.0.1:<端口>`，在 `新威考研-资料/.claude/launch.json` 追加一条配置后用 `preview_start` 打开 `真题套卷.html#y=<年份>`，交卷（顶栏「交卷」→ 弹窗确认）后逐题抽查：无 `.katex-error`、草图位置对、宽 375 时 `scrollX` 为 0。
**约束**：只写 `_build/rich/<年份>.txt`、`_build/rich/chk/<年份>.py`（构建生成的 `assets/exam/rich/` 文件不用管）。**不要改** `engine.js`、`exam.css`、`rich_build.py`、`kp.txt`、`sk.py`、页面 HTML——别的会话正同时写别的年份；发现构建脚本 bug 或需要新语法，写进最终报告。**不要 git commit**，主会话最后统一提交。题量大，按题推进、随写随构建，别攒到最后。
**完成标准**：本年全部题都有完整精解，构建通过、复算全过、浏览器抽查过；最终报告写：题数、草图数、新建的 @tpl/@kp 清单（id＋名字）、抓出的原解析错误、没把握的地方。
