其之壹树的语言

树是 n 个结点、n−1 条边、无环连通的结构（n=0 叫空树）。除根外每个结点只有一个父亲，所以边数比结点数少一。

术语：结点的孩子数是结点的度，所有结点度的最大值是树的度。度为 0 的叫叶子，其他叫分支结点。根到结点的路径上结点数叫层次（根是第 1 层），子树的最大层数叫高度。路径长度是路径上边的条数。有序树子树左右不能换。

咒灵
高度和层次：默认根在第 1 层

「高度为 h 的树」默认根是第 1 层，单结点高度为 1。看到题目另作说明就按题目。

术式
树的两个恒等式

边数：总结点数 = 总度数 + 1，也就是 n = 边 + 1。
度为 m 的树：n = n₀+n₁+…+n_m，同时 n = 1·n₁+2·n₂+…+m·n_m + 1。两式相减就能解出叶子数 n₀ = 1 + n₂ + 2n₃ + … + (m−1)n_m。
k 叉树第 i 层最多 k^(i−1) 个结点；高为 h 最多 (k^h−1)/(k−1) 个。

走一遍：度为 3 的树，3 个度 3、2 个度 2、4 个度 1，问叶子。总度数 = 9 + 4 + 4 = 17，n = 18。n₀ = 18 − 3 − 2 − 4 = 9。也可以直接代公式：1 + n₂ + 2n₃ = 1 + 2 + 6 = 9。

森林：每棵树都满足「结点 = 边 + 1」，所以 树的棵数 = 结点数 − 边数。

合上页面说一遍：为什么 n = 边 + 1？怎样由各度结点数求叶子？

除根外每个结点有一条边通向父亲。n₀ = 1 + n₂ + 2n₃ + …。

其之貳二叉树的性质

二叉树：每个结点最多两个孩子，左右有序。两种特殊形态：满二叉树：每层都满，高 h 有 2^h − 1 个结点。完全二叉树：除最后一层外全满，最后一层靠左。它的编号和满二叉树一一对应，所以能用数组存。

性质 ① 的推导：n = n₀ + n₁ + n₂；边数 n−1 = n₁ + 2n₂。两式相减就得 n₀ = n₂ + 1。

术式
五条性质

① 叶子比度 2 的多一个：n₀ = n₂ + 1。
② 第 i 层最多 2^(i−1) 个结点，高 h 最多 2^h − 1 个。
③ 完全二叉树高度：h = ⌈log₂(n+1)⌉ = ⌊log₂n⌋ + 1。
④ 编号：i 的左孩子 2i，右孩子 2i+1，父亲 ⌊i/2⌋，所在层 ⌊log₂i⌋+1。
⑤ 完全二叉树的叶子：n₀ = ⌈n/2⌉，最后一个分支结点编号 ⌊n/2⌋；n 为偶数时有且只有 1 个度为 1 的结点，奇数时没有。

完全二叉树问结点数

「第 k 层有 m 个叶子，结点最多是多少」：最多的时候第 k 层后面还有一层。第 k 层共 2^(k−1) 个结点，非叶结点数 = 2^(k−1) − m，每个非叶都有 2 个孩子。总数 = 前 k 层全部 + 2×(非叶数)。 例：第 5 层有 6 个叶子。第 5 层共 16 个，10 个非叶，下一层 20 个。总数 31 + 20 = 51。

存储：顺序存储只适合完全二叉树，否则空着一大片。其他都用二叉链表（data + lchild + rchild）。n 个结点的二叉链表有 n+1 个空指针（2n 个指针，用掉 n−1 个）。这 n+1 个空位，就是下一话线索二叉树的原料。

其之參四种遍历

遍历是把树排成线性序列。名字里的先中后，说的都是根的访问时机：先序（根左右）、中序（左根右）、后序（左右根）。前三个的递归代码只差一行，而这个框架是树类算法的总模板。

模板：递归三行
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

void PreOrder(BiTree T) {
    if (T == NULL) return;
    visit(T);                // 先序：放第一行
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

非递归的本质就是自己维护 第 04 话 那个栈。层序用队列：出队一个，就把它的孩子入队。四种遍历都是 O(n)，每个结点只访问一次；空间：递归和栈是 O(h)，层序是 O(最宽一层)。

模板：层序遍历（队列）
void LevelOrder(BiTree T) {
    BiTree Q[MaxSize], p;
    int front = 0, rear = 0;
    Q[rear++] = T;
    while (front < rear) {
        p = Q[front++];
        visit(p);
        if (p->lchild) Q[rear++] = p->lchild;
        if (p->rchild) Q[rear++] = p->rchild;
    }
}
模板：中序非递归（后序就在这上面多一个「上次访问」标记）
void InOrder2(BiTree T) {
    BiTree S[MaxSize], p = T;
    int top = -1;
    while (p || top != -1) {
        if (p) { S[++top] = p; p = p->lchild; }  // 一路向左压栈
        else {
            p = S[top--];
            visit(p);                             // 弹出时访问
            p = p->rchild;                        // 转向右子树
        }
    }
}

其之肆由序列还原

术式
能唯一确定二叉树的组合

中序 + 先序 / 后序 / 层序 都可以。先序 + 后序不行。
方法：先序（或后序）找根，中序切左右子树，递归。

走一遍：先序 A B D E C F，中序 D B E A C F。

  1. 先序第一个 A 是根。中序里 A 左边 D B E 是左子树，右边 C F 是右子树。
  2. 左子树 3 个，所以先序接下来 3 个 B D E 是左子树的先序。B 是根，中序 D B E 切出 D、E。
  3. 右子树先序 C F，C 是根，中序 C F 中 C 在前，所以 F 是右孩子。

先序 + 后序为什么不行：只有一个孩子时，分不清是左还是右。

三条秒杀结论

先序和中序相同 ⟺ 所有结点没有左子树（右斜）。 先序和后序相反 ⟺ 每层只有一个结点（高度 = 结点数）。 先序序列固定，不同二叉树个数 = 卡特兰数：因为先序相当于入栈序列，中序相当于出栈序列。n=4 时 14 棵。

其之伍综合题：递归模板的应用

树类算法题大多是把递归三行的 visit 换成别的东西。下面两个模板分别用参数把深度带下去。

模板：求 WPL
int WPL(BiTree root, int depth) {       // depth 初值 0
    if (root == NULL) return 0;
    if (root->left == NULL && root->right == NULL)
        return root->weight * depth;
    return WPL(root->left, depth + 1) + WPL(root->right, depth + 1);
}
模板：表达式树转中缀
void Tree2Exp(BTree *root, int deep) {   // deep 初值 1
    if (root == NULL) return;
    if (root->left == NULL && root->right == NULL) {
        printf("%s", root->data);        // 叶子：操作数，不加括号
    } else {
        if (deep > 1) printf("(");       // 除根以外的子表达式都加括号
        Tree2Exp(root->left, deep + 1);
        printf("%s", root->data);
        Tree2Exp(root->right, deep + 1);
        if (deep > 1) printf(")");
    }
}
术式
树类代码题三个模子

求全局量（高度、结点数、WPL）：return f(左)+f(右)+…。
要知道层数（宽度、路径）：参数 depth 往下传。
判定（是否 BST、是否平衡）：全局 flag 或返回值带回，中序递增判 BST。

合上页面说一遍：默写递归三行、层序。三个模子各解决什么问题？

求全局量用返回值相加；要层数就传 depth；判定用全局 flag 或返回值。

2010實戰树·度与结点数
在一棵度为 4 的树 T 中，若有 20 个度为 4 的结点，10 个度为 3 的结点，1 个度为 2 的结点，10 个度为 1 的结点，则树 T 的叶结点数是（　）。

设树中度为 i（i=0,1,2,3,4）的结点数分别为 ni，树中结点总数为 n，则 n = 分支数 + 1，而分支数又等于树中各结点的度之和，即 n = 1+n1+2n2+3n3+4n4 = n0+n1+n2+n3+n4。依题意，n1+2n2+3n3+4n4 = 10+2+30+80 = 122，n1+n2+n3+n4 = 10+1+10+20 = 41，可得出 n0 = 82，即树 T 的叶结点个数是 82。
直接代：叶子数 = 1 + 1×1(度 2) + 2×10(度 3) + 3×20(度 4) = 82。度为 1 的结点不产生额外叶子。
再深一层
三步走，30 秒拿分：
① 总分支数 = 4×20 + 3×10 + 2×1 + 1×10 = 122；
② 总结点数 n = 分支数 + 1 = 123；
③ 非叶结点 = 20+10+1+10 = 41 → 叶结点 = 123 − 41 = 82。
⚠️ 选项设计得极毒：122 是分支数（D，漏了 +1 又忘减非叶）、41 是非叶结点数（A，减反了）、113 是凑数。三个错误选项对应三种典型手滑，做完务必回头确认自己求的是「叶」而不是「分支」或「非叶」。
2016實戰森林·结点与边
若森林 F 有 15 条边、25 个结点，则 F 包含树的个数是（　）。

解法 1：树有一个重要性质，即在 n 个结点的树中有 n−1 条边，「那么对于每棵树，其结点数比边数多 1」。本题森林中的结点数比边数多 10（25−15 = 10），显然共有 10 棵树。
解法 2：此题也可看成考查图的性质——生成树和生成森林。对于图的生成树有一个重要性质，即图中顶点数若为 n，则其生成树含有 n−1 条边。与解法 1 用到的是同一性质。
森林：每棵树都有「结点 = 边 + 1」，所以 树的棵数 = 结点数 − 边数 = 25 − 15 = 10。
再深一层
森林 = 若干棵树，每棵树「结点比边多 1」→ 有几棵树就多出几：
树的棵数 = 结点数 − 边数 = 25 − 15 = 10。
这条一句话结论几乎年年能用（2016 考森林、2010 考树），配套记忆：
· 一棵树：n 结点、n−1 边；
· k 棵树的森林：n 结点、n−k 边；
· 反过来，给边数和结点数就能倒推棵数。
⚠️ 别把「森林转二叉树」的那套绕进来，本题纯数数。
2009實戰完全二叉树·层与叶
已知一棵完全二叉树的第 6 层（设根为第 1 层）有 8 个叶结点，则该完全二叉树的结点数最多是（　）。

第 6 层有叶结点，完全二叉树的高度可能为 6 或 7，显然树高为 7 时结点最多。完全二叉树与满二叉树相比，只是在最下一层的右边缺少部分叶结点，而最后一层之上是个满二叉树，且只有最后两层上有叶结点。若第 6 层上有 8 个叶结点，则前 6 层为满二叉树，而第 7 层缺失 8×2 = 16 个叶结点，所以完全二叉树的结点数最多为 27−1−16 = 111。
第 6 层共 32 个结点，8 个是叶子，24 个非叶。最多情况是第 7 层：48 个。总计 63 + 48 = 111。
再深一层
与 5.2-12（问"最少"，答 39）是同一场景的双胞胎，成对记忆。
算法（问"最多"）：
① 第 6 层有叶结点 ⇒ 树高只能是 6 或 7，求最多 → 取 7；
② 树高 7 ⇒ 前 6 层必须全满 = 63 个，第 6 层共 32 个结点；
③ 其中 8 个是叶（没孩子），另 24 个各带 2 个孩子 → 第 7 层有 48 个；
④ 总数 = 63+48 = 111。
（等价写法：满 7 层 127 个，减去那 8 个叶子本该有的 16 个孩子 = 111。）
⚠️ 为什么第 6 层的叶子必须排在最右边？完全二叉树的第 7 层结点必须"从左往右连续"，所以第 6 层带孩子的结点在左、没孩子的在右——这也保证了「8 个叶子」的情形确实可构造。
⚠️ 选项 39 就是双胞胎题的答案（最少），看清"最多/最少"。
2011實戰完全二叉树·叶结点数
若一棵完全二叉树有 768 个结点，则该二叉树中叶结点的个数是（　）。

最后一个分支结点的编号为 ⌊768/2⌋ = 384，所以叶结点的个数是 768−384 = 384。
【另解】n = n0+n1+n2 = n0+n1+(n0−1) = 2n0+n1−1，其中 n = 768，而在完全二叉树中 n1 只能取 0 或 1，当 n1=0 时，n0 为小数，不符合题意。因此 n1=1，所以 n0 = 384。
用性质⑤：n₀ = ⌈768/2⌉ = 384。
再深一层
套 5.2-14 的一招鲜：叶结点数 = n − ⌊n/2⌋ = ⌈n/2⌉ = ⌈768/2⌉ = 384。（3 秒题。）
另解的奇偶判断也要会：768 是偶数 ⇒ n1 = 1（恰有一个结点只有左孩子）⇒ n0 = n/2 = 384、n2 = 383。
验算：384+1+383 = 768 ✅、n0−n2 = 1 ✅。
⚠️ 选项 385 是"多算一个"（把那个度为 1 的结点误当叶子），257/258 是三分之一处的凑数。凡是完全二叉树数叶子，先写 ⌈n/2⌉，再用 n0=n2+1 回验一遍，两秒钟绝不出错。
2011實戰先序后序·中序可能性
一棵二叉树的先序遍历序列和后序遍历序列分别为 1,2,3,4 和 4,3,2,1，该二叉树的中序遍历序列不会是（　）。

先序序列为 NLR，后序序列为 LRN，因为先序序列和后序序列刚好相反，所以不可能存在一个结点同时有左右孩子，即二叉树的高度为 4（单支树，4 个结点连成一条链）。1 为根结点，根结点只能有左孩子或右孩子，因此在中序序列中，1 或在序列首或在序列尾，选项 A、B、C、D 皆满足。仅考虑以 1 的孩子结点 2 为根结点的子树，它也只能有左孩子（或右孩子），因此在中序序列中，2 或在序列首或在序列尾，选项 A、B、D 皆满足，而 C 不满足。
先序和后序相反，所以这是一条单链。于是每个结点要么只有左孩子要么只有右孩子，用上面的结论排除。
再深一层
先序 1234 + 后序 4321（正好相反）⇒ 这是一条 4 结点的单支链（每个结点只有一个孩子，见 5.3-30）。链的形态：1→2→3→4，每一步可左可右，共 2³=8 种链。
中序序列的规律：对单支链，每个结点在中序里要么在剩余段的最前、要么在最后（取决于它带的是左孩子还是右孩子）。
· 1 是根 → 中序首或尾；确定后，2 又是子链的根 → 剩余段的首或尾……
· 逐层"首/尾"二选一，能生成 8 种合法中序。C 的"3,2,4,1"里，1 在尾（✓）、2 应在剩余段 {3,2,4} 的首或尾，但它在中间 → 非法。
我枚举全部满足"先序1234+后序4321"的树，得到 8 种合法中序：1234/1243/1342/1432/2341/2431/3421/4321，唯独没有 3241 → 选 C。
2015實戰遍历·形态计数
先序序列为 a,b,c,d 的不同二叉树的个数是（　）。

根据二叉树先序遍历和中序遍历的递归算法中递归工作栈的状态变化得出：先序序列和中序序列的关系相当于以先序序列为入栈次序、以中序序列为出栈次序。因为先序序列和中序序列可以唯一地确定一棵二叉树，所以题意相当于"以序列 a,b,c,d 为入栈次序，则出栈序列的个数为？"，对于 n 个不同元素入栈，出栈序列的个数为 (1/(n+1))·C(2n,n) = 14。
卡特兰数，C(8,4)/5 = 14。这和 出栈序列数 是同一个数，原因就是上面那条结论。
再深一层
"先序序列固定，问有多少棵不同二叉树" = 卡特兰数 Cₙ。n=4 → C₄ = C(8,4)/5 = 70/5 = 14，选 B。
三种等价理解（任选一个记）：
① n 个结点的不同二叉树形态数 = 卡特兰数（先序序列一旦固定，形态数 = 形态种类数）；
② = n 个元素的合法出栈序列数（先序入栈、中序出栈）；
③ 卡特兰数列：1, 2, 5, 14, 42, 132…（C₃=5、C₄=14、C₅=42 必背，第3章出栈序列同款）。

2017實戰先序中序·相同条件
要使一棵非空二叉树的先序序列与中序序列相同，其所有非叶结点须满足的条件是（　）。

先序序列先访问父结点，接着访问左子树，然后访问右子树。中序序列先访问左子树，接着访问父结点，然后访问右子树，递归进行。若所有非叶结点只有右子树，则先序序列和中序序列都先访问父结点，后访问右子树，递归进行。
先序「根左右」和中序「左根右」要相同，必须没有左子树。
再深一层
先序 NLR = 中序 LNR ⟺ 让"左子树 L"消失 ⟺ 所有非叶结点只有右子树。选 B。
· 去掉 L 后：先序变 N R(根右)、中序变 N R(根右)，完全相同。
· 这样的树是一棵向右倾斜的单支树。
⚠️ C"度均为1"是陷阱：度均为1 的单支树可能向左斜（那样先序≠中序，见 5.3-31）也可能向右斜，不能保证相同，必须明确是"只有右子树"。
· 对照 5.3-15：中序=后序 ⟺ 无右子树（向左斜）；先序=中序 ⟺ 无左子树（向右斜），两条正好对称，一起记。
我枚举 n≤7 验证："先序=中序" ⟺ 只有右子树，零反例。
2012實戰先序后序·祖先关系
若一棵二叉树的先序遍历序列为 a,e,b,d,c，后序遍历序列为 b,c,d,e,a，则根结点的孩子结点（　）。

先序序列和后序序列不能唯一确定一棵二叉树，但可以确定二叉树中结点的祖先关系：当两个结点的先序序列为 XY 与后序序列为 YX 时，则 X 是 Y 的祖先。考虑先序序列 a,e,b,d,c、后序序列 b,c,d,e,a，可知 a 为根结点，e 为 a 的孩子结点；此外，由 a 的孩子结点的先序序列 e,b,d,c、后序序列 b,c,d,e，可知 e 是 bcd 的祖先，所以根结点的孩子结点只有 e。
先序第一个 a 是根，后序倒数第二个 e 紧贴在根之前。先序第二个也是 e，说明 a 只有一个孩子 e。
再深一层
先序+后序虽不能定树，但能用"先序 XY / 后序 YX ⟺ X 是 Y 祖先"判祖先关系。
· 先序首 a、后序末 a → a 是根。去掉 a，看它的子树部分：先序 e,b,d,c、后序 b,c,d,e。
· 这段的先序首 e、后序末 e → e 是这整段的祖先，即 e 是 b、d、c 的共同祖先 → e 是 a 的唯一孩子（若 a 还有别的孩子 x，x 与 e 会是兄弟，e 就不可能是 x 的祖先了）。
· 所以根 a 的孩子只有 e，选 A。
我枚举全部"先序 aebdc + 后序 bcdea"的树（共 4 棵），根的孩子恒为 {e}。
2014實戰WPL·带权路径长度
二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树 T，采用二叉链表存储，结点结构为 (left, weight, right)，其中叶结点的 weight 域保存该结点的非负权值。设 root 为指向 T 的根结点的指针，请设计求 T 的 WPL 的算法，要求：1) 给出算法的基本设计思想；2) 使用 C 或 C++ 语言给出二叉树结点的数据类型定义；3) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
二叉树的带权路径长度有两种常见的计算方法：① 根据 WPL 定义，WPL = 树中全部叶结点的带权路径长度之和；② 根据带权二叉树的性质，WPL = 树中所有非叶结点的权值之和（叶结点权值×深度求和 等价于 非叶结点权和，此处非叶权 = 其子树叶权之和，记住结论即可）。
【解法1·基于定义·递归】设根结点深度为 0，孩子深度 = 父深度+1。遍历到叶结点则返回 weight×深度，否则返回左右子树 WPL 之和。
【解法2·非叶权和·后序】遍历时令非叶结点的 weight 域 = 其孩子权值之和，则 WPL = 所有非叶结点 weight 之和。
【注意】官方标准答案在遍历到度为 1 的结点时会传入空指针导致异常，但作为 408 算法题，只要思想正确、逻辑正确即可得满分，无须抠边界。
typedef struct node{
    int weight;
    struct node *left, *right;
}BTree;
//解法1：基于定义的递归实现
int WPL(BTree *root){
    return wpl_pre(root, 0);           //根深度为 0
}
int wpl_pre(BTree *root, int d){
    if(root->left==NULL && root->right==NULL)   //叶结点
        return root->weight * d;                //带权路径长度 = 权 × 深度
    int s=0;
    if(root->left)  s+=wpl_pre(root->left,  d+1);   //累加左子树
    if(root->right) s+=wpl_pre(root->right, d+1);   //累加右子树
    return s;
}
带一个 depth 参数往下传；叶子处累加 weight*depth。这是 树类大题最常见的写法：参数往下传，返回值往上传。
再深一层
答案：递归遍历，累加"每个叶结点的 weight × 它的深度"。（解法1 最直观，推荐考场写这个。）
设计思想：设根深度为 0，往下每层 +1。到叶结点就返回 weight × depth，非叶结点返回左右子树 WPL 之和。
结点定义：typedef struct node{ int weight; struct node *left,*right; }BTree;
解法2（备选）：WPL 还等于"所有非叶结点权值之和"（若把每个非叶结点的权设为其子树叶权和），用后序算——但这法要改写树，不如解法1 干净。
⚠️ 王道标注：官方代码在遇到度为 1 的结点时会对空孩子取 weight 导致越界，但 408 算法题按思想给分，不抠边界；写代码时对叶结点先判断即可规避。
我用 Python 把两种解法都实现，2000 棵随机带权二叉树上 WPL 值完全一致。
2017實戰表达式树·转中缀
请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。例如，两棵表达式树的输出应分别为 (a+b)*(c*(-d)) 和 (a*b)+(-(c-d))。结点定义 typedef struct node{ char data[10]; struct node *left,*right; }BTree;。要求：1) 给出算法的基本设计思想；2) 采用 C 或 C++ 语言描述算法，关键之处给出注释。
表达式树的中序序列加上必要的括号即等价的中缀表达式。可以基于二叉树的中序遍历策略得到所需的表达式。表达式树中分支结点所对应的子表达式的计算次序，由该分支结点所处的位置决定。为得到正确的中缀表达式，需要在生成遍历序列的同时，在适当位置增加必要的括号。显然，表达式的最外层（对应根结点）和操作数（对应叶结点）不需要添加括号。
【实现】改造中序递归：除根结点和叶结点外，遍历到其他结点时，在遍历其左子树之前加左括号，遍历完右子树后加右括号（用深度 deep 判断，deep>1 才加括号）。
void BtreeToE(BTree *root){
    BtreeToExp(root, 1);              //根的深度为 1
}
void BtreeToExp(BTree *root, int deep){
    if(root==NULL) return;           //空结点返回
    else if(root->left==NULL && root->right==NULL)   //叶结点（操作数）
        printf("%s", root->data);    //输出操作数，不加括号
    else{
        if(deep>1) printf("(");      //非根分支结点，左括号
        BtreeToExp(root->left, deep+1);
        printf("%s", root->data);    //输出操作符
        BtreeToExp(root->right, deep+1);
        if(deep>1) printf(")");      //非根分支结点，右括号
    }
}
就是带括号的中序。关键点：根和叶子不加括号，只有 deep>1 的分支结点才加。
再深一层
答案：中序遍历表达式树 + 在非根非叶的分支结点两侧补括号。
设计思想：中序遍历一棵表达式树，得到的就是中缀表达式的"骨架"，但缺括号。补括号的规则：
· 叶结点（操作数）不加括号；
· 根结点（最外层）不加括号（最外层无歧义）；
· 其余分支结点：在递归其左子树前打 (、递归完右子树后打 )。
用一个深度参数 deep 实现："deep>1 才加括号"（deep=1 是根）。
⚠️ 一元负号 -d 这种（左子树空）也能正确处理——中序走时左子树空就直接输出运算符再输出右操作数，配合括号得 (-d)。
我用 Python 实现该算法，对题干两棵样例树分别输出 (a+b)*(c*(-d)) 和 (a*b)+(-(c-d))，与题目要求完全一致。
