:::say
这是网络最贵的一话。==发送窗口 = min(rwnd, cwnd) 再减在途==，以及拥塞控制的四个阶段。流量控制和拥塞控制相似但对象不同，先把它们分开。
:::

== 可靠传输 {rel}
**累积确认**：ack=n 说明 n 之前全收到了。**超时重传**：`RTO` 根据 RTT 加权平均计算（Jacobson），略大于 RTT。

:::shu RTT 估计
`RTTs = (1−α)·RTTs + α·新 RTT`（α=1/8）
`RTTd = (1−β)·RTTd + β·|RTTs − 新 RTT|`（β=1/4）
`RTO = RTTs + 4·RTTd`。
:::

**快重传**：连续收到 3 个==重复 ACK==（共 4 个相同 ACK）就立即重传，不等超时。

@q net:5.3.4-08 | 按时序看：第三次重复 ACK 到达的时刻，就是快重传的时刻。

== 流量控制 {flow}
:::ana 水龙头和水桶
接收方告诉发送方：我的水桶还能装多少（rwnd）。发送方发的不能超过它。
:::

**零窗口**：rwnd=0 时发送方停发，定时发一个 1 字节的探测（持续计时器），防止窗口更新丢失后死锁。

:::shu 发送窗口
`发送窗口 = min(rwnd, cwnd)`
`可发字节数 = 发送窗口 − 在途未确认的`
:::

@q net:5.3.5-08 | 发送窗口 = min(4000, 2000) = 2000。发了两段只确认一段，在途 1000，还能发 1000。这就是本话第一个公式。
@q net:5.3.5-11 | 慢开始 4 个 RTT 累计发 1+2+4+8 = 15 KB，缓存只剩 1 KB，rwnd = 1 KB。cwnd 虽然到了 16，发送窗口 = min(16, 1) = 1 KB。

== 拥塞控制 {cong}
由发送方靠 `cwnd` 自己猜网络状况。四个算法：

:::shu 拥塞四步（核心）
**慢开始**：cwnd < ssthresh 时，每个 RTT 翻倍。==但不超过 ssthresh==。
**拥塞避免**：cwnd ≥ ssthresh 时，每个 RTT +1。
**超时**：`ssthresh = cwnd/2`，`cwnd = 1`，重新慢开始。
**3 个重复 ACK（快重传 + 快恢复）**：`ssthresh = cwnd/2`，`cwnd = ssthresh`，然后线性增长。
:::

@ cwnd_steps(['ok']*7+['to']+['ok']*7+['dup']+['ok']*3)

:::trap 三个细节
**① 翻倍封顶到 ssthresh**：cwnd=8，ssthresh=12 时，下一轮是 12，不是 16。
**② 超时那一刻就变 1**，不占一个 RTT。
**③ 3 个重复 ACK**：不回到慢开始。
:::

:::vow 题干给的是字节不是段
MSS=1 KB 时可以把数都当段算。题目给 MSS 的其他数字（比如 2 KB、1460 B），要统一单位。
:::

@q net:5.3.6-10 | cwnd=16 超时：ss=8，cwnd=1。1→2→4→8→9：第 4 个 RTT 结束后 9（拥塞避免 +1）。
@q net:5.3.6-11 | ss=4，cwnd 依次 2、4、5、6…10 个 RTT 后到 12。但 rwnd 恒为 10，发送窗口 = min(12, 10) = 10。其实看到「rwnd=10」，选项里只有 A 不超过 10。
@q net:5.3.6-12 | 1→2→4→8→16→32，5 个 RTT = 25 ms。
