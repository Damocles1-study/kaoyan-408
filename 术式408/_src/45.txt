== IP 分组 {header}
@ bits([('版本 4',4),('首部长 4',4),('服务 8',8),('总长度 16',16,'gd')],unit='',cap='第 1 行：首部长单位 4 B（最小 5→20 B），总长度单位 1 B（上限 65535）')
@ bits([('标识 16',16),('标志 3',3,'gd'),('片偏移 13',13,'gd')],unit='',cap='第 2 行：标志 MF=1 后面还有分片，DF=1 不许分片；片偏移单位 8 B')
@ bits([('TTL 8',8),('协议 8',8),('首部校验和 16',16)],unit='',cap='第 3 行：TTL 每跳 −1；协议 6=TCP 17=UDP 1=ICMP；校验和只校验首部')
@ bits([('源 IP 32',32,'bu')],unit='')
@ bits([('目的 IP 32',32,'bu')],unit='')

:::shu 首部三个单位（必考）
**首部长度** ×4 B。**总长度** ×1 B。**片偏移** ×8 B。
口诀：「一八四，总片首」——总长度 1，片偏移 8，首部长 4。
:::

:::shu 分片
**每片的数据长度必须是 8 的倍数**（最后一片除外）。
MTU 1500，首部 20：每片数据最多 1480 B（1480/8=185）。
一个 3980 B 总长的分组（数据 3960）：1480+1480+1000。偏移 0、185、370。MF：1、1、0。
只有最终目的主机才重组。
:::

== IP 地址 {addr}
@ table([['类','前缀','网络部分','范围'],['A','0','8','0–127'],['B','10','16','128–191'],['C','110','24','192–223'],['D','1110','组播','224–239'],['E','1111','保留','240–255']],mono=True)

:::shu 特殊地址
**0.0.0.0**：本机（只能做源）。**127.x.x.x**：环回。**主机全 0**：网络地址。**主机全 1**：广播（只能做目的）。**255.255.255.255**：受限广播。
**私有**：`10/8`、`172.16/12`、`192.168/16`。
:::

== 子网与 CIDR {cidr}
:::shu 子网四问（/n）
**掩码**：n 个 1。
**网络地址**：IP AND 掩码。
**广播地址**：网络位不动，主机位全 1。
**可用主机数**：`2^(32−n) − 2`。
**块大小（当字节）**：`256 − 掩码那一字节`。
:::

:::flash 快算
把 IP 中被切的那个字节按块大小找倍数。比如 `180.80.77.55/22`：掩码第 3 字节 252，块 4；77 落在 76–79 里，所以网络 `180.80.76.0`，广播 `180.80.79.255`。
:::

@q net:4.2.2S-14 | 就是上面算的。
@q net:4.2.2S-12 | 掩码 248 → 块 8 → 主机 6；子网 256/8 = 32。
@q net:4.2.2S-13 | /30，主机 2 个；目的 .3 是这个子网的广播地址，子网里所有主机都能收到，最多 2 个。
@q net:4.2.2S-15 | 128=2⁷，/16→/23；主机 2⁹−2 = 510。
@q net:4.2.2C-07 | 共同前缀 19 位：32、40、48、56 二进制的高 3 位相同。
@q net:4.2.2C-08 | /20 = 4096。分 5 块要最小：一半一半切：2048、1024、512、256、256；256−2 = 254。

== 路由转发 {forward}
:::shu 最长前缀匹配
目的 IP 和每条路由的前缀比较，都匹配时选 ==最长的那条==。
**默认路由** `0.0.0.0/0`：没有其他匹配时走它。
**直接交付**：目的在同一网段，发给目的本身。
**间接交付**：发给默认网关。
:::

:::vow 分组转发时不变的和变的
经过路由器：IP 地址==不变==（NAT 除外）；MAC 地址==每一跳都换==；TTL −1，首部校验和重算。
:::

@q net:4.2.4-02 | 三条都匹配时取最长。169.96.40.5 匹配 /27。
@q net:4.2.4-06 | 下一跳就是相邻路由器在同一网段的接口。
@q net:4.2.4-07 | R 转发时：源 MAC = R 的出接口；目的 MAC = H2。IP 不变。
@q net:4.2.4-09 | H1 和 H3 掩码不同：判断是否同网段要自己用自己的掩码算。
