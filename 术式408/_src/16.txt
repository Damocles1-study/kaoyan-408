== 五大部件 {parts}
冯·诺依曼结构的核心是~~存储程序~~：指令和数据都以二进制放在主存里，机器自动逐条取出执行。

@ svg(560,180,box(20,70,90,40,'输入设备'),box(450,70,90,40,'输出设备'),box(235,10,100,40,'主存','bk'),box(170,110,90,44,'运算器\nALU','gd'),box(310,110,90,44,'控制器\nCU','gd'),arrow(110,90,170,125),arrow(400,125,450,90),'<rect x="158" y="100" width="254" height="64" fill="none" class="rdl" stroke-dasharray="5 4"/>',T(285,174,'CPU',13,'rdt'),arrow(285,50,240,110),arrow(250,110,300,50),cap='五大部件：运算器和控制器合起来叫 CPU；CPU 和主存合起来叫主机')

:::shu 冯·诺依曼的要点
1. 五大部件组成。
2. 指令和数据同等地位，都放在存储器，**按地址访问**。
3. 指令和数据都用**二进制**表示。
4. 指令由操作码和地址码组成。
5. 指令在存储器顺序存放，靠 **PC** 自动 +1 顺序执行（也可改变）。
6. 以运算器为中心（现代多以存储器为中心）。
:::

:::flash CPU 怎么区分指令和数据
存储器里都是 0 和 1。==取指周期取到的是指令，执行周期取到的是数据==。
:::

:::shu 六个寄存器（后面每一章都要用）
**PC** 程序计数器：下一条指令地址。程序员可见。
**IR** 指令寄存器：当前指令。不可见。
**MAR** 主存地址寄存器：位数对应地址线。不可见。
**MDR** 主存数据寄存器：位数对应存储字长。不可见。
**GPR** 通用寄存器；**PSW** 程序状态字（含标志位）。
:::

**一条指令怎么跑**：把这些寄存器串起来看。比如当前要执行 `LOAD R1, [5]`（把地址 5 的内容放进 R1）。

1. **取指**：PC 的值送 MAR，存储器读出指令送 MDR，再送 IR；PC 加 1，指向下一条。
2. **译码**：控制器分析 IR 里的操作码，知道这是取数。
3. **执行**：把地址 5 送 MAR，读出内容送 MDR，再送 R1。

每条指令都是这个循环，CPU 从开机到关机就在重复这件事。

**几个「长度」别混**：**机器字长** = CPU 一次能处理的二进制位数（通用寄存器、ALU 的宽度），「32 位机器」说的就是它。**存储字长** = 一个存储单元的位数，MDR 与它相同。**指令字长** = 一条指令的位数，IR 与它相同。三者可以不相等。**MAR** 位数决定能访问多少单元：MAR 32 位、按字节编址，就是 4 GB。

:::recall 五大部件是什么？MAR、MDR、IR、PC 各存什么？机器字长是什么？
运算器、控制器、存储器、输入、输出。MAR 存要访问的地址，MDR 存读写的数据，IR 存当前指令，PC 存下一条指令的地址。机器字长是 CPU 一次处理的位数。
:::

:::trap 硬件只能直接执行机器语言
汇编语言也要汇编器翻译。硬件描述语言（Verilog）是用来设计硬件的，不是被执行的。
**编译**：一次译完，生成目标文件。**解释**：边翻译边执行，不生成目标文件，所以每次运行都要翻译。

**系统的层次**从下到上：微程序机器 → 传统机器（机器语言）→ 操作系统 → 汇编 → 高级语言。下层为上层提供服务。~~软硬件逻辑等价~~：同一功能既可由硬件也可由软件实现，前者快，后者灵活。

==  性能公式 {perf}
一个程序跑多久，拆开看只有三个因子：多少条指令、每条平均几个周期、一个周期多长。

:::shu CPU 执行时间
`CPU 时间 = 指令条数 × CPI × 时钟周期`
         = `指令条数 × CPI / 主频`
`MIPS = 主频 / (CPI × 10⁶)`
`平均 CPI = Σ (各类比例 × 各类 CPI)`
:::

:::shu 指标的单位
**主频**（Hz）= 1 / 时钟周期。1 GHz → 1 ns。
**CPI**：每条指令的平均时钟周期数。
**MIPS**：每秒百万条指令。**MFLOPS**：每秒百万次==浮点==运算（GFLOPS、TFLOPS、PFLOPS、EFLOPS、ZFLOPS 依次 ×1000）。
**吞吐量**：单位时间完成的量。**响应时间**：从提交到首次响应。
:::

:::trap 三个常见误解
**MIPS 高不等于快**：指令集不同时比较 MIPS 没有意义，RISC 一条做的事比 CISC 少。**主频高不等于快**：还要看 CPI。**CPU 时间不等于总时间**：I/O 时间要分开算，只改善 CPU，I/O 那部分原封不动。
:::

走一遍：主频 2 GHz。程序 10⁹ 条指令，其中 40% 算术（CPI=1）、40% 访存（CPI=3）、20% 转移（CPI=2）。

- 平均 CPI = 0.4×1 + 0.4×3 + 0.2×2 = 2。
- CPU 时间 = 10⁹ × 2 ÷ (2×10⁹) = 1 秒。
- MIPS = 2000 ÷ 2 = 1000。

**只改善一部分**：程序总共 100 秒，其中 CPU 80 秒，I/O 20 秒。CPU 速度翻倍后，CPU 40 秒、I/O 仍 20 秒，共 60 秒，整体只快了 1.67 倍，不是 2 倍。

:::recall 写出 CPU 时间公式和 MIPS 公式。CPU 快一倍，整体为什么快不到一倍？
时间 = 条数 × CPI ÷ 主频；MIPS = 主频 ÷ CPI ÷ 10⁶。因为 I/O 时间不变。
:::

:::domain
**存储程序：**指令和数据同地位；取指周期取到的是指令。
**性能公式：**时间 = 条数 × CPI / 主频；MIPS = 主频 / CPI。
**只改善一部分：**未改善的部分不变，分开算。
:::
