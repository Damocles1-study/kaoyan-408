== 基本原理 {base}
CPU 要访问主存时，先在 Cache 里找。数据以**块**（行）为单位在 Cache 和主存之间搬。

:::shu 性能公式
命中率 H = 命中次数 / 总访问次数。
**先访问 Cache，不命中再访问主存**：`T = H·Tc + (1−H)(Tc+Tm)`。
**同时访问**：`T = H·Tc + (1−H)·Tm`。
**CPI 带缺失**：`CPI = CPI₀ + 每条指令访存次数 × 缺失率 × 缺失损失`。
:::

@q co:3.5-28

== 三种映射 {map}
:::ana 停车场
**直接映射**：每辆车只能停指定的车位（车牌尾号决定），停了就要赶走原来那辆。**全相联**：随便停，但找车时要所有车位都看一遍。**组相联**：分成几个区，指定区内随便停。
:::

:::shu 地址划分三步
**① 块内偏移** = log₂(块大小)，==块大小以字节算要用「编址单位」==。
**② 组号** = log₂(行数 / 路数)。
**③ 标记** = 地址总位数 − 前两者。
找块：`块号 = 地址 / 块大小`，`组号 = 块号 % 组数`。
:::

:::shu Cache 总容量（真题常考）
每行 = 数据位 + 标记位 + 有效位(1) + 脏位(回写才有，1) + 替换位(LRU 才有)。
总容量 = 行数 × 每行位数。
:::

@q co:3.5-31 | 块 16B（4 字），4K 字 = 1K 行。标记 32−10−4 = 18，+有效 1 + 脏 1 = 20 位，+数据 128 位 = 148 位。总共 148K 位。这是公式的直接应用。

== 替换算法 {repl}
只有全相联和组相联需要。**随机**；**FIFO**（不考虑局部性）；**LRU**（用计数器，n 行 log₂n 位，最常用，块数大于组大小时可能抖动）；**LFU**。

== 写策略 {write}
:::shu 写命中和写不命中
**写命中**：**全写**（同时写主存，配写缓冲）；**回写**（只写 Cache，被替换时才写回，每行加脏位）。
**写不命中**：**写分配**（调入 Cache，再写，配回写）；**非写分配**（只写主存，配全写）。
:::

现代常用组合：回写 + 写分配。

:::trap 多级 Cache 和分离
**L1 分离**（指令 Cache、数据 Cache）解决[[22|结构冒险]]。**L1 和 L2 之间常全写，L2 和主存之间常回写**。Cache 中的数据是主存的副本，多核时有==一致性==问题。
:::

== C 程序命中率 {cprog}
这是最爱考的题型。方法：==只看第一次访问这一块时缺失，然后这一块的其他元素全命中==。

:::shu 算命中率的步骤
**① 算每块放几个元素**：块大小 / 元素大小。
**② 按代码访问顺序看**：按行访问（空间局部性好）：每块缺失 1 次。
**③ 循环内读 + 写同一元素**：写的那一次一定命中（刚读过）。
**④ 按列访问**：看 Cache 能不能装下一列的所有块。
:::

@q co:3.5-32 | 每块 4 个元素。每个 a[k] 读 1 次写 1 次，共 8 次访问，只有第 1 次缺失。缺失率 1/8 = 12.5%。这里 Cache 容量够不够都一样，因为是顺序访问。
@q co:3.5-综04 | 2010 大题。程序 A 按行访问，程序 B 按列访问。Cache 只有 8 行（512 B）。这是 [[05|行优先]]和 Cache 的连接：A 的命中率高得多。
@q co:3.5-综05 | 2013 大题：把 CPI、低位交叉、Cache 缺失损失串在一起。缺失损失 = T + (n−1)·r，这里用的就是 [[30]] 的公式。

:::domain
**地址：**标记 | 组号 | 块内；路数翻倍，标记多一位。
**容量：**行数 × (数据 + 标记 + 有效 + 脏)。
**写：**全写配非写分配，回写配写分配。
**C 程序：**每块只缺一次；写紧跟读必命中。
:::
