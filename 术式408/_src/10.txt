:::old
邻接矩阵和邻接表的 BFS 时间复杂度？ || O(n²)；O(n+e)。
保证 n 个顶点的图在任何情况下连通，最少多少边？ || C(n−1,2)+1。
BFS 能解决什么最短路径？ || 无权图的单源最短路径。

:::say
建一张通信网要把所有城市连起来，线路总长最短：最小生成树。导航要从一个点到另一个点最近：最短路径。这一话四个算法每一个都不难，关键是能==手算出每一步的表==。
:::

== 最小生成树 {mst}
连通带权图中，权值和最小的生成树。两个算法都基于同一性质：==跨越任意割的最小边，一定在某棵 MST 里==。把顶点分成两堆，连接两堆的最便宜那条边一定值得选。

**Prim** 从一个点长大：已选集合 S，每次选一条连接 S 和外面的最小边，把新顶点纳入。

@ prim_steps('A')

**Kruskal** 从边出发：所有边按权排序，从小到大看，两端已经连通就跳过（否则成环），否则选上。判断是否连通用[[07|并查集]]。

@ kruskal_steps()

:::shu 两个算法对比
|算法|思路|时间|适合|
|Prim|从一个点长大，每次选跨越的最小边|O(n²)（矩阵）|稠密图|
|Kruskal|所有边排序，能选就选，用并查集判环|O(e log e)|稀疏图|
:::

:::shu MST 的性质
**代价唯一，树可能不唯一。**
所有边权不同 ⟹ MST 唯一（反过来不成立）。
Prim 从不同点开始，选边次序不同，但代价相同。
最小的边不一定在所有 MST 中（若有并列最小边且成环）；但==严格唯一最小==的那条边一定在每棵 MST 中。
:::

== Dijkstra：单源最短路径 {dij}
:::ana 烧绳子
从源点点火，火沿着边烧，速度相同。每次最先被烧到的那个顶点，它的最短距离已经确定了，再也不会变短。这要求==权值不能为负==。
:::

下面这张图是这一节的例子：

@ dijkstra_steps({'1':(50,100),'2':(170,40),'3':(290,40),'4':(290,160),'5':(170,160)},[('1','2',10),('1','5',5),('2','3',1),('2','5',2),('5','2',3),('5','3',9),('5','4',2),('3','4',4),('4','3',6),('4','1',7)],'1')

:::shu Dijkstra 手算表头
每一轮写一行：`S 集合 | dist[每个顶点] | path[每个顶点]`。
1. 未确定的顶点中选 dist 最小的 u，放入 S。
2. 用 u 更新：若 `dist[u]+w(u,v) < dist[v]`，更新 dist[v]，path[v]=u。
时间 **O(n²)**。不能处理负权。
:::

:::trap MST 和最短路径树不是一回事
Prim 比的是「边权」，Dijkstra 比的是「到源点的累计距离」。代码几乎相同，只差这一句。两者产出的树在大部分图上都不同（随机图上超过 6 成不同）。
:::

**为什么不能有负权**：Dijkstra 的前提是确定了的顶点不会再变短。设 a→b 权 2，a→c 权 3，c→b 权 −2。第一轮确定 b=2，可真正最短是 a→c→b = 1。

:::recall Dijkstra 的一轮做两件事，是什么？和 Prim 差在哪一句？
选 dist 最小的未确定顶点；用它松弛其他顶点。Prim 比的是到集合的边权，Dijkstra 比的是到源点的累计距离。
:::

== Floyd：所有点对 {floyd}
Dijkstra 跑 n 遍可以得到所有点对，Floyd 代码更短。思路：只允许经过前 k 个顶点时的最短路径，逐步放开 k。第 k 轮问：经过 k 中转，会不会比现在短？所以中转点**一定要写在最外层**。允许有负权边，但不能有负权回路。时间 O(n³)。

:::code c 模板：Floyd
for (int k = 0; k < n; k++)         // 中转点在最外层
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;
            }
:::

@ floyd_table(3,[(0,1,6),(0,2,13),(1,0,10),(1,2,4),(2,0,5)])

**路径还原**：`path[i][j]` 存中转点，递归地展开 i→k 和 k→j。

:::shu 三种最短路径算法
|算法|问题|复杂度|负权|
|BFS|无权单源|O(n+e) / O(n²)|无权|
|Dijkstra|带权单源|O(n²)|不允许|
|Floyd|所有点对|O(n³)|允许负边，不允许负环|
:::

:::link 这是网络的路由算法
[[47|OSPF]] 用的就是 Dijkstra；[[47|RIP]] 用的距离向量，是 Bellman-Ford 思想。
:::

:::domain
**Prim：**长点，选最小跨越边。**Kruskal：**边排序 + 并查集。
**Dijkstra：**选 dist 最小，松弛，不能负权。
**Floyd：**k 在最外层。
**MST 代价唯一，树不一定唯一。**
:::
