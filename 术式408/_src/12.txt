:::say
查找题考的就是 ASL（平均查找长度）。这一话把顺序、折半、分块、散列四种放在一起比，并把折半判定树和线性探测手算练到不会错。
:::

== 顺序与折半 {seq}
**ASL** = Σ 查找概率 × 比较次数。成功和失败要分开算。

:::shu 顺序查找
成功 ASL = **(n+1)/2**。失败（无序、有哨兵）= **n+1**。
**有序顺序表的失败** ASL 可以提前结束，= n/2 + n/(n+1)。
:::

:::code c 模板：折半查找（要求有序 + 顺序存储）
int BinSearch(int a[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (a[mid] == key) return mid;
        else if (a[mid] > key) high = mid - 1;
        else low = mid + 1;
    }
    return -1;
}
:::

折半的过程可以画成**判定树**。n=11 时：

@ tree('6(3(1(,2),4(,5)),9(7(,8),10(,11)))',hl='',cap='判定树：mid 向下取整时，每个结点的右子树比左子树多 0 或 1 个结点。结点所在层 = 成功时的比较次数')

:::shu 判定树三条
**高度** `h = ⌈log₂(n+1)⌉` = 最多比较次数（成功或失败都不超过 h）。
**逐结点判据**：mid 向下取整时，每个结点 `右子树结点数 − 左子树结点数 ∈ {0, 1}`；向上取整时反过来。整棵树要==始终如一==。
**中序遍历有序**（它也是 BST）。失败结点有 n+1 个，都在外部。
:::

== 分块查找 {block}
块内无序、块间有序，再建一个索引表。**ASL = 索引查找 + 块内查找**。

:::shu 分块 ASL
长度 n 分 b 块、每块 s 个：
索引和块内都顺序查：`ASL = (b+1)/2 + (s+1)/2`，当 `s = √n` 时最小，为 `√n + 1`。
索引用折半：`ASL = ⌈log₂(b+1)⌉ + (s+1)/2`。
:::

== 散列 {hash}
:::ana 储物柜
不比较，直接算出柜号。两个人算出同一个柜号就是冲突，主要工作就是处理冲突。
:::

:::shu 常用构造与冲突处理
**散列函数**：除留余数法 `H(k)=k%p`（p 取不大于表长的最大质数）；直接定址、数字分析、平方取中。
**开放定址法**：`Hᵢ = (H(k)+dᵢ) % m`。线性探测 dᵢ=1,2,3…；平方探测 dᵢ=1²,−1²,2²,−2²…；双散列。
**拉链法**：同一个地址的放一条链表。
**装填因子** `α = n / m`。ASL 只依赖 α，==不直接依赖 n==。
:::

:::trap 删除和聚集
**开放定址法不能直接删除**，只能做标记（否则断了后面的探测路径）。拉链法可以直接删。
**堆积（聚集）**：线性探测的特点，它让不同同义词竞争同一批地址，直接影响的是 ASL，不影响存储效率。
:::

:::shu 手算 ASL
**成功**：每个关键字比较次数之和 ÷ 关键字数。
**失败**：对散列函数的每个可能取值（注意是 `mod p` 的 p 个，不是表长 m），一直走到空位，比较次数算上这次碰到空位的比较 ÷ p。
:::

下面就是 2010 大题的数据，表长 10（α=0.7），H=(key×3)%7，全部由程序计算：

@ hash_lp([7,8,30,11,18,9,14],10,7,3)

:::domain
**折半：**判定树高 ⌈log₂(n+1)⌉，右比左多 0 或 1。
**分块：**s=√n 最优。
**散列：**ASL 只看 α；失败除 p 不除 m；开放定址不能硬删。
:::
