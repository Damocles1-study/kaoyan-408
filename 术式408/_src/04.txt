:::say
线性表哪都能插，栈和队列故意限制操作位置。限制带来了性质：栈后进先出，队列先进先出。这两个性质后面到处都用：函数调用、表达式、进程调度、缓冲。
:::

== 栈：只能从一头进出 {stack}
:::ana 羽毛球筒
最后塞进去的那颗最先被倒出来：LIFO（后进先出）。n 个元素入栈，出栈序列的总数是卡特兰数。
:::

:::shu 卡特兰数与判合法
n 个不同元素的合法出栈序列数：`C(2n,n) / (n+1)`，n=3 时 5，n=4 时 14，n=5 时 42。
判合法：==对每个已出栈元素，在它之后出栈且比它先入栈的元素，必须按入栈的逆序出现==。
:::

:::flash 判「不可能的序列」
看序列中任意一个数 x：比 x 小（先入栈）且排在 x 后面的那些数，必须是==递减==的。出现递增就不合法。例：1,2,3,4 入栈，序列 3,1,2,4 中，3 后面比 3 小的是 1,2，递增，不合法。
:::

顺序栈的栈顶指针有两种约定，答案完全不一样，一定要看清题目：

|约定|入栈|出栈|栈空|栈满|
|top 指向栈顶元素，初值 −1|`S[++top]=x`|`x=S[top--]`|`top==-1`|`top==MaxSize-1`|
|top 指向下一个空位，初值 0|`S[top++]=x`|`x=S[--top]`|`top==0`|`top==MaxSize`|

**共享栈**：两个栈共用一个数组，栈底分放两头，向中间长。栈满条件是 `top1+1==top2`。**链栈**：头插头删，表头当栈顶，所有操作 O(1)，没有上溢问题。

== 队列：两种判满 {queue}
FIFO（先进先出）。数组实现时，rear 一直走到末尾就「假溢出」了，解决方法是取模，也就是~~循环队列~~。

:::shu 循环队列（rear 指向队尾下一位）
队空：`front == rear`
队满：`(rear+1) % M == front`
长度：`(rear − front + M) % M`
入队：`rear = (rear+1) % M`；出队：`front = (front+1) % M`
区分满和空的另外两种方法：加 `size` 计数，或者加 `tag` 记录最后一次操作是入还是出。
:::

:::trap 约定一变，公式全变
上面讲的是「rear 指向队尾下一位」。如果改成「rear 指向队尾元素本身」，判空判满都要改。别背公式，==手动画 3 个格子走一遍==。
:::

**链式队列**：头指针删、尾指针插，判空是 `front==rear`（带头结点）。删除最后一个元素时要把 rear 也改回头结点，这是个常漏的小细节。

**双端队列**：两头都能进出。受限版本（一端输入受限 / 一端输出受限）要判断某序列能否得到，就模拟一遍。

:::vow 什么场景用什么结构
「缓冲」「依次」「先来先服务」→ 队列；「括号匹配」「函数调用」「递归」「回退」→ 栈。
:::

== 栈的应用：表达式求值 {expr}
人习惯写中缀 `a+b*c`，但计算机要看优先级和括号，很麻烦。后缀表达式 `abc*+` 不要括号，从左到右扫一遍就能算完，所以编译器要先做转换。

:::shu 中缀转后缀
从左到右扫描：
**操作数** → 直接输出。
**左括号** → 入栈。
**右括号** → 一直弹栈并输出，直到弹出左括号（括号都不输出）。
**运算符** → 把栈里==优先级高于或等于==它的运算符都弹出输出（遇到左括号停），再把自己压栈。
扫描完 → 栈内全部弹出。
:::

走一遍 `a+b*(c-d)/e`：

@ expr_steps('a+b*(c-d)/e')

:::shu 后缀表达式求值
从左到右扫：操作数入栈；遇到运算符弹出两个，==先弹出的是右操作数==，`次栈顶 op 栈顶`，结果压回。
:::

== 栈的应用：递归与函数调用 {recur}
**括号匹配**：左括号入栈，右括号弹栈比较，配不上或栈空就是错；扫描完栈不空也是错。

而**递归**的本质是系统帮你维护了一个栈（递归工作栈）：每进入一层函数，压入一个~~栈帧~~（参数、返回地址、局部变量）。所以递归深度就是空间。

:::trap 三句常见错话
「非递归改写必须用栈」错（尾递归可以直接写循环）。「确定了入栈次序就确定了出栈次序」错。「栈两端都能操作」错。
:::

:::deep 用两个栈模拟队列、用队列做树的层序
**两个栈模拟队列**：S1 负责入，S2 负责出。S2 空时把 S1 全倒过去，顺序就反转成了先进先出。
**队列的其他应用**：层序遍历（[[06]]）、BFS（[[09]]）、进程就绪队列（[[26]]）、打印缓冲。
:::

:::recall 判断出栈序列合法的方法？循环队列判满？中缀转后缀对运算符怎么处理？
x 后面比 x 小的要递减。`(rear+1)%M==front`。把栈里优先级高于或等于它的都弹出，再压入。
:::

:::domain
**栈：**判序列看「后面比它小的要递减」。
**循环队列：**空 `f==r`，满 `(r+1)%M==f`，改约定就手画。
**中缀转后缀：**高或等优先级先弹，括号不输出。
**后缀求值：**先弹的是右操作数。
:::
