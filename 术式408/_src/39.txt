== I/O 接口 {port}
接口就是设备和 CPU 之间的翻译官。

@ svg(600,140,box(10,50,100,44,'CPU','bk'),box(190,20,190,100,'','bx'),T(285,36,'I/O 接口',13,'',w=800),box(205,50,70,28,'数据','gd',12),box(285,50,80,28,'状态/命令','gd',12),box(240,86,90,26,'地址译码','bx',12),box(470,50,110,44,'设备','tn'),arrow(110,72,190,72),arrow(380,72,470,72),cap='数据缓冲、状态、命令三类寄存器（端口）。CPU 访问端口用 I/O 总线')

**I/O 接口**（I/O 控制器）的作用：地址译码选设备、缓冲数据匹配速度、转换信号格式、传递命令和状态。它有三类寄存器，都叫**端口**：

- **数据端口**：读写数据。
- **状态端口**：CPU 读，看设备忙不忙、有没有出错。
- **控制端口**：CPU 写，发命令。

CPU 通过 I/O 指令读写这些端口，数据一般在通用寄存器和端口之间传送。

:::shu 端口编址
**统一编址**：端口和内存共用地址，用访存指令（MOV）。指令丰富，但占地址。
**独立编址**：专门的 I/O 指令（IN/OUT），独立的地址空间。清晰，但指令少。
:::

== 三种方式 {ways}

 (flow([('CPU','bk'),('不断读状态\n问好了没','rd'),('设备','bx')],gap=26,size=12),'<b>程序查询</b>：CPU 一直问。实现简单，CPU 浪费最多。分为独占查询和定时查询。'),

 (flow([('CPU 设好参数\n（首地址、长度）','bk'),('DMA 控制器\n接管总线','gd'),('整块传完\n发一个中断','bk')],gap=20,size=12),'<b>DMA</b>：CPU 只管开始和结束，==整块传完才一个中断==。中间由 DMAC 直接在设备和主存之间传。')],'三种 I/O 方式')

:::shu CPU 占用率
**查询（定时）**：`占比 = 每秒查询次数 × 单次周期数 ÷ 主频`。
**中断**：每秒中断次数 = `传输率 ÷ 每次传的字节数`；`占比 = 每秒次数 × 每次开销周期 ÷ 主频`。
**DMA**：每秒中断次数 = `传输率 ÷ 块大小`；`占比` 同上。
:::

算一遍：主频 1 GHz，设备 2 MB/s，一次中断服务 100 个周期。

- **中断方式**，每次传 4 B：每秒 50 万次中断，50 万 × 100 = 5×10⁷ 周期，占 **5%**。
- **DMA 方式**，每块 4000 B，每次预处理和后处理共 500 周期：每秒 500 次，500 × 500 = 2.5×10⁵ 周期，占 **0.025%**。

如果给的是「服务程序 18 条指令，CPI=5」，一次开销就是 18×5 = 90 个周期，再加响应的周期。

**定时查询要多频繁**：设备每 5 ms 准备好一个数据，就至少每 5 ms 查一次，每秒 200 次，否则会丢数据。

:::recall 三种方式下 CPU 分别做什么？占用率公式的三个量？
查询：一直问。中断：每次传一个单位时被叫一次。DMA：只管开始和结束。每秒次数 × 每次周期 ÷ 主频。
:::

== 中断的细节 {detail}
中断响应的三件事由**中断隐指令**完成：关中断、保存断点、引出服务程序（[[23]] 已讲）。中断请求是在指令结束时查询的（==DMA 请求是存取周期结束时响应==）。

**单重中断**处理时不再响应其他中断，一直关中断到结束。**多重中断**：处理中可以被更高优先级打断，所以在保存现场、设屏蔽字之后要**开中断**。这也是屏蔽字存在的理由。

:::shu 响应优先级和处理优先级
**响应优先级**：同时请求时先理谁，硬件固定，改不了。
**处理优先级**：谁可以打断谁，由==屏蔽字==决定，OS 可改。
屏蔽字某位为 1 表示屏蔽那一级。屏蔽自己和处理优先级更低的；能打断我的（比我高的）写 0。
:::

走一遍：四级中断，要求处理优先级 L2 → L0 → L3 → L1。各级屏蔽字（M3 M2 M1 M0）：

|级别|能打断它的|屏蔽字|
|L2|无|1111|
|L0|L2|1011|
|L3|L2、L0|1010|
|L1|L2、L0、L3|0010|

:::rev 若 L3、L1 同时请求，CPU 正在执行 L0 的服务，会先响应谁？
L0 的屏蔽字 1011 只开放 L2，所以 L3、L1 都被屏蔽。等 L0 结束，再按响应优先级决定先响应谁。
:::

== DMA 细节 {dma}
:::shu DMA 三阶段
**预处理**（CPU）：设主存首地址、设备地址、字数、方向。
**传送**（DMAC）：申请总线、传输、修改地址和计数。
**后处理**（CPU）：中断处理，校验。
:::

**DMA 控制器的组成**：主存地址计数器（放下一个要传的地址）、传送长度计数器、数据缓冲寄存器、DMA 请求触发器、控制和状态逻辑。**长度计数器减到 0** 就发中断。

**DMA 传送一个字的过程**：设备准备好 → DMAC 申请总线 → CPU 让出总线 → DMAC 送地址、读写主存 → 地址加一、计数减一 → 放开总线。

:::shu DMA 与 CPU 抢总线
**CPU 停止访存**：DMA 期间 CPU 不访存。整块传完才放开。
**周期挪用（窃取）**：DMA 偷一个存取周期，==优先级高于 CPU==，因为设备数据不等人。
**交替访问**：CPU 和 DMA 轮流用，要求 CPU 周期足够长。
CPU 不访存时不受影响，还可以继续做内部运算。
:::

:::shu 设备分类（OS 口径）
**块设备**（磁盘，可寻址）、**字符设备**（键盘，不可寻址）。**网络设备**（套接字）。低、中、高速。
**控制方式演化**：程序查询 → 中断 → DMA → **通道**（一个专用处理器，执行通道程序，一次管多个块、多个设备）。
:::

:::recall 中断和 DMA 对比：传送单位、由谁传、何时响应、谁的优先级高。屏蔽字怎么写？
中断按字，CPU 传，指令结束时响应，优先级低；DMA 按块，DMAC 传，存取周期结束时响应，优先级高。能打断我的位写 0，其余写 1。
:::

:::domain
**编址：**统一用访存指令，独立用 IN/OUT。
**占用率：**次数 × 每次周期 / 主频。
**屏蔽字：**能打断我的那些位写 0。
**DMA：**块传送、存取周期结束响应、优先级高于 CPU。
:::
