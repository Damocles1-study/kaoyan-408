== I/O 接口 {port}
接口就是设备和 CPU 之间的翻译官。

:::shu 端口编址
**统一编址**：端口和内存共用地址，用访存指令（MOV）。指令丰富，但占地址。
**独立编址**：专门的 I/O 指令（IN/OUT），独立的地址空间。清晰，但指令少。
:::

:::shu 三种方式的 CPU 占用率（核心公式）
**查询（定时）**：`占比 = 每秒查询次数 × 单次周期数 / 主频`。
**中断**：每秒中断次数 = `传输率 / 每次传的字节数`；`占比 = 每秒次数 × 每次开销周期 / 主频`。
**DMA**：每秒中断次数 = `传输率 / 块大小`；`占比` 同上；再问是否抢总线。
:::

== 中断的细节 {detail}
**中断隐指令**完成：关中断、保存断点、引出服务程序（[[23]] 已讲）。中断请求是在指令结束时查询的（==DMA 请求是存取周期结束时响应==）。

:::shu 响应优先级和处理优先级
**响应优先级**：同时请求时先理谁，硬件固定。
**处理优先级**：谁可以打断谁，由==屏蔽字==决定，OS 可改。
屏蔽字 Mi=1 表示屏蔽第 i 级。各级的屏蔽字通常也屏蔽自己和优先级低的。
:::

下面这道是典型：响应优先级 L0→L4，要求处理优先级改成 L4→L0→L2→L1→L3。

:::rev L1 的屏蔽字（M4 M3 M2 M1 M0）怎么写？
处理 L1 时，只有 L4、L0、L2 能打断它（处理优先级比它高），所以这三位是 0，其余（L3、L1 自己）是 1。写成 M4 M3 M2 M1 M0 = `0 1 0 1 0`，即 **01010**。
:::

== DMA 细节 {dma}
:::shu DMA 三阶段
**预处理**（CPU）：设主存首地址、设备地址、字数、方向。
**传送**（DMAC）：申请总线、传输、修改地址和计数。
**后处理**（CPU）：中断处理，校验。
:::

:::shu DMA 与 CPU 抢总线
**CPU 停止访存**：DMA 期间 CPU 不访存。
**周期挪用（窃取）**：DMA 偷一个存取周期，==优先级高于 CPU==（设备数据不等人）。
**交替访问**：CPU 和 DMA 轮流用。
注意 CPU 不能「因 DMA 而做不了事」，只有访存受影响。
:::

:::shu 设备分类（OS 口径）
**块设备**（磁盘，可寻址）、**字符设备**（键盘，不可寻址）。**网络设备**（套接字）。低、中、高速。
**控制方式演化**：查询 → 中断 → DMA → 通道。
:::

:::domain
**编址：**统一用访存指令，独立用 IN/OUT。
**占用率：**次数 × 每次周期 / 主频。
**屏蔽字：**能打断我的那些位写 0。
**DMA：**块传送、存取周期结束响应、优先级高于 CPU。
:::
