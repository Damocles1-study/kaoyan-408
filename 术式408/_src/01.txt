:::say
复杂度是全书最送分的一节，每年稳定一道选择题。这一话的目标只有一个：==看到代码，10 秒写出语句频度的求和式==，别再靠「感觉」。
:::

== 先把几个词讲明白 {concept}
~~数据结构~~说的是三件事：**逻辑结构**（元素之间什么关系：线性、树、图、集合）、**存储结构**（在内存里怎么放：顺序、链式、索引、散列）、**运算**（能对它做什么）。

:::trap 逻辑结构和存储结构不能混
「有序表」是逻辑结构（只说顺序关系，和存储无关）；「循环队列」是存储结构（它规定了用数组加取模）。这个辨析每隔几年就会出一道选择题。判断方法：把「用什么存」这个信息去掉，这个词还有意义吗？有意义就是逻辑结构。
:::

~~算法~~要满足五个特性：有穷、确定、可行、输入、输出。好算法追求四件事：正确、可读、健壮、高效。注意 ==算法可以有零个输入，但至少要有一个输出==。

== 时间复杂度：只做一件事 {time}
找到执行次数最多的那条语句（基本操作），写出它的执行次数 `T(n)`，取最高阶项，扔掉系数。

:::shu 复杂度由小到大
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)
:::

三种循环，三种写法。这三种足够覆盖历年真题的所有题型。

=== ① 循环变量线性变化：直接求和
两层循环 `for(i=1;i<=n;i++) for(j=1;j<=i;j++) x++;`，内层执行 i 次，所以 `T(n) = 1+2+…+n = n(n+1)/2`，是 O(n²)。

=== ② 循环变量按倍数变化：设次数为 t
`for(i=1;i<=n;i*=2) x++;`。设循环跑了 t 次，第 t 次时 i = 2^{t}，由 2^{t} ≤ n 解出 t ≤ log₂n，所以是 O(log n)。

=== ③ 条件里藏着平方：把条件翻译成 t
`while(i*i<=n) i++;` 跑 t 次之后 i = t，由 t² ≤ n 解出 t ≤ √n，所以是 O(√n)。

:::shu 循环题万能三步
1. 设基本语句执行了 t 次。
2. 写出第 t 次时循环变量的值（用 t 表示）。
3. 代入循环条件，解出 t 和 n 的关系。
:::

:::rev 这段代码是多少？`for(i=1;i<=n;i*=2) for(j=1;j<=i;j++) x++;`
外层 i 取 1, 2, 4, …, 2^{k}（2^{k} ≤ n）。内层次数等于 i，所以总次数是等比数列求和：`1+2+4+…+2^k = 2^(k+1) − 1 ≈ 2n`。**答案 O(n)，不是 O(n log n)。**
这是一个经典坑：外层 log n 次、内层最多 n 次，直接相乘只是上界，不是紧界。内层次数随外层变化时，==必须老老实实求和==。
:::

@q ds:1.2-14 | 外层 k 每次 ×2，跑 log₂n 次；内层上限写死是 n，==和 k 无关==，所以这里才可以直接相乘，得 O(n log n)。和刚才那道「内层等于 i」的题对比着记。
@q ds:1.2-16 | 条件 `n>=(x+1)*(x+1)` 翻译过来就是 x+1 ≤ √n，属于第③种。

=== ④ 递归：写递推式
递归函数看两个东西：一共调用多少层，每层干多少活。

:::shu 递归的三个标准式
`T(n)=T(n−1)+O(1)` ⟹ O(n)（阶乘）
`T(n)=2T(n/2)+O(n)` ⟹ O(n log n)（归并、快排最好）
`T(n)=2T(n−1)+O(1)` ⟹ O(2ⁿ)（汉诺塔、未优化斐波那契）
:::

@q ds:1.2-13 | 每次递归只调用自己一次，n 层，每层 O(1)，所以 O(n)。

== 空间复杂度：算额外开的那部分 {space}
只算算法**额外**用到的内存，输入数据本身不算。常见只有三档：

- 几个临时变量：O(1)，叫~~原地~~算法。
- 开一个和输入等长的辅助数组：O(n)。
- 递归：==递归深度就是空间==。层数为 n 则 O(n)，层数为 log n 则 O(log n)。

:::trap 递归不是不占空间
递归调用的每一层都要压栈（[[20|第 20 话]]会看到栈帧真实的样子）。所以快排虽然没有开数组，空间却是 O(log n)，最坏 O(n)。选择题问「空间复杂度」时必想递归深度。
:::

== 最好、最坏、平均 {case}
同一算法在不同输入上差别可以很大。没有特殊说明时，`O()` 指==最坏情况==。平均复杂度要算期望，比如顺序查找平均比较 `(n+1)/2` 次，但阶还是 O(n)。

:::flash 选项里都是 O(n)、O(n²) 这种时
代入 n=4、n=8 手算次数，看 n 翻倍时次数翻几倍：翻 2 倍是 O(n)，翻 4 倍是 O(n²)，只多一点点是 O(log n)。比推公式还快，且不会被缩放系数骗。
:::

@q ds:1.2-15 | `sum += ++i`：第 t 轮时 sum = 1+2+…+t ≈ t²/2，代入 `sum<n` 得 t ≈ √(2n)，即 O(n^{1/2})。同样是第③种模子。

:::domain
**一句话：**设 t，写循环变量，代入条件。
**内外层相关时要求和，不能相乘。**
**递归：**时间看递推式，空间看深度。
:::
