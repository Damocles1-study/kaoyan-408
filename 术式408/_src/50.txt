== 两种模型 {model}
**C/S**：服务器长期在线，客户之间不直接通信。**P2P**：每个结点既是客户也是服务器，没有固定服务器；可扩展，上传能力随结点增长。

== DNS {dns}

人记域名，机器用 IP，DNS 负责转换。域名是层次的，从右往左越来越具体：`www.abc.com`。
@ tree('根(com(abc(www),xyz),cn(edu(tsinghua)),org)',binary=False,dx=64,r=22,cap='层次域名：根 → 顶级域 → 权威')

:::shu DNS 要点
**应用层，主要 UDP 53**（报文小，可用 TCP）。
**递归查询**：我问你，你帮我查到答案。**迭代查询**：你告诉我下一步问谁。
**主机 → 本地域名服务器**：通常递归。**本地 → 其他**：通常迭代。
**缓存**：可以大幅减少查询。
**最多查询次数**：根 → 顶级 → 权威；再多一级，多一次。
:::

**域名服务器的层次**：**根域名**服务器（知道顶级域在哪）→ 顶级域服务器 → **权威**服务器（知道具体主机）→ 本地域名服务器（帮你查）。

走一遍查 `www.abc.com`，本地无缓存，本地服务器迭代：

1. 主机向本地服务器递归查询（1 问）。
2. 本地问根，根说去问 com（1 问 1 答）。
3. 本地问 com，com 说去问 abc.com（1 问 1 答）。
4. 本地问 abc.com，得到 IP（1 问 1 答）。
5. 本地回答主机（1 答）。

共 8 个报文。如果是递归查询，主机到本地、本地到根、根到顶级、顶级到权威也都是一问一答，同样 8 个，但压力全在根上，所以根一般不递归。

:::flash 数报文
迭代、完全无缓存：本地问根、顶级、权威（可能多层）。每一次都是一问一答。
**2 个问/答 + n 次迭代 = 2(n+1)。** 有缓存时最少 0 次。
:::

== FTP {ftp}
:::shu FTP 关键
**两条 TCP 连接**：**控制连接**（21，全程保持）、**数据连接**（传一次建立一次，传完就关）。
**主动模式**：服务器用 20 端口连客户。**被动模式**：服务器随便开一个端口，客户去连。
带外控制，有状态。
:::

== 电子邮件 {mail}
@ flow([('发件人\n用户代理','bx'),('发件服务器','bk'),('收件服务器','bk'),('收件人\n用户代理','bx')],labels=['SMTP','SMTP','POP3/IMAP'],gap=60,cap='发信是推，收信是拉：推 推 拉')

:::shu 邮件协议
**SMTP**：TCP 25，推送，**只支持 7 位 ASCII**。所以有 **MIME** 把二进制编码成 ASCII（base64）。
**POP3**：TCP 110，下载后（通常）删除，无状态。
**IMAP**：TCP 143，在服务器上操作，有状态。
**HTTP** 也可以取邮件（网页邮箱）。
:::

**邮件格式**：信封（SMTP 用）、首部（From、To、Subject）、正文。收信为什么用另一种协议？SMTP 是推，而收件人不是一直在线，所以要主动拉。

== HTTP {http}

**URL**：`协议://主机:端口/路径`。一次访问：DNS 解析 → TCP 建连 → 发请求 → 收响应 → 渲染，页面里的图片再各取一次。
:::shu HTTP 特点
**TCP 80**；**无状态**（用 **Cookie** 补）。
**非持久连接（1.0）**：每个对象一个 TCP。**持久连接（1.1）**：一个 TCP 多个对象；分**非流水线**、**流水线**。
**方法**：**GET**（取，参数在 URL）、POST（提交）、HEAD（只要首部）、PUT、DELETE。
**状态码**：200 OK，301 永久移动，304 未修改，404，500。
**Web 缓存（代理）**：把常用对象存在近处，减少访问。用 `If-Modified-Since` 问是否变化。
:::

:::shu RTT 账本（n 个对象 + 1 个 HTML）
|方式|RTT|
|非持续、串行|**2(n+1)**|
|非持续、无限并行|**4**|
|非持续、m 条并行|**2 + 2⌈n/m⌉**|
|持续、非流水线|**n + 2**|
|持续、流水线|**3**|
一个 RTT 建连，一个 RTT 拿 HTML。不算发送时延。
:::

算一遍：HTML 加 5 张图，n=5。非持久串行 12；非持久无限并行 4；2 条并行 2+2×3 = 8；持久非流水线 7；持久流水线 3。

为什么是这些数：TCP 建连要 1 个 RTT，取一个对象要 1 个 RTT。非持久每个对象都要付这两个 RTT；持久只付一次建连。第一个 HTML 总要单独取，因为要读了它才知道有几张图。

:::trap 起点差一词差 1 RTT
「从开始建立连接」和「从连接已建立开始」差 1 个 RTT。**给了 MSS 和文件大小时，上面的公式全部作废**，要按 cwnd 逐轮画。这里默认一次取一个对象。
:::

:::recall DNS 迭代 8 个报文是哪些？FTP 两条连接？邮件推推拉？n 对象的五个 RTT？
主机问本地 1 问 1 答，本地问根、顶级、权威各一问一答。控制 21，数据 20。SMTP 推两段，POP3 或 IMAP 拉一段。2(n+1)、4、2+2⌈n/m⌉、n+2、3。
:::

:::domain
**DNS：**UDP 53；递归 / 迭代；无缓存 2(n+1) 报文。
**FTP：**两连接，21 控制，20 数据。
**邮件：**SMTP 推推，POP3 拉；7 位 ASCII + MIME。
**HTTP：**非持续 2(n+1)，持续 n+2，流水线 3。
:::
