== 简单选择排序 {sel}
每趟选出最小的放到前面。不管数据如何，比较次数都是 `n(n−1)/2`，时间 O(n²)，**不稳定**（交换会跨过相同元素）。交换次数不超过 n−1，所以移动少。

== 堆 {heap}
堆是一棵存在数组里的完全二叉树。大根堆：父 ≥ 子。

@ heap_steps([53,17,78,9,45,65,87,32])

:::code c 模板：堆的下沉（下标从 1 开始）
void HeadAdjust(int A[], int k, int len) {
    A[0] = A[k];
    for (int i = 2 * k; i <= len; i *= 2) {
        if (i < len && A[i] < A[i + 1]) i++;   // 取较大的孩子
        if (A[0] >= A[i]) break;
        A[k] = A[i];
        k = i;
    }
    A[k] = A[0];
}
void HeapSort(int A[], int len) {
    for (int i = len / 2; i > 0; i--) HeadAdjust(A, i, len);   // 建堆
    for (int i = len; i > 1; i--) {
        int t = A[1]; A[1] = A[i]; A[i] = t;                   // 堆顶换到末尾
        HeadAdjust(A, 1, i - 1);
    }
}
:::

:::shu 堆的几个结论
**建堆**：从 ⌊n/2⌋ 向前下沉，时间 **O(n)**（书上界 4n，比较次数实际约 1.88n）。
**下沉**：比较两个孩子 1 次，较大孩子和父亲 1 次，所以每层最多 **2 次比较**。
**插入**：放到末尾向上调，每层 **1 次比较**。
**删除**：末尾补到堆顶，向下调。
**堆排序**：最好最坏都是 O(n log n)，O(1) 空间，不稳定。
**应用**：取前 k 大（维护大小为 k 的小根堆）；优先队列。
:::

:::trap 插入比较和下沉比较次数不同
上滤一层比 1 次（和父亲比）；下滤一层比 2 次（先比两个孩子）。这是几道真题的全部考点。依次插入建堆 ≠ 整体建堆，结果常常不一样。
:::

== 归并排序 {merge}
@ merge_steps([49,38,65,97,76,13,27])

:::code c 模板：归并
void Merge(int A[], int low, int mid, int high) {
    int i = low, j = mid + 1, k = low;
    for (int t = low; t <= high; t++) B[t] = A[t];     // B 是辅助数组
    while (i <= mid && j <= high)
        A[k++] = (B[i] <= B[j]) ? B[i++] : B[j++];     // <= 保证稳定
    while (i <= mid) A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
}
void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}
:::

:::shu 归并
时间永远 **O(n log n)**，空间 **O(n)**，**稳定**。趟数 ⌈log₂n⌉。m 路归并趟数 ⌈log_m n⌉。
两个长 m、n 的有序表合并：最少比较 min(m,n) 次，最多 m+n−1 次。
:::

== 基数排序 {radix}
不比较，按位分配、收集。从最低位开始。

@ radix_steps(['110','119','007','911','114','120','122'])

:::shu 基数排序
d 位、r 进制：时间 **O(d(n+r))**，空间 **O(r)**，**稳定**。
用的是链式队列，每趟 r 个队列。
移动次数与初始序列无关。
:::

== 外部排序 {ext}
数据放不下内存，就要分段读、归并。总时间几乎全部耗在 ==磁盘 I/O== 上，所以优化目标是减少归并趟数。

@ flow([('初始段\n（内排生成）','bx'),('归并','bk'),('归并','bk'),('一个有序文件','gd')],gap=30,cap='外部排序的两步：生成初始归并段，然后多路归并')

:::shu 外排四个工具
**① 归并趟数** `S = ⌈log_k r⌉`（k 路、r 个初始段）。k 越大或 r 越小，趟数越少。
**② 败者树**：k 路归并时选最小值的比较从 k−1 次降为 ⌈log₂k⌉ 次，使总比较次数和 k 无关。
**③ 置换-选择排序**：内存区 w 时生成更长的初始段（平均 2w），减小 r。
**④ 最佳归并树**：段长不等时，归并顺序按哈夫曼树（WPL 就是 I/O 次数）。严格 k 叉，要补虚段：若 `(r−1) % (k−1) = u ≠ 0`，补 `k−1−u` 个长度 0 的虚段。
:::

:::link 最佳归并树 = 哈夫曼树
[[07#huff|第 07 话]] 那道 6 个有序表的大题就是它。这个道理就是：先合并的部分被多读写几次，所以把小的放在最下面。
:::

:::trap 趟数公式和图不一样
败者树减少的是每次选最小的比较次数，==不会减少归并趟数==；k 变大 I/O 趟数减少，但内存要给 k+1 个缓冲区。两者不要混。
:::

== 总表 {all}
:::shu 排序总表（默写）
|算法|最好|平均|最坏|空间|稳定|每趟就位|
|直接插入|n|n²|n²|1|✓|✗|
|折半插入|n log n 比较|n²|n²|1|✓|✗|
|希尔|—|n^1.3|n²|1|✗|✗|
|冒泡|n|n²|n²|1|✓|✓|
|快排|n log n|n log n|n²|log n|✗|✓|
|简单选择|n²|n²|n²|1|✗|✓|
|堆排|n log n|n log n|n log n|1|✗|✓|
|归并|n log n|n log n|n log n|n|✓|✗|
|基数|d(n+r)|d(n+r)|d(n+r)|r|✓|✗|
:::

:::flash 口诀
**不稳定四兄弟：**快（快排）些（希尔）选（简单选择）堆（堆排）。
**与初始序列无关：**简单选择、堆、归并、基数——「选一堆龟（归）基」。
**每趟至少一个到最终位置：**冒泡、选择、快排、堆。
**数组变链表反而变慢：**希尔、堆（都依赖下标随机存取）。
:::

:::shu 怎么选排序
n 小：直接插入或简单选择。基本有序：直接插入或冒泡。n 大：快排、堆、归并。要稳定且 n 大：归并。关键字位数少、n 大：基数。内存放不下：外排。
:::
