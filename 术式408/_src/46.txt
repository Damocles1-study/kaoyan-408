:::say
IP 搞定了，其他协议都是在帮 IP 干活。这一话多是选择题，要记住==每个协议封装在谁里面、干什么==。
:::

== ARP {arp}
:::ana 喊一嗓子
我知道你的 IP，但发帧要 MAC。在局域网里喊一声（广播）：「谁是 x.x.x.x？」对方单独回（单播）。
:::

:::shu ARP
**作用**：同一网段内，IP → MAC。
**请求广播，响应单播**。有缓存。
跨网段时：解析的是==默认网关的 MAC==。
:::

== DHCP {dhcp}
:::shu DHCP 四步（应用层，基于 UDP）
**① Discover**（广播，源 0.0.0.0）
**② Offer**（服务器提供）
**③ Request**（广播，告诉所有服务器我选谁）
**④ ACK**
给 IP、掩码、网关、DNS。
:::

== ICMP {icmp}
**ICMP 封装在 IP 中**。两类：**差错报告**（目的不可达、时间超过、参数问题、改变路由）和**询问**（回送 ping、时间戳）。

:::shu 两个应用
**ping**：回送请求和回答。
**traceroute**：依次发 TTL=1,2,… 的分组，收「时间超过」确定路径。
:::

== NAT {nat}
@ table([['方向','内网 → 外网','外网 → 内网'],['源','私有 IP:端口 改成 公网 IP:新端口','—'],['目的','—','公网 IP:端口 查表改回 私有 IP:端口']])

:::shu NAT 要点
既看 IP 也看端口，所以路由器==工作到了传输层==。解决 IPv4 不够用。外部不能主动访问内网（除非端口映射）。
:::

== IPv6 {v6}
:::shu IPv6 主要特点
**128 位**地址。首部固定 **40 B**（+扩展首部）。去掉首部校验和；==路由器不分片==（只有源主机分，路由器发 ICMP「分组太大」）。
**地址表示**：8 组 16 位十六进制，连续 0 可用 `::`（一次）。
**单播、组播、任播**（没有广播）。
**过渡**：双栈、隧道。
:::

== IP 组播 {mc}
:::shu 组播
**D 类地址**：224.0.0.0 ~ 239.255.255.255，只能做目的。
**IP→MAC**：低 23 位映射到 `01-00-5E-...`（所以 32 个 IP 对一个 MAC）。
**IGMP**：主机和本地路由器，只在本地。
**组播路由**：建树。
:::

== 移动 IP {mobile}
:::shu 三个实体
**移动节点、归属代理、外地代理**。
**永久地址（归属地址）+ 转交地址**。
**过程**：节点注册转交地址 → 通信方发到永久地址 → 归属代理截获并==隧道==转发 → 外地代理解封 → 给移动节点。回程可以直接发。
:::

== 网络层功能 {func}
:::shu 路由 vs 转发
**路由**：全局，生成路由表（路由算法）。**转发**：本地，查表送出端口。
**路由表 ≠ 转发表**。
:::

:::shu SDN（软件定义网络）
**控制平面和数据平面分离**：控制器集中算路由，通过**南向接口**下发流表，交换机只转发。**北向接口**向应用开放。
:::

:::shu 拥塞控制 vs 流量控制
**拥塞**：全局，网络负载过高。**流量控制**：端到端，接收方跟不上。网络层丢弃分组、路由队列都和拥塞有关。
:::

**数据报 vs 虚电路**：数据报无连接，分组独立选路，可能乱序；虚电路先建连接（但不等于可靠），按序。

== 路由器 {router}
:::shu 路由器结构
**路由选择部分**：运行路由协议。**分组转发部分**：输入端口、交换结构、输出端口。
输入和输出端口都可能排队，输出排队严重时丢弃（拥塞）。
**实现到第 3 层**。
:::

:::domain
**ARP：**IP→MAC，请求广播响应单播。
**DHCP：**发现、提供、请求、确认，UDP。
**ICMP：**IP 承载；ping 与 traceroute。
**IPv6：**128 位，40 B，路由器不分片。
**移动 IP：**隧道。
:::
