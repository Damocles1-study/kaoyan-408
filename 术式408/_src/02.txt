== 顺序表：先记住它的特点 {seq}
顺序表就是**数组**，逻辑上相邻的元素物理上也相邻。第 i 个元素的地址是 `LOC(aᵢ) = LOC(a₁) + (i−1)·sizeof(T)`，所以能==随机存取==，这是它最大的本事；代价是插入删除要挪元素。

@ cells(['a₁','a₂','a₃','a₄','a₅','',''],hl={2:'gd'},ptr={2:'删除 i=3'},idx=[0,1,2,3,4,5,6],cap='删除第 3 个：a₄、a₅ 都要往前挪一格。下标从 0 开始，位序从 1 开始，这是最容易写错的地方')

:::shu 顺序表三个平均移动次数
插入：平均移动 **n/2** 个（有 n+1 个位置可插）
删除：平均移动 **(n−1)/2** 个（有 n 个可删）
查找：平均比较 **(n+1)/2** 次（成功时）
:::

:::code c 顺序表的结构与插入删除（基本功，要能默写）
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

// 在位序 i（从 1 开始）插入 e
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1) return false;   // 判位置
    if (L.length >= MaxSize) return false;         // 判满
    for (int j = L.length; j >= i; j--)            // 从后往前挪，否则会覆盖
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;
    L.length++;
    return true;
}

// 删除位序 i，用 e 带回
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++)             // 从前往后挪
        L.data[j - 1] = L.data[j];
    L.length--;
    return true;
}
:::

:::trap 挪动方向
**插入从后往前挪，删除从前往后挪。** 反过来会把数据覆盖掉。C 语言里 `&L` 引用是 C++ 语法，考试允许用。
:::

== 四个原地技巧 {tricks}
数组上的算法大多是下面四招的组合。

=== 招式一：逆置
数组整体逆置，只需要首尾交换，走到中点停。

:::code c 模板：逆置 [left, right] 这一段
void Reverse(int a[], int left, int right) {
    while (left < right) {
        int t = a[left]; a[left] = a[right]; a[right] = t;
        left++; right--;
    }
}
:::

**循环左移 p 位**只用三次逆置。把序列看成两段 `XY`，要变成 `YX`：

=== 招式二：双指针（快慢指针）
一个读指针 `i` 扫全部元素，一个写指针 `k` 指向下一个要写入的位置。删除所有值为 x 的元素：

:::code c 模板：原地过滤（快慢指针）
void DelX(SqList &L, int x) {
    int k = 0;                        // 写指针：k 之前都是要保留的
    for (int i = 0; i < L.length; i++)
        if (L.data[i] != x)
            L.data[k++] = L.data[i];
    L.length = k;
}
:::

=== 招式三：有序合并（归并思想）
两个有序表，每次取两者中较小的那个。如果只需要第 k 小，不必真的合并，走到第 k 步就停。归并的思想在 [[15|第 15 话]] 的归并排序、外部排序还会用到。

:::code c 模板：合并两个有序表
bool Merge(SqList A, SqList B, SqList &C) {
    if (A.length + B.length > MaxSize) return false;
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length)
        C.data[k++] = (A.data[i] <= B.data[j]) ? A.data[i++] : B.data[j++];
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];
    C.length = k;
    return true;
}
:::

**推广：多个有序数组同时走**。每个数组一个指针，每次只推进当前值最小的那个指针，因为其他指针往后只会更远。总时间 O(总长度)。这个套路在求「几个有序数组各取一个，差距最小」这类问题时直接可用。

=== 招式四：用下标当哈希（空间换时间）
元素值落在有限范围（比如 1 到 n）时，开一个标记数组 `count[]`，把值当下标。遇到「找缺失的数」「找重复的数」「绝对值去重」，第一反应就是它。

:::code c 模板：标记数组（找未出现的最小正整数）
int FindMissMin(int A[], int n) {
    // 答案一定落在 1..n+1，因为 n 个数最多把 1..n 占满
    int *B = (int *)malloc(sizeof(int) * n);
    memset(B, 0, sizeof(int) * n);
    for (int i = 0; i < n; i++)
        if (A[i] > 0 && A[i] <= n)    // 超出范围的不影响答案
            B[A[i] - 1] = 1;
    int i;
    for (i = 0; i < n; i++)
        if (B[i] == 0) break;
    free(B);
    return i + 1;
}
:::

=== 主元素：相互抵消
一个元素出现次数超过一半，叫主元素。不用开数组：让不同的元素两两抵消，主元素一定会剩下。扫描时记候选 c 和计数 cnt，相同加一，不同减一，减到 0 就换候选。最后再扫一遍确认。

:::code c 模板：投票法找主元素
int Majority(int A[], int n) {
    int c = A[0], cnt = 1;
    for (int i = 1; i < n; i++) {
        if (A[i] == c) cnt++;
        else if (cnt > 0) cnt--;
        else { c = A[i]; cnt = 1; }
    }
    cnt = 0;                         // 第二趟：确认
    for (int i = 0; i < n; i++)
        if (A[i] == c) cnt++;
    return cnt > n / 2 ? c : -1;
}
:::

== 写算法题的三块 {how}
写算法题，交的不只是代码。三块都要有：

|部分|写什么|
|基本设计思想|用文字讲明白你要怎么做|
|算法描述（C/C++）|代码，关键处写注释|
|时空复杂度|写明时间和空间|

:::vow 写法三条
1. **暴力解也有分。** 想不到最优就写暴力，不要空着。
2. **思路必须单独写。** 只写代码，思路那部分分就没了。
3. **语法小错不要紧。** 少个分号没事，别在语法上纠结。
:::

:::flash 判断方向
要时间尽可能高效 → 往往是用空间换时间（开标记数组）。要 O(1) 空间 → 双指针、逆置、排序后扫描。
:::

:::recall 默写这四个模板：逆置、过滤、合并、标记数组。三次逆置为什么能循环移位？
(X⁻¹Y⁻¹)⁻¹ = YX。
:::

:::domain
**写法：**思路 → 代码 → 复杂度，三块都要写。
**四招：**逆置 · 快慢指针 · 有序合并 · 下标当哈希。
**判方向：**要时间快就开标记数组，要 O(1) 空间就双指针或逆置。
:::
