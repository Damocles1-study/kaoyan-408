这一话讲指令在 CPU 内部怎么走。别背图，记住==每一步其实就是把数据从一个寄存器送到另一个寄存器==，这张图你就能自己画出来。

== CPU 的组成 {parts}
CPU = ~~运算器~~（ALU、通用寄存器、PSW、暂存器）+ ~~控制器~~（PC、IR、指令译码器、时序、微操作发生器）。

:::shu 位数题的两个公式
**PC** 位数 = 主存**地址**位数。指令按字对齐时，低位恒 0，至少可少 log₂(字节数)。
**MAR** = 地址位数；**MDR** = 存储字长；**IR** = 指令字长。
:::

== 指令周期 {cycle}
一条指令 = 取指 → 间址（可选）→ 执行 → 中断检测（可选）。

@ flow([('取指周期\nFE=1','gd'),('间址周期\nIND=1',),('执行周期\nEX=1','bk'),('中断周期\nINT=1',)],gap=34,cap='四个周期靠触发器区分；取指周期结束时判断是否间址，执行结束时判断是否有中断')

:::shu 四个周期的微操作（默写）
**取指**：`PC→MAR`；`MEM→MDR`；`MDR→IR`；`PC+1→PC`（读命令由 CU 发）。
**间址**：`Ad(IR)→MAR`；`MEM→MDR`；`MDR→Ad(IR)`。
**执行**：看指令。
**中断**：`SP−1→SP, SP→MAR`；`PC→MDR` 写入内存；向量地址 `→PC`。
:::

== 数据通路 {path}
数据通路是指令执行时数据走的路。单总线：所有部件接一条内部总线，一次只能走一个数，==这就是为什么要暂存器==。

@ svg(600,230,'<line x1="30" y1="110" x2="580" y2="110" class="ln" style="stroke-width:6"/>',T(555,95,'内部总线',12,'mt'),box(40,20,60,34,'PC','gd'),box(120,20,60,34,'MAR'),box(200,20,60,34,'MDR'),box(280,20,60,34,'IR','bk'),box(40,160,70,34,'R0~Rn'),box(170,160,50,34,'Y','bu'),box(240,145,80,50,'ALU','rd'),box(350,160,50,34,'Z','bu'),box(450,20,110,34,'主存 MEM','tn'),*[f'<line x1="{x}" y1="54" x2="{x}" y2="110" class="ln"/>' for x in (70,150,230,310)],'<line x1="75" y1="110" x2="75" y2="160" class="ln"/>','<line x1="195" y1="110" x2="195" y2="160" class="ln"/>',arrow(220,177,240,177),arrow(320,177,350,177),'<line x1="375" y1="110" x2="375" y2="160" class="ln"/>',arrow(280,110,280,145),arrow(450,37,340,37,'ln'),cap='单总线数据通路：Y 暂存一个操作数，Z 暂存 ALU 结果，否则同一条总线不能同时走两个数')

:::shu 单总线 add R1,R2 的微操作
`R1→Y`（第一个操作数放暂存）
`R2→bus，ALU 做加法，→Z`
`Z→R1`
每行占一个时钟周期（一次只能走一个）。这就是为什么单总线慢；三总线、专用通路可以同周期完成。
:::

:::trap 内总线一个周期只能有一个源
答「能否同时」的题，就看是不是同一条总线。比如 `PC+1→PC` 单总线也要经过 Z，走不同的周期。
:::

**单周期 / 多周期**：单周期所有指令 CPI=1，时钟按最慢的指令；不能共用部件同一周期做两件事。**多周期**分几个周期。

== 控制器 {ctrl}
指令 → 微操作的翻译器。两种实现：

:::ana 硬布线和微程序
**硬布线**：背下来的条件反射，快但改不了。**微程序**：查手册。把每条指令拆成一串微指令，存在控制存储器 CS 里。慢一点，改手册就行。
:::

@ table([['','硬布线','微程序'],['实现','组合逻辑电路','CS（ROM）中存微指令'],['速度','快','慢（要读 CS）'],['扩展','难','容易'],['适用','RISC','CISC']])

:::shu 微程序名词
**微操作**：最小控制动作（一个信号）。**微指令**：一个周期内发出的一组微命令。**微程序**：一条机器指令对应的微指令序列。
**控存 CS** 用 ROM，存在 CPU 内部；按地址访问。
**CMAR/CMDR**：微地址和微指令寄存器。
:::

:::shu 微指令编码（2012、2014 真题）
**直接编码**：一位对应一个命令，最长最快。
**字段直接编码**：互斥的命令放一个字段。一个字段 m 个命令需要 `⌈log₂(m+1)⌉` 位（==+1 是留一个「什么都不做」==）。
**下地址字段**：位数 = ⌈log₂ 微指令总数⌉。
:::

:::domain
**指令周期：**取指 → 间址 → 执行 → 中断。
**取指微操作：**PC→MAR，MEM→MDR，MDR→IR，PC+1→PC。
**单总线：**一次一个，所以要 Y、Z。
**控制：**硬布线快，微程序易改；字段位数 ⌈log₂(m+1)⌉。
:::
