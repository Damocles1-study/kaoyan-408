== x86 速读 {x86}
这里用 Intel 风格：`mov dest, src`，目的在前。32 位 x86 的寄存器：`eax`（累加，存返回值）、`ebx`、`ecx`（计数）、`edx`、`esp`（栈顶）、`ebp`（当前栈帧底）、`esi`、`edi`。

|指令|含义|
|`mov a, b`|a ← b|
|`mov eax, [ebp+8]`|从内存取：eax ← M[ebp+8]|
|`lea eax, [ebx+ecx*4]`|取地址不访存：eax ← ebx+ecx×4，也常用来做乘加|
|`add/sub/imul/shl/sar`|加/减/乘/左移/算术右移|
|`cmp a, b` `test a, a`|只改标志位不存结果|
|`jmp L`|无条件转移|
|`je jne`|等于/不等于|
|`jg jge jl jle`|有符号比较|
|`ja jae jb jbe`|无符号比较|
|`push x` `pop x`|`esp-=4; M[esp]=x` / `x=M[esp]; esp+=4`|
|`call f`|压入返回地址，跳到 f|
|`ret`|弹出返回地址到 EIP|
|`leave`|`mov esp,ebp; pop ebp`|

:::vow 读汇编的三个习惯
1. `[ ]` 才是访存；`lea` 里的 `[ ]` 不访存。
2. `[ebp+8]` 是第一个参数，`[ebp−4]` 是第一个局部变量。
3. 看到 `cmp`，下一条就是条件转移。两条连起来读。
:::

**条件码**就是[[17|第 17 话]]的标志位。`cmp a,b` 做 a−b，只更新 ZF、SF、OF、CF，不存结果。`jg` 判断的是 `ZF=0 且 SF=OF`，`ja` 判断的是 `CF=0 且 ZF=0`。同样的二进制，看有符号还是无符号，由后面的转移指令决定。

== 选择与循环 {ctrl}
机器没有 if 和 for，只有比较和跳转。

:::code asm if (a>b) x=a; else x=b;
    mov eax, [ebp+8]     ; a
    cmp eax, [ebp+12]    ; a − b
    jle ELSE             ; 条件取反后跳转
    mov [ebp-4], eax     ; x = a
    jmp END
ELSE:
    mov eax, [ebp+12]
    mov [ebp-4], eax     ; x = b
END:
:::

:::trap 条件是反着写的
C 写 `if(a>b)`，汇编跳走的条件是 `a<=b`：条件不成立才跳走，成立就顺序往下做。读的时候翻译成「否则才走 ELSE」。
:::

:::code asm for (i=0;i<n;i++) sum+=a[i];
    mov ecx, 0              ; i = 0
L1: cmp ecx, [ebp+12]       ; i − n
    jge L2                  ; i>=n 跳出
    mov edx, [ebp+8]        ; 取数组首地址 a
    mov eax, [edx+ecx*4]    ; 变址寻址 a[i]，每元素 4 字节
    add [ebp-4], eax        ; sum += a[i]
    add ecx, 1
    jmp L1
L2:
:::

循环有三个特征：开头有比较和向外的跳转，中间有变址，末尾有向回的 `jmp`。向回跳的转移是后面[[22|控制冒险]]和分支预测的主要对象，也是时间局部性的来源。

== 函数调用：栈帧 {frame}
函数调用要解决四件事：参数怎么传、怎么回来、局部变量放哪、调用前的寄存器怎么还原。全部靠栈，这正是 [[04#recur|第 04 话]]说的递归工作栈的真实形状。

一个完整的小函数：

:::code asm int add(int x, int y) { int s = x + y; return s; }
add:
    push ebp             ; 保存调用者的帧
    mov  ebp, esp        ; 建立本帧
    sub  esp, 16         ; 开局部变量空间
    mov  edx, [ebp+8]    ; x
    mov  eax, [ebp+12]   ; y
    add  eax, edx
    mov  [ebp-4], eax    ; s = x + y
    mov  eax, [ebp-4]    ; 返回值放 eax
    leave                ; esp=ebp，弹出旧 ebp
    ret                  ; 弹出返回地址
:::

为什么是 `[ebp+8]`？ebp 指向的是旧 ebp，往上 4 字节是返回地址，再往上才是第一个参数。

**寄存器谁来保存**：函数都要用寄存器，被调函数改了怎么办？约定如下。**调用者保存**：`eax`、`ecx`、`edx`，调用前如果还要用，自己先压栈。**被调用者保存**：`ebx`、`esi`、`edi`，被调函数要用就先压栈，返回前恢复。

:::shu 函数调用五句话
**① 参数**从右向左压栈；第一个参数离 ebp 最近，`[ebp+8]`。
**② call** 压返回地址；**ret** 弹返回地址。
**③ 函数开头**：`push ebp; mov ebp, esp`。
**④ 返回值**放 eax。
**⑤ 递归调用 n 层，就有 n 个栈帧**；栈溢出就是这里用完了。
:::

:::recall 画出栈帧，标出第一个参数、返回地址、旧 ebp、第一个局部变量的位置。
从高到低：参数 [ebp+8]、返回地址 [ebp+4]、旧 ebp [ebp]、局部变量 [ebp−4]。
:::

=== 从机器码读地址
`call` 常用相对寻址：机器码里存的偏移 = 目标地址 − **下一条**指令地址。比如 `call` 在 00401020H，长 5 字节，目标 00401000H：偏移 = 00401000H − 00401025H = FFFFFFDBH（−37）。按小端写进机器码就是 `E8 DB FF FF FF`。

一段函数的长度 = 最后一条指令的地址 + 该指令长度 − 第一条地址。

== CISC 与 RISC {risc}
CISC 的思路是硬件多做事，一条指令干很多，代码短。后来发现常用的只是一小部分（80% 的时间在跑 20% 的指令），于是 RISC 把指令精简，把常用的做快。

:::domain
**读：**`[]`才访存，cmp 连条件转移读，C 条件反写。
**栈帧：**[ebp+8] 是参数，[ebp−4] 是局部变量；返回值 eax。
**链接：**符号解析 + 重定位。
**RISC：**定长、Load/Store、硬布线、适合流水线。
:::
