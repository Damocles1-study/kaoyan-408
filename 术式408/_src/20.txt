== x86 速读 {x86}
真题用的是 Intel 风格：`mov dest, src`（目的在前）。主要寄存器：`eax`（累加/返回值）、`ebx`、`ecx`（计数）、`edx`、`esp`（栈顶）、`ebp`（栈帧底）、`esi`、`edi`。

|指令|含义|
|`mov a, b`|a ← b|
|`mov eax, [ebp+8]`|从内存取：eax ← M[ebp+8]|
|`lea eax, [ebx+ecx*4]`|取地址不访存：eax ← ebx+ecx×4，也常用来做乘加|
|`add/sub/imul/shl/sar`|加/减/乘/左移/算术右移|
|`cmp a, b` `test a, a`|只改标志位不存结果|
|`jmp L`|无条件转移|
|`je jne`|等于/不等于|
|`jg jge jl jle`|有符号比较|
|`ja jae jb jbe`|无符号比较|
|`push x` `pop x`|`esp-=4; M[esp]=x` / `x=M[esp]; esp+=4`|
|`call f`|压入返回地址，跳到 f|
|`ret`|弹出返回地址到 PC（EIP）|
|`leave`|`mov esp,ebp; pop ebp`|

:::vow 读汇编的三个习惯
1. `[ ]` 才是访存；`lea` 里的 `[ ]` 不访存。
2. `[ebp+8]` 是第一个参数，`[ebp−4]` 是第一个局部变量。
3. 看到 `cmp`，下一条就是条件转移。两条连起来读。
:::

== 选择与循环 {ctrl}
:::code asm if (a>b) x=a; else x=b;
    mov eax, [ebp+8]     ; a
    cmp eax, [ebp+12]    ; a − b
    jle ELSE             ; 条件取反后跳转
    mov [ebp-4], eax     ; x = a
    jmp END
ELSE:
    mov eax, [ebp+12]
    mov [ebp-4], eax     ; x = b
END:
:::

:::trap 条件是反着写的
C 写 `if(a>b)`，汇编跳走的条件是 `a<=b`。绝大多数编译器这样写。看到 `jle`，翻译回来是「否则才执行下面」。
:::

:::code asm for (i=0;i<n;i++) sum+=a[i];
    mov ecx, 0              ; i = 0
L1: cmp ecx, [ebp+12]       ; i − n
    jge L2                  ; i>=n 跳出
    mov edx, [ebp+8]        ; 取数组首地址 a
    mov eax, [edx+ecx*4]    ; 变址寻址 a[i]，每元素 4 字节
    add [ebp-4], eax        ; sum += a[i]
    add ecx, 1
    jmp L1
L2:
:::

可以看到循环必有一个向回跳的转移，这正是 [[22|控制冒险]]、分支预测以及 Cache 的时间局部性的来源。

:::shu 函数调用五句话
**① 参数**从右向左压栈；第一个参数离 ebp 最近，`[ebp+8]`。
**② call** 压返回地址；**ret** 弹返回地址。
**③ 函数开头**：`push ebp; mov ebp, esp`。
**④ 返回值**放 eax。
**⑤ 递归调用 n 层，就有 n 个栈帧**；栈溢出就是这里用完了。
:::

== 从源程序到可执行文件 {link}
:::shu 三个工具各自干什么
**编译器**：C → 汇编（.s）。
**汇编器**：汇编 → 可重定位目标文件（.o），每个模块地址从 0 开始。
**链接器**：两个任务，① ~~符号解析~~（把引用和定义对应），② ~~重定位~~（合并各段，把相对地址改成运行时地址）。
**静态链接**：库代码直接进文件；**动态链接**：运行时才链接，节省内存、方便升级。
:::
