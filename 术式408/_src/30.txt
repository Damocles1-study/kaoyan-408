这一卷只回答一个问题：==快的存储小而贵，慢的存储大而便宜，怎么让机器看起来又快又大==。答案是分层加局部性。这一话先把最底下的硬件讲清楚：一块内存到底长什么样，怎么接到 CPU 上。

== 为什么要分层 {level}
CPU 执行一条指令是纳秒级，主存读一次要几十纳秒，磁盘读一次要几毫秒，差距是几十倍到百万倍。如果 CPU 每次都直接等主存，它一大半时间都在空转。全用最快的器件又贵到装不起。

出路是把少量快存储放在 CPU 旁边，把常用的东西放进去，不常用的放远处。这能成立，靠的是程序的一个规律。

:::shu 程序的局部性
**时间局部性**：刚访问过的，很快还会再访问（循环变量、循环里的指令）。
**空间局部性**：访问了某地址，很快会访问它附近（数组、顺序执行的指令）。
:::

@ pyramid([('寄存器','bk'),('Cache（SRAM）','gd'),('主存（DRAM）',),('SSD / 磁盘',),('磁带 / 网络存储','tn')],cap='从上到下：更慢、更大、每比特更便宜')

相邻两层之间，上层放的是下层的一部分副本。其中两对最要紧：

- **Cache—主存**：解决速度。全由硬件管，程序员看不见。
- **主存—辅存**：解决容量。硬件和操作系统一起管，这就是虚拟内存。

:::link 跨科第一枢纽
**局部性原理** → [[31|Cache]] / [[33|TLB]] / [[34|页面置换 LRU]] / [[37|磁盘预读]]。这些机制之所以有效，理由都是同一个。
:::

== 存储器怎么分类、用什么指标衡量 {kind}
按**存取方式**分，这是最容易混的一组：

|方式|怎么找数据|存取时间和位置的关系|例子|
|随机存取 RAM|直接按地址选中|和地址无关|SRAM、DRAM|
|只读存储 ROM|同样按地址随机读|和地址无关，只是通常不改写|BIOS 芯片|
|顺序存取|从头一路走到那儿|和位置有关|磁带|
|直接存取|先定位到一小片，再在片内顺序找|介于两者之间|磁盘|
|相联存取|按内容比对，不按地址|所有项同时比|TLB、Cache 的标记比较|

ROM 这个名字容易误导。它**也是随机存取**，「只读」说的是能不能随便改，不是怎么找。U 盘和 SSD 用的 Flash 就属于这一家族，只是能电擦写。CD-ROM 虽然名字带 ROM，却是光盘，靠旋转定位，不是随机存取。

三个指标：

- **存储容量** = 存储字数 × 字长。
- **存取时间**：从发出读命令到数据就绪。
- **存取周期**：连续两次独立读写之间的最小间隔。存取周期 **大于** 存取时间，多出来的部分是恢复时间（DRAM 读完要写回，尤其明显）。

还有一个概念要分开：**地址线的条数取决于地址空间，不取决于实际插了多少内存**。地址空间 64 MB、按字节编址，就要 26 位，哪怕只插了 32 MB。

== SRAM、DRAM、Flash {chip}
这三种的区别都能从「存一位用什么」推出来。

**SRAM** 用触发器存一位，要 6 个晶体管。只要通电，状态就一直保持，读出也不破坏，所以快；但占地大，容量做不大。于是拿来做 Cache。

**DRAM** 用一个电容存一位（电容有电表示 1），只要 1 个晶体管，密度高、便宜，做主存。代价有两个：

1. 电容会漏电，所以要定期**刷新**，通常 2 ms 内要把所有行刷一遍。刷新按**行**进行。
2. 读的时候电容放电，信息就没了（**破坏性读出**），必须马上写回去（再生）。这就是它存取周期长的原因。

**Flash** 用浮栅晶体管，断电不丢。读很快，但写之前必须先擦除，而且只能整块擦，所以写慢。

=== DRAM 的地址复用
DRAM 容量大，地址位数多。为了少占芯片引脚，把地址分两次送：先送行地址（行选通 RAS），再送列地址（列选通 CAS），用同一组引脚。

:::shu DRAM 引脚怎么算
**地址引脚** = ⌈地址位数 / 2⌉（复用，减半）。**数据引脚** = 每单元位数。
**行列怎么分**：行列尽量接近，让引脚最少；不能完全相等时**行数取少的**，因为刷新按行，行少刷新快。
:::

算一遍：一块 1M×8 位的 DRAM，地址 20 位，复用后 10 根；数据 8 根；共 18 根引脚（不算电源和控制）。而一块 2K×1 的芯片，地址 11 位：行 5 位、列 6 位，所以 32 行 64 列，地址引脚 6 根。

:::recall DRAM 和 SRAM 差在哪？为什么 DRAM 要刷新？为什么地址引脚能减半？
SRAM 用触发器，不刷新、读不破坏、快、贵，做 Cache。DRAM 用电容，会漏电所以要刷新，读会放电所以要再生，便宜，做主存。地址分行列两次送，同一组引脚用两次，所以减半。
:::

=== 刷新的三种安排
|方式|怎么排|特点|
|集中刷新|攒到周期末尾一口气刷完|有一段「死区」不能读写|
|分散刷新|每次读写后顺带刷一行|没有死区，但存取周期变长一倍|
|异步刷新|把 2 ms 均分给各行，定时刷一行|前两者折中，最常用|

:::deep 内存条、SDRAM 和行缓冲
**行缓冲**：DRAM 读一行时，整行都被读到一个 SRAM 缓冲里。如果下一次还访问这一行，只送列地址即可，快很多。这也是空间局部性的一次应用。
**SDRAM**：同步 DRAM，读写由统一时钟控制，CPU 发出命令后可以先做别的事，到点再取。支持突发传输，给一次首地址，连续传多个字。**DDR** 在时钟上下沿都传数据，同样频率下速率翻倍。
**内存条**：多块 DRAM 芯片焊在一块板上，共同组成一个更宽的存储器，数据线通常 64 位。下面讲的位扩展就是它的原理。
:::

== 多模块存储器 {multi}
CPU 比 DRAM 快太多，又换不了器件，就用并行来补。

:::ana 四个仓库管理员
**单体多字**：一个管理员一次搬四件。搬得多，但四件必须都用得上。
**低位交叉**：四个管理员，货号连续的货分给不同的人。你要连续的货时，第一个人还没搬完，第二个人已经出发了，货一件接一件地到。
:::

**单体多字**：一个模块，一次读出多个字。要求指令和数据都连续存放才划算。

**高位交叉**：高位选模块，连续地址落在同一个模块里。它只扩容量，**不提速**。

**低位交叉**：低位选模块，模块号 = 地址 % m。连续地址依次落在不同模块上，可以错开启动。

@ svg(600,170,*[box(30+i*140,20,110,34,f'M{i}（地址 %4={i}）','bk' if i==0 else 'bx',12) for i in range(4)],*[box(30+i*140,70,110,28,['0,4,8…','1,5,9…','2,6,10…','3,7,11…'][i],'bx',12) for i in range(4)],T(300,126,'低位交叉：相邻地址落在不同模块，可以错开启动',13,'rdt'),T(300,150,'高位交叉：连续地址落在同一模块，只扩容量',12,'mt'),cap='四体低位交叉')

算一遍：四体低位交叉，每个模块存取周期 T = 200 ns，总线传一个字 r = 50 ns。第一个字 200 ns 到手，之后每隔 50 ns 到一个。连续读 8 个字用 200 + 7×50 = 550 ns。如果是单个模块，要 8×200 = 1600 ns。

:::shu 低位交叉公式
连续读 n 个字：`T + (n−1)·r`。理想情况 `r = T / m`。
**访问冲突**：相邻不足 m 次的两次访问落到同一模块，后者要等前者的周期结束。
:::

判断冲突只看地址 % m。比如四体下，访问 1、5：都在模块 1，相隔不到 4 次，后者要等。

**双口 RAM** 是另一种并行：一块存储器有两组独立的地址、数据线，两个 CPU 可以同时访问不同单元；访问同一单元时才要排队。

:::recall 低位和高位交叉谁能提速？连续读 n 个字要多久？什么算冲突？
低位提速，高位只扩容。`T+(n−1)r`。相邻不足 m 次访问了同一模块就冲突。
:::

== 主存和 CPU 怎么连 {connect}
单片芯片的容量和位数都不够，要拼。三根线束：**地址线**选单元，**数据线**传数据，**控制线**（读写、片选）说干什么。

@ svg(640,190,T(150,12,'位扩展：地址都接，数据各接几位',13,'rdt'),box(30,30,70,34,'CPU','bk'),box(170,24,110,30,'4K×4（D7~D4）'),box(170,64,110,30,'4K×4（D3~D0）'),arrow(100,40,170,39),arrow(100,52,170,79),T(150,118,'两片合成 4K×8',12,'mt'),T(470,12,'字扩展：数据都接，高位地址译码片选',13,'rdt'),box(340,30,70,34,'CPU','bk'),box(340,90,70,30,'译码器','gd',12),arrow(375,64,375,90),box(480,24,110,30,'2K×8 第 0 组'),box(480,64,110,30,'2K×8 第 1 组'),arrow(410,40,480,39),arrow(410,105,480,79),arrow(410,100,480,45),T(470,118,'低位地址都接；高位选谁工作',12,'mt'),T(320,170,'字位同时扩展：先拼位，再拼字',13,''),cap='位扩展增加每个单元的位数；字扩展增加单元个数')

- **位扩展**：单元数够，位数不够。地址线、片选全部并联，每片接数据线的一段。这几片同时工作。
- **字扩展**：位数够，单元数不够。数据线并联，低位地址并联，**高位地址经译码器选其中一片**。任一时刻只有一片工作。
- **字位同时扩展**：先拼成一「组」（位扩展），再选组（字扩展）。

完整走一遍：用 2K×4 的芯片组成 8K×8。

:::shu 扩展四步
**① 片数** = 总容量 ÷ 单片容量。
**② 位方向** 每组几片；**字方向** 几组。
**③ 地址**：低位接芯片（log₂单片单元数），高 ⌈log₂组数⌉ 位译码。
**④ 控制**：CPU 的 `MREQ#` 接译码器使能，保证 CPU 访问 I/O 时不会误选内存。
:::

:::trap ROM 和 RAM 混装
ROM 区和 RAM 区要分别算片数。主存常常低地址放 ROM（比如引导程序），其余放 RAM，两边用的芯片规格可以不同，算的时候按区域分开除。
:::

:::recall 位扩展和字扩展，哪些线并联、哪些不并联？
位扩展：地址、片选都并联，数据分段接，所有片同时工作。字扩展：数据并联、低位地址并联，高位地址译码产生片选，每次只有一组工作。
:::

:::domain
**局部性：**时间 + 空间；整个存储体系的基础。
**DRAM：**电容、破坏读、按行刷新、地址复用减半（行取少）。
**低位交叉：**T+(n−1)r；相邻不足 m 次同模块就冲突。
**扩展：**片数 = 总容量 ÷ 单片；高位地址译码选组。
:::
