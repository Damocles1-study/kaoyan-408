:::say
这一卷的主题是一句话：==快的存储小而贵，慢的存储大而便宜，怎么让机器看起来既快又大==？答案是分层和局部性。先从主存的硬件讲起。
:::

== 存储层次 {level}
@ pyramid([('寄存器','bk'),('Cache（SRAM）','gd'),('主存（DRAM）',),('SSD / 磁盘',),('磁带 / 网络存储','tn')],cap='从上到下：更慢、更大、更便宜。Cache-主存：硬件管，解决速度；主存-辅存：硬件+OS 管，解决容量')

:::shu 程序的局部性
**时间局部性**：刚访问过的还会被访问（循环变量）。
**空间局部性**：刚访问地址的附近也会被访问（数组、顺序指令）。
它是 Cache、TLB、虚拟内存、磁盘预读、DNS 缓存能工作的唯一原因。
:::

:::link 跨科第一枢纽
**局部性原理** → [[31|Cache]] / [[33|TLB]] / [[34|页面置换 LRU]] / [[37|磁盘预读]]。题干看到「命中率为什么高」，答案就是局部性。
:::

**分类**：按存取方式分：**随机存取** RAM（任何地址时间相同）；**顺序存取**（磁带）；**直接存取**（磁盘：先定位到一小片，再顺序）；**相联存储器**（按内容，比如 TLB）。

== SRAM、DRAM、Flash {chip}
@ table([['','SRAM','DRAM','Flash'],['原理','触发器（6 管）','电容（1 管）','浮栅'],['破坏性读','否','<b class="r">是，读后要再生</b>','否'],['刷新','不要','<b class="r">要，约 2ms 一次</b>','不要'],['易失','是','是','<b class="r">否</b>'],['速度','快','较慢','读快写慢'],['集成度','低','高','高'],['用途','Cache','主存','U 盘、SSD']])

:::shu DRAM 的地址复用
DRAM 把地址分两次送（先行 RAS，后列 CAS），所以==地址线减半==。行列尽量接近，且让行数小一点（行越少，刷新越省）。
刷新按**行**。集中、分散、异步三种方式。
:::

:::trap Flash 不能原地改
Flash 写之前要先擦除，且按块擦除，所以读快写慢。这是 [[37|SSD]] 的所有麻烦（磨损均衡）的来源。
:::

== 多模块存储器 {multi}
CPU 比 DRAM 快太多。两种提速：

:::ana 四个仓库管理员
**单体多字**：一个人一次拿四件，必须同时用。**低位交叉**：四个人轮流，地址连续时一个接一个开始拿，整体就快了。
:::

@ svg(600,170,*[box(30+i*140,20,110,34,f'M{i}（地址 %4={i}）','bk' if i==0 else 'bx',12) for i in range(4)],*[box(30+i*140,70,110,28,['0,4,8…','1,5,9…','2,6,10…','3,7,11…'][i],'bx',12) for i in range(4)],T(300,126,'低位交叉：相邻地址落在不同模块，可以错开启动',13,'rdt'),T(300,150,'高位交叉：地址连续时落在同一模块（只是扩容量，不提速）',12,'mt'),cap='四体低位交叉：连续读 n 个字的时间 = T + (n−1)·r，r = T / m')

:::shu 低位交叉公式
存取周期 T、m 体、总线传输周期 r，要求 `T ≤ m·r`。
连续读 n 个字：`T + (n−1)·r`。
**冲突**：相邻 m 次访问内，访问同一模块。
:::

:::link 这也是 [[31]] 的命中开销
Cache 块往往比总线宽。缺失时从主存读一块用的就是低位交叉，2013 年大题就这么出。
:::

== 主存与 CPU 的连接 {connect}
内存芯片容量不够，要扩展。

@ svg(640,190,T(150,12,'位扩展：地址都接，数据各接几位',13,'rdt'),box(30,30,70,34,'CPU','bk'),box(170,24,110,30,'4K×4（D7~D4）'),box(170,64,110,30,'4K×4（D3~D0）'),arrow(100,40,170,39),arrow(100,52,170,79),T(150,118,'两片合成 4K×8',12,'mt'),T(470,12,'字扩展：数据都接，高位地址译码片选',13,'rdt'),box(340,30,70,34,'CPU','bk'),box(340,90,70,30,'译码器','gd',12),arrow(375,64,375,90),box(480,24,110,30,'2K×8 第 0 组'),box(480,64,110,30,'2K×8 第 1 组'),arrow(410,40,480,39),arrow(410,105,480,79),arrow(410,100,480,45),T(470,118,'低位地址都接；高位选谁工作',12,'mt'),T(320,170,'字位同时扩展：先拼位，再拼字',13,''),cap='位扩展增加每个单元的位数；字扩展增加单元个数')

:::shu 扩展三步
**① 算片数**：`总容量 / 单片容量`。比如 8K×8 用 2K×4：要 8 片（4 个字位 × 2 位）。
**② 算译码**：字方向 m 组，高 ⌈log₂m⌉ 位给译码器。
**③ 分地址**：写出每组的起止地址，用地址高位。
**片选**：CPU 的 `MREQ#` 接到译码器使能，保证不会在 I/O 时选中内存。
:::

:::domain
**局部性：**时间 + 空间；整个存储体系的基础。
**DRAM：**电容、破坏读、要刷新、地址复用减半（行少）。
**低位交叉：**T+(n−1)r；相邻 m 次同模块就冲突。
**扩展：**位扩展接地址，字扩展译码；片数=总容量/单片。
:::
