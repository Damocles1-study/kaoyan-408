== 从程序到内存 {load}
**编译** → **链接** → **装入**。程序中的地址最开始是逻辑地址（每个模块从 0 开始），最终要变成物理地址。

:::shu 三种装入与三种链接
**绝对装入**：编译时确定物理地址，只适合单道。
**静态重定位**：装入时一次性改地址，装入后不能移动。
**动态重定位**：运行时才转换，==需要重定位寄存器==；程序可以移动，是现代系统的方式。
**静态链接**：运行前合并；**装入时动态链接**；**运行时动态链接**（用到才链接）。
:::

:::shu 进程的内存映像（高地址到低地址）
@ mem([('内核','tn','高地址'),('用户栈（向下长）','gd'),('共享库映射区'),('堆（向上长）','bu'),('未初始化数据 .bss'),('已初始化数据 .data'),('只读代码 .text','bk','低地址 0x08048000')],w=280)
:::

:::link 接上之前的知识
.text、.data、.bss 就是 [[20#link|第 20 话]] 目标文件里的那些节。栈和堆之间的那一大片空着没用，==这就是虚拟内存的用武之地==：没有用到的地方不用占物理内存。
:::

**内存保护**：**上下限寄存器**或**基址 + 界限寄存器**（重定位寄存器 + 界地址寄存器）：逻辑地址 < 界限 才合法；否则越界中断。

**内存共享**：纯代码（可重入）可以映射到多个进程。**覆盖**：程序自己分段，常用的留在内存；**交换**：把进程整个换到外存（中级调度）。

== 连续分配 {cont}
@ table([['方式','特点','碎片'],['单一连续','一个用户程序','内部'],['固定分区','预先分好，大小可不同','<b class="r">内部碎片</b>'],['动态分区','按需分','<b class="r">外部碎片</b>，靠紧凑解决']])

:::shu 动态分区算法
|算法|怎么找|特点|
|首次适应 FF|地址递增，第一个够大的|综合最好、低地址碎片|
|临近适应 NF|从上次结束处开始|高地址大块被用掉|
|最佳适应 BF|按容量递增，刚好够的|==留下最多小碎片==|
|最坏适应 WF|按容量递减，最大的|大块很快用完|
:::

:::trap 回收要合并
回收时看相邻：和前、和后、和前后都空闲要合并，否则分区数加减不一样。下面这道题考的就是合并。
:::

== 分页 {page}
把进程和内存都切成等大的片，一片叫**页**，放在**页框**。没有外部碎片，内部碎片很小。

@ bits([('页号 P',20,'bk'),('页内偏移 W',12)],cap='32 位地址，页大小 4 KB')

:::shu 地址转换（基本分页）
`P = A / 页大小`；`W = A % 页大小`。
页表中查 P 得到页框号 F，`物理地址 = F × 页大小 + W`。
**页表项大小**：至少能表示页框号（以及控制位），通常取 4 B。
**一次访存实际上访问了两次内存**：一次读页表、一次读数据。
:::

:::ana 书和目录
虚拟页号是章节号，页框号是这一章实际印在哪几页。每次要先翻目录（读页表），再翻到正文（读数据）。所以要有 TLB 这张便签，把常查的目录抄在手边，下一话会讲。
:::

=== 多级页表
页表太大放不下：32 位地址、4 KB 页：2²⁰ 个页表项 × 4 B = 4 MB，还要连续。解决：页表也分页。

:::shu 多级页表的算法
每级页表最多占一页。一页能放 `页大小 / 页表项大小` 个表项，==每级页号的位数 = log₂(这个数)==。
**4 KB 页、4 B 页表项：一页 1024 项，每级 10 位。** 所以 32 位地址是 10+10+12。
**k 级页表，访存 k+1 次**（没有 TLB 时）。
**优点**：不需要连续大内存，未使用区域不用建表。
:::

:::link 这就是一棵树
多级页表是多叉树，根是页目录。和 [[13|B 树]]、[[35|多级索引 inode]]是同一个算法：==一块能放多少指针，决定每层多宽==。
:::

== 分段与段页式 {seg}
@ bits([('段号 S',8,'bk'),('段内偏移',24)],cap='段的长度不一样，所以段表要存段长，以便做越界检查')

:::shu 分页 vs 分段
|维度|分页|分段|
|目的|系统管理|用户需要（代码、数据各一段）|
|大小|固定|不固定|
|地址空间|一维|==二维==（段号+偏移）|
|碎片|内部|外部|
|共享和保护|难|==方便==|
段表项：段长、段基址。转换前要检查 `偏移 < 段长`，否则越界。
:::

**段页式**：先分段，段内分页。访问内存三次（段表、页表、数据）。

:::domain
**分页转换：**P=A/页大小，物理地址=F×页大小+W。
**多级页表：**每级位数 = log₂(页大小/表项大小)；k 级访存 k+1 次。
**分段：**段表多一个段长，先判越界；二维地址，便于共享。
**动态分区：**最佳适应碎片最多；回收要合并。
:::
