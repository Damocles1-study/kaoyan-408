== 两类算法 {algo}
:::ana 问邻居还是看地图
**距离向量**：问邻居「你到哪多远」，加上我到你的距离。**链路状态**：所有人都广播自己知道的链路，每人画完整地图，自己跑 Dijkstra。
:::

== RIP {rip}
:::shu RIP
**应用层，UDP 520**。距离向量。
**距离 = 跳数，16 = 不可达**。
**定期（30 s）只和邻居交换**自己的整个路由表。
**更新**：收到 `<N, d>` 来自 X：`d+1` 比现有的小就更新；来自同一个下一跳，一律以它的为准。
**坏消息传得慢**（计数到无穷）；好消息传得快。
:::

== OSPF {ospf}
:::shu OSPF
**IP 协议直接承载（协议号 89）**。链路状态。**Dijkstra**。
**洪泛**给所有路由器，只在变化时（或定期长周期）。
**可分区域**；主干区域 0；支持多路径负载均衡。
**报文**：Hello、DD、LSR、LSU、LSAck。
:::

@q net:4.4zh-05 | 这就是 [[10]] 那道。按 LSI 表画出图，再做 Dijkstra。下一跳是从 R1 发出的方向。

== BGP {bgp}
:::shu BGP
**AS 之间**。**TCP 179**。路径向量。
只寻求==较好的路径==（可达，而不是最优）。
**步骤**：BGP 发言人之间建立 TCP 连接，交换路径向量。
:::

:::shu 记忆表
|协议|封装|算法|范围|
|RIP|UDP|距离向量（跳数）|AS 内|
|OSPF|IP|链路状态（Dijkstra）|AS 内|
|BGP|TCP|路径向量|AS 间|
:::

@q net:4.4.5-04 | 就是上面的表。

:::shu 层次路由
Internet 分成**自治系统 AS**。AS 内 **IGP**（RIP、OSPF），AS 间 **EGP**（BGP）。
**静态路由**：管理员手动。**动态路由**：协议维护。
:::

@q net:4.4zh-04 | 2013。聚合：同一方向的子网合并，/25 单独留下靠最长前缀生效。R1 和 R2 之间是 AS 之间，所以 BGP，封装在 TCP。

:::domain
**RIP：**UDP、跳数、16 不可达、坏消息慢。
**OSPF：**IP、Dijkstra、分区域。
**BGP：**TCP、AS 间、不求最优。
:::
