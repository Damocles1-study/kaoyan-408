:::say
路由表从哪来？少量网络可以手工配，这叫**静态路由**。大网络要路由器互相通信，自动算出来，这叫**动态路由**。图算法你已经会了（[[10]]），这一话讲怎么在分布式环境下用它。
:::

== 两类算法 {algo}
:::ana 问邻居还是看地图
**距离向量**：问邻居「你到哪多远」，加上我到你的距离。没有全局信息。
**链路状态**：所有人都广播自己知道的链路，每人画完整地图，自己跑 Dijkstra。
:::

=== 距离向量
每个路由器只和邻居交换**自己的整张路由表**。收到后更新：

**从 X 收到 `<N, d>`：** 算 `d+1`（经 X 到 N 的距离）。

1. 表里没有 N：加入，下一跳 X。
2. 表里有 N，下一跳就是 X：一律用新值，即使变大了。X 是我通往 N 的路，它说的最新。
3. 下一跳不是 X：`d+1` 更小才更新。

走一遍：R1 的表是 Net1 距离 3（经 R2），Net2 距离 5（经 R3），Net3 距离 2（经 R2）。R2 发来 Net1 4，Net2 2，Net3 8，Net4 6。全部加 1 得 5、3、9、7。

|目的|旧|新|原因|
|Net1|3 经 R2|==5 经 R2==|下一跳就是 R2，听它的|
|Net2|5 经 R3|==3 经 R2==|更短|
|Net3|2 经 R2|==9 经 R2==|下一跳就是 R2，听它的|
|Net4|无|==7 经 R2==|新网络|

=== 链路状态
每个路由器把和自己相邻的链路状态**洪泛**给所有路由器。于是每个路由器都有相同的全网地图，各自用 **Dijkstra** 算最短路。只在链路变化时才发。

|比较|距离向量|链路状态|
|交换内容|整张路由表|只有自己的邻接链路|
|发给谁|只发邻居|洪泛给所有路由器|
|知道多少|只知道方向和距离|全局拓扑|
|收敛|慢|快|

== 层次路由 {hier}
互联网太大，所有路由器都存整个网络放不下，所有人都用一种算法也协调不了。所以分成一个个**自治系统 AS**（一个机构管理的网络）。

- **AS 内**：内部网关协议 IGP（RIP、OSPF），追求最短。
- **AS 间**：外部网关协议 EGP（BGP），追求可达，并要符合商业策略。

== RIP {rip}
:::shu RIP
**应用层，UDP 520**。距离向量。
**距离 = 跳数，最大 15，16 = 不可达**。所以只适合小网络。
**定期（30 s）只和邻居交换**自己的整个路由表。180 秒收不到就认为邻居不在了。
**坏消息传得慢**（计数到无穷）；好消息传得快。
:::

**慢收敛**的原因：距离向量只说「我到那多远」，不说路径，R3 不知道 R2 的路就是经过自己的。两者来回把距离加大，直到 16 才知道不可达。解决办法之一是水平分割（不把信息发回给来源）。

== OSPF {ospf}
:::shu OSPF
**IP 数据报直接承载（协议号 89）**。链路状态。**Dijkstra**。
**洪泛**给区域内所有路由器，只在变化时（或定期长周期）。
**可分区域**；主干区域 0；支持多路径负载均衡。
**报文**：Hello（发现邻居）、DD（数据库描述）、LSR（请求）、LSU（更新）、LSAck（确认）。
:::

**分区域**的原因：洪泛的范围限制在区域内，减少开销。跨区域由区域边界路由器汇总。

== BGP {bgp}
AS 之间不能只看最短：要考虑政策（谁给钱，不走竞争对手）。每个 AS 内部的度量也不一样，比不了。所以只交换**路径向量**：到某网络要经过哪些 AS。

:::shu BGP
**AS 之间**。**TCP 179**。路径向量。
只寻求==较好的路径==（可达，且没有环），不求最优。
**步骤**：BGP 发言人之间建立 TCP 连接，交换路径向量。
:::

路径里列出了经过的 AS，看到自己就知道有环，所以 BGP 不会计数到无穷。

:::shu 记忆表
|协议|封装|算法|范围|
|RIP|UDP|距离向量（跳数）|AS 内|
|OSPF|IP|链路状态（Dijkstra）|AS 内|
|BGP|TCP|路径向量|AS 间|
:::

为什么各用不同的承载？RIP 定期全发，丢了下次再说，用 UDP。OSPF 自己有确认，直接用 IP。BGP 要可靠地交换大量信息，又只发增量，用 TCP。

:::recall 默写三种协议的封装、算法、范围。距离向量表怎么更新？
RIP：UDP、距离向量、AS 内。OSPF：IP、链路状态、AS 内。BGP：TCP、路径向量、AS 间。+1 后比较，同一下一跳一律听它的。
:::

:::domain
**RIP：**UDP、跳数、16 不可达、坏消息慢。
**OSPF：**IP、Dijkstra、分区域。
**BGP：**TCP、AS 间、不求最优。
:::
