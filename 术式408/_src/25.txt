:::say
进入 OS 的主战场。程序是一本菜谱，进程是正在做菜的厨师。这一话把进程的数据结构、状态和线程讲完。
:::

== 进程 {proc}
:::ana 菜谱和做菜
**程序**是菜谱（静态的）；**进程**是照着菜谱做菜的这一次过程（动态的）：要占灶台（CPU）、食材（内存）、切到哪一步（PC）都要记住。同一本菜谱可以同时被两个厨师做，所以一个程序可以对应多个进程。
:::

**进程 = PCB + 程序段 + 数据段**。PCB 是进程存在的唯一标志，里面放着 PID、状态、优先级、寄存器的保存区、内存指针、打开的文件。

== 进程控制与组织 {ctrl}
**原语**：不可中断的一段程序，通过关中断或硬件指令实现。创建、撤销、阻塞、唤醒都用原语，在内核态执行。

:::shu 创建进程三件事
申请 PCB、分配资源（内存）、插入就绪队列。
**引起创建**：用户登录、作业调度、提供服务、用户请求（`fork`）。
**fork 后**：子进程得到父进程地址空间的一份（写时复制）；`exec` 替换地址空间。
:::

组织：各状态的 PCB 串成**队列**（[[04|第 04 话]]的队列就在这里用上了），或者用索引表。

== 线程 {thread}
进程切换代价大（要换页表、TLB、Cache 全部失效）。线程共享地址空间，切换只需要换寄存器和栈。

:::shu 进程 vs 线程
**进程**：资源分配的基本单位。**线程**：CPU 调度的基本单位（引入线程后）。
**线程共享**：代码段、数据段、堆、打开的文件。
**线程私有**：PC、寄存器、==栈==、线程 ID。
同一进程内线程切换**不引起**进程切换。
:::

:::trap 线程的栈
技术上一个线程可以用指针访问另一个线程的栈。但是==考试答「不共享」==，就按「栈私有」作答。
:::

**多对一**：多个用户线程映射到一个内核线程。一个阻塞全部阻塞。

**多对多**：折中。

== 进程通信 {ipc}
进程之间地址空间隔离，要通信只能靠 OS。

:::shu 四种通信方式
**共享内存**：映射同一块物理内存，最快；同步要自己做（PV）。
**消息传递**：`send/receive`，直接或通过信箱（间接）；内核复制，慢。
**管道**：半双工，字节流，一端写一端读。满了写阻塞，空了读阻塞，所以是一个==有容量限制的生产者消费者==。
**信号**：异步通知（如 Ctrl+C）。进程从内核态返回用户态时检查，并执行信号处理函数。
:::

:::domain
**状态：**运行→阻塞是主动，阻塞→就绪被唤醒。
**进程 = 资源单位，线程 = 调度单位。**
**栈私有**；用户级线程 OS 看不到、一个阻塞全阻塞。
**通信：**共享内存最快，管道半双工。
:::
