:::shu 地址一共切两次
**第一次（虚拟地址）**：VPN | 页内偏移 W。`W = log₂(页大小)`。
**第二次（物理地址）**：Tag | 组号 | 块内。
TLB 全相联时，整个 VPN 就是标记；组相联时再切一次。
:::

== TLB {tlb}
页表放在主存，每次访存都要多跑一趟。~~快表~~是一种放页表项的专用 Cache，用 SRAM、相联存储器实现。

@ table([['','TLB','Cache','页表'],['存什么','页表项（VPN→PPN）','主存块','VPN→PPN'],['用什么做','<b class="r">SRAM（相联）</b>','SRAM','主存 DRAM'],['缺失谁处理','硬件（或 OS）','硬件','缺页由 OS 处理'],['映射','全相联/组相联','三种都有','—']])

:::shu 带 TLB 的访存时间（2009 年那道）
TLB 命中：`Tlb + Tm`
TLB 缺失、页表命中：`Tlb + Tm(页表) + Tm + 更新`
缺页：`Tlb + Tm + 缺页处理 + (TLB命中后访存) Tlb + Tm`
最后一项是因为要==重新执行本条指令==。
:::

:::trap TLB、页表和 Cache 的组合
**TLB 命中，页表一定有效**（TLB 中的是页表子集）。
**页面没有在内存，Cache 一定没有**（Cache 是主存子集）。
所以「TLB 命中 + 缺页」「页缺失 + Cache 命中」都不可能。
:::

== 段式与段页式（组原口径） {seg}
组原大纲要求只要知道基本原理：段式：段号 + 偏移 → 段表 → 物理地址；段页式：段号 + 页号 + 偏移 → 段表 → 页表 → 物理地址。

:::domain
**一条路：**VA → TLB → 页表 → PA → Cache → 主存。
**切两次：**VPN|W；Tag|组|块内。
**不可能：**TLB 命中而缺页；缺页而 Cache 命中。
**缺页：**处理完重新执行本条。
:::
