== 结构 {struct}
@ svg(600,180,'<ellipse cx="160" cy="90" rx="150" ry="70" class="bx"/>','<ellipse cx="160" cy="90" rx="100" ry="46" class="bx"/>','<ellipse cx="160" cy="90" rx="50" ry="22" class="bk"/>','<path d="M160 44 L 200 20" class="rdl"/>',T(210,14,'磁道',12,'rdt',a='start'),'<path d="M240 75 L 400 75" class="rdl"/>',box(400,60,120,30,'磁头臂','gd',12),T(450,120,'盘面 + 磁道 + 扇区；',12,'',a='middle'),T(450,140,'所有盘面同位置的磁道 = 柱面',12,'',a='middle'),cap='地址：柱面号 + 盘面号 + 扇区号。按柱面组织可以减少磁头移动')

**结构**：磁盘有多个**盘面**，每面一个磁头；盘面上一圈圈的是**磁道**；磁道分成**扇区**；所有盘面半径相同的磁道组成**柱面**。**地址** = 柱面号 + 盘面号 + 扇区号。

为什么按柱面编址？磁头臂一起动，同一柱面上换盘面不用寻道。所以连续数据应放同一柱面。

读一个扇区要三步：把磁头移到磁道（**寻道**）；等扇区转到磁头下（**旋转延迟**）；读过这个扇区（**传输**）。

:::shu 磁盘访问时间
`Ta = 寻道时间 + 平均旋转延迟 + 传输时间 + 控制器延迟`
**平均旋转延迟** = 转一圈时间的一半 = `1/(2r)`。
**传输时间** = 字节数 ÷ (每圈字节 × 转速)，或字节数 ÷ 传输率。
:::

算一遍：6000 转/分，即 10 ms 一圈，旋转延迟 5 ms。平均寻道 8 ms，每道 100 个扇区，读一个扇区要 10÷100 = 0.1 ms。一次访问 8 + 5 + 0.1 = 13.1 ms。其中寻道和旋转占了绝大部分，所以优化它们最划算。

**磁盘最小读写单位是扇区**，不是字节。**RAID** 把多块盘组成一个：RAID 0 条带（快，无冗余）；RAID 1 镜像（可靠）；RAID 5 分布式校验（兼顾）。条带化靠并行提速，镜像和校验才提高可靠性。

**磁盘的管理**：

**格式化**：
- **物理（低级）格式化**：划分扇区，写校验。
- **分区**：把磁盘分成多个逻辑盘。
- **逻辑（高级）格式化**：建立文件系统（根目录、空闲空间管理）。

**引导块**：开机时 ROM 里的自举程序把引导块读入内存。它在磁盘的固定位置。**坏块**：低级格式化时会预留备用扇区，坏了就用备用的替换（简单系统由 FAT 标记）。

:::recall 访问一个扇区的时间由哪几段组成？三种格式化各做什么？
寻道、旋转、传输。物理格式化划扇区；分区分逻辑盘；逻辑格式化建文件系统。
:::

== 调度算法 {sched}
多个请求排队时，顺序决定磁头走多远。请求序列 `98 183 37 122 14 124 65 67`，磁头起始 53，向大的方向走，0~199 道：

@ disk([98,183,37,122,14,124,65,67],53,'FCFS')
@ disk([98,183,37,122,14,124,65,67],53,'SSTF',cap='SSTF 最短寻道优先：可能饥饿')
@ disk([98,183,37,122,14,124,65,67],53,'SCAN',cap='SCAN 电梯：走到头（199）才掉头')
@ disk([98,183,37,122,14,124,65,67],53,'LOOK',cap='LOOK：走到最后一个请求就掉头')
@ disk([98,183,37,122,14,124,65,67],53,'CSCAN',cap='C-SCAN：单向，走到头后直接回到 0。虚线是返回')
@ disk([98,183,37,122,14,124,65,67],53,'CLOOK',cap='C-LOOK：单向，到最后一个请求回到另一边最小的请求')

:::trap C-SCAN 的返程算不算距离
返程是一段真实的移动，但不同题目口径不同：有的把返回那段算进总距离，有的不算。题干问「移动距离」时先看怎么说的，没说就把两种都算一下再看选项。
:::

:::shu 算法对比
|算法|特点|缺点|
|FCFS|公平|慢|
|SSTF|每次最近|饥饿，磁臂黏着|
|SCAN|到头再回|两端不公平|
|C-SCAN|单向|一圈才一次|
|LOOK / C-LOOK|不到头就回|实际常用|
:::

== 其他优化 {opt}
除了调度，还有几种办法：**提前读**（读一块时连带读后面的，靠空间局部性）、**延迟写**（先放缓冲区，以后一起写）、**磁盘高速缓存**、**连续分配**（减少寻道）。

**交替编号**：磁盘转得快，读完一个扇区要处理一下，这时下一个扇区已经过头了，又得等一圈。于是把逻辑相邻的扇区在物理上隔开放。例如交替因子 2:1 时物理顺序是 0 4 1 5 2 6 3 7。**错位命名**：相邻盘面的 0 号扇区错开一点，换盘面的那一点时间正好转到。

== 固态硬盘 {ssd}
:::shu SSD 的特点
由**闪存块**构成，每块多个页；**按页读写，按块擦除**。写之前必须先擦。
读快（随机访问），写比读慢；没有机械部件，所以无寻道延迟，调度算法基本用 FCFS。
**闪存转换层（FTL）**：逻辑块到物理页的映射。
**磨损均衡**：每块擦写次数有限。**动态**：写入时选低磨损的块；**静态**：周期性搬动长时间不变的数据。
:::

为什么有 FTL？闪存不能原地改写，改一页要把新数据写到别处，并把旧页标记为无效。**闪存翻译层**负责维护这个映射，让上层仍然觉得是在写同一个块号。之后再集中回收无效页（**垃圾回收**）：把块里还有效的页搬走，擦除整块。

**为什么写慢**：不只是擦除慢，有时写一页要先搬动一整块。这种情况越多，写得越多，寿命也越短。

:::recall 六种磁盘算法各有什么特点？SSD 的读、写、擦单位？
FCFS 公平慢；SSTF 最近优先会饥饿；SCAN 到头掉头；LOOK 到最后请求掉头；C- 版本单向。按页读写，按块擦除。
:::

:::domain
**时间：**寻道 + 1/(2r) + 传输 + 控制。
**算法：**SCAN 到头、LOOK 到请求、C- 单向。
**C-SCAN 返程：**口径看题。
**SSD：**页读写、块擦除；磨损均衡。
:::
