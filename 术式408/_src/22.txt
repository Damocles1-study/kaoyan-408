:::say
组原第二大考点。洗衣、烘干、叠衣服三件事，如果一次只洗一批太慢；流水线就是让每个环节同时都有活干。==一个周期出一条指令==，同时带来三种冒险。
:::

== 基本概念 {base}
经典 5 段：**IF** 取指、**ID** 译码读寄存器、**EX** 执行、**MEM** 访存、**WB** 写回。

@ pipe([('I1',['IF','ID','EX','MEM','WB'],1),('I2',['IF','ID','EX','MEM','WB'],2),('I3',['IF','ID','EX','MEM','WB'],3),('I4',['IF','ID','EX','MEM','WB'],4)],'时空图：第 5 个周期之后每周期完成一条')

:::shu 流水线指标（k 段、n 条、周期 Δt）
**总时间** `T = (k + n − 1)Δt`。
**吞吐率** `TP = n / T`，理想最大 1/Δt。
**加速比** `S = n·k·Δt / T`，n 很大时趋近 k。
**效率** `E = S / k`。
**时钟周期** = ==最慢段的时间 + 段寄存器延迟==。
:::

:::shu 利于流水线的指令系统特点
指令定长、格式规整（Ⅰ）；只有 Load/Store 访存（Ⅱ）；对齐存放（Ⅲ）。这就是 RISC。
:::

== 三种冒险 {hazard}
冒险就是==下一条指令不能在下一个周期开始==。

:::ana 记忆
**结构冒险**：两个人抢一台机器。**数据冒险**：我要的东西你还没做出来。**控制冒险**：不知道下一步往哪走。
:::

=== 结构冒险
硬件资源不够：比如同一周期取指和访存都要用存储器。解决：**指令 Cache 和数据 Cache 分离**（这就是分离的主要目的）。

=== 数据冒险
只考写后读（RAW）：后一条的源寄存器等于前面某一条的目的寄存器。

@ pipe([('add R1,R2,R3',['IF','ID','EX','MEM','WB'],1),('sub R4,R1,R5',['IF','*','*','ID','EX','MEM','WB'],2)],'不转发：要等前一条 WB。假定 WB 前半周期写、ID 后半周期读，第 5 周期两者可同时进行，阻塞 2 个周期。题目会写明假设')

:::shu 数据冒险三种解法
**① 阻塞（插 nop）**：简单，慢。
**② 转发（旁路）**：把 EX 或 MEM 的结果直接送到 ALU 入口。ALU 结果一般不用阻塞。
**③ 编译器重排**：把无关的指令调到中间。
**Load-use 特例**：`load R1` 后紧跟使用 R1，==转发也要阻塞 1 个周期==，因为 MEM 才有数据。
:::

:::flash 判定数据冒险
**只看每条的源寄存器是否是前面还没写回的目的寄存器。** 距离 ≥ 3 条（没有转发、WB 前半写）就没事。
:::

=== 控制冒险
遇到转移指令时，还没算出来转不转，后面的指令已经进去了。

:::shu 控制冒险的处理
**① 阻塞**：等分支结果出来。
**② 提前判断**：把比较放在 ID 段，只损失 1 个周期。
**③ 分支预测**：静态（总预测不转）、动态（根据历史，循环命中率很高）。
**④ 延迟槽**：转移指令后一条总是执行（MIPS）。
预测错了要**清空（flush）**已经进入流水线的指令。
:::

== 高级流水线 {adv}
:::shu 超标量 / 动态
**超标量**：多条流水线，==一个周期发射多条指令==，CPI 可小于 1。不缩短单段时间。
**超流水**：一个周期分成更多小段，提高主频。
**超长指令字 VLIW**：编译器把多条指令打包。
**动态流水线**：可以乱序执行、顺序提交，由硬件调度。
:::

== 多处理器（选择题） {mp}
:::shu Flynn 分类
**SISD**：普通单核。**SIMD**：一条指令处理多个数据（向量、GPU、数组运算）。**MISD**：现实中几乎没有。**MIMD**：多核、多处理器。
:::

@ table([['概念','一句话','辨析'],['向量处理器','SIMD 的代表','专做数组运算'],['硬件多线程','一个核同时维护多个线程的 PC/寄存器','细粒度（每周期切）、粗粒度（阻塞才切）、同时（SMT，一周期发多线程指令）'],['多核','一块芯片多个核','共享 L3（常见）和主存'],['SMP','共享内存多处理器','所有处理器地址空间相同、访问对等（UMA）；需要 Cache 一致性']])

:::domain
**指标：**T=(k+n−1)Δt，周期按最慢段 + 寄存器延迟。
**冒险：**结构（分离 Cache）、数据（转发，load-use 仍阻 1）、控制（预测、flush）。
**超标量：**一周期发多条，不缩短每段时间。
**分类：**向量=SIMD，多核=MIMD。
:::
