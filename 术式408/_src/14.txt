:::say
排序这两话的主要考法是：给你一趟或两趟结果，判断是什么算法；或者对比时间、空间、稳定性。我们不背代码优先，先记住==每种算法一趟之后序列长什么样==。
:::

== 基本概念 {base}
~~稳定性~~：相同关键字的相对次序排序后不变。稳定与否和算法好坏无关。~~内部排序~~在内存，~~外部排序~~要用外存。

:::shu 比较排序的下界
基于比较的排序，最坏至少要 `⌈log₂(n!)⌉` 次比较，也就是 Ω(n log n)。
:::

== 直接插入 {ins}
:::ana 打牌理牌
左手有序，右手摸一张牌，从后往前比，插到合适的位置。
:::

:::code c 模板：直接插入
void InsertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int x = a[i], j;
        for (j = i - 1; j >= 0 && a[j] > x; j--)   // 严格大于才挪，保证稳定
            a[j + 1] = a[j];
        a[j + 1] = x;
    }
}
:::

:::shu 直接插入与折半插入
**直接插入**：最好 O(n)（已有序），最坏 O(n²)，稳定，O(1) 空间。适合基本有序或 n 小。
**一趟特征**：前 k 个有序，但==不一定是最终位置==。
**折半插入**：比较次数减少到 O(n log n)，但==移动次数不变==，总时间仍 O(n²)，稳定。
:::

== 希尔排序 {shell}
把序列按增量 d 分组，组内做直接插入，然后缩小 d 到 1。

:::shu 希尔排序
时间约 O(n^1.3)，最坏 O(n²)。**不稳定**。只能用顺序存储。
**判增量**：看相距 d 的元素是否各自有序。
:::

== 冒泡排序 {bubble}
相邻比较，大的往后换。每一趟把一个最大值送到末尾。一趟里没发生交换就提前结束。

:::shu 冒泡
最好 O(n)，最坏 O(n²)，稳定，O(1) 空间。
**一趟特征**：末尾（或开头）增加一个==最终位置==的元素。
:::

== 快速排序 {quick}
:::ana 选一个人站中间
选一个枢轴，比它小的站左边，比它大的站右边。这一趟之后，它就站到了==最终位置==。然后两边各自递归。
:::

@ quick_steps([46,79,56,38,40,84,27,92])

:::code c 模板：快排划分（要能默写）
int Partition(int a[], int low, int high) {
    int p = a[low];                         // 枢轴
    while (low < high) {
        while (low < high && a[high] >= p) high--;
        a[low] = a[high];
        while (low < high && a[low] <= p) low++;
        a[high] = a[low];
    }
    a[low] = p;
    return low;
}
void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int m = Partition(a, low, high);
        QuickSort(a, low, m - 1);
        QuickSort(a, m + 1, high);
    }
}
:::

:::shu 快排
平均 **O(n log n)**，最坏 **O(n²)**（已有序或逆序），空间 O(log n)（递归栈），**不稳定**。
平均性能是内部排序中最好的。
**第 k 小 / 第 k 大**：只递归一边，平均 O(n)。
**判第二趟结果**：第一趟后至少 1 个元素到位；第二趟后==至少 3 个==（枢轴在中间时），若第一趟枢轴在端点，则至少 2 个。
:::

:::domain
**插入：**前 k 个有序但未必就位；折半只省比较。
**希尔：**看相距 d 的元素，不稳定。
**冒泡：**每趟一个最值就位。
**快排：**每趟枢轴就位，第二趟至少 2–3 个。
:::
