:::say
排序的算法多，但都在两件事上做文章：怎么比较，怎么移动。这两话不背代码优先，先记住==每种算法一趟之后序列长什么样==，这最能看出算法在做什么。
:::

== 基本概念 {base}
~~稳定性~~：相同关键字的相对次序排序后不变。稳定与否和算法好坏无关。~~内部排序~~在内存，~~外部排序~~要用外存。

:::shu 比较排序的下界
基于比较的排序，最坏至少要 `⌈log₂(n!)⌉` 次比较，也就是 Ω(n log n)。
:::

== 直接插入 {ins}
:::ana 打牌理牌
左手有序，右手摸一张牌，从后往前比，插到合适的位置。
:::

走一趟：`49 38 65 97 76`。第 1 趟把 38 插到 49 前：`38 49 65 97 76`。第 2、3 趟 65、97 不用动。第 4 趟把 76 插到 97 前。每趟前 k 个有序。

@ insert_steps([49,38,65,97,76,13,27])

:::code c 模板：直接插入
void InsertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int x = a[i], j;
        for (j = i - 1; j >= 0 && a[j] > x; j--)   // 严格大于才挪，保证稳定
            a[j + 1] = a[j];
        a[j + 1] = x;
    }
}
:::

:::shu 直接插入与折半插入
**直接插入**：最好 O(n)（已有序），最坏 O(n²)，稳定，O(1) 空间。适合基本有序或 n 小。
**一趟特征**：前 k 个有序，但==不一定是最终位置==。
**折半插入**：比较次数减少到 O(n log n)，但==移动次数不变==，总时间仍 O(n²)，稳定。
:::

== 希尔排序 {shell}
直接插入在基本有序时很快，n 小时也快。希尔利用这两点：把序列按增量 d 分组（相距 d 的元素为一组），组内做直接插入。d 大时每组短；d 逐步缩小时序列越来越有序。最后 d=1 就是直接插入，此时已基本有序，很快。

@ shell_steps([49,38,65,97,76,13,27,49,55,4])

:::shu 希尔排序
时间约 O(n^1.3)，最坏 O(n²)。**不稳定**（相同元素可能分到不同组）。只能用顺序存储，因为要按增量随机访问。
**判增量**：看相距 d 的元素是否各自有序。
:::

:::deep 希尔省的是移动，不是比较
随机序列上希尔的移动次数总比直接插入少，但 n 不大时比较次数反而可能更多。所以「基本有序用插入」冲的是比较，「n 中等用希尔」冲的是移动。
:::

== 冒泡排序 {bubble}
相邻比较，大的往后换。每一趟把一个最大值送到末尾（或者最小值冒到开头）。一趟里没发生交换说明已有序，提前结束。走一趟：`3 1 4 2`：3>1 换，3<4，4>2 换，得 `1 3 2 4`，4 就位。

:::shu 冒泡
最好 O(n)，最坏 O(n²)，稳定，O(1) 空间。
**一趟特征**：末尾（或开头）增加一个==最终位置==的元素。
:::

== 快速排序 {quick}
:::ana 选一个人站中间
选一个枢轴，比它小的站左边，比它大的站右边。这一趟之后，它就站到了==最终位置==。然后两边各自递归。
:::

走一趟划分：`46 79 56 38 40`，枢轴 46。从右找小于 46 的，40 放到左边空位；从左找大于 46 的，79 放到右边空位；继续，38 放到 79 原来的位置；56 放到 38 原来的位置……直到两指针相遇，46 落位。结果是 `40 38 46 56 79`。

@ quick_steps([46,79,56,38,40,84,27,92])

:::code c 模板：快排划分（要能默写）
int Partition(int a[], int low, int high) {
    int p = a[low];                         // 枢轴
    while (low < high) {
        while (low < high && a[high] >= p) high--;
        a[low] = a[high];
        while (low < high && a[low] <= p) low++;
        a[high] = a[low];
    }
    a[low] = p;
    return low;
}
void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int m = Partition(a, low, high);
        QuickSort(a, low, m - 1);
        QuickSort(a, m + 1, high);
    }
}
:::

:::shu 快排
平均 **O(n log n)**，最坏 **O(n²)**（已有序或逆序），空间 O(log n)（递归栈），**不稳定**。
枢轴越接近中位数越好，递归树矮；已有序时每次只去掉一个，退化成冒泡。
**平均性能**是内部排序中最好的。要用顺序存储（随机存取）。
**第 k 小**：只递归一边，平均 O(n)。
**第二趟结果**：第一趟后至少 1 个元素到位；第二趟后==至少 3 个==（枢轴在中间时），若第一趟枢轴在端点，则至少 2 个。
:::

:::recall 默写 Partition。这四种排序各自「一趟之后」有什么特征？
插入：前 k 个有序但未必就位。希尔：相距 d 的元素有序。冒泡：末尾一个就位。快排：枢轴就位，左小右大。
:::

:::domain
**插入：**前 k 个有序但未必就位；折半只省比较。
**希尔：**看相距 d 的元素，不稳定。
**冒泡：**每趟一个最值就位。
**快排：**每趟枢轴就位，第二趟至少 2–3 个。
:::
