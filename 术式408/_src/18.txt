== 浮点的结构 {struct}
`N = (−1)^S × M × 2^E`。和科学计数法一样，只是底数是 2。

@ bits([('S',1,'rd'),('阶码（移码）8 位',8,'bk'),('尾数 23 位（隐含 1.）',23)],cap='float：1 + 8 + 23 = 32 位。double：1 + 11 + 52 = 64 位')

:::shu IEEE 754 单精度
|项目|float|double|
|偏置值|127|1023|
|规格化真值|(−1)^S × 1.f × 2^(e−127)|(−1)^S × 1.f × 2^(e−1023)|
|e 全 0（非规格化）|±0.f × 2⁻¹²⁶，含 ±0|±0.f × 2⁻¹⁰²²|
|e 全 1|f=0 是 ±∞，f≠0 是 NaN|同左|
|最大正数|`(2−2⁻²³) × 2¹²⁷`，7F7F FFFFH|(2−2⁻⁵²)×2¹⁰²³|
|最小规格化正数|`1.0 × 2⁻¹²⁶`，0080 0000H|1.0×2⁻¹⁰²²|
:::

:::trap 偏置值不是 128
IEEE 754 的移码偏置是 127，和普通移码的 128 不同。所以阶码 e 的实际范围是 1~254，对应指数 −126~+127。全 0 和全 1 留作特殊用途。
:::

:::shu 手转三步（十进制 → 位模式）
1. **写成二进制**并规格化：`−8.25 = −1000.01B = −1.00001 × 2³`。
2. **算三段**：S=1；e = 3+127 = 130 = 1000 0010；f = 00001 后面补 0。
3. **四位一组**：1100 0001 0000 0100… = C104 0000H。
:::

== 精度与类型转换 {prec}
float 有 24 位有效数字（含隐含的 1），超过就会丢。

:::shu 转换谁会丢精度
**int → float**：可能丢（int 有 31 位有效，float 只有 24 位）。
**int → double**：不丢。**float → double**：不丢。
**float/double → int**：小数被截掉，可能溢出。
**double → float**：可能丢，可能溢出。
**大数吃小数**：`(d+f)−d` 不一定等于 f。
:::

== 浮点加减 {add}
:::shu 五步（顺序固定）
**① 对阶**：小阶向大阶看齐，小阶尾数右移（精度损失最小）。
**② 尾数相加减**。
**③ 规格化**：尾数溢出右规（阶码 +1），绝对值太小左规（阶码 −1）。
**④ 舍入**：0 舍 1 入或恒置 1，可能再触发规格化。
**⑤ 判溢出**：阶码上溢才是真溢出，阶码下溢当作机器零。
:::

:::trap 溢出的判据
**尾数溢出不一定结果溢出**，右规后能救回来。真正溢出看阶码。对阶不会引起阶码溢出。
:::

== 对齐与大小端 {layout}
**大端**：最高字节放低地址（书写顺序）。**小端**：最低字节放低地址（x86）。

@ svg(560,120,T(55,20,'0x12345678',13,'',w=800),T(30,55,'大端',13,'rdt'),*[box(70+i*50,38,50,30,t,'bx') for i,t in enumerate(['12','34','56','78'])],T(30,95,'小端',13,'rdt'),*[box(70+i*50,78,50,30,t,'gd' if i==0 else 'bx') for i,t in enumerate(['78','56','34','12'])],T(320,55,'地址从左到右递增',12,'mt',a='start'),T(320,95,'小端：低地址放低字节',12,'rdt',a='start'),cap='同一个 int 的两种放法')

:::shu 结构体对齐规则
1. 每个成员的地址必须是自己大小的整数倍。
2. 整个结构体大小必须是最大成员大小的整数倍。
3. 成员顺序影响大小。`char+int+short`（1+3 空+4+2+2 空 = 12）比 `int+short+char`（4+2+1+1 空 = 8）费空间。
:::

@ mem([('int a（4 字节）','bk','C008'),('char b + 1 字节空 + short c','gd','C00C')],w=300,cap='2012 真题 struct{int a; char b; short c;}：b 在 C00C，c 在 C00E，共 8 字节')

:::domain
**754：**1.f × 2^(e−127)，手转三步。
**精度：**24 位，int→float 可能丢，大数吃小数。
**加减五步：**对阶小向大，真溢出看阶码。
**对齐：**成员对齐到自身大小，总大小对齐最大成员。**小端：**低地址放低字节。
:::
