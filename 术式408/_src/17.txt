这一话的中心是一句话：==机器里只有一串位，它是什么数，由你怎么解释决定==。同一个 `1111 0110`，看成无符号是 246，看成补码是 −10。抓住这一点，所有 C 语言类型转换题都变成同一道题。

== 进位计数制 {radix}
机器只认二进制，人爱看十进制，十六进制是二进制的缩写（4 位一组）。

**十进制转二进制**：整数部分除 2 取余，倒着写；小数部分乘 2 取整，顺着写。例如 13.625：13 = 1101，0.625 → 1.25 取 1，0.5 取 0，1.0 取 1，得 .101，所以 1101.101B = D.AH。有些小数（比如 0.1）转不尽，这是[[18|浮点数]]精度问题的来源。

== 四种编码 {code}
以 8 位为例，真值范围和转换方法：

@ table([['编码','规则','8 位范围','零'],['原码','最高位是符号，其余是绝对值','−127 ~ +127','+0、−0 两个'],['反码','负数：符号外全部取反','−127 ~ +127','+0、−0 两个'],['补码','负数：取反 +1','<b class="r">−128</b> ~ +127','只有一个'],['移码','真值 + 偏置值（8 位偏置常取 128）','−128 ~ +127','只有一个']])

:::shu 补码三招
**负数求补码**：绝对值的二进制「取反 +1」。或者从右往左，第一个 1 及其右边不变，左边全部取反。
**求 −x**：不管 x 正负，连符号位一起「取反 +1」。
**真值**：`−b₇·2⁷ + b₆·2⁶ + … + b₀`。最高位是负权，这是最本质的定义。
:::

走几个 8 位的例子：

|真值|原码|反码|补码|移码|
|+5|0000 0101|0000 0101|0000 0101|1000 0101|
|−5|1000 0101|1111 1010|1111 1011|0111 1011|
|−128|无|无|1000 0000|0000 0000|

移码就是补码把符号位取反。它的好处是比大小时可以直接按无符号比，所以浮点数的阶码用它。

:::ana 补码就是时钟
12 小时的钟上，往回拨 2 小时和往前拨 10 小时是一回事。n 位补码就是一个模 2ⁿ 的钟：减 x 等于加 2ⁿ−x。这就是为什么 ==减法可以用加法器做==，补码的全部意义都在这里。
:::

:::shu 边界值（必背）
n 位补码：最小 `−2^(n−1)`（1000…0），最大 `2^(n−1)−1`（0111…1），−1 是全 1。
n 位无符号：最大 `2ⁿ−1`（全 1）。
8 位 −128 的机器数 `80H`；16 位 −32768 的机器数 `8000H`；32 位 `8000 0000H`。
:::

== C 语言类型转换：位不变，解释变 {cast}

:::shu 转换三条规则
**① 同宽度**：位不变，解释变。`无符号 = 补码 + 2ⁿ`（补码为负时）。
**② 长→短**：截断高位。
**③ 短→长**：看**原类型**，无符号补 0（零扩展），有符号补符号位（符号扩展）。
**混合运算**：int 和 unsigned 运算时，int 转成 unsigned。
:::

这就是 C 语言**强制类型转换**的全部规则。一个容易出事的例子：`unsigned n = 0; for (int i = 0; i <= n - 1; i++)`。`n−1` 是无符号，等于 2³²−1；i 也被转成无符号比较，条件永远成立，死循环。

:::recall 同一串位：转成同宽无符号、截短、加长，分别怎么变？
同宽位不变；截短留低位；加长看原类型，有符号补符号位，无符号补 0。
:::

== 加法器与标志位 {alu}
**一位全加器**有三个输入（两个加数位和低位来的进位），两个输出。为什么 n 位加法器能同时做加减？因为前面说过，减 Y 等于加 Y 的补码，即 Y 取反再加 1。

**一位全加器**：`S = A⊕B⊕C_in`，`C_out = AB + (A⊕B)C_in`。n 个串起来就是**串行进位加法器**，进位一位位传，慢；**先行进位（CLA）** 用并行逻辑同时算出所有进位，快。**ALU** 的核心就是一个带控制端的加法器。

@ svg(600,170,box(190,60,220,50,'n 位加法器','bk'),arrow(240,10,240,60),arrow(360,10,360,60),T(240,5,'X',13),T(360,5,'Y ⊕ Sub',13,'rdt'),arrow(490,85,410,85),T(530,85,'Cin = Sub',13,'rdt'),arrow(300,110,300,150),T(300,162,'F',13),arrow(190,85,100,85),T(50,85,'Cout',13),box(440,120,150,36,'OF SF ZF CF','gd'),arrow(380,110,440,136),cap='一个加法器 + 一个 XOR：Sub=0 时做 X+Y，Sub=1 时 Y 取反且 Cin=1，就是 X−Y')

:::shu 四个标志位
**ZF** 结果全 0。**SF** 结果最高位（看作有符号时的符号）。
**OF** 有符号溢出：`OF = C_n ⊕ C_(n−1)`（最高位进位 ⊕ 次高位进位）。等价：两个同号数相加，结果符号相反。
**CF** 无符号的进位/借位：`CF = C_out ⊕ Sub`。加法时 CF=C_out，减法时取反。
:::

走一遍 8 位运算，四个标志都算：

|运算|机器数|结果|ZF|SF|OF|CF|含义|
|127 + 1|`7F + 01`|`80`|0|1|==1==|0|有符号溢出，无符号 128 正确|
|255 + 1（即 −1 + 1）|`FF + 01`|`00`|1|0|0|==1==|无符号溢出，有符号 0 正确|
|3 − 5|`03 − 05`|`FE`|0|1|0|==1==|无符号不够减，有符号 −2 正确|

**判断溢出的三种等价办法**：① 同号相加，结果变号；② 最高位进位和次高位进位不同；③ **双符号位**（变形补码）：用两位符号，`00` 正、`11` 负是正常，`01` 正溢出、`10` 负溢出。双符号位只在运算时用，存储时只存一位，因为正常数的两位符号总是相同的。

:::vow 分清谁看谁
**CF 只对无符号有意义，OF 只对有符号有意义。** 硬件不知道你是什么类型，四个标志都算出来；哪个有用，由后面的指令决定。
:::

:::shu 比较后的条件（指令系统的条件转移就是它）
|比较|无符号|有符号|
|X = Y|ZF=1|ZF=1|
|X > Y|CF=0 且 ZF=0|SF=OF 且 ZF=0|
|X < Y|CF=1|SF≠OF|
:::

:::recall 不看书，写出 OF 的两种判断方法，并说明 CF 什么时候有意义。
同号相加结果变号；最高位和次高位进位异或。CF 只对无符号数有意义。
:::

== 移位 {shift}
:::shu 三种移位
**逻辑移位**（无符号）：左右都补 0。
**算术右移**（有符号）：高位补符号位，相当于 ÷2 向下取整。
**算术左移**：低位补 0，相当于 ×2，符号位变化则溢出。
:::

:::trap −1 算术右移还是 −1
补码负数右移是向负无穷取整。−1>>1 = −1。所以 C 里 `-1/2 = 0` 但 `-1>>1 = -1`。
:::

== 乘除 {mul}
乘除的电路比加减复杂，但原理就是竖式，只要明白结构。

:::ana 就是竖式
二进制乘法就是竖式：看乘数的最低位，是 1 就把被乘数加到积的高半部分，然后积和乘数一起右移一位。除法是试减：不够减商 0，够减商 1。
:::

@ svg(600,150,box(30,20,200,36,'被乘数 X（n 位）'),box(60,90,130,36,'加法器 / ALU','bk'),box(250,90,150,36,'积高位 Hi'),box(400,90,150,36,'乘数/积低位 Lo'),arrow(130,56,130,90),arrow(190,108,250,108),T(470,140,'一起右移，看 Lo 最低位',12,'rdt'),cap='乘法器结构：n 位 × n 位，n 次加和移位，得到 2n 位积；计数器控制 n 次')

:::shu 乘除要记的结论
**n 位 × n 位 = 2n 位。** C 的 `int * int` 只取低 32 位，所以可能溢出。
**乘法溢出判断**：有符号：高 n 位不是低 n 位符号的扩展；无符号：高 n 位不全为 0。
**除法溢出**：只有 **最小负数 ÷ (−1)**，以及除以 0（产生异常）。
C 语言整数除法向 0 取整；移位是向下取整。
:::

**补码一位乘（Booth）** 看乘数相邻两位：`01` 加被乘数，`10` 减被乘数，`00`、`11` 只移位。连续的 1 只在头尾各算一次，减少加法次数。

**除法**是试减：够减商 1，不够商 0。**恢复余数法**不够减时要把减掉的加回来。**不恢复余数法**（加减交替）不加回，下一步改成加，节省步骤。商一共 n 位时要做 n 次（加减交替的第一步另算）。

**硬件**：乘法器由被乘数寄存器、乘积寄存器、加法器和计数器组成。除法器类似，用左移。多位乘法也可做成阵列乘法器，用更多电路换速度。

:::link 移位 + 加法替代乘法
`x*5 = (x<<2)+x`。[[20|机器级代码]]里 `lea`、`shl` 出现，编译器就是这么做的。在读汇编题时要能看出来。
:::

:::domain
**一串位：**同宽转换位不变；长转短截断；短转长看原类型。
**补码：**最高位负权，范围多一个负数。
**标志：**CF 看无符号，OF 看有符号。OF=最高两位进位异或。
**移位：**算术右移补符号，向下取整。
:::
