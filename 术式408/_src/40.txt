中断方式的 CPU 占用率怎么算？ || 每秒中断次数 × 每次周期 ÷ 主频。
DMA 请求什么时候响应？ || 存取周期结束时。

:::say
上一话是硬件怎么传，这一话是软件怎么组织。设备千差万别，应用却只想调一个 `read`。分层就是为了让每层只管一件事，换设备时只改最下面。

== 四层软件 {layer}
@ pyramid([('用户层 I/O 软件（printf、SPOOLing）','bx'),('设备独立性软件（命名、保护、缓冲、分配）','gd'),('设备驱动程序（把抽象命令翻译成设备操作）','bk'),('中断处理程序','rd'),('硬件','tn')],cap='I/O 请求自上而下，响应（中断）自下而上')

**走一遍 read**：用户程序调 `read` → 系统调用进内核 → **设备独立性软件**把文件名和偏移翻译成逻辑块，查缓冲区，没有再往下 → **驱动程序**把块号算成柱面、磁头、扇区，写设备控制器的端口，启动设备，进程阻塞 → 设备完成发中断 → **中断处理程序**保存现场、唤醒进程 → 数据逐层交回。

:::shu 每层干什么
**用户层**：库函数、假脱机。
**设备独立性**：逻辑设备名映射、权限检查、缓冲、错误报告、分配回收。
**驱动程序**：==计算柱面、磁头、扇区==，启动设备。每种设备一个，对上提供**统一接口**。
**中断处理**：保存状态，处理完唤醒进程。键盘敲一下，最先响应的就是它。
:::

:::recall 四层从上到下是什么？算柱面在哪层？
用户层、设备独立性、驱动、中断处理。驱动程序。
:::

== I/O 接口（API） {api}
:::shu 应用程序接口
**字符设备接口**：`get/put`，字节流，不可寻址。
**块设备接口**：`read/write/seek`，块，可寻址。
**网络设备接口**：**套接字** `socket`。
**控制**：特殊操作用 `ioctl`。
**阻塞 I/O**：调用后进程等，直到完成。**非阻塞 I/O**：立即返回，没数据就返回错误，要自己再问。
:::

== 缓冲 {buf}
为什么要缓冲：匹配 CPU 和设备的速度差、减少中断次数、提高并行性。

**单缓冲**：系统一个缓冲区。设备往里读（T），满了之后把数据搬到用户区（M），用户处理（C）。设备读下一块时要等缓冲区空出来，也就是 M 结束。
**双缓冲**：两个缓冲区。设备读第二个时，第一个可以同时搬。

:::ana 流程图
**T**：设备→缓冲区的时间。**M**：缓冲区→用户区的时间。**C**：用户处理时间。
:::

:::shu 块设备的时间
**单缓冲，稳态每块**：`max(T, C) + M`。
**单缓冲，n 块总时间**：`n(T+M) + C`。
**双缓冲，稳态每块**：`max(T, C+M)`。
**双缓冲，n 块总时间**：`nT + M + C`。
:::

:::trap n 块总时间不等于稳态 × n
问 n 块就用下面两行的公式。第一块的启动情况和后面不同。
:::

走一遍：T=80，M=10，C=40，读 5 块。

- 单缓冲：T 和 C 可以并行，每块节拍 `max(80,40)+10 = 90`。5 块总时间 = 5×(80+10) + 40 = 490。
- 双缓冲：每块节拍 `max(80,50) = 80`。5 块总时间 = 5×80 + 10 + 40 = 450。

:::recall 单、双缓冲的稳态公式和 n 块公式？
单：max(T,C)+M；n(T+M)+C。双：max(T,C+M)；nT+M+C。
:::

**循环缓冲**：多个缓冲区连成一圈，生产者消费者（[[28]]）的翻版。**缓冲池**：统一管理的公共缓冲区，分空、输入、输出三个队列，谁要谁取。

**缓冲和高速缓存**：缓冲放的可能是唯一副本（要写的数据），高速缓存放的是副本，目的是加速。

== 设备分配 {alloc}
:::shu 分配用到的数据结构
**SDT**（系统设备表）→ **DCT**（设备控制表）→ **COCT**（控制器）→ **CHCT**（通道）。分配时依次查：设备、控制器、通道都空闲才算成功。
**逻辑设备表 LUT**：逻辑名 → 物理设备。这就是**设备独立性**：程序用逻辑名，换设备不用改程序。
**方式**：独占、分时共享、虚拟（SPOOLing）。**安全分配**：发一个请求就阻塞；**不安全分配**：可继续请求，并发高但可能死锁。
:::

== SPOOLing {spool}
:::ana 打印机
打印机是独占设备。用一块磁盘做输出井，把所有人的打印任务先放在磁盘，再由守护进程一件件打印。每个人都感觉自己独占了打印机。比方的局限：任务其实还在排队，只是不用占着打印机等。
:::

:::shu SPOOLing 的结论
**把独占设备改造成共享设备**：虚拟设备。
**组成**：输入井、输出井（磁盘）；输入缓冲、输出缓冲（内存）；输入进程、输出进程（守护进程）。
**由系统完成，不需要用户控制**。它破坏死锁的「互斥」条件。
:::

:::domain
**层次：**用户 → 设备独立 → 驱动 → 中断。算柱面在驱动。
**缓冲：**单 n(T+M)+C；双 nT+M+C。
**SPOOLing：**独占变共享，输入输出井。
:::
