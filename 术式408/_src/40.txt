== 四层软件 {layer}
@ pyramid([('用户层 I/O 软件（printf、SPOOLing）','bx'),('设备独立性软件（命名、保护、缓冲、分配）','gd'),('设备驱动程序（把抽象命令翻译成设备操作）','bk'),('中断处理程序','rd'),('硬件','tn')],cap='I/O 请求自上而下，响应（中断）自下而上')

:::shu 每层干什么
**用户层**：库函数、假脱机。
**设备独立性**：逻辑设备名映射、权限检查、缓冲、错误报告、分配回收。
**驱动程序**：==计算柱面、磁头、扇区==，启动设备。每种设备一个。
**中断处理**：保存状态，处理完唤醒进程。
:::

== I/O 接口（API） {api}
:::shu 应用程序接口
**字符设备接口**：`get/put`，字节流。
**块设备接口**：`read/write/seek`，块，可寻址。
**网络设备接口**：`socket`。
**阻塞 I/O**：调用后进程等，直到完成。**非阻塞 I/O**：立即返回，轮询询问状态。
:::

== 缓冲 {buf}
为什么要缓冲：匹配速度差、减少中断次数、提高并行性。

:::ana 流程图
**T**：设备→缓冲区的时间。**M**：缓冲区→用户区的时间。**C**：用户处理时间。
:::

:::shu 块设备的时间
**单缓冲，稳态每块**：`max(T, C) + M`。
**单缓冲，n 块总时间**：`n(T+M) + C`。
**双缓冲，稳态每块**：`max(T, C+M)`。
**双缓冲，n 块总时间**：`nT + M + C`。
:::

:::trap n 块总时间不等于稳态 × n
2011 真题的干扰项 1000 和 1500 就是照稳态乘出来的。问 n 块就用下面两行的公式，把第一块的启动代价算对。
:::

@q os:5.2-38 | 单 10×150+50 = 1550；双 1000+50+50 = 1100。
@q os:5.2-39 | 2 块：2×105 + 90 = 300。
@q os:5.2-41

**循环缓冲**：多个缓冲区连成一圈，生产者消费者（[[28]]）的翻版。**缓冲池**：统一管理的公共缓冲区。

== 设备分配 {alloc}
:::shu 分配用到的数据结构
**SDT**（系统设备表）→ **DCT**（设备控制表）→ **COCT**（控制器）→ **CHCT**（通道）。
**逻辑设备表 LUT**：逻辑名 → 物理设备。
**方式**：独占、分时共享、虚拟（SPOOLing）。安全分配 vs 不安全分配。
:::

== SPOOLing {spool}
:::ana 打印机
打印机是独占设备。用一块磁盘做输出井，把所有人的打印任务先放在磁盘，再由守护进程一件件打印。每个人都感觉自己独占了打印机。
:::

:::shu SPOOLing 的结论
**把独占设备改造成共享设备**：虚拟设备。
**组成**：输入井、输出井（磁盘）；输入缓冲、输出缓冲（内存）；输入进程、输出进程（守护进程）。
**不需要用户作业控制**。它破坏死锁的「互斥」条件。
:::

@q os:5.2-42
@q os:5.2-36 | 单核下 CPU 只有一个，进程只能并发；CPU、设备、通道相互可并行。
@q os:4.2-54 | read 在用户进程请求之后，进程进入内核，数据未到就睡眠。

:::domain
**层次：**用户 → 设备独立 → 驱动 → 中断。算柱面在驱动。
**缓冲：**单 n(T+M)+C；双 nT+M+C。
**SPOOLing：**独占变共享，输入输出井。
:::
