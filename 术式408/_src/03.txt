== 单链表：用「改绳子」想问题 {single}
:::ana 把结点想成人手拉手
每个结点是一个人，`next` 是他的右手。手里抓不住的人就彻底找不回来了（内存泄漏）。所以改指针的铁律是：==先让新人抓住后面的人，再让前面的人抓住新人==。
:::

结点结构，以及为什么总要带一个**头结点**：有了它，第一个数据结点也有「前驱」，插入删除不用单独判断表头。空表判断：带头结点 `L->next==NULL`，不带头结点 `L==NULL`。

:::code c 单链表结点定义
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
:::

 (chain(['a','c'],head='p',bare=True,null=True),'要在 p（结点 a）后面插入 s。此时 p->next 指向 c。'),
 (chain(['a','s','c'],hl={1:'gd'},bare=True),'第一步 `s->next = p->next;`：s 先抓住 c。此时 a 还连着 c，什么都没丢。'),
 (chain(['a','s','c'],hl={1:'gd'},ptr={0:'p'},bare=True),'第二步 `p->next = s;`：a 再抓住 s。两句反过来，c 就丢了。')],'后插操作：两句不能颠倒')

:::shu 单链表四个基本动作
后插：`s->next = p->next; p->next = s;`
删除 p 的后继：`q = p->next; p->next = q->next; free(q);`
前插（不知道前驱）：先后插，再交换 p 和 s 的 data。
删除 p 本身（不知道前驱）：把后继的 data 拷过来，删掉后继。尾结点不能这样做。
:::

=== 建表与逆置
头插法建出来的链表是==逆序==的，尾插法是正序的。这两个动作是所有链表大题的积木。

:::code c 模板：头插法原地逆置（2019 真题要用）
void Reverse(LNode *L) {          // L 带头结点
    LNode *p = L->next, *r;
    L->next = NULL;               // 把头结点摘出来当新表
    while (p != NULL) {
        r = p->next;              // 先记住后继，否则断了
        p->next = L->next;        // 头插
        L->next = p;
        p = r;
    }
}
:::

== 双链表与循环链表 {double}
双链表多一个 `prior` 指针，能往回走。

:::shu 双链表的两个动作（在 p 后插入 s；删除 p 的后继 q）
插入改 ==4 个指针==：
`s->next = p->next;`
`if (p->next) p->next->prior = s;`
`s->prior = p;`
`p->next = s;`
删除只需要改 ==2 个指针==：
`p->next = q->next;`
`if (q->next) q->next->prior = p;`
:::

@ chain(['a','b','c'],double=True,cap='双链表：每个结点两根指针。循环双链表的头结点 prior 指向尾结点，尾结点 next 指向头结点')

@q ds:2.3-32 | 删 p 只需要让它的两个邻居互相抓手，改 2 个指针。循环双链表没有空指针，所以不需要判 NULL。

**循环单链表**尾结点的 next 指回头结点，判空条件是 `L->next==L`。如果只设**尾指针** r，那么头尾都能 O(1) 访问（`r->next` 就是头结点）：这是选择题的高频结论。

:::trap 「操作最快」类题目
问「哪种链表删除最后一个结点最快」：要找到尾结点的前驱，单链表无论设不设尾指针都要遍历，只有==双链表==（循环双链表）是 O(1)。别被「设了尾指针」骗了。
:::

**静态链表**：用数组下标当指针，`next` 存下标，结束标志一般是 −1。不能随机存取，但插入删除不用挪元素。

@q ds:2.3-33 | 静态链表思路。a 后面接 f，f 后面接 e，只改 a 和 f 的「链接地址」，e 不变。

== 顺序表 vs 链表 {cmp}
|维度|顺序表|链表|
|存取|随机存取，O(1)|顺序存取，O(n)|
|按序号查找|O(1)|O(n)|
|按值查找（无序）|O(n)|O(n)|
|按值查找（有序）|折半，O(log n)|只能 O(n)|
|插入删除|要挪元素，O(n)|改指针 O(1)，但找位置 O(n)|
|存储密度|=1|<1（有指针开销）|

== 四道真题，四个套路 {exam}
下面四题的解法都是可以直接默写的模板。先自己想，再翻答案。

=== 套路一：先后指针拉开距离（2009）
倒数第 k 个：让 q 先走 k 步，然后 p、q 一起走。q 到头时，p 正好在倒数第 k 个。一趟扫描，O(n)。

@q ds:2.3-综17 | 这就是全书最经典的「拉开距离」。一趟，时间 O(n)，空间 O(1)。

:::code c 模板：倒数第 k 个
int Search_k(LinkList list, int k) {
    LNode *p = list->next, *q = list->next;
    int count = 0;
    while (q != NULL) {
        if (count < k) count++;
        else p = p->next;
        q = q->next;
    }
    if (count < k) return 0;      // k 超过链表长度
    printf("%d", p->data);
    return 1;
}
:::

=== 套路三：绝对值当下标（2015）
题目给了 `|data|≤n`，这几乎是把「开一个大小 n+1 的标记数组」写在脸上了。这是 [[02|第 02 话]] 招式四在链表上的翻版。

@q ds:2.3-综19 | 删除要用前驱，所以指针 p 停在被检查结点的前面。时间 O(m)，空间 O(n)。
