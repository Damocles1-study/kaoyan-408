数据讲完了，现在看指令。这一话和下一话问的是同一个问题：==CPU 看到的程序长什么样==。指令集（ISA）是软件和硬件之间的约定，程序员和 CPU 设计者都看它。

== 指令格式 {fmt}
一条指令要说清两件事：干什么（**操作码 OP**），对谁干（**地址码**）。

@ bits([('操作码 OP',6,'bk'),('地址码 A1',6),('地址码 A2',6),('地址码 A3',6)],cap='一条三地址指令')

按地址字段的个数分：

|类型|形式|含义|
|零地址|`OP`|操作数隐含，如 `nop`、栈式指令|
|一地址|`OP A`|另一个操作数隐含在累加器 ACC 里|
|二地址|`OP A1,A2`|`(A1) OP (A2) → A1`|
|三地址|`OP A1,A2,A3`|`(A1) OP (A2) → A3`|

操作码位数决定能有多少条指令，地址字段位数决定能寻址多大。指令长度有限，地址越多，每个地址的范围就越小。

**定长 vs 变长**：定长指令取指和译码简单，适合流水线（RISC）；变长节省空间（CISC）。

**扩展操作码**：指令字长固定，让地址少的指令用更长的操作码。规则只有一条：**短码不能是长码的前缀**，否则译码时分不清。

走一遍：16 位指令，每个地址 4 位。

|指令类型|编码|条数|
|三地址（OP 4 位）|`0000` ~ `1110`|15|
|二地址（OP 8 位）|`1111 0000` ~ `1111 1110`|15|
|一地址（OP 12 位）|`1111 1111 0000` ~ `1111 1111 1110`|15|
|零地址（OP 16 位）|`1111 1111 1111 0000` ~ `…1111`|16|

每层留一个前缀 `1111` 给下一层。

:::shu 扩展操作码算术
从地址最多的开始。k 位操作码有 2ᵏ 种，分给高层 a 条，剩 `2ᵏ−a` 个前缀。每个前缀再扩展 m 位，得到 `(2ᵏ−a)×2ᵐ` 条下一层指令。
:::

== 寻址方式 {addr}
指令字段里写的数，不一定就是要操作的地址。它有可能要先做一些计算。为什么要这么麻烦？因为指令短，地址字段装不下完整地址；而且程序要处理数组、指针、函数调用这些情况。

~~形式地址 A~~ 是指令里写的那个数。~~有效地址 EA~~ 是真正去访问的地址。

@ table([['方式','有效地址','取操作数访存','用途'],['立即','操作数就是 A','0','给常数'],['直接','EA = A','1','简单，范围小'],['间接','EA = (A)','2','扩大范围、指针'],['寄存器','操作数在 R','0','快，地址短'],['寄存器间接','EA = (R)','1','指针'],['相对','EA = (PC) + A','1','转移，位置无关'],['基址','EA = (BR) + A','1','多道程序重定位'],['变址','EA = (IX) + A','1','<b class="r">数组下标、循环</b>'],['堆栈','EA = SP','1（硬件栈 0）','函数调用']])

用一组数字走一遍。设 A = 2000H，寄存器 R = 1000H（也作变址寄存器），内存 M[1000H] = 5000H，M[2000H] = 3000H，M[3000H] = 4000H。

|方式|EA|操作数|
|立即寻址|无|2000H|
|直接寻址|2000H|3000H|
|间接寻址|M[2000H] = 3000H|4000H|
|寄存器寻址|无|1000H|
|寄存器间接|1000H|5000H|
|变址寻址|1000H + 2000H = 3000H|4000H|

**直接寻址**范围由 A 的位数决定，太小。**间接寻址**用一次访存换来更大的范围，但多访存一次。

后三种（相对、基址、变址）都是「寄存器 + 形式地址」，统称**偏移寻址**，区别在于谁变：

:::ana 基址和变址只差一个思路
**基址**：基址寄存器 BR 固定（由 OS 设定），A 变化。程序整体搬家时只改 BR。
**变址**：A 固定（比如数组首地址），IX 每次循环加一个元素大小。程序员可以改 IX。
所以按下标访问数组是==变址==，程序重定位是==基址==。
:::

举数组的例子：`double a[]` 首地址 2000H，用变址寄存器 IX 存偏移。访问 a[i] 时 IX = 8i，EA = 2000H + IX。如果 IX 现在是 40H（64），下标就是 8。

**相对寻址**：EA = (PC) + A，A 是补码。目标和当前指令的相对距离固定，所以程序搬到哪都不用改，这叫位置无关代码。

:::trap 相对寻址的 PC
取指时 PC 已经自增了，所以 `EA = 当前指令地址 + 指令长度 + 位移量`。指令在 3000H，长 4 字节，位移 −8：EA = 3000H + 4 − 8 = 2FFCH。
:::

:::shu 位数与范围
形式地址 A 有 n 位：**直接**范围 2ⁿ；**相对**位移（补码）`−2^(n−1) ~ 2^(n−1)−1`。
按字节编址、字长 w 字节：地址要 ÷w 才是字号。按字编址时寻址范围单位是字。
:::

**堆栈寻址**：操作数在栈顶，指令里不用写地址。硬件栈（寄存器做的）不访存，软件栈（内存里）要访存一次。

:::recall 不看表，九种寻址方式的 EA 分别怎么算？基址和变址差在哪？
立即无 EA；直接 A；间接 (A)；寄存器无 EA；寄存器间接 (R)；相对 (PC)+A；基址 (BR)+A；变址 (IX)+A；堆栈 SP。基址 BR 固定由 OS 管；变址 IX 由程序改，用于数组。
:::

:::domain
**寻址：**数组 → 变址；重定位 → 基址；转移 → 相对。
**相对：**PC 已经加过这条指令的长度。
**扩展操作码：**从地址多的开始，算剩余前缀 × 2ᵐ；短码不是长码的前缀。
:::
