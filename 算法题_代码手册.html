算法题训练场（42 个模板）

408 算法设计题（通常为第 41 题）的 C 语言弹药库 · 以王道教材与统考真题为准逐章校订 · 基石层与套路层都在里面：每章教材的基本操作（顺序表/链表/栈队列/线索树/并查集/查找四件套/五大基础排序/BF 与 KMP/Prim·Kruskal·Dijkstra·Floyd）＋ 历年真题的解题套路 · 每张卡都标了三维掌握度：🔴🟡🔵 等级 + 📌该背什么 + 🧠该懂什么 + ✍️怎么算过关 · 可开「默写模式」逐行自测，并给每张卡打默写卡记录遗忘曲线

先读：408 算法题得分学

  • 三段式作答，三段都给分：① 算法思想（文字说清套路）② 代码（C / C++，规范伪代码通常也可）③ 时空复杂度。复杂度是白给的分，永远别忘写。
  • 暴力保底：想不出最优解就写 O(n²) 暴力——408 评分通常仍给大部分分数；空着才是 0 分。先写个暴力占住分，有时间再优化。
  • 先声明再动手：结点/结构体定义、变量含义、边界假设先写清，阅卷人看得懂才有分。凡涉及下标的题，第一行先声明「下标从 0 起 / 从 1 起」。
  • 先地基后套路：标着【基石】的 6 张是王道每章正文的基本操作（顺序表与链表增删查、栈与循环队列、线索二叉树与并查集、查找四件套、基数排序、最小生成树与最短路径）——这些不熟，后面的套路都是空中楼阁；其余 36 张是真题与综合题的套路层。
  • 套路优先：408 算法题 80% 落在下面 42 个模板的变形上——反转、双指针（含间隔 k / 尾对齐）、归并、划分、树递归、层次队列、非递归栈（祖先类）、顺序存储下标法、建树与森林转换、哈夫曼、标记数组空间换时间、图的遍历 / 回溯 / 拓扑排序 / 邻接矩阵扫行列、五大基础排序、快速选择与三向划分。先认出套路，再改模板。
  • 默写训练法：点开模板 → 读懂思路 → 看 📌背 / 🧠懂 两栏 → 开「默写模式」→ 在纸上写 → 逐行点击核对 → 对照 ✍️检查点逐条打勾 → 点「✅ 记一次默写」。🔴 默级卡要在两个不同日期各过一次才算真过。

怎么用这份手册：三个掌握等级 × 卡内三分区

等级含义达标标准（硬判据，不含糊）张数
🔴 默 闭卷在白纸上写出可直接提交给阅卷人的完整 C 代码：含结构体假设、边界判断、返回值、末尾复杂度说明 限时内一次写对，与本卡代码逐行比对零差错；且在两个不同日期各过一次才算真过 —
🟡 改 骨架能背，细节允许现场推导；重点是认出变形、说出改哪几行 给一道变形题，3 分钟内口述改动点，再写出来比对：主干正确、细节最多 1 处小错 —
🔵 读 不要求默写。要求看懂给定代码、能填空、能指出 bug、能答复杂度 给一段挖 3 个空的代码：全填对 + 说出时空复杂度 + 指出一处边界隐患 —

卡内分区放什么达标标准
📌 背 不需要理解、必须条件反射的：边界写法、公式、常数、口诀、「哪个位置标记」这类硬规定 看到关键词 3 秒内说出，说不出即没背
🧠 懂 必须讲得出「为什么」的：为什么这样写才对、不这样写会错在哪 能对着白纸讲给别人听，或当场举出反例；只会背结论不算过
✍️ 写 落到笔尖的代码与步骤 见每张卡的 ✍️ 达标检查点：限时 + 逐条打勾，任一条错即未过
