408 知识串联 · 四科主线与跨科连接

408 的可怕不在单科,在于四科是同一台机器的四个剖面——串起来学,一份力气四科收钱;实线=科内依赖,虚线=跨科连接(综合题命题点)

总纲:每个结构只问三件事——怎么存(逻辑/物理)、怎么走(遍历)、多快(复杂度)。大题 41 题的本质是「在对的结构上套对的走法」,代码手册的 28 个模板就是「走法」的全集。
当前主战场 = 排序（第8章，148 题已整章完成，42 道统考真题是全书真题密度之最）:这一章与前七章的性格完全不同——前面考「这个结构长什么样」,本章考「这个过程走到第几步是什么样」,所以只有两根主线:① 动手模拟一趟的结果（靠手）② 表 8.1 的五列（靠背）。内部排序的分水岭是「每趟能不能定死一个元素的最终位置」——能的是选择/交换家族(冒泡、简单选择、堆形成全局有序;快排只定枢轴),不能的是插入、希尔、归并、基数(只造局部有序),这一问单独撑起 2009/2010/2012/2014/2019 五道真题。外部排序则只有一张地图:减 I/O ⟹ 减趟数 S = ⌈log_k r⌉ ⟹ 要么增大 k(用败者树抵消内部变慢)、要么减小 r(用置换-选择);段长不等时用最佳归并树。148 道课后题、14 张第8章套路卡、排序九合一 + 外排三件套模拟器、精读版第8章 均已上线(第8章整章完工,数据结构第1–8章全书就绪);前一战场 查找(第7章):查找四合一模拟器 + 精读版第7章 + 136 道课后题——全章度量衡只有一个 ASL,三个分母见 套路卡 T7-1。

02组成原理:从一个比特到一条流水线

flowchart LR
  A["数据表示
补码·IEEE754·校验"] --> B["运算方法与ALU"]
  B --> C["存储层次
Cache·主存·虚存"]
  C --> D["指令系统
寻址方式·CISC/RISC"]
  D --> E["CPU
数据通路·中断·流水线"]
  E --> F["总线与 I/O
中断·DMA"]
  A -.溢出判断是ALU考点.-> B
  C -.Cache缺失与缺页共用局部性.-> E
  E -.中断机制是IO的地基.-> F
总纲:组成就是「一条指令的一生」:取指(存储层次)→ 译码(指令系统)→ 执行(ALU/通路)→ 访存(Cache/虚存)→ 写回,流水线把一生切成五段重叠。做题时把自己当那条指令走一遍,比背结构图牢。

04计算机网络:自底向上五层楼

flowchart LR
  A["物理层
码元·带宽·奈奎斯特/香农"] --> B["链路层
成帧·CSMA/CD·交换机"]
  B --> C["网络层
IP·子网·路由"]
  C --> D["传输层
TCP/UDP·可靠传输·拥塞"]
  D --> E["应用层
DNS·HTTP·邮件"]
  B -.可靠传输GBN/SR在传输层重考一遍.-> D
  C -.IP分片受链路层MTU牵制.-> B
  E -.DNS先行是一切应用的第0步.-> C
总纲:网络只有一道大题:「一个数据包的旅行」——应用层出发,层层封装下楼,过交换机(看 MAC)、过路由器(看 IP、换 MAC),到对面层层解封上楼。任何协议题先问:它在哪层?看什么地址?

05跨科枢纽:一份力气四科收钱

枢纽思想它在四科的分身(全是考点)
局部性原理组成:Cache 命中的全部理由;OS:页面置换(LRU 赌的就是它)、TLB、预调页与工作集、磁盘预读;数构:顺序表缓存友好;网络:Web 缓存/CDN。一条原理吃四科的题。
滑动窗口链路层 GBN/SR 与 TCP 流量控制是同一个协议的两次出场——发送窗口/接收窗口/累计确认一套话术,学一次考两层。
中断组成:中断的硬件流程(关中断→保存断点→找入口);OS:系统调用、进程切换、时钟中断全骑在它上面;I/O:程序查询→中断→DMA 的演进主线。
分块 + 映射Cache 行 / 内存页 / 磁盘块 / 文件簇 / 网络分组(MTU)——全是「定长切块 + 地址映射」同一个动作。地址结构题(标记|组号|块内)与(页号|页内)与(网络号|主机号)是三胞胎。
队列与缓冲数构:队列本体;OS:就绪队列、缓冲池、SPOOLing;组成:指令预取队列;网络:路由器排队与丢包(拥塞的物理根源)。
树数构:二叉树/哈夫曼/B+树;OS:多级页表是树、目录树;文件系统与数据库索引=B+树;网络:交换机生成树协议(STP)。
栈数构:栈本体、表达式求值、递归;组成/OS:函数调用栈、中断现场保存;编译递归下降。「递归改非递归」大题=手工模拟调用栈。
流水/并行组成:五段流水线与冒险;网络:连续 ARQ 本质是「发送流水线」;OS:多道程序=宏观并行。信道利用率公式和流水线吞吐率公式长得像不是巧合。
