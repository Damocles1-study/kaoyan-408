⭐ 两个重心要分开说：按失分密度是 6.4 电子邮件（0.71 道真题/页，全章第一）——5 道真题散落在 2012、2013、2015、2018、2025 五个年份，十三年间反复考； 按分值则是 6.5 万维网（绝对第一）——2011 与 2021 两道综合真题 ≈ 30 分，且都是跨 ch3/ch4/ch5 的全栈串联题； 次之是 6.3 的 2023 综合真题（≈13 分）。6.1 只有 4 页 1 道真题，但全是可直接背下来的对照关系，投入 20 分钟稳拿 2 分。
⭐⭐ 3 道综合真题（≈43 分），性质完全不同，必须各练透一遍： 2011 = 抓包 + 全栈（以太网帧逐字节定位 → ARP 广播 → 持续非流水线 6RTT → NAT 改字段）· 2021 = 机制推演（一次 Web 访问要发两次 ARP：先问本地域名服务器、再问默认网关；交换机自学习只记源 MAC；H2 只收到 2 个广播帧）· 2023 = FTP + TCP 缝合（这道题就是 ch5 传输层「2023 年真题缺口」的真身：双连接持久性 + SYN/FIN 各消耗 1 个序号 + 拥塞窗口逐轮演化 + 吞吐率换算）。
📐 三条母公式/账本： ① DNS——一次完整迭代解析最多 8 个 UDP 报文（4 查 4 答）；本地服务器最多查 n 次（n = 域名标号数）；有缓存则 0 次；报文总数 2n+2。 ② HTTP RTT 账本（n 个引用对象，从「建 TCP 连接」起算）—— 非持续串行 2(n+1)（2024 真题 = 16）· 非持续无限并行 4（习题 = 4）· 非持续 m 条并行 2+2⌈n/m⌉（上取整不能省）· 持续非流水线 n+2 · 持续流水线 3（与 n 无关）。 ③ 端口表——20 21 23 25 53 69 80 110 161 严格递增，只有 DNS(53)、TFTP(69)、SNMP(161) 用 UDP，其余全 TCP；补记 HTTPS 443、DHCP 67/68。
⚠️⚠️ 本章最贵的三条分界线： ① 起点在哪，RTT 就差 1——「从建立 TCP 连接开始」比「从发出 HTTP 请求开始」多 1RTT； 2020 真题问「到浏览器收到页面」记 2RTT（1.5 握手 + 0.5 取页），2023 真题问「到确认全部收到」记 6RTT（1 建连 + 5 数据），两题记法不同，必须逐题读题干。 ② 一旦题目给出 MSS 与文件大小，所有 RTT 公式立即作废，改逐轮画拥塞窗口——TCP 初始 cwnd 仅 1MSS，持续连接省得掉握手、省不掉爬升（2022 真题 = 4RTT，6.6 疑难点 3 用整段讲它）。 ③ 对象数 = 引用对象数 + 1（那个 HTML 主文档）——习题「100 张图要开关 101 次连接」、2024 真题「7 张图算 8 个对象」全靠它。
⚠️ 四条最容易记反的方向： Set-cookie 在响应报文、Cookie 在请求报文 · SMTP 管前两段推、POP3 只管最后一段拉（2013 与 2025 是一对镜像真题）· 递归发 1 条、迭代发多条（习题 10 与 2010 真题是同题干镜像）· 熟知端口一律属于服务器端，客户端永远是系统自动分配的短暂端口（这把刀在 6.3 一节就砍了三次）。
