⭐⭐ 本章第一条分界线：响应优先级 vs 处理优先级。 响应优先级由硬件排队器固定决定、不可动态更改，决定「谁先开始执行服务程序」； 处理优先级由中断屏蔽字动态调整，决定「谁能打断谁」＝「谁先执行完」。 屏蔽字是「门票」（决定能否进判优电路），判优电路是「排队规则」（进去之后按硬件顺序排）。 ⚠️ 这条在 7.3-04(Ⅴ)、7.3-17、7.3-46(D)、7.3-52(A，2024 真题) 四处反复考， 2024 真题就死在「中断屏蔽字用于确定中断响应的优先级」这一字之差上。 例 7.3 与 7-综04 是最好的注脚：A、C、D 同时请求先响应 A（响应优先级），而 C 一进去加载屏蔽字 0110 就被 D 打断（处理优先级）。
⭐⭐ 第二条分界线：断点＝硬件存，现场＝软件存。 断点（PC + PSW）由中断隐指令（硬件）在中断响应阶段自动保存； 现场（通用寄存器 + 中断屏蔽字）由中断服务程序（软件）进入后显式保存。 原因见 7.3-13 的「逻辑死结」：执行任何指令都会改变 PC，软件根本来不及存自己的断点。 中断隐指令只做三件事——「关、存、寻」：① 关中断 ② 保存断点 ③ 中断服务程序寻址（2012 真题 7.3-37）。
⭐⭐ 第三条分界线：中断查「指令末尾」，DMA 查「总线周期末尾」。 中断请求的是 CPU 处理时间 ⟹ 必须等当前指令执行完；DMA 请求的是总线使用权 ⟹ 一个存储周期结束就能插进来。 一条指令含多个总线周期 ⟹ DMA 的响应机会远多于中断 ⟹ 响应更快，且访存优先级 DMA > CPU。 ⚠️ 7.3-04(Ⅱ/Ⅲ) 把两者的时机对调、7.3-22(D)、7.3-24、7.3-25(B) 全是同一族陷阱。 三个时机排成一排：DMA（总线周期末）＜ 中断（指令末）＜ 异常（指令执行中，随时）。
⭐ 三种 I/O 方式的并行度表（7.3-19a/b）： 查询 = CPU 与外设串行、传送与主程序串行； 中断 = CPU 与外设并行、传送与主程序串行（服务程序仍由 CPU 亲自跑）； DMA = 两者都并行。 ⟹ 中断与 DMA 的唯一区别就在「数据真正搬运的那一刻」。
⭐ DMA 三种共享主存方式：停止 CPU 访存（整块 / 最简单 / CPU 完全空闲）· 周期挪用（单字 / 最常用 / 每字都要申请释放总线）· 交替访存（CPU 周期分两个子周期固定分时 / 最复杂 / CPU 完全不停）。 ⚠️ 2020 真题（7.3-47）的经典张冠李戴：把「整块传送期间 CPU 不能访存」（停止 CPU 访存的特征）安在了「周期挪用」头上。 周期挪用是「挪一个存储周期传一个字后立即释放」，每个字传完 CPU 就能访存。
⚠️⚠️ 计算题的头号分水岭：「每秒次数」除的是什么。 中断方式 ÷ 数据缓冲寄存器字长（如 4B，因为缓冲满一次就中断一次）； DMA 方式 ÷ 数据块大小（如 1000B / 5000B，因为整块传完才中断一次）。 这一条差别造成的数量级差距就是 DMA 的全部意义。 ⚠️ 第二个坑：CPI 什么时候用。 题目给「N 条指令」⟹ 必须乘 CPI；给「N 个时钟周期」⟹ CPI 是幌子，别乘。 2009 真题（7-综07）与 2018 真题（7-综10）都是第 1 问要乘、后面的问不乘。
⭐ 中断可行性判据（例 7.2 / 2022 真题 7.3-49 / 7-综02 / 7-综10-2 共用）： T设备（外设填满缓冲区的时间） > T中断（响应 + 处理时间）⟹ 可行；反之数据被覆盖，必丢。 2022 真题的错项正是把不等号写反了：「外设准备数据的时间应小于中断处理时间」。
⭐ 四层链条（7.5 常见问题 2，全章最易混）： 中断类型号 —（×表项长度）→ 向量地址 —（取内容）→ 中断向量（＝服务程序入口地址）—（送 PC）→ 中断服务程序。 「中断向量地址」是「入口地址」的地址，比「中断向量」多一层间接（7.3-02 的 C、7.3-06 正反两问）。 ⚠️ 中断类型号走数据线，中断请求/响应信号走控制线（2012 真题 7.2-14：命令字、状态字、中断类型号全部走数据线）。
⭐ 外中断 vs 内中断（2009 / 2020 / 2025 三年反复考）： 属外中断——键盘输入（2009）· 定时器到时、网络数据包到达（2020）· DMA 传送结束（2025）； 不属外中断——访存缺页（2009、2020 两次充当干扰项，是内部异常）· 除数为 0 · 执行断点指令 · 浮点运算下溢（按机器零处理，根本不产生中断） · 总线事务结束（同步操作，不产生中断）。 判据一句话：这件事是不是「CPU 执行指令以外」发生的。
⚠️ 本章的「红旗词」：「只要…就…」「一定」「立即」「所有」在中断题里几乎必错—— 因为中断系统到处是「除非被屏蔽」「除非关中断」「异常不受此限」的例外（7.3-12 的 D、7.3-42 的 D、7.3-46 的 B）。 但反过来：「CPU 检测到中断请求就一定响应」是对的—— 「检测到」三个字已经蕴含「未被屏蔽且开中断」（7.5 问题 1 · 2021 真题 7.3-48 · 2023 真题 7.3-50）。一词之差，全章分水岭。

⚠️ 两处口径需知晓（已在对应题的解析中写明）：
① 7-综03 第 2 问：书答 105%，精确值是 104.86%（书把 52428800 记作 52.4×10⁶ 后再除）。 结论（>100%，即使 CPU 全部时间用于查询也喂不动磁盘）完全不受影响，但要求写计算过程时按精确值更稳。
② 7-综05 第 1 问：书答 15μs，未把周期窃取本身的 1200×0.2μs = 240μs 计入「占用处理器时间」。 王道口径 = 周期窃取占的是存储周期/总线，此时 CPU 若不访存仍可执行，不算占处理器。 考场按书答 15μs；但要知道那句「传输 1200 个字符共需 1200 个存储周期」不是废话。 本题真正的价值是比值：15μs（DMA）vs 6000μs（中断）＝ 1 : 400，恰好等于「每 400 个字符才中断一次」。
