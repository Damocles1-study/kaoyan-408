🔥 5.6 指令流水线是全章失分密度第一（20 页 18 真题 = 0.90 真题/页，且 2023/2024/2025 连考四道）—— 四大公式必须默写：Δt = max(各段延迟)（⚠️ 题干给了流水段寄存器延时就要加上，2018 真题； 写了「忽略缓存时间」就不加，2009 真题）· T = (k + n − 1)Δt · TP = n / T，n→∞ 时上限 = 1/Δt · 超标量（度 m）T = k + (n − m)/m。
⚠️⚠️ 首条指令的完成时刻 = 各段实际时间之和，不是 k×Δt（选 05：2+2+1 = 5ns 而非 6ns， 总时间 5 + 99×2 = 203ns）——题干写「各段时间不等长」并把每段都给全时，就是冲这个坑来的。
⭐ 三种冒险 × 四个阻塞拍数，是本节所有计算题的分水岭：
· 结构冒险（争同一硬件）⟹ ① 功能部件使用原则（每指令至多用一次、固定阶段用 ⟹ 插空段） ② 加硬件（读写口分离、指令 Cache 与数据 Cache 分离，2014 真题问「主要目的」答的正是减少流水线资源冲突）；
· 数据冒险（RAW）⟹ 延迟 / 转发（旁路） / 编译器调序。四个拍数：有转发普通 RAW = 0 拍 · 有转发 load-use = 1 拍 · 无转发但可前半拍写后半拍读 = 2 拍 · 无转发且读写不可同拍 = 3 拍 （2012、2014 两道综合真题都用最后这个 3）；
· 控制冒险（转移/中断/异常改 PC）⟹ 延迟分支（插 C 条 nop）/ 分支预测（静态恒定、动态按历史， 动态更准的依据是局部性原理）。beq 要到 MEM 段才把转移地址送 PC ⟹ C = 3 拍（2023、2014 真题）。
⚠️⚠️ 转发能提前「取」，不能提前「产生」——load-use 冒险即使有转发也必须阻塞 1 拍 （2024 真题 C 项「所有数据冒险都可通过转发解决」正是错在这里；2023 真题的 I3 就是 load-use）。
⭐ 「哪几对指令有数据冒险」的机械解法（2016/2019/2023 三年同一题型）： 先给每条指令标出「写谁 / 读谁」，再逐对查「后者读的是不是前者写的」。 ⚠️ 三个最易漏判的读写来源：store 要读寄存器（2019 真题 I3/I4）· beq 要读两个寄存器（2023 真题 I2/I3）· slt 这类比较指令要写寄存器（选 11 说法Ⅲ）。 同写一个寄存器（WAW）在「按序发射按序完成」下不出问题，是 2016 真题的干扰项。
⚠️ 「存在数据冒险」≠「会发生阻塞」：2016 真题问前者，2023 真题问后者—— 转发把普通 RAW 治好了，冒险仍在、阻塞没了。
⭐ 四类 CPU 的 CPI（2020 真题一网打尽）：单周期 = 1（但 Δt 极长）· 多周期 > 1 · 基本流水线 = 1 · 超标量 < 1 · 超流水线 = 1 但主频更高。 ⚠️ 那是「理想情况下」；2025 真题补刀：实际 CPI 与 Cache 缺失率密切相关（缺失要插等待周期）。
⚠️ 2025 真题两处反直觉：PC 是专用寄存器、不属于通用寄存器组； 单周期 CPU 的控制器比多周期更简单（无状态机）—— 与 5.3「单周期硬件成本更高」不矛盾：贵的是数据通路，简单的是控制器，两者分开记。
🔗 5.6 综 02 与综 03 是同一道 23 分大题（2014）的上下半，也是 408 里组原 × OS 交叉最深的一题： 转移目标 = (PC) + 4 + OFFSET×4（「+4」是相对寻址基准、「×4」靠地址差 ÷ OFFSET = 4 推出）· 6 条指令 24B < 32B 块且块首对齐 ⟹ 指令 Cache 命中率 (6000−1)/6000 = 99.98% · 访盘 1 次、查 TLB 1001 次——那个 「+1」来自缺页故障处理后重新执行当前指令，又查了一次 TLB， 正是 5.5 断点口诀的现金兑付。
📌 5.7 多处理器是全章最轻的一节（7 页仅 1 道真题，0.14/页），但考纲明列、2022 刚考过： Flynn 四分类（⚠️ 标量流水线处理机是 SISD——流水线不改变 Flynn 分类；向量处理器是 SIMD）· 硬件多线程三方式（细粒度每拍切换 / 粗粒度阻塞才切换 / 只有 SMT 才有指令级并行； ⚠️ 2022 真题错项正是「硬件多线程只可用于多核」——单核照样能用）· 双核 vs 超线程（超线程只复制线程状态部件、共享 Cache 与 ALU ⟹ 会争抢，实际只提升 10%～30%）· SMP 共享单一物理地址空间（两大一致性要求：互斥锁保原子性 + 硬件协议保 Cache 一致）。
⚠️ 本节判错第一信号是绝对化措辞：「仅仅是运算并行」（选 17）·「而无其他硬件要求」（选 18）· 「只可用于多核」（2022 真题）——三题同一个套路。

⭐ 5.3 必背三条铁律（10 道综合题全靠它们）： ① 任一时刻总线上只能有一个部件发送，接收方可以有多个（「一发多收」——写微操作序列时 同一拍里出现两个 Xout 一定错）； ② ALU 是组合逻辑、无存储能力 ⟹ 必须有输入暂存器 Y，否则两个输入端会同时拿到同一个数据； ③ ALU 输出不能直连总线 ⟹ 必须有输出暂存器 Z，否则输出经总线反馈回输入端干扰运算。 ②③ 就是 2022 真题第 2 问的原题，两句话必须能默写。
⭐ 取指阶段周期数公式：N + 2（送 MAR 1 拍 + 主存读 N 拍 + 送 IR 1 拍）—— 2022 真题给 N = 5，答案就是 7 个时钟周期。
⚠️ 单周期处理器不能采用单总线结构（2016 真题，书上单独框成【注意】）—— 单总线一拍只允许一次传输，而单周期要在一拍内做完取指、访存、运算。 由此还推出：单周期必须指令/数据存储器分离、部件不能复用要配多份实例、数据通路里没有 IR、PC 无须写使能。
⚠️ 「处理器总是每来一个时钟信号就开始执行一条新指令」永远是错的—— 自编题 07 与 2019 真题 16 一字不差地考了两遍：只有单周期成立， 多周期要好几拍一条，流水线也只在「理想情况下」才做得到。
🔥 本节两条必背主线：
① 「位数取决于谁」四连（12/13/23/24 题，2016 与 2020 两年真题都从这出）—— IR = 指令字长 · 通用寄存器 = ALU = 机器字长 · MDR = 存储字长 · MAR/PC = 地址总线宽度； ⚠️ 指令按字边界对齐且 PC 用字地址时，PC 位数 = ⌈log₂(主存容量 ÷ 指令字长)⌉，可比 MAR 短 （2016 真题的 30 位就是这么来的，取指时把 PC 左移 2 位补回去）。
② 「用户可见 / 不可见」三分（06/17/20/22 题，2010、2015、2021 三年考同一张名单）—— 可见 = 通用寄存器 + 专用地址寄存器（基址/变址/SP）+ PC；只读可见 = 标志寄存器 FR； 不可见 = IR、MAR、MDR、页表基址寄存器。 ⚠️ 「完全透明」只有 IR 这一类——状态寄存器能被条件转移指令读、只是不能写，属「半透明」， 这是 20 题说法 Ⅳ 判错的唯一依据，也是本节最细的一处失分点。
⚠️ 三处高频「因果倒置」陷阱，本节连考三题：取指的依据永远是 PC（07 题，转移指令只是改 PC 的人，不是取指的依据）· 条件转移的依据是标志寄存器（05 题，PC 是结果不是依据）· 区分指令与数据靠指令周期的阶段 （2009 真题，不可能靠译码结果——译码本身就以「已知是指令」为前提）。
⚠️ PC 自增量 = 当前指令长度 ÷ 编址单位，不是数字 1（11 题）—— 只有「按字编址 + 单字指令」时才真的加 1，而真题基本都是按字节编址。 这条直接撑起 ch4 相对寻址 EA = (PC) + A 里那个「(PC) 是自增后的值」的铁律。
⚠️ 空操作指令 nop 的指令周期里，PC 照样自增（2011 真题 C 项）—— 「空操作」空的是执行阶段，不是整个指令周期；正因为它真的消耗一个周期， 5.6 节才能用插入 nop 的办法给流水线插气泡。
🔥 5.4 控制器：五道综合题全是同一个模板 ——「微指令字长三段式」
微指令字长 = 操作控制字段 + 判别测试字段 + 后继地址字段，三段各有一条算法， 最容易糊涂的是「哪一段要 +1」：
· 操作控制字段 · 直接编码：位数 = 微命令数，不 +1（全 0 天然表示无操作）；
· 操作控制字段 · 字段直接编码：Σ⌈log₂(第 i 组微命令数 +1)⌉，每组都要留一个「本字段无操作」编码；
· 判别测试字段：⌈log₂(可判定外部条件数 +1)⌉，那个 +1 是「不转移」；
· 后继地址字段：⌈log₂(控存单元数)⌉，不 +1。它 = μPC 位数 = ⌈log₂(微指令总条数)⌉，三个数永远相等。
⚠️⚠️ 2012 真题（22 题）恰好「+1」加不加都是 15 位——因为 7、3、12、5、6 全不是 2 的整数幂， 那道题根本验不出你会不会这条规则；真正区分的是综 04：5、8、2、15、22 里 8 = 2³、2 = 2¹， 忘掉 +1 会算成 16 位而正确答案是 18 位。⟹ 判据：组内微命令数恰是 2 的整数幂时，「+1」才咬人。
⚠️⚠️ 本章最狠的审题分水岭：「平均 n 条微指令」里包不包含公共取指微指令。 包含 ⟹ 先减再补一份（综 02：(4−1)×80 + 1 = 241 ⟹ CM = 256×32b = 1KB）； 不包含 ⟹ 直接加（2014 真题：32×4 + 2 = 130 ⟹ 2⁷ = 128 不够，必须 8 位）。 两题加减方向相反，全看题干那个括号。
⭐ 综 03 自带检验点：28 + 3 + 9 = 40 位，恰好等于题给控存字长 40 位——考场上务必用它复核，这是本节唯一能当场验算的题。
🔥 5.5 异常和中断：只有 5 页却有 4 道真题（0.80/页，全章第二），且书标「2009、2016、2020、2025」四考，2025 刚考过。
⭐ 断点口诀：「故障退回重做，自陷与中断都往下走，终止直接不走了。」 故障（缺页/除零/非法操作码）断点 = 当前指令；自陷（系统调用/断点/单步）与外中断断点 = 下一条； 终止（校验错/总线错）回不去了。
⭐ 「是异常还是中断」唯一判据：把 CPU 停下来，这件事还会不会发生？ 会 ⟹ 外中断（缺纸、键盘、DMA 结束、定时器）；不会 ⟹ 内部异常（缺页、除零、无效操作码、存储保护错、系统调用）。
⚠️ 三个必栽的坑：「访存时缺页」是异常不是中断（2016 真题；OS 教材叫它「缺页中断」是旧口径，别串）· 「自陷」是内部异常不是外部中断（2020 真题）· Cache 缺失是纯硬件事件，无须异常处理程序（05 题，与缺页的分野）。
⚠️ 「响应」由硬件做、「处理」才是内核程序（08 题 D 项的陷阱）—— 关中断 + 保存断点/PSW + 查中断向量表这三步全程无软件介入，服务程序的第一条指令才是软件的起点。
⚠️ 检测时机一字不能改：异常在「执行每一条指令的过程中」检测，中断在「每条指令执行结束、取下条指令之前」检测。
