📐 七条母公式/母套路：发送窗口 = min[rwnd, cwnd]（5 道真题共用）· 拥塞窗口逐轮演化四步（定起点 → 慢开始 ×2 但封顶到 ssthresh → cwnd ≥ ssthresh 后 +1MSS → 出事件跳变）· 序号三条（seq = 本段首字节 / ack = 已收全末字节 +1 / SYN 与 FIN 各消耗 1 个序号、纯 ACK 不消耗）· 连接管理四个时间量（客户发数据 1RTT · 服务器发数据 1.5RTT · 客户释放 1RTT + 2MSL · 服务器释放 1.5RTT）· UDP 分片（先 +8 再除 1480，偏移按 185 递增）· 效率与利用率 · UDP 检验和「回卷 + 取反」缺一不可。
⚠️ 九条分界线：端到端（进程↔进程）vs 点到点 · 传输层校验整个报文 / IP 只校验首部 · 端口号只有本地意义 ⟹ TCP 与 UDP 可同号、FTP 控制 21 数据 20 · 伪首部不下传不上交、不计入 UDP 长度、UDP 长度含首部最小为 8、检验和不用填全 0 算出 0 填全 1 · UDP 面向报文保边界 / TCP 面向字节流不保边界 · 窗口单位是字节、数据偏移单位是 4B · 同一报文段里 seq 与 ack 毫无关系、第二次握手的 seq 可为任意值 · 超时后新门限 = 当前 cwnd 的一半（不是旧门限的一半）、2cwnd > ssthresh 时封顶到 ssthresh · 问「最短」全程指数、问「最长」全程线性。
