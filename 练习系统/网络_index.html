计算机网络和前三科有什么不一样

①「🤖 核对与延伸」这一栏在网络干两件事。数构是跑 C 程序对拍、组原是 Python 复算位模式与周期数、 OS 是排程与 PV 穷举，而网络的计算题全是「存储转发流水线」，所以核对栏一律 用 Python 逐分组逐链路做事件级模拟（不套公式），把每一跳的时刻列出来，再把每个错误选项「是怎么算出来的」还原。 本章 5 道计算真题里有 3 道的干扰项，正是「把流水线当串行」或「漏掉最后一跳」造出来的。
② 错因标签换成了网络一套。网络的失分源不是不会公式，是层次判错和单位换算，所以标签是 层次归属判错 / 单位·进制换算错 / 流水线当串行算 / 端到端与点到点混 / 概念边界混 / 协议特性记反 / 读图漏条件 / 公式套错。
③ 记录与前三科完全分家。四科的做题记录、错题本、统计各存各的（localStorage 键 net_* vs os_* vs co_* vs ds_*），互不覆盖。
④ 网络第 1 章的两个主战场泾渭分明。1.1 是计算（三种交换方式 + 性能指标，5 道计算真题全在这）， 1.2 是概念（分层、协议服务接口、OSI 与 TCP/IP，9 道概念真题全在这）。 刷题时错在 1.1 请勾「流水线当串行算 / 单位·进制换算错」，错在 1.2 请勾「层次归属判错 / 端到端与点到点混」。

📐 六条母公式 / 母套路
① 分片三步：每片最大 = ⌊(MTU−20)/8⌋×8 → 片数 = ⌈数据总量/该值⌉ → 片偏移 = 累计字节数÷8（MF 除末片外全为 1； 多级 MTU 要串行做两次）。
② 子网划分四步：由「需求 + 1（路由器接口）」定主机位 n → 前缀 = 32−n → 先大后小、边界对齐切块 → 写 CIDR + 掩码 + 范围。
③ 路由聚合三步：找完全相同的前几段 → 只展开有差异的那一段 → 数出从高位起连续相同的位数 k，前缀 = 相同段位数 + k。
④ 最长前缀匹配：逐条做「目的 & 掩码」，匹配项中取前缀最长者；特定主机路由 /32 最高、默认路由 /0 最低。
⑤ DV 算法三步：每条邻居向量整体加上「我到该邻居的链路代价」→ 逐目的取最小 → 自己那格填 0。
⑥ BGP 选路四级：LOCAL-PREF 最高 → AS-PATH 最短 → 热土豆 → BGP 标识符最小。

⚠️ 八条分界线（命题人反复设坑处）
1. MF=1 表示后面还有片 / DF=0 才允许分片——两个标志位极性方向相反。
2. 分片可在源主机或中间路由器；重组只在目的主机；IPv6 则只有源主机能分片。
3. IP 地址端到端不变、MAC 地址逐跳改变；唯一例外是 NAT 路由器（它还改端口号，因此涉及传输层）。
4. ARP 是网络层 · DHCP 是应用层（走 UDP）· ICMP 是网络层（封装在 IP 里但不是高层协议）· IGMP 是 IP 的组成部分。
5. RIP 应用层走 UDP 520 · OSPF 网络层直接封装进 IP（协议号 89）· BGP 应用层走 TCP 179。
6. 「同一网络」的判定用发送方自己的掩码；路由器不会从分组的入口再转发回去（教材 45 题与 2016 真题的胜负手）。
7. 末字节 255 ≠ 广播地址（要看掩码）；/30 的两个可用地址 = 网络地址+1 与 广播地址−1，已知一端立推另一端。
8. 转发 = 单路由器 + 数据平面；路由选择 = 多路由器协同 + 控制平面（与 4.1.4 SDN 首尾呼应）。

📐 全章母公式只有四条
① 信道利用率 U = min(1, N·TD / (TD + RTT + TA))　② 实际速率 = U × 带宽
③ 帧的发送时间 ≥ 争用期（端到端往返 2τ）　④ 最短帧长 = 数据传输速率 × 争用期
争用期恒 = 512bit 的发送时间：10Mb/s ⟹ 51.2μs · 100Mb/s ⟹ 5.12μs · 1Gb/s ⟹ 0.512μs（恒定的是比特数不是微秒数）。

⚠️ 八个必踩的坑（每个都有真题作证）
1. TA 有三种口径：说「忽略确认帧发送时延」⟹ 0（2018）；给了确认帧长度就必须算（2020，40% vs 66.7% 全在这）； 说「捎带确认」⟹ TA = TD（2017、2012）。
2. 帧长给的是范围时取最小值（2012：取 512B 会算出 3 位，正解 4 位）。
3. 门槛一律上取整（2015 的 7.2 帧 ⟹ 需 4 位，向下取 7 就掉进选项 A）。
4. SR 的最大信道利用率低于 GBN（2023，反直觉——SR 要把序号空间分一半给接收窗口）。
5. 距离题别忘 ÷2（争用期是往返：2009 减 80m 不是 160m；2019 单向 5.12μs 不是 10.24μs）。
6. 路上有中间设备要减掉它的转发时延（2016 的 Hub 1.535μs；且必须先折半再减，先减后折半会得 359m）。
7. 有效数据速率：分子用 1500B（净载荷），分母的发送时延用 1518B（整帧）（2010 综合题的采分点）。
8. 退避 k = min(冲突次数, 10)（2023 的 4 次未封顶 ⟹ 768μs；2025 的 11 次已封顶 ⟹ 1023×51.2μs = 52.3776ms）。

🔑 四张速查表
· 三协议窗口：停等 WT=WR=1 · GBN WT ≤ 2ⁿ−1 且 WR=1 · SR WT+WR ≤ 2ⁿ 且 WR ≤ WT（常取 2ⁿ⁻¹）。 确认语义是 2009 与 2011 两道真题的分水岭：GBN 累积确认（取最大确认号，重传其后全部）· SR 独立确认（只重传超时的那几个）。
· 会不会冲突：信道划分（静态）❌ · 随机访问（动态）✅ · 轮询访问（动态但）❌——「动态 ≠ 会冲突」是这张表唯一的坑。
· 802.11 地址 1/2/3：地址 1、2 永远是这一跳的直接接收方与直接发送方，地址 3 补上被 AP 顶掉的那一端（上行填目的、下行填源）。 IFS 长短：SIFS < PIFS < DIFS（新接入用 DIFS，同一对话用 SIFS）。 NAV 三段：收到 RTS 的站盖最长、CTS 次之、DATA 最短（2024 直接查 CTS 那一行 = SIFS+DATA+SIFS+ACK）。
· 冲突域与广播域：物理层 (1,1) · 数据链路层 (N,1) · 网络层 (N,N)；VLAN 是例外——交换机本身不隔离广播域，配了 VLAN 就可以。 交换机自学习六字口诀：「学源、查目的、找不到就泛洪」。

⭐⭐ 本章计算题的母公式（四道真题共用）：
T ＝ k·r + (m−1)·r，其中 k ＝ 链路段数（＝中间设备数 + 1）、m ＝ 分组数、r ＝ 每段发送时延。 含义是「首个分组灌满流水线花 k·r，此后每隔 r 出来一个」。带传播时延时再加 k·p。
四道真题的包装各不相同：
· 2010（80.16ms）——分组 1000B 含 20B 首部，分组数要用有效数据 980B 去除；三台交换机走最短路 ⟹ k=3。
· 2013（1600ms / 801ms）——同时问报文交换，报文交换两段完全串行，分组交换几乎全程并行，差距近一半。
· 2023（80.10ms）——不给传播时延，给时延带宽积 1000b，要先除以带宽换算出 0.01ms。
· 2025（TMS > TPS > TCS）——三段速率 10/100/1000Mb/s 各不相同， 稳态节拍由瓶颈段决定（320μs）；TPS 与 TCS 只差 3.2μs， 快解是比较「建链 32μs」与「首分组多走后两跳 35.2μs」。
· 2024 是唯一不用母公式的一道：问最大吞吐量，做两层 min-max（路径内取 min，路径间取 max），答 10Mb/s。

⭐⭐ 本章概念题的四条分界线（1.2 的 9 道真题全卡在这四条缝上）：
① 三种「通信范围」的定语——「两个相邻节点间／点到点」＝数据链路层（2022）； 「主机到主机／路由选择」＝网络层；「端到端／进程之间」＝传输层（2009）。 题干不加定语时，流量控制在第 2、3、4 层都有；加了定语才唯一。
② 「为 X 提供服务的是谁」永远是 X 的下一层——2014（会话层←传输层）、2013（应用层的相邻层＝表示层） 都是这一条，方向一上一下。
③ OSI 与 TCP/IP 在「哪层提供哪种服务」上正好对调—— OSI：网络层两种都有、传输层仅面向连接；TCP/IP：网际层仅无连接、传输层两种都有（2021）。 书上明写「两类协议栈的区别是联考的考点，而这个区别是常考点」。
④ 协议三要素看图判定——给首部格式图＝语法；给时序图＝时序（2020）； 给「收到 X 该做 Y」＝语义。三道题题干都在讲 TCP 握手，答案却各不相同。
