📐 六条母公式/母套路：分片三步（每片最大 = ⌊(MTU−20)/8⌋×8 · 片数 = ⌈数据/该值⌉ · 偏移 = 累计÷8）· 子网划分四步（需求+1 定主机位 → 前缀 → 先大后小边界对齐 → 写范围）· 路由聚合三步（找相同段 → 展开差异段 → 数连续相同位）· 最长前缀匹配 · DV 三步（整体加 → 逐列取最小 → 自己填 0）· BGP 选路四级（偏好 → AS 跳数 → 热土豆 → 标识符）。
⚠️ 八条分界线：MF=1 后面还有片 / DF=0 才允许分片 · 分片可在中途、重组只在目的主机 · IP 端到端不变、MAC 逐跳改变（NAT 是唯一例外） · ARP 网络层 / DHCP 应用层走 UDP / ICMP 网络层 / IGMP 是 IP 的组成部分 · RIP 走 UDP 520、OSPF 直接进 IP（89）、BGP 走 TCP 179 · 「同一网络」由发送方自己的掩码判定、 路由器不从入口转发回去 · 末字节 255 ≠ 广播地址 · 转发 = 数据平面 / 路由选择 = 控制平面。
